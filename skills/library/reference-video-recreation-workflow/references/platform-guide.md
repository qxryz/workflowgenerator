# MiniMax Design 平台适配依据

来源：MiniMax Design 使用指南。读取日期：2026-09-08；页面显示 8 月 28 日修改。通过浏览器读取了本任务相关章节及页面内 v3.0、v3.0.4 更新说明。本文为相关能力的归纳，不是完整指南副本、API 规范或实测记录。

## 文档能力与技能落点

| 来源章节 | 文档描述 | 技能中的应用 |
| --- | --- | --- |
| 4. Agent Conversation | 引用文件和画布资产；支持图片、视频和音频；自动选模型或 Ask 模式 | 优先读取用户引用；遵循当前选模模式 |

## 不能从指南推断的能力

本次读取的内容没有提供以下能力的具体接口或保证：

- 编辑器原生独立合成及主合成的结构与操作方法。
- 可编程文本/形状图层、关键帧、贝塞尔缓动、遮罩和表达式的完整支持范围。
- 平台保存或导出后文字、关键帧、特效、嵌套等属性的实际保留范围。
- 平台可移交项目文件的格式、打包和重新导入规则。
- 工具名称、参数 schema、鉴权、异步任务查询/取消接口、并发及重试限制。

这些是“未由所读文档确认”，不是“平台不支持”。执行时读取工具 schema 或实际界面并做小规模验证。独立时间线窗口不证明支持独立场景合成；画布文本节点不证明支持时间线文字图层；成功导出不证明完整可编辑。

## 平台内验收场景

下面是待执行用例，编写本文件时尚未在 MiniMax Design 内运行。

| 用例 | 输入/前提 | 合格表现 |
| --- | --- | --- |
| 不可读参考 | 视频链接打不开，只有封面 | 请求全片上传；不虚构逐镜内容 |
| 平台默认路由 | 用户给视频，没有指定模型服务 | 使用已启用的平台模型；不引入外部生成服务 |
| 精确动效硬要求 | 要求独立合成及可编辑文字和关键帧 | 先验证能力；不以分组或生成视频冒充完成 |
| Ask 模式 | 平台选模设置为 Ask | 按该设置交互，不自动改变设置 |
| 异步恢复 | 停止回复后原生成任务仍运行 | 复查原任务及结果，不重复提交 |
| 用户改画布 | 用户换掉选定素材或引用 | 读取新状态，保留用户选择 |
| 局部返工 | S02 排版不符 | 修改 S02，并复查相邻衔接，保留其他已验收场景 |
| 项目交付 | MiniMax Design 保存或导出操作完成 | 重新打开或核验项目资源与已支持编辑属性；失败即报告部分交付 |

结构校验只能证明 SKILL.md 格式正确。完成这些用例，特别是代表性场景的保存、渲染及工程重新打开，才构成平台运行验证。

## 本项目指定的视频模型

用户在平台指南之后补充指定 H3，并提供 H3 使用手册。因此本技能的视频生成默认使用 H3；用户明确指定其他模型时，先核验其能力再遵循选择。指定模型失败后按主运行文件的有界重试和切换规则处理。H3 具体规格及提示词规范见 [H3 操作参考](h3-model-guide.md)。默认选择不代表平台已连接或生成已实测。
