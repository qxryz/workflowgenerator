供 `blender-workflow` 在生成或修改形体时按需读取。先读第 1–2 节，再跳到相关操作和第 13 节验收。目标是把语言要求落实为可编辑、尺寸可核验的几何，而非仅让操作指令执行成功。

本文已将 13 份 Blender 官方分发工程中的对象、曲线、修改器参数、节点连接及内置说明提炼成操作知识，可离线直接使用。文中的【工程事实 Pxx】是实际读取结果；其余步骤是面向新任务的建模建议，不冒充原作者的完整制作历史。工程索引在第 14 节，无需下载示例或打开研究文件。

## 1. 方法选择：先判断形状与用途

先识别“路径、截面、表面、实体、独立零件”，再选工具。同一作品可混用方法，统一由尺寸和装配关系约束。

| 需求特征 | 优先方法 | 切换条件或注意事项 |
|---|---|---|
| 管道、扶手、线缆、装饰边框 | Bezier/NURBS + Curve Bevel | 分叉接头需另做连接拓扑；相交曲线不会自动焊成实体 |
| 方管、型材、连续线脚 | Curve + Bevel Object 或自定义 Profile | 任意闭合截面用 Bevel Object；Profile 编辑器适合自定义倒角轮廓 |
| 拱门、拱窗、字形面板 | 平面闭合轮廓挤出；洞口用闭合切割体 | 有洞的面不能直接用一个普通 n-gon 表示 |
| 弯曲墙、弧形柜台 | 路径扫掠；圆弧可直接生成内外弧网格 | 检查内弧半径与厚度、顶底面和端面 |
| 瓶、碗、旋钮、车轮 | 母线 + Screw/Spin | 非轴对称把手、嘴部单独构造 |
| 两端截面不同的外壳、风道 | 截面环桥接放样 + 必要的 Subdivision | 截面对应关系先于加密；没有通用原生 Loft 操作器可直接假定 |
| 箱体、机械壳、家具板件 | 网格编辑 + Boolean/Solidify/Bevel | 基础体可作起点，关键是最终轮廓和连接 |
| 左右对称的车身、角色、外壳 | 半模 + Mirror | 精确中央接缝；最后再做有意的不对称 |
| 重复螺栓、栏杆、瓦片、叶片 | Linked Duplicate、Array 或 GN 实例 | 少量规则重复不必构建复杂节点网络 |
| 连续弯折、扭转、锥化 | Simple Deform、Curve Modifier、Lattice | 变形方向必须有足够分段 |
| 角色、软玩具、岩石 | 低模 + Subdivision，或 Sculpt/Remesh | 需要绑定时补适合变形的拓扑 |
| 浮雕、贴片、曲面文字、针脚 | Shrinkwrap 或 UV 表面采样 | 空间投射与 UV 映射解决不同问题 |
| 融合的有机体、柔和交汇 | Voxel Remesh 或支持版本中的 SDF | 薄壁和锐边会受采样分辨率影响 |
| 沟槽、砖缝、小划痕 | 影响轮廓则建几何，否则考虑法线/凹凸 | 凹凸贴图不会改变外轮廓或形成真实孔洞 |

连续曲线、弧形、拱形、圆角、弯曲墙体、流线型结构，不得默认用多个立方体拼接。连续曲面可以由共享顶点的分段网格近似，只要满足轮廓误差；禁止的是用重叠或相邻小方块充当连续成品。砖块、板材、螺栓本来就是独立零件，应保留合理边界。

## 2. 几何约束：尺寸、坐标与精度

### 建模前固定什么

用简短参数记录或对象自定义属性保存：总宽深高、单位、路径/轴线、截面、壁厚、圆角、孔位孔径、对称平面、重复间距、装配间隙、最终用途。只记录本任务需要的项；用户已给出的数值优先，缺失数值先作合理假设，影响验收的歧义才询问。

- 单张参考图提供投影轮廓，不提供真实背面和绝对尺度。先匹配相机的透视/正交关系；避免为了贴合一个错误相机而扭坏三维模型。
- UI 单位与数据坐标分开考虑。在采用物理长度的场景中，米数 = Blender 数据长度 × `scene.unit_settings.scale_length`；仅切换显示为毫米不会把已有顶点缩放。记录换算，例如 scale_length 为 1 时 2 mm 写为 0.002。
- UI 可显示角度，但 `rotation_euler` 及常见修改器角度属性通常以弧度存储；写入前做度/弧度换算。节点的普通数值输入是否代表角度，按其接口定义判断。
- 每个部件确定本地长轴、厚度方向和原点；镜像平面、旋转轴、Curve 变形轴及 GN 的对象空间均依赖它们。
- 对齐孔轴、接触面和底面时使用数值坐标、明确的吸附目标或自定义变换方向；先检查 Pivot 与 Transform Orientation。Align Rotation to Target 会改变朝向，比例编辑会影响邻近点，精确局部编辑前确认这些状态。
- 新建且未绑定的部件，尽早确定尺度；已有绑定、形态键、共享数据、链接资产或修改器栈不能机械地“Apply All Transforms”。先看依赖，在副本或适当局部空间中修改。
- 验收世界空间尺寸时读取评价后几何，并乘对象的 `matrix_world`。旋转物体的局部 `dimensions` 不等于世界轴对齐包围盒；GN 实例也需纳入测量。

### 怎样确定分段

先按轮廓误差与最终镜头决定分段，局部增加，不以“面数多”作为质量证明。

圆弧半径为 R，角跨度为 θ（弧度），均匀分 n 段，弦高误差为 `e = R × (1 − cos(θ / (2n)))`。当 `0 < e_max < R` 时，可取 `n ≥ θ / (2 × acos(1 − e_max/R))` 并向上取整。这适用于解析采样圆弧，也说明 Poly 不应被一概禁止。Bezier 近似圆弧还需检查曲线自身的近似误差，不能只看显示细分。

近景高光需要的曲面质量可能高于单纯轮廓要求。检查实际预览，不把示例工程的分辨率、倒角段数或细分级别当作默认值。

## 3. 网格基础：挤出、内插、桥接、镜像与连接

### 用少量正确的操作建立结构

- **Extrude Region（区域挤出）**：从面生成连贯的台阶、侧壁、肋或壳体；多个相邻面作为一区域一起挤出。Individual Faces 会分别挤出，适合独立凸起，不能替代连续壁面。取消位移后可能仍留下重叠的新顶点，需检查而非重复执行。
- **Inset Faces（内插面）**：先建立边框、凹槽或内缘，再挤出。Region 保持整体边框；Individual 用于每个面各自成框。窄角处检查重叠，内插一个实心凹陷不等于贯穿孔。
- **Loop Cut / Subdivide**：为变形和截面变化补边。Loop Cut 依赖可连续追踪的面流；遇到三角面、极点或 n-gon 中断时，按结构补边，不能反复加细分掩盖断流。
- **Bridge Edge Loops（桥接边循环）**：两圈边用于接管、接壳、放样。优先让点数、绕向和起点一致，先去掉挡住通道的端面，再桥接并检查扭转。
- **Grid Fill / Fill**：规则闭合边界需要四边面时考虑 Grid Fill；静态平面盖可用 n-gon。非共面、带孔或会明显变形的区域不能依赖一个大 n-gon。
- **Merge by Distance**：只合并预期重合点，阈值小于最小设计间隙。它不会自动求相交面的并集；大阈值会吞掉缝隙和薄壁。

### 对称结构

建半边 → 将接缝顶点精确放在镜像平面 → Mirror → 必要时开启 Merge 与 Clipping → 再细分。Merge 阈值只覆盖中央接缝，Clipping 防止编辑时穿过平面，不会修复离平面很远的错位点。检查负缩放、镜像对象和顶点法线。

【工程事实 P02】`GEO-scooter-body`、`GEO-seat` 的启用栈均为 Mirror → Subdivision，视口细分级别 1；随后还存在关闭的 Lattice。这支持“半模控制主体再平滑”，不支持把该 Lattice 宣称为当前生效的必需步骤。

### 什么才算连在一起

- **Join Objects / Join Geometry**：把数据或几何分量收进同一个容器，接触处仍可能有缝、重叠和内部面。
- **Bridge / Weld**：已对应的边界用共享顶点连接，适合管口、放样和接缝。
- **Boolean Union**：对相交实体求并集，适合需要真实融合的硬表面。
- **Voxel Remesh / SDF**：通过体积采样重建融合表面，适合有机过渡，代价是拓扑和细节变化。
- 独立零件正常装配无需强行并集。先确定“焊接一体、接触装配、可活动连接”是哪一种，再实现。

## 4. 曲线与截面：管道、边框、线缆

### 路径类型与手柄

Bezier 适合少量关键点控制方向和曲率；从端点、拐点和曲率变化处布点。AUTO 方便平滑，但可能在尺寸边界外过冲；ALIGNED 保持切线共线；VECTOR 制造明确硬角；FREE 可独立控制左右手柄。需要精确切线时手动设手柄，不把所有点统一改成 AUTO。

NURBS 适合平顺路径，由阶数、权重和控制点共同决定形状。阶数不能超过可用点数；开启端点约束可使非循环曲线通过首尾控制点，但不表示经过所有中间控制点。不要将控制多边形当作输出曲线。

精确圆或规则圆弧优先使用圆形构造/解析坐标。用三次 Bezier 近似半径 R、夹角 α 的圆弧时，每段不超过 90°，切向手柄长度可用 `4R/3 × tan(α/4)`；它是近似，严格尺寸仍需按误差核验。

### 把路径变成几何

1. 定义路径平面、方向和闭合状态；空间路径用 3D Curve。用 `use_cyclic_u` 表示循环，避免多放一个重合末点。
2. 圆管用 ROUND Bevel。单位缩放、点半径为 1、无额外变形时，`bevel_depth` 对应圆截面的基准半径；直径还受点 `radius`、对象变换及后续修改器影响。
3. 非圆截面用独立的闭合二维 Curve 作 Bevel Object，并明确设置 `bevel_mode='OBJECT'` 和 `bevel_object`；沿路径验证截面的朝向与原点。自定义倒角轮廓用 PROFILE 模式，不要混同 Bevel Object。
4. `resolution_u` 控制路径求值密度，`bevel_resolution` 控制相应倒角模式的截面采样；两者解决不同方向的折线。先辨认折线方向再加密。
5. 开放路径配闭合截面，需要实体端面时开启 Fill Caps，并核验端面。闭合路径没有两个“端部”；开放截面不能靠 Fill Caps 自动变成任意封闭实体。
6. 先统一点半径、tilt、截面轴向和曲线 `twist_mode`；空间路径陡转或回折时检查截面翻转和自交。提高分辨率不能修复错误朝向。
7. 保留路径与截面源，只有后续必须处理顶点、布尔或格式转换时再生成网格副本。截面辅助对象不得成为成品里意外可见的第二个零件。

【工程事实 P01】`inner frame` 是 4 点闭合 Bezier，使用 PROFILE 模式、13 个自定义轮廓点及 Mirror；路径 resolution 为 16、bevel resolution 为 9。装饰细节可放在截面中复用，不必沿框手摆几十个小块。

【工程事实 P02】`GEO-rack` 的三条 NURBS 分别有 7、2、2 个点，Round Bevel depth 为 0.007，场景米制 scale_length 为 1；路径 resolution 为 12、bevel resolution 为 4。它的 Fill Caps 为关闭状态，因此这个样例不能直接充当水密管道验收标准。

## 5. 拱门、弯曲墙与整体变形

### 拱门、拱窗和轮廓洞口

先确定拱脚高度、净宽、拱顶形状、构件宽度与前后深度。半圆拱的内半径由净宽的一半决定；椭圆、尖拱等按其真实类型建，不能全部套半圆。

- 独立拱形框：构造一致的内外轮廓，建立中间带状面，沿墙深挤出并连接端部；也可在同一 2D Curve 中组织外环/内环，但必须检查填充方向和洞口是否保留。
- 墙上的拱洞：用闭合拱形轮廓生成贯穿墙体的切割实体，再 Boolean Difference。切割体比墙深略长，避免端面共面；洞口附近检查薄壁和倒角。
- Curve 的 2D 填充发生在局部 XY 平面。挤出沿局部 Z 向两侧展开，`extrude` 不能不经测量就当作单侧总墙厚；无倒角、单位变换时总厚通常为 2 × extrude。严格墙深可用平面网格沿明确方向挤出，或用 Solidify 的厚度与 offset。
- 网格的单个面不能含内部洞环；用桥接/分片面保留洞，或使用布尔，不要让自动三角化把洞填满。

### 等厚圆弧墙

已知中心线半径 R、厚 t、高 h、角区间 θ₀…θ₁：要求内半径 `R−t/2 > 0`；在每个采样角构造内外半径、底顶高度共 4 个顶点。将相邻截面用四边面连接成内壁、外壁、顶和底，开放弧段补两端面；完整圆环闭合首尾而不生成重复接缝。

这样得到可测量的连续网格。采样密度按第 2 节误差计算；不用一排旋转立方体近似墙。弧面上的窗、扶手和柱子共享同一中心路径及弧长定位。

### 自由曲线墙与变形

- 平面自由曲线墙：沿中心路径扫掠矩形截面，使截面横向为厚度、竖向为高度；先用小段验证截面朝向。急弯内侧可能自交，即使“厚度数值正确”也要改曲率或局部结构。
- 已有直墙或连续条带：沿本地变形轴布置足够的截面环，用 Curve Modifier 的 Deform Axis 对齐路径；核对双方原点、相对位置和变换。只有两端顶点的长立方体无法平顺弯曲。
- Array → Curve 常用于先延长直模块再整体弯曲；若需要每根柱子保持笔直，只改变位置和朝向，应沿路径实例化，而非把柱子本身一起弯坏。
- Simple Deform 用于规则 Bend/Twist/Taper/Stretch：确认变形轴、Origin 和 Limits，再确定分段。Lattice 用少量笼格点控制大形，笼体应包住目标，检查绑定对象及修改器是否启用。
- 先弯中面再加厚，往往便于控制弯曲后的厚度；对已有实体弯曲则需重新量内外壁。没有一种变形顺序能对所有曲率自动保证等厚。

## 6. 放样、旋转体与流线型外壳

### 多截面放样

用于风道、船壳、鞋体、座椅、入口和出口不同的管壳。Blender 原生可用网格截面环 + Bridge Edge Loops，或按索引生成面；不能假定存在 `bpy.ops.loft`。Surface/NURBS 工具适用于合适的控制网，不能假定任意曲线自动放样。

1. 按形状变化布置入口、最大宽处、收缩处、出口等截面，而非等距堆大量环。
2. 统一环的点数、绕向、起始角及局部坐标架；非圆截面按语义对应尖角与平段。
3. 相邻环依次桥接。程序生成时连接 `ring[i][j]` 与下一环的对应 j/j+1，末边循环；若法线反了调整绕序，不能只靠双面材质掩盖。
4. 先低密度检查轮廓，再增加沿长度的控制环或 Subdivision。桥接本身不会自动得到所有期望的曲率。
5. 需要壳厚时从清楚的中面/外面加厚；开放风道连接内外口缘，实心壳体按用途封盖。
6. 发现螺旋扭曲时先查起点错位和截面朝向，发现收缩塌陷时查截面过疏、尖端拓扑和细分支撑。

### 旋转体

在包含旋转轴的平面上画母线 → 指定 Screw 的轴和原点 → 设角度与 steps/render_steps → 完整旋转时合并周期接缝 → 检查法线、轴上点和端口。

- 瓶/碗需要厚度：母线可同时描述外壁、口沿、内壁和底部；或先做单层面再 Solidify。底部和瓶口不是同一种封口。
- 轴上顶点合并到一条合理的极点结构，避免重复轴点、零面积面；细分模型的极点尽量避开主高光区域。
- 圆周段数按轮廓和近景需求增加；增加母线点控制纵向曲率，两种分段不能互相替代。
- 螺旋 Screw 需要非零 screw_offset，注意它会改变轴向结构，不是普通旋转体的默认设置。

【工程事实 P09】Pudding 节点将 Curve Line 重采样为 5 个点，在模拟后设置沿程半径，再用 Curve Circle 作 Profile 接入 Curve to Mesh 并开启 Fill Caps。可迁移的方法是“稀疏中心线控制 + 截面成形”；静态形体不需要复制模拟区域。

## 7. 厚度、开孔、倒角与修改器顺序

### Solidify

从法线一致的表面生成厚度。指定 thickness 和 offset：offset 0 以原面为中面，正负侧取决于法线；用边缘封口选项连接边界。Even Thickness 或 Complex 模式可改善部分拐角，但不保证急弯、重叠或非流形输入一定正确。

先决定保持外尺寸还是内净尺寸，再选择偏移方向。已有内外壁的实体不应再无目的地 Solidify；负缩放或翻转法线会改变厚度方向。评价后测最窄处、拐角和开口边缘。

### Boolean 开孔、切槽、并集

1. 主体与切割体先建立可判断内外的体积；通孔切割体完全穿过目标，盲孔按深度终止。
2. Difference 切除，Union 融合，Intersect 保留交集。静态复杂切割可先尝试 Exact 求解，仍需避免退化面、仅相切和共面边界。
3. 孔径、孔位、轴线分别参数化；重复孔可阵列切割体，检查切割体彼此是否重叠和最终孔间最薄壁。
4. 保留带名称的切割体和修改器，检查最终渲染可见性；显示为 wire 不能代替关闭其渲染可见性。
5. 后续要细分或大幅变形时，整理孔边环和附近面流。Boolean 留下的长瘦三角形/n-gon 在静态平面可接受，在曲面高光或关节处通常要重构。
6. 毛刺或无变化时先查作用对象、启用状态、接触关系、法线和零面积面，再换求解器；不要连续重复 Apply。

### Bevel：圆角是几何控制

先明确目标是圆形倒角、斜切面还是装饰轮廓。新建部件尽早处理非等比尺度，已有依赖按第 2 节处理。

- `offset_type` 决定 `width` 的含义，可有 OFFSET、WIDTH、DEPTH、PERCENT 或版本支持的其他模式；它既不是统一的半径，也不是直径。输入边角度、profile 与模式共同决定最终圆角。
- segments 1 是单斜面，多段才近似曲面。可从 2–4 段预览，近景再按高光增加；圆弧状倒角常以 profile 0.5 起步，仍需核验几何。
- 用 Angle、Weight 或 Vertex Group 限定真正要处理的边；精确选边时不要指望角度阈值永远得到正确范围。
- Clamp Overlap 可以避免部分自交，但会局部缩小倒角，造成“不等宽”。检查最短边、孔边、薄壁及交汇角；必要时调整拓扑或减小圆角。
- 对严格圆角半径要求，检查截面而非只读 width；在 90°、单位尺度、圆弧 profile 的特定配置中才可推导宽度和半径的对应关系。
- Smooth Shading、按角度平滑或 Weighted Normal 调整法线插值，不会增加轮廓分段、焊合缝隙或修复非流形。Weighted Normal 不是每个模型都必需。

### 修改器顺序按结果选择

| 目标 | 可考虑的顺序 | 为什么及核验点 |
|---|---|---|
| 左右连续的平滑壳体 | Mirror → Subdivision | 先合并中央边界再平滑，检查接缝 |
| 弯曲薄片的真实厚度 | 形体/变形 → Solidify → Bevel | 在最终表面上加厚，再圆化壳边 |
| 有贯穿孔的实体壳 | Solidify（若起点是单面）→ Boolean → Bevel | 孔贯穿实体，新增孔缘一起倒角 |
| 保持表面先平顺、口缘较硬 | Subdivision → Solidify → 小 Bevel | 避免先加厚后细分把口沿收成软边 |
| 刻意圆润的家具/道具 | Bevel → Subdivision | 倒角带参与控制后续细分，检查缩形 |
| 刚性零件沿曲线排列 | 原型 Bevel → 实例分布 | 原型保持刚性；整条实体弯曲则是另一条流程 |

【工程事实 P03】`Book` 使用 book.thickness 节点组 → Solidify（0.005）→ Bevel（OFFSET 0.002、2 段）；节点组通过输入 Thickness 控制 Z 缩放。`Dresser` 使用按 Weight 限定的 Bevel（OFFSET 0.01、3 段）→ Subdivision（视口 1、渲染 2）。参数是工程数据单位，不能照搬为任意任务的物理厚度或圆角半径。

## 8. 细分、有机形体与雕刻

### Subdivision 与拓扑用途

- Catmull-Clark 改变形状且常收缩；Simple 主要加密。细分不负责修复乱拓扑，先确认基形轮廓。
- 在需要保形的边附近加支撑环，环距控制过渡宽度；不是把支撑环一律放到低曲率区。过密支撑会夹高光，均匀加环也未必必要。
- Edge Crease 可减少支撑环，但需检查转角及导出是否保留；不要同时盲加高 crease、多级倒角和极近支撑。
- 四边面有利于规则细分和边流；平面静态盖、局部三角面并非天然错误。关节、嘴眼轮廓、主要弯折与高光区更需要有组织的边流，极点尽量移出这些区域。
- 绑定前检查关节处有足够环数，并用少量姿态检验塌陷/拉伸；最终要动画的网格不能只通过静态正面验收。
- 四边面细分每升一级面数约 ×4。分别选择视口和渲染级别，完成形体前不追求高等级。

### 雕刻阶段与局部控制

先以低密度网格、低级 Multires 或体积粗模确定比例和轮廓，再细化结构，最后做皱褶和纹理。多球/基础体可以用于有机粗模，但需要融合时应 Remesh 并整理过渡，不能停留在穿插状态。

- Grab/Elastic Deform 用于大形；Snake Hook 可拉出头发、角或肢体趋势，但长距离拉伸会改变局部密度，后续考虑重采样/重拓扑。
- 【工程事实 P07】内置说明中的 Topology Auto-Masking 约束连通区域；Face Sets 约束语义区域；Boundary 类保护边界；View/Area Normal 按朝向过滤；Cavity 可选凹处，反转后选凸处。手指、薄片、前后靠近的面应先隔离影响范围。
- 【工程事实 P04】内置说明指出 Grab Silhouette 可限制一侧轮廓的抓取对另一侧的影响，适合手指等靠近的薄结构；不是让整个网格一起拉动。
- 【工程事实 P05】说明将 Snake Hook 的 Elastic 与 Radius Falloff 区分：Elastic 的影响可传播到笔刷半径之外，适合具有弹性的大形变化；因此不能将笔刷圆圈当作严格修改边界。
- 【工程事实 P06】`cream.003` 基础网格 240 个四边面，Multires 总级数 4；说明中的 Displacement Smear 处理多分辨率位移细节，而不是简单拖动基础拓扑。该模式需相应 Multires 数据，不能只复制一个高密度终态网格就宣称保留工作流。

### Remesh 与 Multires 不能随意替换

Voxel Remesh 适合融合和重整密度，体素需明显小于要保留的最薄特征，先粗后细。体素边长减半时，同一体积的采样成本量级可增至约 8 倍；实际受稀疏体积等实现影响。检查孔洞、尖端和薄膜是否消失。

Remesh 会改变拓扑，可能丢失/改变 UV、形态键、权重及细节；对已有 Multires 雕刻不要直接破坏基网格顶点关系。需要重拓扑时保留高模，建立低模后再投射或烘焙细节。动画低模、雕刻高模和打印实体是不同交付，不强求一份拓扑包办。

## 9. Geometry Nodes：重复、程序化与性能

### 什么时候值得使用

数量、间距、尺度、路径或分布会反复调整时使用 GN；几块固定板件可直接编辑，少量相同部件可共享数据。先做一个合格原型，再复制，避免成百上千个实例放大原型错误。

- 直线重复：Array 的 Constant Offset 对应固定距离，Relative Offset 随原型包围盒变化；选择与设计约束一致的方式。
- 曲线重复：Curve → Resample/Curve to Points → Instance on Points；切线/Rotation 控制朝向，设置好原型长轴。长度模式控制间距，数量模式控制总数，闭合曲线检查接缝不重复放件。
- 面上分布：Distribute Points on Faces → Instance on Points；有最小间距需要时考虑 Poisson Disk。点间距不自动保证不同尺度零件完全不相交。
- 随机变化：固定 seed，限制转角和尺度的合理区间。需要动画稳定时使用稳定 ID，拓扑改变后的 Index 不应被假定保持同一对象身份。
- 属性控制：先指定字段在哪个几何和域上求值。Point、Face、Face Corner、Spline/Curve、Instance 不是可任意互换的索引空间。拓扑变化前需要保留的值用 Capture/Store，按后续采样关系读取。
- GN 中的 Field 是随上下文求值的表达式，不是独立几何组件。节点有连线不等于结果正确：检查输入域、类型、空间、Selection、活动输出及实例状态。

### 实例、实体化与循环

尽可能保留实例共享原型。需要逐顶点变形、跨实例合并或下游要求真实网格时再 Realize Instances；Realize 只展开实例，不会焊点或布尔融合。支持实例的导出器不一定需要实体化，按格式和实际输出核验。

Repeat Zone 用于结果依赖上一轮的累计生成，如花瓣分层、迭代生长；简单 N 个相同件用实例分布即可。循环里传递几何和层号，明确每轮是在替换还是累加，防止意外指数复制。Simulation Zone 处理跨时间状态，静态重复不能因此强加模拟依赖。

【工程事实 P08】`F-Rose01Anim` 通过 Repeat Zone 传递累积几何与递增 ID，每轮生成花瓣层并 Join；`GN_Flower.001` 使用 Mesh Circle → Instance on Points → Transform → 输出。可迁移为“单件形状、每层布局、层间变化分开控制”。

【工程事实 P02】`cobblestone` 中 Mesh to Points 接 Instance on Points，再对实例旋转/平移并合并。铺路石是独立重复件，适合实例；不能由此推导连续路面也应拆成小方块。

### SDF 与节点工具的适用边界

【工程事实 P12】工程说明要求 Blender 5.0 或更新，资产顺序为 SDF_M_Root（体素与带宽）→ SDF_M_Boolean → SDF_M_Mesher，可选在网格化后用 SDF_M_Smooth。实际 Mesher 读取命名网格并 Grid to Mesh。适合柔和融合，但精确薄壁、锐边和细孔需按采样误差检查；版本没有该能力时用原生 Boolean 或适合任务的 Remesh 重建，不能宣称同等精度。

【工程事实 P13】Impact Fracture Tool 读取 Mouse Position 与 Viewport Transform，经射线确定受影响网格岛，再执行破碎和 Randomize Islands；该工程已有 281 个 Bevel 修改器。它是依赖视口点击上下文的节点工具，不能当作一个普通 GN 修改器直接套上运行。自动化要么通过可用交互工具提供合法上下文，要么重建显式“作用几何、冲击位置/方向、种子、迭代数”的流程。

## 10. 表面贴合：标志、针脚与毛发

### Shrinkwrap 与 UV 采样的选择

空间上已有位置的贴片、铆接装饰或重拓扑网格：先给贴片足够面数 → 按需要 Subdivision/加密 → Shrinkwrap → 必要的 Solidify/小倒角。Nearest Surface Point 可能吸到附近错误侧面；Project 需设轴、方向和投射范围。Offset 防止共面闪烁，但仍须检查悬浮和穿透。

平面设计要沿服装等表面展开：使用 UV 对应更合适。先确保目标 UV 无不期望的重叠/退化，图案坐标与 UV 在同一参数空间；对象变换、接缝和 UV 拉伸都影响结果。UV 像素距离不等于世界空间距离。

### 针脚配方

1. 在平面/UV 空间绘制连续字形或缝线路径，以沿程距离重采样；固定针距参数，不手摆每根线。
2. 建一小段带弯起高度的针脚曲线作原型，设置半径，使用路径切线定向并实例化；随机变化保持小幅且固定种子。
3. 后续需要逐点表面映射时先展开这些曲线实例。用 Sample UV Surface 从目标 Mesh 采样位置与法线，按“采样位置 + 法线 × 高度”放置，并检查 Is Valid。
4. Invalid 点应修正到有效 UV 区域或按设计剔除；不可把采样失败返回的默认位置当作有效结果。
5. UV 拉伸会改变针距和线粗。严格物理间距可在映射后的路径再按弧长采样；局部面积比例只能近似补偿各向同性尺度，不能修复全部方向性拉伸。

【工程事实 P10】`embroidered_text` 的路径分支是按 Length 重采样 → Fillet → Delete Geometry → 实例点；针脚分支是 Curve Line → Transform → Set Curve Radius → 重采样 → Set Position。随后实例按切线定向、旋转并 Realize。`wrap_geometry_UV` 采样位置与法线，删除无效采样，并用“原面面积/UV 面面积”的平方根调节高度和曲线半径。可直接学习其分工，不需复制 29 个节点才算正确实现。

### 毛发与曲线细节

先做少量 guide curves，明确附着表面和 UV，控制根部到末端的长度、半径、梳理方向，再插值增密、成束、卷曲和添加噪声。根部需稳定绑定；更换目标拓扑或 UV 后重新检查附着。渲染可保留 Hair Curves，是否转网格取决于交付格式。

【工程事实 P11】四个 `Fur - …` 对象是 `CURVES` 类型，分别绑定表面对象及 `UVMap`，每个有 616 根输入曲线；这不是最终插值毛发数。`fur.sheep` 的连接包含 Noise → Shrinkwrap Hair Curves → Guide Map → Curl，之后继续成束和扰动。传统 Bezier/NURBS 的 `CURVE` 与毛发 `CURVES` 数据结构不同，Agent 必须先辨认类型再操作。

## 11. Agent 执行：数据、上下文与可恢复修改

此节用于未来被授权的建模任务；阅读本 Reference 本身不要求启动 Blender、打开官方文件或测试当前场景。

- 继承 SKILL.md 的作品身份和连接检查。任何修改限定到本次作品的对象/集合；不用清空整个场景作为通用初始化。
- 将用户参数集中管理，再派生坐标和修改器设置。名称按角色可用 `PATH_`、`PROFILE_`、`PART_`、`CUTTER_`，关键是能稳定找到对象，不依赖“当前选中的那个”。
- 通过 Blender 内的代码工具操作时，优先明确对象引用的 `bpy.data` API 或受控 BMesh；`bpy.ops` 依赖 mode、active object、selection 与 editor context，不能只设置 active 就假定作用域正确。
- Apply/Convert/Transform 等操作前明确目标选择集；必要时记录原状态、隔离选择、执行并恢复。多物体 Edit Mode、共享 mesh 数据、父子变换会扩大影响，应先检查；只修改一个副本时确认数据是否需要 single-user。
- 每个几何阶段是一次可核验批次：创建 → 更新依赖图 → 读取输出类型/尺寸/关键参数 → 少量预览。批量重复件可以一次生成，不必每个点单独调用工具。
- 创建节点时检查当前 Blender 版本的 node type、socket identifier 和输入类型；旧示例中的显示名/插槽序号不是稳定 API。不要猜测 `bpy.ops.loft`、旧自动平滑属性或新版节点一定存在。
- 用 `evaluated_get(depsgraph)` 读取修改器后的对象；临时 `to_mesh()` 用后 `to_mesh_clear()`。单对象网格快照不自动涵盖所有未展开实例，测量时遍历实例变换或在检查副本中实体化。
- 重试只补齐失败的目标阶段，先查是否已创建同名对象/修改器，避免超时后重复生成。不要用另起一套遮挡几何掩盖第一次错误。
- 保留可编辑源与交付副本；命名恢复来源或保存建模阶段即可，不要求每次都把一套不可见副本永久塞进文件。导出副本不能夹带切割体、截面和参考物。
- 验证文件保存到本次作品路径，按需处理字体、贴图、链接库和缓存依赖。单次命令无异常不是成功交付证据。

## 12. 完整任务配方

以下数值仅作示例；用户尺寸、镜头和用途优先。按配方生成后仍执行第 13 节检查。

### A. 带通孔的圆角设备外壳

要求：120 × 80 × 35 mm，壁厚 2 mm，侧面 Ø20 mm 通孔，盖与底壳可分离。

记录外尺寸与装配间隙 → 建底壳外表面并向内 Solidify 2 mm，保持外尺寸 → 用贯穿侧壁的圆柱切孔 → 对需要的边做小 Bevel → 盖板独立建模，按间隙定位。圆角选择按第 7 节处理，不把 bevel width 直接等同半径。核验外包络、孔内直径、孔位、最窄壁厚及盖缝；孔不能只有表面圆形凹痕，盖也不能被 Union 成不可拆的一体。

### B. 90° 弧形墙带扶手

要求：中心线半径 3 m，厚 0.2 m，高 2.8 m。

按第 5 节生成内半径 2.9 m、外半径 3.1 m 的连续封闭墙体，按轮廓误差确定分段 → 在同一中心路径派生扶手路径并加圆形截面 → 立柱按弧长采样、保持竖直 → 小倒角。分别核验墙厚、端面、接缝、扶手与柱的连接；白模也必须保留完整弧线。

### C. 瓶身与非对称把手

记录口径、最大直径、高度与壁厚 → 母线 + Screw 做瓶身，构造真实内壁和口沿 → Bezier + Bevel 做把手 → 按产品是否一体选择布尔融合并整理接头，或保持独立装配。核验瓶口开放、底部封闭、把手抓握空间和接头过渡；不对整个瓶子盲加 Subdivision 导致口径缩水。

### D. 可改宽度的流线型柜台

用入口/两端、最宽处及转折处截面环控制连续壳体 → 桥接放样 → 只在保形边加支撑 → 需要时细分 → 加厚并处理口缘。台面和柜门按真实零件另做，面板分缝从主表面派生；保持主轮廓和厚度由统一参数控制。改宽度后复查截面扭转、圆角和开门间隙，不能把各模块分别缩放后留下接缝。

### E. 毛绒动物或雕刻角色

低密度身体与头部先定轮廓 → Mirror 或局部遮罩控制对称/分区 → 需要融合处 Remesh → 修剪耳、口鼻与四肢过渡 → 若需绑定先重拓扑和试姿态，再做细节 → 毛发以 guide + 表面绑定增密。短毛和纹理不能掩盖头身比例错误；静态展示可采用与动画不同的拓扑预算。

### F. 曲面织物上的缝字

先建立衣片与有效 UV → 平面字形路径 → 针距采样与原型实例 → 按 UV 采样贴合 → 校正半径、离面高度和接缝 → 在最终镜头检查可读性。只改文字时更新路径，不逐根重排针脚；衣片变形后检查附着和间距。

## 13. 故障定位与交付验收

| 可见问题 | 先检查 | 有效修正 |
|---|---|---|
| 曲面仍像折线，即使已 Smooth | 轮廓方向的分段、控制点和求值几何 | 加该方向分段或重建曲线；法线平滑只影响着色 |
| 管道/墙体突然扭转 | tilt、twist mode、截面轴、环绕向与起点 | 修坐标架/对应关系，再调采样 |
| 圆角不等宽或挤成尖角 | 非等比缩放、Clamp、窄面、limit method | 局部修拓扑、尺度或半径，不能只加 segments |
| 镜像中线有缝/脊 | 原点、平面位置、Merge 阈值、重叠内部面 | 对齐并焊合正确接缝，检查细分后的高光 |
| Boolean 无洞或有毛刺 | 是否真贯穿、共面相切、求解器、法线 | 修切割体和退化面，再处理孔边 |
| 曲面贴片吸到背面 | 投射方向、附近表面、目标空间和 Offset | 改投射约束/位置，必要时用 UV 对应 |
| GN 无输出或复制爆量 | 输出连通、输入组件、Selection、实例/循环状态 | 检查最小分支，修类型/域与累计逻辑 |
| 雕刻拉动邻近手指/背面 | Topology/Face Sets/朝向遮罩和笔刷影响范围 | 隔离区域，使用适合的 Grab/遮罩方式 |
| 视口正常，最终不同 | 修改器 show_render、render_levels、依赖与帧状态 | 检查渲染求值和依赖，不把视口图等同最终结果 |

按交付目的选择验收项，不给所有任务强加同一套拓扑：

- **共同检查**：对照要求查看轮廓、比例、关键孔位/尺寸、曲率和装配关系；侧视/背视或关键截面补看主相机隐藏的问题。记录实际测量与容差，超差先修几何。
- **静态展示**：最终视角检查轮廓、可见细分折线、高光断裂、接缝闪烁、穿插和悬浮；材质、灯光不能用来隐藏结构错误。
- **动画**：检查关节姿态、附着、法线翻转、实例/随机稳定性及关键帧。只有任务含模拟才检查缓存、时间依赖与代表帧。
- **打印/实体加工参考**：验证闭合体积、法线、非流形、内部重复面、自交、最薄壁和最小间隙。Blender 的数值正确不自动等于满足某种打印工艺，按用户工艺约束判断。
- **格式导出**：确认是否支持曲线、实例、修改器、材质及坐标单位；检查导出对象集合，在不覆盖工作源的条件下验证文件可读和关键几何。不要把“全部转网格并 Apply”当默认导出策略。
- **可编辑源**：保存本次作品，保留必要参数来源；无丢失的外部依赖、无误显的辅助体。交付说明给出结果文件、完成内容和实际存在的限制，不声称未经检查的质量或性能提升。

下面是来源识别与已提取事实，供维护本文时追溯，非下载清单。版本为文件保存版本的主要版本号；读取环境为 Blender 5.2.1，节点可能经过版本迁移。作者/许可按工程内置说明记录；本 Reference 为方法总结，不附带模型或大段原文。

- **P01 — curve_bevel_profile.blend，2.91**：Daniel Bystedt，内置说明 CC-BY-SA 3.0。7 个对象，3 个传统曲线对象；读取了 Bezier/NURBS 控制点、13 点自定义截面、分辨率和 Mirror。背景存在无目标 Boolean，不能把所有留存修改器视为有效步骤。
