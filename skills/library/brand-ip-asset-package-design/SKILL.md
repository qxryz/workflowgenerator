# IP物料制作

当用户想把一个 IP 角色扩展成一套可复用的物料系统时，使用这个工作流。目标不只是做一张图，而是先锁定角色身份，再逐步扩展成可控的一组交付物：IP 3D 形象图、IP 九宫格表情包、IP 多种服装主体形象、IP 海报场景延伸、IP 文创周边等。用户可以提供草稿图、成品参考图，或者只给文字想法；每个模块结束后都要展示结果并询问是否继续，用户也可以随时只做部分物料，不必走完整流程。

## STEP 0：收集输入与范围

1. **先确认是草稿输入还是文字输入**。
   - 如果用户已经有草稿图/参考图，就把它作为 IP 锚点。
   - 如果用户只有文字想法，就先问他要不要先设计草稿图，还是直接进入成品化角色图。
2. **确认本次要做哪些模块**。
   - 询问用户现在要做：3D 形象图、九宫格表情包、服装主体形象、场景海报、文创周边中的哪些部分。
   - 如果用户不确定，推荐默认顺序：角色基础形象 → 变体延展 → 场景延展 → 周边延展。
3. **锁定固定身份**。
   - 记录角色的脸、头型、发型、轮廓、身体比例、核心符号、核心配色和必须保留的配件。
   - 记录哪些可以变：姿势、表情、服装、道具、场景、包装。
4. **确认生产风格**。
   - 草稿阶段默认只出黑白线稿，不上色，不加复杂阴影，不做彩稿。
   - 优先使用用户已经确认过的锚点，比如“保持角色外观完全一致”“不改变造型/服装/颜色/发型和任何细节设定”“明亮干净的色调”“柔和光影过渡”“简洁现代的视觉氛围”“泡泡玛特风格”“3D 卡通角色”。
   - 如果用户要换方向，先更新身份锁再继续生成。

## STEP 1：如果没有草稿，先生成草稿方向

如果用户没有提供可用的草稿图或参考图，不要直接跳到周边或海报。

1. 先给出 3-4 个草稿方向。
2. 生成一组黑白线稿草稿备选。
3. 展示给用户，让他选定一个作为身份锚点。
4. 只有用户选定之后，才能进入后续步骤。

如果用户已经提供清晰的草稿或成品参考图，这一步可以跳过。

## STEP 2：建立 IP 基础形象

先生成核心 IP 3D 形象图，作为后续所有物料的身份锚点。

- 保持固定身份不变。
- 如果用户想要更精致，就把草稿细化为完整的 3D 卡通潮玩手办成品。
- 如果用户想检查一致性，可以做少量核心视图或配色版本，但仍然保持同一角色。
- 3D 形象完成后，可以顺带询问用户是否需要其他配色版本。
- 展示结果后，询问是否继续下一个模块。

## STEP 2.5：配色优先规则

当用户要给 IP 出配色方案时，优先按下面这套规律：

1. 先从温暖、低攻击性的底色入手，例如奶油白、奶茶色、蜜桃粉、燕麦色、薄荷绿、雾霾蓝。
2. 每个方案保持“1 个主色 + 1 个辅色 + 1 个点睛色”的结构。
3. 同一系列要尽量保持相同的明度和饱和度区间，只在色相上做变化。
4. 如果是盲盒或系列形象，就在统一色域里换主色，让每个款式有差异但仍像同一家族。
5. 如果是实物周边或图鉴展示，优先使用低饱和、高明度色，再用少量深色或金属色做轮廓和精致感点缀。

## STEP 2.6：动态延展方案（可选）

当用户已经完成 3D 形象图后，可以顺带询问是否要做常规动态延展方案，或直接根据需要生成一张动态参考板。

1. 保持角色外观完全一致，只变化动作、视角、神态和轻微互动。
2. 默认做 8 个不同的动态方案，要求自然、有差异化、角度丰富，避免重复僵硬。
3. 道具尽量简单，如需出现就让角色手拿或直接接触，不要独立摆在旁边。
4. 适合输出为白底参考板、动作提案页或动态设定页。
5. 生成后询问用户是否继续做后续物料。

### 动态延展提示词模板

“基于提供的 IP 设定，保持统一风格，在纯白背景上生成 8 个不同的常规动态延展方案，要求动态自然、有差异化、角度丰富、有互动感，全方位规避动作、视角、神态重复僵硬问题。保持角色外观完全一致，只变化动作、角度、神态与轻微互动，道具简洁，如需出现则让角色手持或直接接触。”

## STEP 2.7：通用提示词模板库

当用户已经确认角色锚点后，可以把下面的模板直接填空使用。模板的作用是让每次生成都保持一致的身份逻辑，同时允许用户随时改动细节。

### A. 基础 3D 形象模板

“基于同一个 IP 角色本体，保持【脸部 / 头套 / 发型 / 身体比例 / 核心符号 / 主配件】完全不变，只做【成品化 / 配色优化 / 细节精修】。草稿阶段仅输出【黑白线稿 / 线描草图 / 无色稿】，不加颜色和复杂阴影。风格为【泡泡玛特风格 / 3D 卡通潮玩手办 / 高清可爱 / 明亮干净 / 柔和光影 / 简洁现代】。”

### B. 表情包模板

“基于同一个 IP 角色，保持角色外观完全一致，不改变【造型 / 服装 / 颜色 / 发型 / 细节设定】。在统一风格下生成【九宫格 / 8 宫格】表情包，只变化【表情 / 动作 / 姿势】，例如开心、生气、难过、惊讶、疑惑、打招呼、哭泣、害羞等。”

### C. 服装主体模板

“基于同一个 IP 角色本体，保持角色脸部、头套、身体比例和核心识别细节完全不变，只做【常规主题 / 个性化主题】服饰搭配。
- 常规主题：角色穿【服装名称】，搭配【道具 1 / 道具 2 / 道具 3】，动作是【动作描述】。
- 个性化主题：先分析 IP 风格，给出适合这个 IP 的角色形象定制建议，再整理成可生图提示词，最后生图。
整体仍然是同一个 IP 角色的 3D 卡通潮玩手办。”

### D. 场景海报模板

“基于同一个 IP 角色，保持角色外观完全一致，不改变任何核心细节。把角色放入【海上冲浪 / 森林探险 / 拳击比赛 / 潮玩展示】等主题场景中，周围加入【场景元素】，整体做成充满活力和童趣的 3D 海报。”

### E. 文创周边模板

“基于同一个 IP 角色，生成一张儿童文创周边设计图，白色背景，设计简洁、鲜艳、活泼、充满童趣，适合儿童使用。把角色应用到【笔袋 / 书包 / 铅笔 / 橡皮擦 / 水杯 / 午餐盒 / 毛绒玩具】等产品上，保持图案统一、色彩明快、识别度高。”

### F. 用户细节调整模板

当用户说要改细节时，只替换受影响字段：
- 想改角色身份：替换“职业 / 主题”
- 想改动作：替换“动作描述”
- 想改道具：替换“道具”
- 想改风格：替换“泡泡玛特风格 / 3D 卡通 / 现代简洁”等风格描述
- 想改模块范围：只重做当前模块，不回退整条流程

## STEP 3：表情包模块（可选）

当用户要做 IP 九宫格表情包或表情贴纸时：

1. 保持同一个角色模型、服装、配色和主配件不变。
2. 只变化表情、小动作和姿势。
3. 默认做 3×3 九宫格，包含 9 种不同情绪，除非用户要求别的数量。
4. 默认使用干净的白色无缝背景，让所有表情包类输出都更清晰统一；只有用户明确要求时才更换背景。
5. 保持整体风格统一，让整组看起来像同一个角色系列。
6. 展示后询问是否继续或修改。

## STEP 4：服装主体形象模块（可选）

当用户想让同一个 IP 做多种身份/服饰时，先问他要做哪一类：常规主题还是个性化主题。

### A. 常规主题

1. 直接生成常见职业或主题服装，如烘焙师、宇航员、赛车手、医生、厨师、警察、画家、歌手等。
2. 保留角色的脸、轮廓、比例和核心符号。
3. 只改服装逻辑、身份道具和角色语义。
4. 每套服装都要能清楚读出新的身份，但仍然像同一个 IP。
5. 默认生成 8 个不同形象，放在同一张白底图上，除非用户要求别的数量。
6. 做完后再询问是否继续下一步。

### B. 个性化主题

1. 先根据 IP 的气质、识别点和风格，分析适合延展的角色方向。
2. 给出适合这个 IP 的角色形象定制建议，再整理成可生图提示词。
3. 再根据确认后的方向进行生图。
4. 保留角色的脸、轮廓、比例和核心符号。
5. 让新造型仍然像同一个 IP，只是在身份、服装和道具语义上做个性化变化。
6. 如果用户要多个身份，把它们作为系列一次性做完，然后暂停询问下一步。

## STEP 5：海报场景延伸模块（可选）

当用户想要主题海报或场景延展时：

海报中的标题、标注和辅助文字默认使用英文，除非用户明确要求中文。

1. 保持同一个 IP 角色不变。
2. 把角色放进充满活力、童趣、故事感的场景里。
3. 场景要服务角色，不要取代角色。
4. 常见方向包括海上冲浪、森林探险、拳击比赛、潮玩展示、节日活动等。
5. 保持结果适合作为海报阅读，并在完成后询问是否继续。

## STEP 6：文创周边模块（可选）

当用户想做文具、儿童用品、商用宣传物料或周边商品时：

1. 先询问用户想做哪一类文创周边，默认可大致分为儿童文创、生活居家类产品、商用宣传物料、角色贴纸等。
2. 如果用户已经有具体想法，先让他补充方向，再确认细分类别后开始生成。
3. 保持 IP 角色识别度。
4. 把角色延展到笔袋、书包、铅笔、橡皮擦、儿童水杯、午餐盒、毛绒玩具、角色贴纸等产品上。
5. 设计要鲜艳、活泼、简洁，并贴合所选使用场景。
6. 默认使用干净白底或简单背景，除非用户要求别的风格。
7. 做完一张周边板或一组产品后，询问是否继续拆分成单品图。

## STEP 7：细节修改与重做

任何时候，如果用户说颜色太淡、姿势太弱、细节缺失、某个部分不完整，都只改受影响的模块：

- 保持身份锁不变，除非用户明确改设定。
- 如果用户要改底稿，先改草稿，再重新生成后续物料。
- 如果用户只要部分结果，就在当前结果后停止，并总结已完成内容。

## STEP 8：交付与继续选择

每完成一个模块后都要：

1. 展示已生成资产。
2. 简要说明保留了什么、改了什么。
3. 用一句短问题询问用户：继续下一步、修改当前模块，还是停止。

用户可以只生成部分物料，不需要强制走完整流程。只要用户是从草稿图开始，就始终按固定顺序逐步推进，并且每完成一步都要询问是否继续下一步。若用户只想要草稿、只想要 3D 形象、只想要表情包，或者只想要周边图，就只做到那一步为止。
