# Material Propagation Poster

把一张主体图和一张纹理参考转化为可控、可循环的动态海报方案。方案必须明确纹理从哪里开始、如何传播、哪些区域必须保护、镜头如何运动，以及每种输出格式交付什么。

## Operating Rules

- 将主体图视为几何、身份和版式来源。除非用户明确要求改变，否则保留轮廓、五官地标、产品边缘、文字块、Logo 和光照方向。
- 将纹理参考视为材质 / 笔触 / 标记来源，而不是第二个主体。提取它的视觉属性、尺度、边缘质量、重复方式和运动潜力；具体颜色由参考图自身传递，不在提示词里凭空改写。
- 每个方案都分清三层：受保护主体、正在生长的纹理、保持不变的背景 / 版式。绝不能让生长效果生成新的脸、肢体、产品部件、字母或 Logo。
- 默认锁定镜头。如果用户要求运镜，镜头必须服务于纹理生长，并写清路径和幅度。
- 必须定义种子点、传播路径、停止规则和循环策略。“纹理扩散”本身不是可执行指令。
- 优先使用 4–8 秒、一个视觉动作、一个主导材质。通过时间、材质强度或路径做变体，不添加无关特效。
- 不要静默为海报新增文字设计。如果用户上传的源海报 / 封面本身已有文字设计，并且用户希望保留，则把原文字作为受保护版式完整保留；如果源图没有文字，或用户不保留原文字，必须先询问是否需要带文字设计的海报，只有用户确认并提供文本 / 主题后才新增文字。
- 除非用户已经在当前会话确认过静态海报 / 关键图，否则不能直接从原始主体图和纹理参考跳到最终视频生成。
- 当源图片本身已经有文字设计时，要把这些文字当作受保护的版式组成部分。除非用户明确要求改字或去字，否则在静态图确认阶段就要保留原有文字设计。
- 在生成静态海报 / 关键图前，如果用户没有明确尺寸或比例，必须先询问尺寸选择。提供常用选项：9:16 竖版社媒视频、4:5 信息流海报、1:1 方形帖子、16:9 横版屏幕，或自定义尺寸 / 比例。确认后的尺寸同时用于静态海报 / 关键图和后续动态视频，除非用户主动修改。
- 如果用户只提供平台用途而不是具体数值，要把平台意图映射为明确比例并在生成前说明：竖屏短视频平台 -> 9:16，信息流海报 -> 4:5，方形社媒帖 -> 1:1，宽屏展示 -> 16:9。
- 动态视频中，主体必须有适当动态，不能完全静止在画面中。可使用高级克制的呼吸式视差、微旋转、材质表面微光、裂缝边缘稳定、细小碎屑悬停或景深层次漂移，但必须保持主体身份和几何结构。
- 文字动效默认应简单、克制、可读。无论是源图原有文字还是用户明确新增的文字，都优先使用轻柔渐显、透明度呼吸、极小幅位置漂移或简单蒙版显现。除非用户明确要求，否则避免激进动态字体、大幅滑动、重度缩放、复杂 3D 挤出、逐词混乱跳动或铺满背景的文字动效。文字必须始终清晰可读，不能融化、重复、乱码或改字。
- 静态海报文字设计应采用精致的编辑海报层级。主标题通过前后叠压、被主体局部遮挡、置于头部 / 物体后方等方式制造空间深度。主标题可使用克制但有性格的展示字体；只有用户提供或需要信息层级时，才加入小字号干净无衬线信息文字。新文字不能压平主体，也不能遮挡重要面部或表情区域。
- 海报背景应服务主体，不与主体竞争。优先使用低细节氛围背景，加入微弱微纹理、隐性有机线条、半调颗粒或做旧表面细节。背景对比度要足够低，保证主体轮廓、文字和纹理生长仍然是视觉层级核心。
- 光线应具有雕塑感和高级质感：明确的顶光 / 侧光、强明暗对照、凹陷处可读的环境遮蔽、柔和但清晰的投影、半哑光或微缎面材质响应。纹理和文字必须继承同一个光线空间。
- 当用户需要波普潮流或复古杂志封面风格时，海报构图应采用居中正面构图，主体占画面极大比例，通常约占 70%–90% 的画幅，形成强烈的封面压迫感与仪式感。主体可以轻微裁切到画框边缘，以增强视觉冲击。
- 文字排版要有复古杂志封面层级：顶部主标题像封面 Masthead 一样横向展开，主体可以与标题发生前后压叠或局部遮挡，形成空间深度。辅助文本可放在中部左右对称区域或底部小字说明，保持封面式的层级秩序，但不能压过主体。
- 背景应偏向暗黑涂鸦肌理与粗粝印刷底层：低明度、低细节，带有微弱街头涂鸦线稿、复古网印噪点、做旧纹理或轻微涂鸦式痕迹。背景必须始终弱于主体，通过明度和纹理密度的对比衬托主体，而不是通过添加过多视觉元素。
- 波普感可以通过主体上的半调 / 丝网印刷网点、以及顺着主体结构起伏的流线火焰 / 潮流图案来体现；这些图案必须融入雕塑或主体本身，而不是游离在外作为装饰噪声。
- 光线仍应保持雕塑感和高级质感：明确的顶光 / 侧光、强明暗对照、凹陷处清晰的环境遮蔽、柔和但明确的投影、半哑光或微缎面材质响应。纹理、文字和暗黑涂鸦背景都必须共享同一个光线空间。
- 如果用户要求文字动效更明显，也只在简单设计语言内加强：更清晰的渐显、稍强的透明度脉冲或单方向干净蒙版显现。不能凭空新增文字，也不能改变确认海报版式。
- 整体海报应呈现高级呼吸感和动效：主体运动、纹理生长、文字运动和镜头微动要协调、克制、有质感，不能像静态图，也不能杂乱失控。
- 纹理蔓延必须发生在主体身上，不能变成主体周围的悬浮装饰。对人像、雕塑、角色或类身体主体，默认蔓延规则是：从脸部开始向外持续流畅生长，沿着眼、鼻、口等五官结构铺展，进入头发 / 卷发体块，再顺着颈部向下自然覆盖全身或胸像表面。生长动作必须连贯、利落、优雅，杜绝缓慢蠕动、虫状扭动、糊状扩散或随机闪烁。
- 必须完整保留主体轮廓、光泽、光照、材质起伏和几何结构。纹理层只是叠加 / 显现一层生长纹样，不能让五官变形、改变发量、扭曲颈部或身体、破坏雕塑高光，也不能替换原有基础材质。
- 主体上的纹理必须采用三维体表贴合方式。图案要随着面部平面、肌肉起伏、卷发、衣褶、翅膀、服装褶皱、产品曲面或吉祥物几何发生符合空间的弯曲、拉伸、压缩和透视变形，避免像一张平面 2D 贴纸直接盖在画面上。
- 必须保留纹理色彩忠实度。当用户提供纹理参考图时，纹理出现在主体表面后，必须还原原纹理的色彩关系、明暗对比和整体色彩性格，同时适配主体光照。除非用户明确要求重新配色，否则不要为了匹配主体、背景或品牌而任意改色。
- 纹理必须保留主体原有光影通道。高光、明暗交界、环境遮蔽、浮雕深度和材质颗粒要透过图案仍然可见。纹理应是保留光影的叠加层，不是完全不透明的重新上色。
- 必要时使用结构分区纹理：外轮廓、头发 / 头冠边缘可用更清晰的装饰图案；面部、衣袍、身体等大平面可用半调、颗粒或渐变纹理；凹陷区域可更密集，但五官地标必须可读。
- 如果用户上传的是海报、封面、传单或任何本身已经带有文字设计的图片，默认必须保留图片里的原有文字设计。除非用户明确要求去字或重做文字，否则不要删除、抹掉、简化、替换原有文字。纹理蔓延可以从文字后方、周围或局部穿过，但前提是不能破坏可读性。
- 对雕塑或大理石类主体，雕塑轮廓和抛光高光结构必须全程清晰可读。纹理是长在雕塑表面的图案，不是新器官、新裂缝、融化、闪烁或噪点粒子效果。
- 最终动效效果必须呈现已确认关键图的状态。视频可以从更干净或局部生长的状态开始，但峰值 / hold / 最终可读海报状态必须明显匹配确认静态海报 / 关键图：同一主体、同一构图、同一纹理落位、若有文字则同一文字设计决策，以及同一整体视觉设计。不能把动画做成偏离已确认关键图的另一种效果。
- 对需要循环的视频，动画应平滑回到关键图状态，或把关键图状态作为主要 hold / 最终帧。如果使用 reset，也不能抹掉用户已确认的设计；确认关键图始终是目标视觉状态。

## Inputs and Defaults

接受以下任意组合：

1. **主体图**：人像、雕塑、产品、服装、建筑、景观、海报、封面或抽象底图。
2. **纹理参考**：热成像 / 彩虹、植物、墨迹、网点、铬液体、织物、故障、颜料、细胞纹理或用户自定义纹理。
3. **可选简报**：标题 / 文案、品牌约束、比例、时长、音频、平台、模型 / 引擎、循环方式。

### Built-in texture recommendations

当用户只上传主体图、没有上传纹理参考图时，必须先向用户推荐内置纹理选项，不能静默编造纹理。根据主体和用途，从以下内置风格中推荐 3–6 个：

1. **矢量植物纹理**：描边植物单元、藤蔓、叶片、花朵、四叶草 / 星状花；适合优雅有机生长、品牌友好插画、柔和 IP、雕塑和装饰海报。
2. **流体 / 火焰渐变纹理**：火焰状或液态波浪分支、嵌套带状结构、热浪上升；适合能量感海报、音乐 / 科技视觉和强烈材质转化。
3. **半调 / Risograph 印刷纹理**：网点、颗粒边缘、印刷条带、扫描线式显现；适合复古印刷、zine、街头、编辑海报和屏幕 / 油墨质感。
4. **光晕 / 热力星爆纹理**：中心放射、多层柔化环、能量晕染；适合神圣感、科幻、能量绽放、高级发光和图标中心构图。
5. **尖锐锯齿 / 斑马纹理**：高频折线、方向性尖刺条纹、撕裂边缘；适合高张力、朋克、运动、动作和快速侵略性扩散。
6. **版画 / 盖印纹理**：重复印章符号、斑驳油墨孔洞、手工不均边缘；适合手作、民俗、档案、海报印刷和逐个盖印显现动效。

推荐时简短说明每个选项为什么适合。用户选择后，把该选项当作静态关键图和视频阶段的纹理参考；若使用内置纹理且没有上传纹理图，可根据主体和文本主题设计协调配色。若存在上传纹理参考图，则主体表面的纹理必须保留其原有色彩性格。

当缺少细节时，不要静默决定媒体生成尺寸 / 比例；必须先询问尺寸选择。若只是提示词草案，可建议默认值：9:16 竖版主版本、5 秒、带高级微动的锁定镜头、静音、首尾无缝匹配、除非请求文字设计否则只改变纹理、保留干净定版帧用于排版。

## Workflow

### 1. Inspect and classify

在写提示词前先建立简短资产简报：

- 主体类别与视觉锚点：脸、手、产品轮廓、建筑线条、标题区等。
- 前景 / 背景分离与保护区域。
- 纹理属性：对比、颗粒、边缘软硬、重复尺度，以及它更像生长、流动、绽放、填充还是沿轮廓扩散。
- 最合适的种子区域，以及顺着主体形体传播的合理路径。
- 输出路线：主视觉循环、社媒裁切、编辑封面、产品 reveal 或 campaign 接触表。

如果输入是完成海报，保持现有版式为锁定底板，只让纹理在指定主体蒙版内生长。若无法推断蒙版，应请求蒙版或描述手动蒙版步骤。

### 2. Select a scenario recipe

读取 [references/scene-presets.md](references/scene-presets.md)，选择一个主预设，最多叠加一个次级 modifier。记录为 `scenario + modifier`，例如 `portrait-sculpture + thermal-spark` 或 `product + liquid-chrome`。

### 3. Confirm size and source-text handling before media generation

在生成静态海报 / 关键图或任何视频之前，如果用户没有明确尺寸 / 比例，必须先确认输出尺寸。让用户选择：

- **9:16 竖版海报 / 视频**：适合抖音、TikTok、Reels、Shorts、手机锁屏和竖版动态海报。
- **4:5 信息流海报**：适合 Instagram / 小红书等信息流海报。
- **1:1 方形帖子**：适合方形社媒图和紧凑封面循环。
- **16:9 横版屏幕**：适合宽屏展示、YouTube、演示文稿或舞台屏幕。
- **自定义**：用户提供明确比例或尺寸。

确认后的尺寸用于静态海报 / 关键图，并在后续动态视频中保持一致，除非用户明确修改。

随后按以下方式处理文字：

- **源图已有文字设计，且用户希望保留**：把原有字体、文字内容、位置、层级和版式作为受保护构图完整保留。不要删除、简化、替换或重新设计。先生成保留原文字、只加入纹理生长状态的静态关键图，并展示给用户确认。
- **源图没有文字，或源图有文字但用户不保留原文字**：询问用户是否需要制作带文字设计的海报。若不需要，生成无文字纹理生长关键图。若需要，让用户输入文本 / 主题，再根据上传主体、文本内容和所选 / 上传纹理的风格与色彩语言，设计一张带文字设计的静态海报，展示给用户确认后才生成动态视频。
- **用户在任何时候明确要求新增或替换文字**：收集简短文本 / 主题，并生成带新文字设计的完整静态海报图供确认。

新文字设计要高级，并与主体和纹理气质匹配。动态视频里的文字动效默认保持简单：渐显、轻微透明度呼吸、极小漂移或干净蒙版显现。

这张确认过的静态图是视频阶段的视觉锁定图，也是目标状态。如果用户要求波普潮流或复古杂志封面风格，批准的海报应遵循居中、高对比、主体大占比、标题压头的版式语言。视频生成必须保留其中的主体身份、纹理落位、构图、已确认尺寸 / 比例、海报 / 版式决策和最终视觉状态。原始主体图与纹理参考仍可作为辅助参考，但确认静态图是主要视觉权威。动态视频必须明显到达或保持这张关键图状态，不能漂移成新的设计。

### 4. Design the growth action

选择一种生长模式：

- **Branching flow**：细线或脉络沿面部平面、衣缝、产品边缘或建筑结构分叉。
- **Bloom**：从种子点扩张为细胞、花、星点或柔软岛状区域，同时保持原始形体可读。
- **Contour fill**：纹理从点或边缘填充一个受限蒙版，适合海报、产品和平面插画。
- **Wrap and cascade**：材质包裹三维形体并向下或向外延展，适合雕塑、服装和瓶身。

必须写清：

`face seed -> facial features -> hair / curled masses -> neck -> body coverage -> stop -> settle`

对人像 / 雕塑 / 角色主体，除非用户明确指定其他种子点，否则默认使用这套蔓延语法。动作必须连续、干净、利落：不能缓慢蠕动，不能虫状扭动，不能闪烁，不能脱离主体漂浮。

使用可衡量语言，例如：“0.4s 从左侧太阳穴开始，1.8s 到达眼罩边缘，3.6s 覆盖颈部 65%，4.2s 冻结，5.0s 回到种子点。”

### 5. Build the shot specification

写出包含 4–6 个关键帧的时间线，至少包括：

- **0.0s**：干净源状态，镜头和光照锁定，但要有预设的微动基线，不能是完全冻结的静帧。
- **Seed**：第一处可见标记及材质行为，同时写清主体的轻微响应运动。
- **Travel**：传播路线和速度，无跳切；纹理传播要与主体呼吸感 / 视差微动协调。
- **Typography motion**：如果海报含文字，必须写清简单可读的文字动效方案：轻柔渐显、透明度呼吸、极小漂移或干净蒙版显现，然后稳定到确认版式。
- **Peak**：最大覆盖状态，必须匹配已确认关键图的纹理落位和设计状态，同时保护主体轮廓、关键锚点和文字。
- **Hold**：0.4–0.8 秒可读海报定版帧；以高级微动保持确认关键图状态。
- **Loop/reset**：反向生长、溶解或匹配切回时不能丢失确认关键图状态；若视频循环，关键图状态仍是目标 / 最终 hold。

每个关键帧包含主体状态、纹理状态、镜头、光照和失败防护。使用 [references/prompt-templates.md](references/prompt-templates.md) 的块顺序。

### 6. Produce the prompt packet

在一次回复或一个文件中交付：

1. **资产简报**：蒙版、锚点、种子、路径和保护区域。
2. **主图生视频提示词**：使用用户语言；当目标引擎更适合英文时，附紧凑英文版。
3. **负向提示 / 防护栏**：防止身份漂移、几何变形、镜头漂移、无关粒子和文字损坏。
4. **分镜表**：时间戳和预期视觉状态。
5. **变体组**：至少三个变体，每个只改变一个变量（生长路径、材质强度或时间）。
6. **后期备注**：文字排版、蒙版、循环缝合、裁切安全区和导出。

如果用户要求直接生成媒体，而不仅是提示词，则必须遵循“先静态图、后视频”的路线：先生成不主动新增文字的海报 / 关键图，询问用户确认，再用确认图生成动态视频。同时仍提供分镜表和 QC 报告。当纹理必须紧密贴合脸、身体、产品或字形时，先生成干净关键帧。

### 7. Run quality control

使用 [references/qc-checklist.md](references/qc-checklist.md)。若结果改变受保护几何、破坏传播路径、出现时间闪烁、损坏文字或丢失材质身份，应拒收或修正。报告失败原因，并给出最小修复提示词，而不是静默接受。

## Scenario Coverage

在不改变核心流程的情况下支持以下路线：

- 人像或雕塑：脸 / 颈 / 服装蒙版，地标保护，沿轮廓生长。
- 服装或产品：沿缝线 / 边缘包裹，Logo 和材质保护，触感 reveal。
- 建筑或室内：沿线条 / 网格扩散，平面蒙版，克制视差。
- 编辑封面或 campaign 海报：锁定文字和版式底板，多面板变体，保留干净定版帧。
- 自然或有机主体：脉络 / 分支 / 细胞生长，可控不对称与柔和停止。
- 数据、科技或抽象视觉：热图、信号、粒子或波形生长，保持网格安全构图。

细节选择只加载 `scene-presets.md` 的相关部分。

## Failure Repair

- **纹理漂浮在主体上方**：加入沿主体法线 / 轮廓贴合的指令，降低视差，把种子锚定在脸部或其他可见主体地标。明确要求纹样长在主体表面，而不是围绕主体漂浮。
- **纹理蔓延太慢或像虫子蠕动**：把蠕动类动词改成连续、干净、利落的生长；指定从脸部到五官、卷发、颈部、身体的蔓延路径，并禁止扭动、糊状扩散和随机闪烁。
- **脸或产品变形**：加强受保护地标，要求“只改变颜色 / 图案；几何和光照保持不变”。
- **生长突然跳变而不是传播**：增加中间状态，要求连续传播，移除场景变化或镜头运动。
- **纹理变成普通噪点**：明确参考纹理的图案、边缘、尺度和重复方式，并禁止无关粒子。
- **纹理颜色丢失或被错误改色**：明确要求主体表面的纹理保留上传纹理参考图的原有色彩关系和明暗对比，同时让主体光照 / 阴影仍然可见。
- **海报文字融化**：先渲染无文字运动画面，再合成可编辑文字；保留干净 hold frame。
- **循环不连续**：使用反向生长或匹配关键图状态帧，并预留最后 0.2 秒稳定到已确认关键图状态。
- **最终视频不像确认关键图**：重写视频提示词，明确要求峰值 / hold / 最终帧呈现已确认关键图状态；减少额外特效、镜头漂移和新的设计变化。
- **源图文字被意外去除或简化**：明确锁定原有文字为受保护版式，写清除非用户要求重设计 / 去字，否则必须完整保留。

## Optional Deterministic Helper

如需可重复的提示词包，可使用 `scripts/build_prompt_packet.py`，输入包含 `title`、`subject`、`texture`、`scenario`、`growth_mode`、`duration`、`aspect_ratio`、`seed`、`route`、`protected_zones` 的 JSON 配置。该脚本只负责格式化提示词包；视觉判断与媒体生成仍按上述流程执行。
