## 流程走查：首次使用制作圆环

1. 确认新建任务、输出规格和应用主机，检查连接器状态；缺失时准备并等待真实结果。
2. 检查 TD 和完整连接组件。缺失资源就报告具体缺项；已有工程则原位导入，不另开工程覆盖现场。
3. 从当前对话读到目标工程和网络后，搭建最小可见圆环，再加颜色及旋转。
4. 每段修改后核对节点错误与实际输出；用短预览检查旋转，不能只看参数或单张截图。
5. 单独保存工程，验证实际路径和依赖，交付可编辑工程及所需预览。
6. 制作中若断连，先回读未知结果并有限恢复；不重复创建、不重开组件、不宣称未生成的文件已完成。

此处是静态流程走查。连接器脚本测试使用模拟服务，不能代替真实 TD 控制、视觉效果或 Windows 验收。


## 1.0.0 稳定性回归（待实机执行）

| 场景 | 预期结果 |
|---|---|
| 两个 TD 实例争用相同连接位置 | 停止写入并确认目标；保留用户工程，不自动结束不属于本任务的实例。 |
| 已打开工程的外部组件相对路径失效 | 读取实际解析路径并报告缺项；不因监听正常就报告控制成功，不另开工程绕过导入。 |
| 参数 page/menuNames 为空，或错误检查方法缺失 | 空字段正常记录；无法检查错误标为未验证，不能认为节点无错误。 |
| 创建标题为“慢半拍”的动画网络 | 新 OP 使用 ASCII 内部名，中文保留为显示内容，不重命名已有用户节点。 |
| 用户只要求音乐驱动画面，没有要求监听 | 保留音频分析，默认不启用 Audio Device Out。 |
| 请求 MP4，但当前编码器节点报错 | 选择经验证的中间格式并完成必要转码和音轨核验；无法满足交付格式时说明差异。 |
| 打开并修改用户提供的 TD .tox 组件 | 正确触发，先区分导入现有工程还是独立打开，保护未保存现场。 |
