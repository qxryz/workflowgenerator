# 小物产品手绘海报动画

本 Skill 用于把一个小型产品图，制作成一张竖版手绘 POP 产品海报，并继续生成一支固定镜头的短动画，表现海报从空白纸面逐步完成的过程。整体视觉是“真实产品摄影 × 黑色马克笔涂鸦 × 手绘贴纸 × 年轻生活方式品牌 POP 海报”。

本 Skill 是 reference 模板驱动，不要从零改写短提示词。执行时必须读取并适配内置提示词：

- `references/poster-image-prompt.cn.md`：海报生图阶段使用。
- `references/poster-video-prompt.cn.md`：视频生成阶段使用。

适合自然被双手托举、环绕、框选或展示的小物件：饮品、口红、香水、护肤品小瓶、手机、耳机、零食、文具、小潮玩、小包装产品等。

不要用于汽车、家具、家电、房地产、大型设备、多产品目录页、App 功能演示、真人口播带货、严肃高奢大片或长剧情广告。

## STEP 1：输入检查与缺失信息确认

### 必需输入

- 一张产品图片。
- 产品名字。

### 产品名字规则

产品名字是必须信息，因为它会成为海报顶部最大的主标题。

1. 先检查用户上传的产品图中是否存在清晰可读的产品名字。
2. 如果产品图中能明确识别产品名字，直接使用，并向用户简短确认。
3. 如果图片中没有可读产品名字、名字被遮挡、无法判断，或存在多个候选名字，必须先询问用户。
4. 不要编造产品名字。

### 副标题语言规则

海报主标题附近需要一个小号副标题。

- 如果主标题是中文，则生成一个简洁的全大写英文副标题。
- 如果主标题本身是英文或拉丁字母品牌/产品名，则生成一个简短中文副标题。
- 副标题字号必须明显小于主标题。

### 三轮提问规则

提问环节必须分成三轮，不要把标题、贴纸和底部小字合并成同一个问题。

#### 第一轮：标题确认

当产品标题缺失、模糊、被遮挡、存在多个候选，或需要用户确认时，第一轮只询问产品标题，不询问贴纸。

- 如果上传图中有清晰产品名，询问用户确认或替换该标题。
- 如果上传图中没有可靠产品名，询问用户提供海报主标题。
- 用户回答后，锁定该标题，并按副标题语言规则生成副标题。

#### 第二轮：贴纸素材策略

标题确认后，再进入第二轮提问，单独确认贴纸素材策略。给用户三个选项：

1. 从上传图里提取。
2. 用户自定义。
3. 随机生成。

如果用户选择自定义贴纸，继续收集具体贴纸文字、图标、图案或小说明。贴纸数量通常使用 4 个，不能超过 4 个；固定为 FRESH 英文亮色块贴纸、ENJOY 英文亮色块贴纸、一个无字黑白气味/热气/动势线贴纸、一个无字黑白圆形/弧线贴纸；其中 FRESH 轻微覆盖产品边缘，圆形/弧线贴纸被产品局部遮挡。如果画面看起来过于单调或偏黑白，优先让随机贴纸里带入一些亮色点缀，而不是只保留黑白线稿。

#### 第三轮：底部小字信息

贴纸策略确认后，再进入第三轮提问，单独收集海报底部小字信息。询问用户是否有门店地址、开业时间、营业时间、店铺说明、产品说明、品牌小句子、活动信息等希望放在海报底部的小字内容。

给用户三个简洁选项：

1. 提供底部信息。
2. 使用图中信息。
3. 由 Skill 生成中性装饰小字。

如果用户提供了底部信息，把它放入海报最底部的一到两行极小辅助文字中。不要编造地址、开业时间、联系方式、价格、优惠或商业承诺。如果用户选择使用图中信息，则从上传产品图中提取安全简短文字。如果用户选择随机/中性生成或跳过，则使用不含商业事实承诺的装饰性小字、产品氛围词或生活方式品牌感短句。

### 画幅比例

图片和视频默认都是 3:4 竖版。如果用户明确要求其他竖版比例，则图片和视频都使用同一个用户指定比例。

## STEP 2：生成最终产品海报图

编写生图提示词前，必须读取 `references/poster-image-prompt.cn.md`。该 reference 是海报视觉结构、标题字体、底部小字、双手绘制层、贴纸风格和禁止项的源模板。

### 提示词适配规则

- 保留 reference 中详细的视觉语言，不要压缩成简短通用海报 brief。
- 只在必要处把饮品专属表达替换为当前产品类别。
- 将 `{{产品名字}}` 替换为已确认产品名。
- 按副标题语言规则替换 `{{副标题}}`。
- 将 `{{产品图片}}` 替换为用户上传产品图的参考角色。
- 按第二轮用户确认的贴纸策略替换 `{{贴纸素材}}`。
- 按第三轮用户确认的底部小字信息替换 `{{底部小字}}`：优先使用用户提供的门店地址、开业时间、营业时间、店铺说明、产品说明或品牌小句子；没有则使用图中安全文字或中性装饰小字。
- 使用 reference 更新后的四贴纸结构：FRESH 英文亮色块贴纸轻微覆盖产品非关键边缘、ENJOY 英文亮色块贴纸放在侧边、一个无字黑白气味/热气/动势线贴纸、一个无字黑白圆形/弧线贴纸被产品局部遮挡，不要再限制回 3 个。
- 保留底部小字要求。优先使用第三轮收集到的底部信息；用户未提供底部文案时，用中性装饰性小字或从产品图中提取简短信息，不能省略。
- 严格保留 reference 中的手写 POP 标题字体要求：粗头马克笔、黑色实心、非矢量抖动边缘、圆角外鼓、松散可爱餐饮/生活方式 POP 字、纯二维、无阴影、无渐变、无立体。
- 产品必须保持真实摄影质感，不得卡通化或 3D 化。

### 海报输出要求

最终海报必须是一张完整竖版海报，包含唯一产品主体、顶部大号手写主标题、小号副标题、真实产品 hero、一双黑色马克笔手绘双手、1–4 个贴纸/涂鸦元素，以及底部一到两行极小辅助文字。

## STEP 3：视频生成前的海报检查

生成视频前，先确认海报是否可用：

- 是一张完整竖版海报。
- 只有一个主产品主体。
- 主标题正确且可读。
- 主标题字体符合严格手写 POP 马克笔要求，而不是标准印刷字体。
- 副标题正确且不抢主标题。
- 产品仍然真实，并与上传图一致。
- 有一双黑色马克笔手绘双手。
- 主要贴纸或涂鸦元素不超过 4 个，并优先满足固定四贴纸结构：FRESH、ENJOY、无字气味/热气/动势线、无字圆形/弧线装饰，并满足 FRESH 在产品前、圆形/弧线在产品后的遮挡关系。
- 底部存在一到两行极小辅助文字。
- 贴纸遮挡关系有设计层次：FRESH 贴纸可轻微覆盖产品非关键边缘，圆形/弧线贴纸可被产品局部遮挡，但都不能遮挡产品核心识别信息。
- 没有分屏、网格、四宫格、第二产品或随机新增可读文字。

如果海报不符合检查项，优先重生成或修正海报。标题错误、底部小字缺失、字体风格错误或产品身份错误时，不要进入视频生成。

---

## STEP 4：生成 7 秒海报制作过程视频

编写视频提示词前，必须读取 `references/poster-video-prompt.cn.md`。该 reference 是最终成品图理解、固定镜头、时间结构、双手击掌后落位、产品贴入、贴纸贴入、声音设计和严格限制的源模板。

### 提示词适配规则

- 使用生成好的海报作为 `@图片1`，它是唯一最终完成状态参考。
- 将 `@图片1` 理解为完成海报，不是普通风格参考。
- 保留 reference 的时间结构和固定镜头规则。
- 用已通过检查的海报事实替换 `{{产品名字}}`、`{{副标题}}`、产品描述、贴纸清单和比例。
- 视频中的贴纸、底部小字、双手位置、产品外缘和荧光描边都必须以最终海报图为准。
- 不得新增海报中不存在的视觉元素。

### 必须保留的视频结构

- 0.00–1.20：标题手写出现，副标题显现。
- 1.20–2.40：双手出现，合十击掌一次，随后短暂停顿，再快速分开并移动到最终海报位置。
- 2.40–3.80：唯一产品贴纸式落位并稳定。
- 3.80–5.80：已有贴纸、涂鸦、产品外缘、荧光描边和底部小字贴入。
- 5.80–7.00：最终完整海报定格，最后 0.50 秒稳定。

### 声音设计

使用 reference 中的纸面手工动画音效：马克笔摩擦声、线条刷刷声、一次轻快击掌声、产品贴入声、纸质贴合声和低音量轻快音乐。不要加入人声、旁白、嘈杂环境音、厚重低频或戏剧化配乐。

## 失败处理

- 如果产品名字错误，先重生成海报。
- 如果标题字体变成标准印刷字体，按 image reference 中的严格 POP 马克笔标题要求重生成。
- 如果底部小字缺失，必须重生成或修正海报，不要忽略。
- 如果海报显得单调或过于黑白，可以使用最多 4 个贴纸/涂鸦元素，并让其中一部分带上更明亮的颜色点缀，但仍保持单张海报结构。
- 如果产品变成卡通、3D 或无关物体，重生成海报，并强化真实产品摄影和参考图一致性。
- 如果视频新增了新文字、新贴纸、第二个产品或改变产品品类，重生成视频，并强化“所有元素只来自最终海报图”。
- 如果视频最后没有回到海报成品图，重生成视频，并强化最后 0.5 秒定格与固定镜头。

## 触发测试

应该触发：

1. “上传这支口红，做成手绘 POP 海报动画。”
2. “用这个手机产品图生成小物产品海报和 7 秒动效。”
3. “这杯奶茶做成手绘贴纸风产品广告视频。”

不应该触发：

1. “给这个产品做真人带货口播。”
2. “做一个汽车品牌大片。”
3. “帮我做 App 功能演示视频。”
