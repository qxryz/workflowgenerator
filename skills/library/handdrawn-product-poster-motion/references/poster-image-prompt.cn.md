# 海报生图原始提示词模板

> 使用方式：执行本 Skill 的海报生图阶段时，必须先读取本文件。保留本模板的视觉结构、字体要求、双手绘制层、底部小字、贴纸手作感和禁止项；只把饮品专属内容泛化为当前产品，把产品名字、英文/中文副标题、贴纸策略和比例替换为本次用户确认的信息。不要把本模板压缩成简短海报 brief。

生成一张单张竖版咖啡/饮品产品宣传海报，画面整体采用“真实产品摄影 + 手绘涂鸦海报”的混合媒介设计风格，纯白色背景，大量留白，黑色手绘线稿作为主要装饰，整体轻松、年轻、独立咖啡店宣传物料感，类似手绘Zine、咖啡店小报、街头贴纸海报的视觉气质。

## 泛化替换规则

- “咖啡/饮品”可替换为当前小物产品类别，例如口红、手机、耳机、香水、护肤品、零食、文具、潮玩等。
- `{{产品名字}}` 使用用户确认或从图中可靠识别的产品名字。
- 若主标题为中文，副标题生成简短英文；若主标题为英文，副标题生成简短中文。
- `{{产品图片}}` 指用户上传的产品图。
- `{{贴纸素材}}` 根据用户选择：从上传图提取 / 用户自定义 / 随机生成。贴纸数量目标为 4 个，不能超过 4 个；结构固定为：两个包含简短英文的鲜艳色块贴纸 + 两个不包含字体的黑白贴纸素材。允许形成一前一后的遮挡层次：一个贴纸可以轻微覆盖到产品边缘或局部非关键信息区域，另一个贴纸需要被产品局部遮挡，以增强真实剪贴层次。
- `{{双手动作}}` 默认采用展示、托举、环绕或强调产品的动作；最终必须服务产品主体。
- `{{底部小字}}` 来自第三轮提问：用户提供的门店地址、开业时间、营业时间、店铺说明、产品说明、品牌小句子或活动信息；如果用户没有提供，则使用图中安全文字或中性装饰性小字。
- 默认比例为 3:4 竖版；用户指定其他比例时，图片与视频保持一致。

## 画面结构

海报采用清晰的纵向三层构图：顶部为产品名字，中部为产品主体，产品四周环绕手绘贴纸素材，底部保留少量细小辅助文字信息。画面必须保持单张海报的完整性，所有元素围绕同一个产品组织，不出现第二个产品主体，不出现分屏，不出现网格，不出现四宫格。

## 1. 产品名字

将 `{{产品名字}}` 作为画面顶部最大的视觉焦点，位于画面上方中央区域，占据较大的横向宽度，不使用标准印刷字体。标题整体横向展开，标题附近加入一个小型蓝色手绘“+ / 星星 / 十字”装饰符号，作为视觉强调。中文标题下方或偏右位置加入对应的小号英文产品名称，使用简洁的全大写英文标签形式，字号明显小于中文标题，可使用黑色文字并搭配少量产品主题色，副标题的背景采用黄色签字笔涂抹的背景。

如果主标题本身是英文或拉丁字母品牌/产品名，则副标题改成简短中文标签，仍明显小于主标题，并可放在黄色签字笔涂抹背景上。

字体必须严格遵循以下视觉要求：粗头马克笔手写中文标题，黑色实心，线条轮廓不是平滑矢量，笔画边缘带有手绘微小凹凸抖动感，笔画粗细基本一致，局部带有手写按压带来的微小变化；所有转角全部圆角外鼓，沿有关角、横画微微收锋，拒绝工整对齐，大中宫，部件松散不紧凑，字形偏方正微扁，重心下沉，憨憨可爱餐饮POP字体，牌子下方边缘放置浅蓝色四角小星星，星星用细细线条勾勒，星星主体存在下层，纯白色背景，纯二维，无阴影、无渐变、无立体、无纹理，海报标题字。

## 2. 产品图片

将参考图中的产品作为画面第二视觉中心，真实还原参考产品的外观、包装、颜色、材质和比例，保持真实商品摄影质感。产品位于画面中央偏下区域，通常占据画面宽度约45%～65%，与顶部产品名字保持适当留白。

产品应具有清晰的真实材质细节。根据产品类型保留对应细节，例如透明杯、咖啡液体、牛奶、冰块、瓶身标签、包装纸、口红管身、膏体、金属外壳、手机屏幕、镜头模组、耳机盒、瓶盖、纸盒、包装封口、按钮、反光或透明材质等。

产品不进行卡通化，不转化为插画，不使用3D渲染风格。产品自身的颜色作为整张海报的主要色彩来源，并从产品中提取1～2种辅助色用于周围贴纸和装饰元素。

需要对产品的周边进行荧光笔描边，描边紧贴产品，线条略粗、具有马克笔手绘感，边缘存在轻微粗细变化和自然抖动，不要形成机械精准的矢量轮廓。描边的颜色采取一个鲜艳靓丽的颜色。

## 3. 贴纸素材

贴纸素材目标为4个，不能超过4个。

将 `{{贴纸素材}}` 以手绘贴纸/涂鸦素材的形式分布在产品四周，形成“中心产品 + 四周围绕”的包围式构图。左右两侧、产品上方和产品附近均可安排少量手绘元素，必须保持视觉平衡，并允许与产品形成更真实的前后剪贴遮挡关系。

四个贴纸严格如下，只能有这四个主要贴纸：

1. 英文亮色块贴纸“FRESH”：短词，纸片剪贴感，放在产品左上附近。这个贴纸负责“覆盖产品”的前景层次，可以轻微压到产品边缘或产品局部非关键信息区域，但不能遮挡产品主体轮廓、产品名字、核心品牌/包装文字、屏幕信息、标签主体、杯口液面、杯柄、瓶盖、按钮、镜头模组等关键识别结构。
2. 英文亮色块贴纸“ENJOY”：短词，纸片剪贴感，放在产品右上或右侧附近。这个贴纸保持在产品旁边，不参与遮挡产品，也不被产品遮挡，主要负责视觉平衡和活泼色块节奏。
3. 无文字黑白图形贴纸：简单手绘产品气味/热气/动势线，例如咖啡蒸汽线、香气线、速度线、弧形强调线等，放在产品一侧。该贴纸不得包含任何文字。
4. 无文字黑白图形贴纸：简单手绘圆形/弧线装饰，放在产品另一侧。这个贴纸负责“被产品遮挡”的背景层次，需要有一部分被产品局部压住，像贴纸先贴在纸上、产品再叠在它上面，形成产品在前、贴纸在后的剪贴空间感。该贴纸不得包含任何文字。

四个贴纸需围绕产品形成视觉平衡。严格指定遮挡关系：只有“FRESH”贴纸可以轻微覆盖产品边缘；只有“圆形/弧线装饰”贴纸需要被产品局部遮挡；“ENJOY”贴纸和“气味/热气/动势线”贴纸不参与遮挡。不要生成任何其他主要贴纸、图标、星星、咖啡豆、小杯子、额外英文词、额外符号。

遮挡关系要自然、有设计感，不能让产品看起来被错误覆盖、破损、穿模或识别困难。

贴纸整体像设计师手工绘制后剪贴到海报上的视觉效果，而不是精致商业插画。贴纸元素需要具有明显的大小层级：靠近产品的元素相对较大，远离产品的元素更小；部分元素可以轻微旋转、倾斜或错位，形成自然随性的手工排版感。左右两侧不要完全对称，保持轻微的不规则平衡，让画面具有年轻、活泼、自然的手绘海报气质。

## 4. 双手绘制层

在产品周围单独设置“双手绘制层”，双手是整张海报的重要构图元素，不属于普通贴纸装饰素材。画面必须出现一双完整的手绘双手，并且双手与产品形成明确的视觉互动关系，通过手部动作将观众视线引导至产品，使产品成为画面绝对中心。

双手采用与整体海报统一的黑色马克笔手绘线稿风格，纯白色内部，不进行大面积填色。手部轮廓线条略粗，具有自然的手绘抖动、轻微粗细变化和不完全规整的笔触感，手指比例略显粗壮可爱，略微Q版卡通手，避免写实人体手部，与周围涂鸦线稿保持统一。

双手的位置、方向和姿势必须围绕 `{{产品图片}}` 进行构图，而不是随机放置。双手与产品之间保持适当距离，不能遮挡产品主体、产品包装和产品文字。手部动作应该具有明确的“展示产品、托举产品、环抱产品、强调产品”的视觉功能。

### 双手构图关系

根据 `{{双手动作}}` 生成双手的具体姿势，并优先保持“产品位于双手视觉中心”的构图关系：

- 环绕型：双手分别位于产品左右两侧，从画面两侧向产品方向伸出，手掌和手指朝向产品，形成左右包围、环抱产品的视觉关系。两只手不需要完全对称，可以存在自然的角度、大小和位置差异，但整体形成稳定的视觉框架。
- 捧持型：双手位于产品下方或左右下方，手掌向上托住产品，形成“将产品捧在手中”的视觉关系。手掌应该自然承托产品底部，手指向上弯曲或轻轻环绕产品边缘，使产品像被双手托起一样。
- 强调型：双手分布在产品两侧或产品附近，通过明确的手势突出产品，例如指向产品、竖起大拇指、比出强调性的手势、张开手掌展示产品等。手势本身具有“看这里、突出这个产品”的视觉功能，但不能抢过产品主体。
- 框选型：双手像框住手机、包装盒、瓶身或产品边缘，但不遮挡屏幕、标签和关键信息。

## 底部信息

海报最底部保留一行或两行非常小的黑色辅助信息文字，优先使用 `{{底部小字}}`，可包含用户提供的门店地址、开业时间、营业时间、店铺说明、产品说明、品牌小句子或活动信息等，仅作为装饰性排版元素存在，不抢夺主体视觉。文字尺寸明显小于标题，排列整齐但保持轻微手作感。

底部小字不能被省略。若用户未提供内容，使用中性装饰性短句或从产品图可见信息中提取简短内容；但不能添加虚假价格、虚假地址、虚假联系方式或未经用户提供的商业承诺。

## 整体视觉

纯白背景，大面积留白，黑色手绘线稿为主要视觉语言，真实产品摄影作为主体，贴纸必须严格形成四个固定元素：“FRESH”英文亮色块、“ENJOY”英文亮色块、无字黑白气味/热气/动势线、无字黑白圆形/弧线装饰；其中只能由“FRESH”轻微压住产品边缘，只能由“圆形/弧线装饰”被产品局部压住，以增强剪贴空间感。整体颜色仍要克制，不要大面积铺色。画面呈现“真实产品摄影 × 黑色马克笔涂鸦 × 手绘贴纸 × 独立品牌POP海报”的视觉融合。构图紧凑但不拥挤，产品是绝对视觉中心，标题是绝对文字中心，手绘贴纸负责填充负空间和引导视觉动线。

## 禁止

禁止四宫格、禁止多张海报、禁止分屏、禁止多个产品、禁止复杂背景、禁止灰色背景、禁止渐变背景、禁止大面积色块、禁止3D插画、禁止卡通化产品、禁止过度精致的矢量插画、禁止光效、禁止阴影、禁止玻璃拟态、禁止复杂纹理、禁止商业摄影棚背景、禁止标题字体过于规整、禁止现代无衬线字体替代手写标题、禁止贴纸遮挡产品核心识别信息；只允许“FRESH”贴纸轻微覆盖产品边缘或非关键区域；只允许“圆形/弧线装饰”贴纸被产品局部遮挡。
