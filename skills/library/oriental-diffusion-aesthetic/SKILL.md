# 东方弥散美学

当用户想把上传的商品、人物、器物、动物或角色图先做成一张东方弥散风格静图，再基于这张图生成短视频时，使用本 Skill。它的默认流程是先出图、再确认、再出视频；如果用户只要静图，就停在静图阶段。

## STEP 1：收图与尺寸

1. 如果用户没有提供源图，先请用户上传要转换的图片。
2. 如果用户提供了多张图，识别哪张是主主体图，哪张只是可选参考；本 Skill 以主主体图为准。
3. 生图前先确认画幅。默认推荐 `3:4`。
4. 如果用户没有明确尺寸，就先问尺寸；如果用户说“默认”，就用 `3:4`。

## STEP 2：分析源图主体

先判断这张图里最重要的主体锚点，再决定静图要保留什么。

优先保留：

- 主体类别与数量；
- 外轮廓与构图；
- 面部印象、姿态、服装、配件、器物结构、Logo 或纹样；
- 原图里已经很清楚的内部色域；
- 哪些背景信息必须保留，哪些必须简化。

常见规则：

- 商品 / 器物：保留外形比例、功能结构、装饰纹样、品牌或识别点；
- 人物 / 角色 / 动物：保留脸部印象、轮廓、标志性服装或配件；
- 如果主体本身有明显的内部色块或花纹，就把这些色块当作后续循环和弥散的基础色域。

## STEP 3：静图提示词内核

静图不是写实照片，也不是普通插画。它要变成一张更扁平、更抽象、居中而克制的东方弥散海报。

### 静图核心规则

- 主体居中，轮廓干净、连续、平滑，尽量像一个器物式图形标志；
- 主体内部保留柔和层级，但不要做成真实光影，也不要做得太厚重；弥散主体要更亮一些、更通透一些，同时更扁平、更抽象，减少局部细节；
- 静图提示词里不要出现循环、波浪、接力、外涌、闪烁、音乐等视频词；
- 内部色彩只使用源图里已经明显存在的色域，不新增外来颜色；
- 如果源图只有两类明显颜色，就只在这两类颜色及其深浅变化里做文章；
- 背景保持偏暗、干净、克制，有细颗粒纸感与留白呼吸，但不要做背景弥散、雾化或脏渐变；整体偏向图形海报感，避免摄影式层次堆叠；
- 边缘光要更明确地勾住外轮廓，形成可见但克制的发光边界，既托起主体又帮助主体与背景分离；但不要靠细碎高光来做真实玻璃感；边缘与内部都要更概括，不要追求真实材质纹理；
- 静图提示词只写效果与结构，不写具体历史器物名、前一张图名或文物参照名；如果用户想要某种发光气雾、分层外扩、边缘光更强、抽象化或印章感，只描述这种视觉结构即可；
- 整体气质要像现代东方器物海报、古籍拓片和轻柔气韵图形的结合，重在安静、空灵和留白。

### 静图编译模板

把静图提示词写成这种结构：

```text
将上传图片中的【主体】转换为东方弥散美学当代纸本海报，画幅【尺寸】。
保留【最重要的 3-6 个识别锚点】，但去除写实感、摄影感和普通插画感。
主体重构为居中、平面化、符号化的器物式剪影，外轮廓像图形标志一样干净、连续、平滑，整体更概括更抽象。
主体内部为大面积、概括化、抽象化的中心向外分层扩散色彩体块：先有更亮的核心区，再有清楚但简化的中间过渡带，最后收束到更明显的外圈光晕，像发光气雾在器身内部形成波浪式推进。
主体内部保留更明显但更概括的柔和层级，只使用原图已有色域的深浅变化，不新增颜色；如果原图内部只有绿色和黄色，就只在深绿、浅绿、深黄、浅黄之间变化。
背景保持偏暗、干净、带细颗粒纸感和留白呼吸的克制暗底空间；背景本身不弥散，但主体边缘的光晕要更明显，让暗底和亮主体的对比更强。
加入克制圆形东方徽记、印章式符号或博物馆卡片式排版；只使用用户提供的文字【如有】，不要编造广告语。文字与符号尽量简化，不要增加复杂装饰。
整体像现代东方器物海报与轻柔雾化图形的结合，不要写实照片、普通漫画、水墨画或赛博霓虹；宁可少一点细节，也不要回到商品摄影。
```

## STEP 4：生成静图

使用默认图像生成路由先出一张静图。

- 先保留主体；
- 再压成更扁平、更有意境的东方弥散风格；
- 不要为了“艺术感”把主体做丢；
- 不要新增原图没有的颜色。

静图出完后，先给用户看结果，再问要不要继续做视频。

## STEP 5：确认是否继续视频

如果用户只要静图，到这里就结束。

如果用户要视频，再继续下一步。

视频前必须确认时长。默认建议 4 秒；如果用户没说，就先问 4、5、6 秒或自定义。

## STEP 6：视频延展

视频只基于用户已接受的静图来做，且不能把静图模板整段搬进视频里；视频只保留固定机位、主体静止、色彩接力外涌和音乐提示。

### 视频运动规则

- 固定机位，镜头完全不动；
- 主体轮廓不变，不位移，不变形；
- 不做背景运动，背景保持静止、干净、克制；
- 只做主体内部色彩运动；
- 颜色只能在原图已有的内部色域里循环，不允许新增颜色；
- 如果主体内部只有两类明显颜色，就只在这两类颜色及其深浅变化里循环；
- 运动方式是“接力式外涌”：一轮颜色往外推进到边缘后，内部立刻接下一轮，不是闪烁，不是回收，不是单次结束；
- 画面要看起来像颜色不断从内部向外涌出，连续重复。

### 音乐规则

- 不单独调用音乐模型；
- 直接把音乐提示词写进视频提示词里；
- 使用视频模型的原生音频能力；
- 默认带轻音乐 / 氛围声，除非用户明确要求静音。

### 音乐提示词模板

```text
极简、中低速、细腻、带清楚脉冲的电子氛围音乐，柔和合成器铺底，少量颗粒化打击或脆响点缀，无人声，不要大鼓点，不要强烈旋律，保持安静、克制、循环感，和主体内部接力式外涌色彩同步；每一轮到边缘时音乐轻微抬升，下一轮起点迅速接上，形成连续循环。
```

### 视频提示词编译模板

视频提示词只写运动、循环和音乐，不重复静图的主体构图描述；静图的器形、轮廓和纸感背景只作为已接受的前提。

```text
固定机位，镜头严格保持完全不动，画面稳定不抖动，无镜头推拉旋转。主体轮廓保持不变，无物体位移，只做主体内部色彩动态变化。颜色必须锁在原图内部已有色域内循环，不新增颜色。变化要像接力式海浪一样不断从内向外扩散：一轮颜色到达边缘后，内部立刻生成下一轮起点，再次向外推进，形成连续重复的外涌循环，不要闪烁，不要回收，不要单次结束。背景保持深色、静止、不动、干净克制，不做背景弥散。音乐提示词直接写入视频提示词，使用极简、中低速、细腻、带清楚脉冲的电子氛围音乐，和颜色外涌节奏同步。
```

## STEP 7：失败修正

如果结果不对，按下面顺序修：

- **出了新颜色**：把颜色锁回原图内部已有色域，只允许深浅变化；
- **像闪烁，不像外涌**：改成接力式外涌，强调“到边缘后下一轮马上接上”；
- **太慢**：提高内部波动密度，让外涌推进更快；
- **背景脏或在动**：去掉背景弥散，只保留干净暗底；
- **主体被做花了**：降低装饰，回到器物式剪影和清楚轮廓。

## 能力边界

本 Skill 只处理单张东方弥散静图和其后续的短视频延展。

不要用于：

- 完整品牌广告；
- KOC / 口播 / 开箱视频；
- 多镜头剧情片；
- 纯修图、换背景、抠图；
- 与东方弥散无关的普通视频剪辑。
