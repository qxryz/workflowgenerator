【动作设定】
角色为同一个全身游戏角色，始终站在画面中央，脚下有一条细长水平地面线。角色动作库包含 8 个状态：
- idle：轻微呼吸起伏的待机站姿
- walk：原地行走循环，重心左右转移，手臂自然摆动
- jump：先屈膝蓄力，再垂直跳起，最后落回原位
- punch：收肩蓄力后快速向前出拳，再收回站姿
- kick：抬膝后向前踢腿，动作干净利落，再收腿回位
- block：双臂抬起护住上身，形成防御姿态，再放松回待机
- hurt：受击后短促后仰或缩肩，明显晃动后稳住
- dead：失去支撑后缓慢倒地，进入清楚的终止姿态
