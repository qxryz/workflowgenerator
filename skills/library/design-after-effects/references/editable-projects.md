# 工程组织、修改与复用

## 新建与保存

读取当前工程再行动。新任务不等于允许丢弃当前未保存工作。若需切换，优先将当前工程保存为明确标记的恢复副本，记录保存路径变化，再建立工作副本；不要静默覆盖用户原文件。已有授权下的正常保存无需再次审批，无法辨别用户希望保留哪个版本时再问。

按规模组织主合成、场景、组件和素材；小动画无需建立空文件夹层级。使用能说明作用的名称，不依赖 Layer 17；命名语言按下节确定。区分主输出合成与素材预合成，标记哪份用于交付。

保存检查点对应已验证状态；输出版本要能追溯，避免命名 final_final。保存为新版本前确认目标文件是否存在；只在用户意图允许时覆盖，验证磁盘上的文件与当前工作版本一致。

## 工程命名语言与跨语言交付

AE 菜单语言只决定应用界面，不会翻译脚本创建的图层名。创建前确定本次工程命名语言并贯穿合成、文件夹、图层、形状组、控制器、标记和交付说明；不能完成后再批量补翻译。

1. 优先遵守用户明确的交付语言或命名要求。已有工程保持原有规范，局部修改不擅自翻译全部对象。
2. 新工程没有约定时，优先使用已知的 Design 显示语言；无法获取时使用本次任务的主要语言，仍不明确时使用简洁英文。不要根据国家、姓名或开发者的历史对话猜用户语言；普通情况直接沿用合理默认，不额外发起确认。
3. 英文 Design 中的新建英文交付使用英文工程标签。共享知识文件或参考说明是中文，不是创建中文标签的依据；不要把中文示例、内部思考或开发备注写进用户的工程。
4. 工程标签与画面文案分开：保留用户确认的字幕、品牌、Logo 和参考中需要复刻的文字，不能为了英文命名翻译画面内容。导入资产的原文件名保持可追溯；必要时仅给使用它的图层设置清晰别名。
5. 名称保持简洁并说明角色。英文例子：`S01_Planet_Reveal`、`Planet_Mono_To_Color`、`Planet_Native`、`Grid_Dots`、`Background_Gradient`；常改控制项写明用途与单位，如 `Enter Duration (s)`。这些是角色示例，不是每个工程必须复制的模板。
6. 用真实对象身份和可用的稳定属性标识访问 AE，不以显示语言猜效果或属性名称。用户要求重命名既有工程时，先检查名称引用的表达式、跨合成依赖和外部交接，修改后回读并验证，不对字符串全局替换。

交付前抽查所有新建的合成／文件夹，以及代表图层、形状组和控制器是否语言一致、用途可理解。可选脚本扫描非目标语言字符只能提示检查，不能自动改掉合法品牌、原始素材名或画面文字。说明实际保留的既有命名例外，不承诺整个项目只含一种文字。

## 读取既有工程

需要解释工程原理或追踪复杂联动时，读取 递归拆解 (`project-analysis.md`)，沿 source、父级、遮罩、表达式与效果引用展开；仅修改局部时保持相应范围。

修改前确认主合成、目标图层、时间范围、父级、源预合成、轨道遮罩、表达式/控制器、效果、音轨与关键帧。保留目标修改前的必要快照（值、关键帧、关联 ID、代表帧）；不是每次改字都扫描整工程所有属性。

将要求转成修改边界：“第 2 镜头标题晚 0.2 秒出现”应明确只改入场键，还是整层 startTime、出场与配音也要移动。根据用户意图和现有设计推断，重要歧义再问。

识别共享预合成与共享素材：替换一个源可能影响多个实例。用户只改一处时建立需要独立的组件副本并验证内部依赖；仅 duplicate 外层不保证内部 source 独立。用户要求全局更新时保留共享结构。

图层 ID 与属性路径必须来自当前工程。用户手动改过、重开了另一工程或结构改变后重新发现，不拿历史 ID 直接写入。应用修改后回读目标，并抽查非目标区域/时段保持原样。

## 可编辑性交付

| 内容 | 期望结构 | 实际检查 |
|---|---|---|
| 文案 | 原生文字层，保留必要字体/样式 | 可替换文字，动画与容器仍有效 |
| 几何/图标 | 有语义的形状组或明确说明的素材 | 颜色、路径/尺寸能按需求改动 |
| 照片/视频 | 独立媒体层或可替换槽 | 换源后裁切和外部动画保持可用 |
| 动画 | 关键帧、合理表达式和必要控制器 | 可调时间/幅度，能理解驱动关系 |
| 组件 | 内部布局与整体运动分开 | 改尺寸或整体位置时文字不漂移 |
| 版本 | 共享与独立关系明确 | 改一个版本不会意外污染其他版本 |

不默认把所有内容转轮廓、拆成逐字图层或逐帧烘焙。原生文字动画器通常更方便改文案；特殊逐字形变确需拆分时保留可编辑源并说明操作。

控制器只暴露常改项，如主色、卡片宽度、入场时长、错峰间隔。使用可辨认名称与单位。表达式不要以易变化的图层序号引用对象，能用稳定控制关系时优先使用，并验证重命名/复制后的行为。

## 改一次验证

模板或重建复用任务在副本里用较长标题、不同长宽比素材或改变入场时长做一次真实修改。检查溢出、换行、对齐、遮罩、父级和循环衔接。记录测试对象和结果，交付版保留用户原内容。不能只检查“工程有文字层”就宣称文字替换可用。

## 整理依赖

保留工作源工程；精简交付工程只在副本上做，保留用户需要的版本、控制源与表达式依赖。不能只沿 source 链剪枝就假设所有跨合成表达式安全。重新链接后检查素材存在、表达式和代表帧，再保存。

字体名与是否可用分开报告；只读审计枚举的字体不是字体安装证明。说明第三方插件与未能验证的替代字体。工程打包后如路径移动，提供同名依赖文件与重连位置；不把绝对路径存在当作跨电脑可移植性已经验收。
