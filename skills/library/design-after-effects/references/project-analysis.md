# 递归拆解与知识索引

用于理解已有 AEP、提炼可复用做法或定位多层联动问题。仅有视频时可以提出结构假设，但不能声称读到了源工程、表达式或精确参数。普通制作只分析相关依赖，不默认逐层学习整个工程。

## 从整体进入依赖，再回到画面

1. **建立整体基线。** 读取当前工程、主输出合成、尺寸、帧率、时长、工作区、渲染器及相关色彩设置。取得用户关注的时间段、代表帧和短预览，标记主要信息、运动方向、阅读停留和声音事件。保存工作副本，记录原始工程位置。
2. **沿驱动关系深入。** 从目标层追踪 source 预合成、Parent、Track Matte、表达式输入/控制器、效果引用的层、摄像机和灯光。区分“谁驱动谁”和“谁遮挡谁”；父子级不是视觉叠放关系。共享源按实例记录外部变换，不因源相同就认为画面相同。
3. **按需展开子合成与属性。** 记录合成/图层身份、关键属性路径、时间和单位、表达式、关键帧的时间/空间插值、渲染开关。进入源预合成时，先检查外层 startTime、stretch、Time Remap 和嵌套帧率设置，不能直接用主合成秒数读取源时间。对重映射或负速度，读实际映射而不是假设线性换算。
4. **提出可检验的解释。** 例如“文字漂移可能来自父级坐标转换”，写出驱动对象、受影响对象、预测变化和其他可能原因。读回的数据是事实；推断的设计意图和未展开依赖分别标记。
5. **在副本中隔离变量。** 固定参考时间、相机、素材和随机种子，每次只改变一个相关驱动项。先回读，再比较局部与主合成的同一时刻；速度问题还需短预览。恢复基线再试下一项，不叠加多个改动后归因给一个参数。纯分析请求保持只读，提供待做实验，不执行试改。
6. **退回整体判断。** 局部更平滑不代表全片更好。回到主合成检查构图、遮挡、音乐、阅读、镜头衔接和非目标对象，再总结适用条件、修改入口、依赖与失败边界。保存用户需要的工程版本；不要让实验内容混入交付版。

遇到重复引用用当前工程的对象身份去重，同时保留引用边；检测环状表达式依赖，不无限递归。大工程优先目标闭包，遇到外部合成引用再扩大范围。`audit-project.jsx` 只提供基础结构/错误审计，不读取完整驱动图、不分析全部表达式或效果链接，不能把它的通过状态当作因果分析完成。

## 记录一条可复用知识

在任务现有记录中保留必要信息，无需为简单任务创建新格式：

| 字段 | 示例内容 |
|---|---|
| 目标与证据 | 主合成中标题在 1.2 秒偏移；基线帧/工程版本 |
| 实际依赖 | 标题 Position 表达式读取控制层，二者处于不同父级空间 |
| 预测 | 直接复制位置数值会错位；转换到同一空间后应对齐 |
| 副本实验 | 只改该位置表达式，保留其他动画；修改内容与实际对象位置 |
| 结果 | 同时检查起点、中段、终点以及主合成；填写实际结果 |
| 结论与边界 | 哪些坐标/父级条件下适用；哪些时段、版本或依赖尚未验证 |

只有完成对照才能写“已验证”。从表格或参考得到的建议先作为知识或假设，不自动成为已验证的配方；一次成功不代表全部 AE 版本、渲染器或插件均适用。
