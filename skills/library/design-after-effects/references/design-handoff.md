# 素材与工程双向交接

用于画布资产进入 AE、AE 输出回到画布，以及从画布反馈继续修改原工程。这里定义要保留的业务信息与验收依据，不假设任何应用已提供导出、上传或结构转换能力。

## 画布资产进入 AE

优先取得选中产物的身份、版本、文字、样式、图层或组件结构、画板尺寸及素材引用，其次才是截图。多对象选区先理解各对象作用，不默认合并成一张背景。

确认文件是源素材、视觉参考、底片还是声音。保持源地址与经验证的本地绝对路径对应；远端素材下载或同步后确认存在、格式、尺寸、时长及音轨。网页地址不能直接当本地路径，下载成功也不保证格式可被 AE 正确导入。

分层素材需验证实际导入模式及图层是否保留。保留尺寸、文字、字体、叠放、变换和裁切。位图可作独立媒体层，需要单独修改的文字或形状按目标重建；不声称位图包含原始图层。

退出条件：指定版本的素材在 AE 中真实可用，关键结构和外观已核对，并记录它与原产物的对应关系。

## AE 结果返回画布

制作或修改完成后，默认保存明确版本的 AEP 及必要依赖，并回传可视产物：静态合成为一张渲染图，动态作品为完整目标时段渲染完成的视频，优先使用可播放的 MP4。依据本次目标而非工程内无关关键帧判断静态或动态；不为静态任务添加运动。用户明确免除渲染或画布展示时遵从，多交付物按要求处理。以新版本关联原产物，保留原设计和参考，同时提供工程文件、主合成、修改入口、字体或插件依赖以及近似范围。

渲染前确认目标合成、尺寸、帧率、目标时段、实际格式和绝对输出路径。中间帧、自检预览和待验收媒体放在任务独立、明确位于创作项目资产扫描范围外的临时目录；不能先进入画布再清理。需要合成或转码时使用不会自动发布的处理方式。短片自检通过后仍需完成目标时段的最终渲染，不能以单帧、视口录屏、缩略图或帧目录代替成片。

确认实际图片可解码并检查尺寸、构图、色彩及需要的透明度；视频须完成渲染和必要合成，验证解码、播放、尺寸、时长、帧率和必要音轨，并检查首中尾、关键运动与切点。命令成功、文件后缀或渲染队列完成标记不足以证明媒体可用。预览必须对应同一已保存 AEP 和目标合成；修改后更新预览，已有合格成片直接复用。

验证后将最终媒体复制或导入持久交付位置，通过已有媒体导入或展示能力回传当前画布，确认正确的图片或视频节点引用真实文件，图片可见或视频可播放，不能依赖临时渲染目录。记录输出资产身份与版本。自动收录已有节点时复用，不重复添加预览或视频缩略图；发布结果未知时先查节点再重试，不重新渲染已有合格文件。若画布不接受 AEP，回传支持的预览格式并提供工程文件链接，明确 AEP 尚未入库。

源工程、预览文件和画布回传分别验收。仅给文件路径或聊天附件不算画布交付；渲染、验证或导入失败时，保留工程和可续跑数据，修复失败步骤或明确交接未完成，不删除原资产。

以下三件事分别验收：图片预览可见或视频预览能播放；AEP 可取得并继续修改；AE 内部图层转换为画布原生节点。第三项需要额外的结构转换能力，本流程不承诺任意 AEP 可直接变成画布节点。

## 从画布反馈继续修改

根据用户选中的输出版本查找对应 AEP、合成及相关对象，先重新读取当前工程再修改。缺少映射时通过已知文件、名称、预览和时间段重新定位，重要歧义才问用户。不要把资产版本或对象身份当作列表序号，不重复导入整套素材或从零生成工程。

局部改字、调色或调整时间应保留非目标内容。生成新工程版本与新预览后更新关联，让用户知道当前画布结果对应哪个工程。

## 长流程的交接记录

可以用现有会话记录或产物目录中的交接文件，不要求固定文件格式。保留实际存在的信息，不编造对象身份或路径。

| 信息 | 记录内容 |
|---|---|
| 创作意图 | 新建、修改、重建、合成或衍生；保留和改变的范围 |
| 来源 | 原产物身份与版本、媒体角色、源地址、已验证的本地路径 |
| 作品定义 | 尺寸、帧率、时长、声音及原生可编辑要求 |
| 工程 | 源 AEP、工作副本、最新保存版本、主合成与相关对象 |
| 检查点 | 已验证完成内容、下一步、操作结果未知或部分完成的证据 |
| 操作者 | 当前处理者、明确的交出或接管依据；记录本身不构成独占权 |
| 输出 | 实际文件、画布关联、检查结果、依赖与未完成部分 |

只读分析不修改工程。多个操作者串行处理时先明确交接，不能因为上一条命令结束就假设整个工程已释放。记录不含凭证或无关素材；保存失败保留原记录。

完整闭环验收：选中画布素材 → AE 制作保存 → 预览回传并关联 AEP → 从画布提出局部修改 → 找回原工程生成新版本。没有执行的阶段标为待验证。
