# 视觉、工程与交付验收

## 制作过程中

进入动画前，先完成 原生结构与素材准备检查 (`native-reconstruction.md`)：几何与渐变有真实编辑入口，关闭参考层后对象仍独立成立；人物素材按最大预定显示尺寸和实际遮挡确认，再复用同一提取结果。此项是制作前置工序，不是成片后通过模糊、羽化或重新生成补救。

选取与风险有关的帧：入场前后、运动中段、稳定阅读、出场与切点。默认中点截图通常不够。预览明确的目标合成；需要精确文字或材质时用原分辨率或细节预览。检查运动模糊时确认预览、合成与图层相关设置都生效。

静帧验证布局与材质；短视频验证速度、停顿、节奏、循环、音画与帧间问题。属性运动采样只验证数值轨迹，不能独自证明视觉质量；缩略联系表也不能证明不存在一帧闪黑。

| 任务 | 优先检查 |
|---|---|
| 静态转动态 | 稳定终态与原设计一致，阅读顺序、时间和留白成立 |
| 视频原生图层级重建 | 视觉对照相同时间点的镜头、轮廓、构图、颜色、层级、运动与材质；另验收文字、形状、路径、动画与效果的独立修改能力；单列近似或无法完成部分 |
| 局部修改 | 目标变化准确，非目标层/时间段未受影响 |
| UI/数据 | 操作因果、数字终值、连线、指针到达与反馈同步 |
| 模板衍生 | 长文案与新素材的溢出、裁切、关联更新符合预期 |

先修影响信息表达和参考识别的大偏差，再做微小纹理。不要用固定的“精致”效果掩盖错误内容。

## 运动曲线验收

按 曲线设计与验证 (`motion-curves.md`) 抽查主要位置、缩放、旋转及显隐的协同；不要只检查层上存在关键帧。回读实际的时间插值、入／出缓动、自动／连续状态及必要的表达式求值，确认没有被线性插值、另一驱动或被忽略的写入错误抵消。

每类不同的动作至少用一个代表片段检查启动是否突兀、峰值是否匹配参考、减速是否拖沓、中间通过点是否误停、停留是否稳定、旋转／缩放与淡出是否对齐。先按正常速度看，再按需逐帧和采样诊断。不要以关键帧图标、统一 influence 数值或开启动感模糊代替运动质量证据。

线性运动、离散保持和连续匀速段可以是正确选择；验收依据参考与设计意图，不以“所有键都有缓动”为指标。曲线无法设置或回读时写明具体属性和限制，不把缺失验证报告为已精修。

## 效果验收

按 效果制作 (`effects-construction.md`) 在代表片段核对真实属性、控制源及其采样阶段、作用对象、透明度和边界余量。选取最大形变、融合／分离、光扫穿过细线、拖尾停止与结束、循环跨缝等相关时刻；静帧和正常速度预览结合，不以成功添加效果判定完成。

检查未被指定处理的人物、文字和背景保持稳定；透明输出需在深浅背景核对边缘。控制图可以不直接显示，但仍须正常驱动效果。在副本中改变一个有意义的参数，确认可继续编辑，再恢复交付值。记录缺失属性、未验证效果与近似方法，不把程序化栅格结果标成可导出的矢量路径。

## 工程检查

audit-project.jsx (`../scripts/audit-project.jsx`) 是可选的只读 AE 工程审计函数体，需由现有连接能力提供兼容的 AE 脚本执行环境；它不能作为 Node 程序直接运行。可通过其 AUDIT_COMP_IDS 变量限定目标及素材来源依赖，省略则检查全工程。脚本不写值、不保存、不切换工程；无法执行时根据下述清单检查，并明确缺少的证据。

检查文件存在、需要原生的文字/形状是否仍原生、关键帧/表达式是否可理解、代理是否影响输出。报告中跨合成表达式依赖和任意时间错误可能不完整；按任务额外预览/求值。源视频含音轨不等于该音轨在输出启用，另查音频开关/混音。

限定目标的审计只沿 source 引用访问，不自动解析表达式中的 comp 名称。涉及跨合成表达式时扩大审计范围。字体列表不是已安装字体检测；空工程、未保存工程、检查被截断或有 unreadable 字段时不能给出“全部通过”。

可编辑性按 工程组织 (`editable-projects.md`) 的具体编辑动作验收，不按图层数量打分。 同时抽查新建合成、文件夹、图层、形状组和控制器的命名语言；英文交付不应夹入知识库的中文示例标签。保留原素材名、既有命名和用户确认的画面文案，不把它们机械判错。

## 渲染与输出

涉及 LUT、跨色彩空间素材或输出偏色时，读取 色彩与输出联动 (`color-rhythm-output.md`)，分别检查输入、工作、显示与输出变换；不以一张播放器截图替代完整判断。

先保存当前要渲染的明确版本，后台渲染磁盘工程时尤其确认该版本已更新。查本机渲染设置和输出模块模板；不要在中文 AE 固定写英文 Best Settings/Lossless。若通过临时队列项查询模板，只在已取得 AE 使用权的任务里创建，并在 finally 中移除本次临时项，保留原队列。

帧范围按实际帧率与工作区计算；明确结束帧是否包含在渲染范围内。例如从 0 开始的 30 秒 25 fps 合成为 0–749，非整数帧率按真实帧时间边界处理，不能盲乘取整。用户没要求音频时不把无音轨视为失败。

渲染进程结束后检查日志、文件大小、媒体流、尺寸、帧率、时长、音轨以及实际播放。有 FFmpeg/ffprobe 时可完整解码检查损坏帧，并结合黑帧/静帧检测与设计意图定位异常；刻意黑场和停留不能机械判错。音画对齐通过对应事件与听看验证。

交付包含用户所需 AEP、成片/预览、实际依赖和简短修改说明。可移动素材包还需验证重新链接后的项目状态和画面。明确输出是原生重建、媒体合成或有已说明的近似；不要声称像素级复刻或全部可矢量编辑而没有证据。

## 对用户报告

简短说明已完成的视觉变化、工程位置/版本、修改入口、检查范围和仍存在的差异。仅准备方案或 AE 连接阻塞时明确尚未生成工程；只有文件和宿主回传成功证据存在，才报告相应交付完成。
