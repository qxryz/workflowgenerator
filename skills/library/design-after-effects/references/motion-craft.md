# 动效设计判断

## 意图到运动

先判断要表达的层级、重量、方向与情绪，再选曲线。以下是设计起点，不是所有任务固定的参数模板。

| 描述/意图 | 可调的设计维度 | 观察与修正 |
|---|---|---|
| 轻盈、柔和 | 较小位移、渐进减速、少量次级跟随 | 避免拖沓和多次回弹；阅读区稳定 |
| 有冲击力 | 更明确的位移/尺度对比、快速主动作、短促停留或收敛 | 不靠高频抖动代替冲击；焦点清楚 |
| 精密、产品感 | 对齐、统一时序、克制的速度变化、明确交互状态 | 相邻组件保持几何关系，操作因果完整 |
| 活泼、有弹性 | 可控过冲与衰减、节奏对比、次级动作 | 终态收敛，不让正文持续摆动 |
| 胶片、朦胧 | 色彩关系、颗粒尺度、少量曝光变化/门抖、柔化 | 区分材质与装饰边框，避免灰雾和文字损失 |

“更快”可能指总时长、动作时长、节奏密度或减少停顿。根据上下文定位；若这些会产生不同且重要的结果再询问，别全片等比加速。

## 时间与空间

具体执行按 运动曲线设计 (`motion-curves.md`)：从参考的启动、峰值、制动和停留规划速度，再写入并回读关键帧，最后用正常速度预览验证。缓动选择在制作前完成，不只是末尾的一次统一润色。

时间曲线控制沿路径的速度，空间曲线控制路径形状；弧线运动不等于平滑时间节奏。普通非弹性 UI 不默认过冲，连续通过的点不必每个都减速到零。错峰应体现层级与因果，避免为每层随机延时。

以实际帧率设计切点；同样 6 帧在 25 fps 与 60 fps 的感受不同。关键姿态对齐参考帧，帧间运动与运动模糊另行检查。以像素/秒、角速度和屏幕相对距离观察速度，而不是只比较关键帧个数。

改帧率、驱动表达式、父级/锚点或模糊曝光时，读取 动画与驱动关系 (`animation-dependencies.md`)；音乐振幅映射、爆点组合与跨镜头运动见 色彩、节奏与输出 (`color-rhythm-output.md`)。

过冲需控制幅度、次数和收敛时间；表达式可作可调控制，但不应烘焙成逐帧键以掩盖参数。需要手工续改的运动优先少量有意义的关键帧和清晰控制器。

## 排版与结构

- 文字真实边界、基线和段落对齐共同决定视觉中心。用实际文字范围计算几何中心，另看视觉是否偏移；不能所有文字都把 anchorPoint 设为 [0,0]。
- 自动换行优先保持信息与层级，其次调整文本框、间距，必要时按可读下限缩字。替换文案后重新检查容器与其他元素，不能只预估字符数。
- 按钮/卡片等整体运动通过父级或预合成承载，内部布局独立；避免文字与底板各写一套近似位置曲线后漂移。
- 注意图层、形状组、合成和世界坐标的区别。父级变换、锚点和预合成变化后重新检查遮罩、渐变和连线，不把所有坐标直接当屏幕坐标。

## 材质与合成

先建立色彩和明暗层级，再添加颗粒、辉光、柔化。颗粒尺度随输出分辨率考虑；高强度效果不能弥补错误构图。模糊边缘出现矩形时检查源范围、效果边缘重复、遮罩和预合成裁切，不一味增加半径。

整层渐变效果不意味着同一形状层每个组都能独立多色标渐变。需要独立控制时拆层/预合成或查询可用原生属性，避免用一个统一效果覆盖所有颜色。

使用 3D 图层前明确相机运动与对象运动的分工；透视不应让展示信息长期难读。形状算子的排列、遮罩方式、图层叠放会改变结果；核对属性树和实际帧。

## 声音与阅读

动画主重音可对齐音乐/配音节奏，但不让每个元素都跟随振幅跳动。确认原视频是否带声音，避免底片环境声和参考音轨叠加。对齐音画时考虑裁剪起点、帧率和编码延迟，用听看结合验证；未经对齐的音频相关系数不能单独判断音轨错误。
