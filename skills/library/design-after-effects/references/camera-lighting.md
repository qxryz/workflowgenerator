# 摄像机与光照

用于 3D 图层镜头、景深、灯光和阴影。先读合成 renderer、图层类型、活动摄像机、Parent、相机/灯光参数、材质选项和实际插件。Classic 3D、Cinema 4D、Advanced 3D 与插件内部渲染能力不同，不套用统一参数表。先在工作副本建立简短可验证场景，再扩展。

## Camera / Null / Target

相机 Position 是机位；Orientation/Rotation 控制朝向，双节点相机还受 Point of Interest 影响。读取相机实际类型及控制来源，不同时给冲突的朝向系统写动画。Null 可以把镜头路径与相机自身调整分开，但父级变换仍参与最终结果；Null 不显示画面也能改变整个镜头。

目标跟随时先确认目标坐标空间。目标的局部 Position 不等于世界位置；有父级时用经过验证的空间转换。指定目标不自动完成构图规划，还需检查遮挡、边缘安全区、主体大小与阅读时间。

### Zoom 与移动机位的区别

Zoom/焦距改变视角和画面放大率，机位移动改变观察点及前后景相对关系。机位固定时单独增大 Zoom 不应被描述为自动改变前后物体的相对透视比例；常见的“长焦压缩感”涉及为了保持主体大小而调整拍摄距离。

若需要推近带来的视差，用机位运动；若需要变焦，用 Zoom；若需要滑动变焦效果，联动两者以维持主体尺度，并逐帧检查前后景关系。不要把 Scale、Zoom、Camera Z 当成视觉完全等价的“放大”。

副本验证：放置前后两个可读对象，先固定相机位置只改 Zoom，再恢复并只移动相机，比较主体大小和前后景关系。真实制作使用用户内容或最小测试副本，不在原工程插入教学对象。

## 景深

DOF 开关决定是否应用景深；Focus Distance 决定焦平面位置，Aperture、Blur Level 等影响失焦模糊。先核对当前渲染器是否提供并支持这些项，再读实际值，不仅凭属性名存在判断已生效。

焦点在相机观察方向上的深度与空间两点的直线距离不是普遍等价，目标偏离光轴时尤其要验证。相机绑定 Null 或目标运动后，固定 Focus Distance 可能不再对准主体；需要跟焦时选择正确空间和深度关系，并预览全过程。

诊断顺序：确认活动相机和 3D 参与 → 核对焦平面 → 检查 DOF 与光圈/模糊 → 检查其他 Blur。文字不清晰时先定位失焦来源，不直接提高锐化。副本中固定构图，只改 Focus Distance 观察清晰区域，再恢复并调 Aperture；不要同时改焦距、机位和光圈后无法归因。

## 灯光类型与使用意图

以下描述传统 AE 灯光的基本选择，具体可用类型与行为按渲染器确认；环境光照/3D 模型材质不强行套用此表。

| 类型 | 设计用途与关键依赖 | 检查点 |
|---|---|---|
| Spot | 有方向与锥形范围，适合局部强调 | 位置、朝向/兴趣点、Cone Angle、Feather、衰减是否覆盖主体 |
| Point | 从一点向周围照明，适合局部空间光源 | 光源与对象距离、衰减、可见亮部位置 |
| Parallel | 用方向控制平行入射关系 | 方向与受光面的关系，不能只移动位置期待像 Point 一样变化 |
| Ambient | 增加整体环境亮度，缺少局部方向塑形 | 是否填平明暗和阴影，不把 Ambient 当成产生定向投影的灯 |

Light Intensity 与 Color 影响输入亮度和颜色；Falloff 影响距离响应。最终观感还取决于材质、相机、曝光/调色和混合方式。先建立一个明确主光，再按画面需要加入补光，不靠不断加灯解决错误材质开关。

## 材质与阴影链

光源、投影对象、承影对象和渲染器必须共同支持阴影。按本机实际属性确认灯光 Casts Shadows、对象投影开关、承影设置、受光/材质项及空间位置。存在 Casts Shadows 开关不保证阴影落在镜头内；光照与阴影可能因 2D/3D 混合或嵌套结构改变。

阴影过硬或噪声大时分别检查当前引擎提供的柔化与质量参数、距离关系和分辨率；不凭其他软件经验发明 AE 参数。材质高光与相机观察角度相关，改灯后要从最终相机检查。

副本最小实验：只保留一盏相关灯和投影/承影对象，逐项开启实际支持的投影链；固定光强只改灯位，检查阴影方向，再恢复并只改强度。若正常层未响应，先读材质和渲染器，不盲目把亮度加到极端。

## 工具与交付

先确认实际可操作的相机、焦点、灯光与材质属性，不把某个预设镜头的可用性当作全部 3D 能力已具备。未暴露的操作需由现有连接能力提供支持，不能宣称已执行。预览以活动相机和实际渲染器为准；编辑视图可见不等于最终输出可见。保留必要控制器、真实插件/渲染器依赖与可修改入口。
