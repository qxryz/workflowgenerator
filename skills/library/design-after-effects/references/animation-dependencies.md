# 动画与驱动关系

适用于动画创建、改时间、改布局与工程拆解。按 递归拆解 (`project-analysis.md`) 在相关副本上做对照；先读取目标属性与驱动关系，再修改，不从界面名称猜参数。

## 主合成、时间与采样

主合成决定最终画面容器和输出时间范围；宽高不会自动重新设计内部布局，延长 Duration 不会自动延长全部图层、子合成或音轨。更改尺寸后检查安全区、定位表达式、媒体裁切和镜头视野；延长后检查入出点、源长度与末尾黑场。

区分三种操作：

- **更改合成帧率：** 改变时间采样网格，不能当作自动加速或减速。不要假定关键帧按秒的时间会等比重排；读取修改前后 keyTime、时长和帧边界，检查按帧计算的表达式、嵌套合成与素材解释设置。
- **解释素材帧率：** 对相应素材可能改变播放时长与速度，要核对音轨和全部共享实例。
- **重定时动画/素材：** 根据目标修改关键帧时间、层 stretch 或 Time Remap。明确是只移动入场，还是改变整层播放及出场，不能用改合成 fps 代替。

时间记录同时保留秒数与用于观察的帧率。连续动画可有子帧关键帧，不为“整齐”全部吸附到整数帧。对照实验先固定一个已知时间键，只改 fps，读回时间并比较播放速度和采样；不要把不同帧号误当同一时刻。

## Transform、父级与坐标

| 参数或关系 | 联动机制与影响 | 实现与验证 |
|---|---|---|
| Position / Parent | 子层位置位于父级空间；父级的移动、旋转、缩放改变最终位置 | 跟随点用实际坐标转换。父级变化后核对连线、遮罩与关键姿态 |
| Anchor Point | 决定缩放和旋转支点；改锚点可能同时改变画面位置 | 需要保持画面位置时补偿 Position，并考虑父级和 3D，不简单对所有场景加减二维偏移 |
| Rotation | 中心支点呈现自转，偏心支点产生绕行；父级旋转参与最终变换 | 先修支点再修速度曲线。检查跨圈角度与方向，避免不必要的整圈旋转 |
| Scale | 与锚点、父级缩放和源分辨率联动；非等比缩放影响形状与文字 | 区分改组件尺寸、改布局和整体缩放。位图放大无法凭矢量开关恢复细节 |
| Opacity | 调整层自身透明度影响合成；普通父子绑定不把父层 Opacity 自动传给子层 | 整组淡出用明确表达式控制或预合成外层；不要只给 Null 写透明度就宣称全部淡出 |

图层空间、形状组空间、合成空间和世界空间不同。表达式中的 `toComp`、`fromComp`、`toWorld` 等用于对应空间转换；3D 投影结果和局部 Position 不可直接互换。读取实际维度，分离维度后的 Position 按单轴处理。静态定位正确后再检查父级运动过程。

## Position / Rotation / Scale 曲线

新建或调整关键帧运动时先读 曲线设计、参考拟合与验证 (`motion-curves.md`)。曲线在代表片段制作时完成；只添加首尾值、所有键统一套缓动或静默忽略写入错误，不构成运动精修。下面用于定位属性、单位及驱动依赖。

时间插值决定属性随时间变化，空间插值决定位置路径。Speed Graph 看速度，Value Graph 看属性值；值曲线斜率才与变化速度相关，不能把值高理解成速度快。按属性单位比较 px/s、deg/s 或 %/s，不复制不相干属性的速度数值。

- Position：先确定通过点与路径，再定到达时间、加减速和停留；持续通过的点不必全部缓出到零。相机和遮罩同时移动时，检查合成画面中的相对运动。
- Rotation：确认锚点与父级后，按角速度调整转动和收敛；旋转快慢与物体屏幕尺寸共同影响边缘速度和模糊。
- Scale：确认目标尺度与可读性，按视觉需要设置短过冲及收敛。百分比线性变化不保证主观速度恒定，不把所有缩放套同一 ease。

Hold 适合离散切换；连续运动可用 Linear 或 Bezier，按实际意图选择。测试时锁定首尾姿态，只改一个属性的时间曲线，对照中间态、峰值速度与切点。速度采样用于诊断，短预览用于判断观感。

## 表达式、Null 与控制器

先判断属性由关键帧、表达式、父级还是效果驱动。写入有表达式属性的基础值不保证改变最终画面，应修改实际控制源，或在用户要解除驱动时有边界地处理表达式。

| 构件 | 机制 | 常见错误与检查 |
|---|---|---|
| `value` | 取得当前属性的表达式前基础值，可保留关键帧贡献 | 区分“基础值 + 偏移”与直接返回常数；回读时区分表达式前后结果 |
| `time` | 当前求值时间，直接使用可能令复制后的层在绝对时间同步 | 相对入场用实际层起点/标记定义局部时间；不要假定从每层 0 秒开始 |
| `wiggle` | 按频率和幅度生成变化；不等于音乐节拍，也不自动在结束时收敛 | 明确轴、幅度、包络、随机策略，检查多次渲染与衔接 |
| `loopOut` | 根据已有关键帧与循环类型延续动画 | 先查有效键和周期。首尾值一致之外，还要检查速度接缝与重复端帧 |
| Null + Slider/Angle/Checkbox | Null 不渲染；通过父级或表达式集中驱动参数 | 名称带用途与单位；Slider 的数值范围由设计约定，不能把所有属性都按 0–100 |
| 跨层/跨合成引用 | 一个属性读取其他对象，形成依赖链 | 查被引用对象、时间、空间与共享范围。改名、删层、复制或 index 改变后重新验证 |

表达式语言和 ExtendScript 执行脚本不是同一环境。表达式不要调用 Node 或工程修改 API。自动复制组件后，在副本里改一个控制值，确认预期实例联动、独立版本不变；不盲目用索引替代稳定引用。

## 动态模糊

分别检查图层与合成 Motion Blur、预览/渲染开关、Shutter Angle、Shutter Phase 及运动来源。快门角度控制模拟曝光时间，快门相位改变采样区间相对帧时刻的位置；模糊与曝光区间内的运动有关，不是固定叠一张模糊图。停住的显示帧也可能受邻近子帧运动影响。

普通图层变换模糊和图层内容内部运动的模糊不同。CC Force Motion Blur、Pixel Motion Blur 或插件自带模糊要按各自能力选择，不能承诺开图层开关就处理所有内部像素运动。避免同时叠加多种模糊而失去可读性。

副本实验固定动画，只改变快门角度，比较快速中段、停留起点与转场边缘；再单独检验相位。不要同时改变曲线与快门后把结果归于一个参数。按当前合成的实际属性核对曝光设置。

## 字体、构图与点缀

真实文字内容、字号、行距、字重和段落框决定占据范围；锚点影响文字运动。`sourceRectAtTime` 可辅助布局但不能代替基线与视觉判断。原生文字动画器保留改文案能力，范围选择器与文本长度的关系必须用长短文案测试。

构图检查稳定阅读帧及运动中段的主体占比、边缘安全区、背景对比和相机投影。点缀的颜色、透明度、节奏应从属信息层级，不因“缺少细节”就给所有空白加运动。改主色或时长时同时检查点缀是否抢焦点、提前出现或遗留在出场后。
