# 从视觉结构重建原生动效

适用于已经确定采用 AE 的参考复刻和静态设计动画化。“像 AE 的视觉风格”本身不改变用户已经选择的视频生成路线。本节的目标是在第一次制作前选对结构，让后续修改自然成立；不是在成片出错后叠加修边效果。

## 先决定什么要保留、什么要重建

按对象判断来源、轮廓、颜色或材质、透明度与遮挡、运动、修改需求。参考图像用于测量和对照；圆、矩形、线条、文字等可由原生对象表达的内容，应重建其生成结构。给一张参考截图加圆形蒙版，得到的仍然是被裁切的截图，不是原生渐变圆。

| 对象 | 制作前的选择 | 应保留的编辑入口 |
|---|---|---|
| 圆、圆角矩形、星形等规则图形 | 参数化形状路径；需要不规则变形时再考虑贝塞尔路径 | 尺寸、圆角或点数等实际适用参数、颜色、变换 |
| 自由轮廓与图标 | 根据参考构建必要的路径；已有可用矢量源时保留或转换其结构 | 顶点、切线、填充、描边、组变换 |
| 渐变色块 | 原生形状渐变填充；需要整层着色时再考虑渐变效果与限定范围 | 渐变方向、位置、颜色及其动画 |
| 文字 | 原生文字与文字动画器；只有轮廓变形确有需要时转形状并保留文字源 | 文案、字体、排版、出现范围、时间 |
| 照片中的人物、产品、实拍纹理 | 保留用户允许使用的真实素材，只做必要分离和合成 | 素材来源、透明度或蒙版、槽位与外部变换 |
| 辉光、颗粒、柔化 | 先明确作用对象，再用实际可用的效果生成 | 效果范围、顺序和少量有意义的控制参数 |

复刻的是可解释的视觉与运动结构，不声称恢复原作者工程。不要把逐帧截图、裁切位图、透明 PNG 或套在原图上的轮廓当成已重建的 MG 图形。用户明确要求复用的原生模板或品牌矢量资产可以保留；不是为了“从零”而丢弃正确源文件。实拍和复杂纹理允许作为媒体的边界仍由本次任务决定。

## 图层、形状、蒙版与效果各负责什么

- 形状路径描述几何；填充和描边给它外观；形状组变换组织局部关系，图层变换负责整个对象的运动。参数化路径通过尺寸、位置等参数描述，贝塞尔路径通过顶点和切线描述。规则圆优先保留参数化编辑，不为模拟圆而添加大量顶点。
- 蒙版限制所属图层的可见区域，不会把被遮盖的位图转换成形状。通过界面创建时要确认选中对象和创建模式：在形状层上创建蒙版与创建形状是不同操作；完成后检查真实内容结构。
- 用另一个对象定义遮挡时，选择合适的轨道遮罩；对象之间的前后关系由合成结构表达，不能靠父子关系替代遮挡。相关版本差异和效果顺序见 合成联动 (`compositing-dependencies.md`)。
- 效果产生材质或改变图层结果，不替代可直接建立的几何。每个蒙版、效果、预合成都应能说明用途；不机械地给每个圆叠加“图层＋蒙版＋效果”。

## 例：复刻一个带渐变的圆

先观察圆的轮廓是否保持圆形、渐变是方向过渡还是中心向外扩散、颜色是否随时间变化、是否有光晕，以及有没有被其他对象遮住。把对象移动、圆自身形变、渐变移动与遮挡揭示分开理解。

最小原生结构可以是：

```text
形状图层：渐变圆
  内容
    圆形组
      椭圆路径：尺寸与局部位置
      渐变填充：类型、颜色、渐变起止位置
      组变换：仅在局部关系需要时使用
  图层变换：位置、缩放、不透明度等主动作
```

1. 建立椭圆路径，用相等宽高表达圆。先匹配轮廓和位置，再匹配颜色关系；不要从参考帧裁一个圆作为图层源。
2. 根据参考选择线性或径向的渐变表达，匹配方向、中心、过渡范围和颜色。渐变属性与图形的整体位置动画分开控制；形状的渐变填充可以独立调整和动画化。
3. 只有局部显隐或切除才增加蒙版；跨图层遮挡用合适的遮罩源。普通完整的渐变圆不需要再加一个同样的圆形蒙版。
4. 参考含光晕或颗粒时，再增加对应效果，或在需要独立控制时分出效果层。预先安排效果所需边界，避免光晕被源或预合成范围截断。材质不应改变原本清楚的轮廓意图。
5. 依据参考驱动图层运动、路径尺寸或渐变属性。若圆只是移动，不给路径每帧重新描点；若是颜色在流动，不把整张圆形贴图移动冒充渐变变化。

当前控制接口未必能直接写入每一种渐变属性。执行前读取实际可用能力和属性；组内渐变不可控制时，可评估“原生几何＋范围明确的可调渐变效果”。其编辑性和效果作用范围仍须成立，不能悄悄退化成截图贴片。两条原生方式都无法满足时说明具体能力缺口。

## 其他常见 MG 结构

| 参考表现 | 优先考虑的原生结构 | 制作前必须区分 |
|---|---|---|
| 线条逐渐画出 | 开放路径＋描边＋修剪路径 | 绘制进度、描边粗细和整条线的位置变化 |
| 阵列或放射图形 | 基础形状组＋重复器 | 规则重复与需要各自独立编辑的对象 |
| 图形相并、挖孔 | 形状路径运算或明确的蒙版组合 | 几何布尔关系与两个独立对象的前后遮挡 |
| 柔光圆或光带 | 原生轮廓与颜色＋范围明确的柔化或辉光 | 主体实体边界与外部光晕 |
| 不规则轮廓变形 | 少量语义对应的贝塞尔路径关键姿态 | 点序、切线与中间形态，不能只匹配首尾 |

形状内容包含路径、绘制操作和路径操作；选择结构时检查算子的作用范围与顺序，不机械复制一套效果栈。 上面的场景映射是本 skill 的制作建议，不是必须套用的固定模板。

## 人物海报：保留像素，最小必要拆层

先画清运动和遮挡关系。只有文字需要运动时，保留原人物像素，不生成另一张脸、不对静止人像逐帧重新分割。优先使用分层源或已验证的透明素材；普通摄影背景不默认使用色度抠图，根据背景与主体关系选择合适的人物分割或蒙版。

例如人物在第一组文字前、第二组文字后：准备必要的背景底层、后方原生文字、同一原图提取的人物前景、前方原生文字。原图已有扁平文字时，背景需清除会残留或重复出现的字；局部补全只服务于实际露出的区域，不重绘人物主体。脸部实体与发丝半透明边缘分别考虑，但不强制切成很多素材。

在做动画前，用实际背景和最大预定显示尺寸确认人物轮廓、发丝、脸颊与下巴没有被误删，透明层没有明显底色污染，文字经过时遮挡关系正确。确认后复用同一素材与蒙版，再设计文字运动。此检查是素材准备的退出条件，不是成片后的补救步骤。素材本身有低清、压缩或生成性变形时，先确认它是否足以承担目标镜头，不承诺通过修边恢复不存在的细节。

## 开始动画前的结构验收

- 关闭参考对照层，重建对象仍由自己的几何、填充和效果独立成立；参考层不作为输出内容，渲染前确认已排除。
- 在副本中试改一次尺寸、渐变颜色或文字，确认不是位图贴片，轮廓、遮挡和材质仍按预期变化；没有必要对每个对象重复同样检查。
- 明确哪些对象保留真实媒体、哪些原生重建、哪些近似；用户要求原生的部分不可用“图层数量很多”代替验收。
- 先确认稳定终态与一个关键运动过程，再扩展时序和细节。后续验收按 质量检查 (`quality.md`)，不能省略连续播放。

具体可写属性、版本差异和最终画面，以当前 AE 实际读取与预览为准。
