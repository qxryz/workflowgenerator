# 色彩、节奏与输出

用于品牌配色、视频后加工、音乐驱动、爆点转场及最终交付。按相关部分读取；修改和预览沿用用户指定的 AE 连接能力。

## 主色、辅色与调色链

主色建立整体基调，辅色区分区域，强调色引导注意；不要机械规定比例。保留原生 Shape/Text/Solid 的可改颜色与全局控制入口。效果、混合模式、灯光和调整层可能使源色与最终显示色不同，品牌色验收必须看最终画面。

Hue/Saturation 调整色相与饱和度，Curves/Levels 改变通道及明暗关系，Lumetri 或 LUT 会参与后续处理；实际作用由选项和处理顺序决定。调整层位置决定处理范围，嵌套组件的调色与总合成调色可能重复。先定位偏色来源，再修改该级，不给每一层补反向颜色掩盖全局错误。

副本实验：固定相机、光照和输入，单独旁路一个调色步骤，对比品牌文字、肤色、灰阶与高光；记录变化发生在哪一级。处理范围不应误伤需要保持原色的标识或文字。

## 音乐节奏与音频驱动

先识别重拍、乐句、停顿、情绪段落和需要对齐的声音事件。振幅峰值不是节拍标签，不能把所有峰值都变成镜头切换。读入出点、音轨选择、源偏移和合成时间；局部剪辑后的波形需与实际输出对齐。

若确需 Audio Amplitude 驱动，先确认本机具备获取振幅或将声音转换为关键帧的能力；AE 菜单提供对应命令不代表当前连接能力已支持。不能在未完成转换时声称已有振幅数据。得到驱动信号后先检查通道、范围和噪声，再设计阈值、平滑、幅度限制及时间包络，最后映射到 Scale、Glow 或 Opacity。

不要把原始振幅直接驱动所有元素。保留主动作与次级响应的层级，静音或声音低谷时不应出现无设计意义的负缩放、闪烁或失控值。用一次局部声音事件验证触发、峰值和恢复时间，听看结合检查延迟；不能只凭曲线峰值对齐就宣称音画同步。

## 爆点组合

冲击可以由短预备、主动作、次级跟随和恢复构成。Scale、Glow、相机抖动、模糊和音效按设计意图编排，峰值可接近但不要求所有参数同帧达到最大；少量先后差可形成因果与重量。字体可读和主体辨识优先于能量堆叠。

实现时给相关强度与时序明确控制入口，保持各通道可独立调整。在副本中固定声音，仅调整一个视觉通道的峰值或衰减，比较冲击帧、恢复帧和相邻镜头。检查重复触发、全片亮度突跳、抖动越界、过冲未收敛与音轨削波。

## 运动转场与效果融合

先确定注意力如何从前镜头进入后镜头，再选择运动方向、速度和匹配对象。按意图保持连续或制造有意反差；“前镜向右，后镜必须向右”不是固定规则。对象运动、相机运动和遮罩揭示可能叠加，比较最终画面中被追踪对象的速度与路径。

蒙版、Directional Blur、Glow、Displacement 和交叉淡化辅助衔接，但不能自动修复不一致的构图或错误时序。两张画面叠加期间，Add/Overlay 等可能产生亮度突峰，Multiply 可能压暗；前后素材色温或曝光不同应定位到源与调色链。

副本对照先去掉装饰效果，只看前镜出场与后镜入场是否成立，再逐个恢复效果。检查切点前后连续帧、过渡中点和短播放，包含 alpha 边缘、黑边、亮度、速度与声音。不要只检查两张首尾静帧。

## 色彩空间与 LUT

记录输入素材的颜色解释、工程色彩引擎/工作空间/位深、显示变换及输出变换。输入到工作空间和工作到输出空间是不同步骤；显示预览与导出处理也不能混为一谈。不存在一个适合全部任务的“电影感色彩空间”。

采用 LUT 前确认它预期的输入编码/色域和输出作用，是技术转换还是创意外观。不要给已转换的素材重复做同一技术转换；不明来源的 LUT 不能凭名称判定兼容。检查工作色彩管理、效果中的转换和输出设置是否重复或遗漏，并保留旁路对照。

Rec.709 输出和 ACES 工作流程不是二选一：项目可在适合的工作流程中处理后转换到交付空间。只有任务、素材和宿主能力需要时才采用 ACES/OCIO；先读取真实配置、输入空间和显示/输出变换，不为了“高级”切换已有工程。

Linearize、位深和超白处理会改变 Glow、Add 和其他效果结果，不能在制作末尾随意切换并假定外观相同。对现有工程先保存副本、保留基线。比较灰阶、品牌色、暗部、高光和透明边缘，并用实际导出文件复核；播放器截图差异不能单独证明像素色值错误。

## 输出联动

输出规格来自用户需求与实际目标平台：宽高、像素宽高比、帧率、时间范围、音频、alpha 和色彩要求。更改输出尺寸不自动重排安全区；更改输出 fps 不等于对关键帧重新定时。需要重定时则读取 动画与时间 (`animation-dependencies.md`)。

Render Queue / Output Module 决定实际渲染设置与编码输出，先查询本机模板和能力。透明交付检查 alpha、预乘/直通解释及目标软件支持，不能承诺 H.264 MP4 带透明通道。工程、渲染器和依赖影响可复现性，文件存在不代表交付合格。

按 交付验收 (`quality.md`) 检查媒体流和实际播放，回看首尾范围、模糊、音画、颜色及长宽比。输出色彩异常时依次排查素材解释、工程工作/显示变换、输出变换与播放器解释，不直接用额外 LUT “压回去”。
