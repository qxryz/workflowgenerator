# 场景工作流

## 从零制作与静态设计动画化

先识别主信息、辅助信息、品牌元素、阅读顺序和留白。保留用户已经确定的静态设计；动画应服务信息出现与视线转移，不能默认把所有层都弹跳、旋转或同时运动。

- 有分层/矢量源：按语义保留文字、图形、产品与装饰，核对源与重建静帧后设计运动。PSD/AI 等的导入模式和可编辑内容须在当前宿主实际验证；不假设任意导入都会保留图层。
- 只有位图：按 素材准备原则 (`native-reconstruction.md`) 保留照片中的人物／产品像素，只重建要独立编辑的文字与图形，按实际遮挡拆分必要区域。先确认可复用的透明层与背景，再制作动画；不能声称自动恢复原图层。复杂背景拆分若会损伤视觉，应说明取舍。
- 用入场、停留、出场划分时间；根据文案长度和用户场景确定阅读时间，动态模糊中的字符不算稳定可读。
- 先检查静止终态，再做主动作、次级动作与转场；简单任务可直接执行。长片按场景构建，在总合成安排节奏，不把全部图层堆进无结构的单合成。

## Design 视频与图形合成

保留原视频、帧率、时间段和色彩信息，确认使用哪条音轨。已有 H3 或其他生成素材不重复生成；视频生成需要用户意图和宿主实际工具支持，AE skill 不自行选择模型或购买生成。

将媒体作为独立可替换层/槽；标题、Logo、标注、遮罩和质感效果保持独立。关注主体避让、对比度、视频运动与文字运动是否竞争。裁切使用明确的 contain/cover 与焦点，不能因横竖版适配切掉产品或人脸。跟踪、抠像、复杂反射等先确认可用能力，不把手动画几个位置键宣称为精确跟踪。

## 视频的 AE 原生图层级重建

先按 原生重建与素材准备 (`native-reconstruction.md`) 选择几何、填充、显隐与效果的职责。可原生表达的 MG 图形不从参考帧裁切再套形状轮廓；人物摄影素材则按运动与遮挡保留原像素，不能为了全原生形式重画人脸。

1. 读取媒体规格、参考时间区间与音频安排。先全片了解叙事，再抽取切点、主要姿态与转场；运动快速时加密采样，不能只看首尾帧。
2. 建立镜头表：时间、背景/素材、前景文字/图形、层级遮挡、运动/镜头、实现类型、置信度。拆分对象自身运动与相机运动，辨别切换、遮罩揭示和形变。
3. 对每类元素选择结构：原生文字、形状/路径、遮罩、预合成、可调效果、动画控制，以及不确定或需要近似的部分。真实纹理与复杂现象先评估原生效果是否满足要求；仅在任务允许媒体合成时采用可替换素材。参考可用于分析与对照，不自动成为输出底片；纯原生任务尤其如此。
4. 优先匹配轮廓、构图、文字、关键姿态与时间；按 运动曲线设计 (`motion-curves.md`) 在代表片段中拟合启动、峰值速度、减速、停留与交接，验证后再完善渐变、材质与细节。缩放和旋转与位置同样需要按设计处理；不能先把全片写成线性键再当作制作完成。临摹静帧不等于复刻运动。外观重要但语义不明的形变，先做小样确认中间态不自交。
5. 用相同时间点与尺寸对照结果，检查主要切点前后、运动中段和停留。针对偏差修改局部，不通过给整条视频添加固定装饰冒充逐镜头重建。

验收时分别检查：视觉上是否还原构图、形态、材质与运动；结构上能否独立修改文字、图形、颜色、路径、出现时间与效果参数。按语义拆分需要独立修改的对象，不必机械地一对象一层；同层形状组也可以提供合理编辑入口。只增加图层数量或把图片切成多块，不能证明重建达标。

## 实际 SVG 源文件处理

仅在输入确实含 SVG 或用户明确要求 SVG 交付时使用本节。视频的 AE 原生图层级重建不以 SVG 为必经中间格式。

SVG 输入不意味着可以直接原生导入或导出 SVG 动画。读取 viewBox、transform、path、fill/stroke、clip/mask 的语义；若导入不保留所需编辑结构，使用经过验证的转换方式建立原生 Shape/文字。贝塞尔控制点需转换为相对顶点切线；椭圆弧需可靠转换，不能把路径字符串直接赋给 Shape。SVG filters、复杂渐变和字体缺失需要逐项映射/验证，明确近似。AE 原生结构与 SVG 的可表达范围不同。

## UI 与交互演示

把界面状态、触发动作、反馈、结果串成因果序列。指针到达后才点击，反馈应与点击关联；用户没有做的操作不凭空插入。组件内部文字、背景、图标和外部整体运动解耦。透视推拉只用于建立焦点，关键文字停留时应足够大且清晰。真实头像/插画若使用素材，应标为媒体；用矢量替代时说明差异。

## 品牌、信息与数据动画

品牌复用的是排版规则、颜色、节奏和运动语法；不要把每个镜头变成相同入场。保留少量有用的风格控制，而非几十个无说明参数。

信息图先定义出现顺序和连接关系，连接端点随对象/父级/镜头变化；数据图保留真实数值、单位、比例和标签。动画不能改变数据含义；不要让插值经过不允许的数值范围。数值动画结束时检查准确终值与格式。

## 版本、循环与交付格式

多语言与横竖版属于重新排版，按组件重排、换行、保留焦点，不能只缩放整幅画面。复用组件前按 工程修改规则 (`editable-projects.md`) 判断共享源与独立副本。

循环检查接缝处的位置、速度、透明度、材质随机性和音频；首尾静帧相同不证明运动连续。定义循环周期，避免重复首帧造成停顿。

透明背景需验证合成 alpha、编码与目标播放器支持；MP4/H.264 不作为透明交付承诺。Web/Lottie/SVG 动画输出需要另外确认导出器和效果支持，不能把任意 AE 效果称为可导出矢量动画。仅按用户要求提供实际支持的格式。
