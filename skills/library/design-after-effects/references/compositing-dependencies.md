# 合成与效果联动

用于处理嵌套、遮挡、蒙版、效果链和图层质感。先读取实际图层、效果顺序、合成设置与引用对象，再进行局部修改。需要实验时遵循 副本对照方法 (`project-analysis.md`)。

## 图层顺序与预合成

二维叠放中，上层结果覆盖/混合下层结果；父子级主要传递变换，不决定前后遮挡。调整层处理其下方适用的合成结果，实际范围受合成边界、遮罩和渲染结构影响。3D 深度排序、交叉、2D 层插入和渲染器使情况更复杂，不能只按时间线层号解释所有画面。

预合成封装结构，也形成渲染边界。关闭 Collapse Transformations 时，源合成通常先形成二维结果再作为外层输入；开启会合并变换并改变渲染顺序及 3D 参与方式，不只是提高清晰度。外层效果、蒙版、混合模式、调整层和内部相机都需要重新核对，不能把开关当作所有嵌套问题的默认修复。

Continuously Rasterize 与 Collapse 使用相似开关位置，但应用对象和目的不同。矢量连续栅格化不使位图变为矢量，也不保证任意滤镜链与开关前相同。普通未连续栅格化图层的默认处理顺序为蒙版、效果、变换；连续栅格化会改变顺序，因此放大、模糊和边缘范围可能变化。

诊断方法：在副本中固定主合成时刻，分别预览源合成与外层结果，仅切换相关折叠开关，比较清晰度、镜头透视、遮挡、边缘裁切和效果范围。即使局部更清晰，也要回主合成检查。需要独立版本时按 共享源规则 (`editable-projects.md`) 复制必要依赖，不能只复制外层实例。

## 蒙版与轨道遮罩

| 参数 | 联动与影响 | 决策与验证 |
|---|---|---|
| Mask Path | 路径处在被作用图层的局部空间，图层变换会改变其屏幕位置 | 定义开闭、点序和路径插值；检查图层同时运动时的揭示位置，不只看路径首尾 |
| Mask Mode / 多蒙版 | Add、Subtract、Intersect 等决定区域组合 | 读实际模式与反转，先隔离单个蒙版再恢复组合，避免把模式错误归因于羽化 |
| Feather / Expansion / Opacity | 分别影响边缘软化、边界扩缩及蒙版贡献，后续模糊和辉光可进一步改变观感 | 固定路径，分别调整一个参数。检查主体边缘是否被吃掉及柔边在主合成上的范围 |
| Alpha Matte | 以遮罩源透明度决定显示区域 | 在保持 alpha 的前提下改遮罩 RGB 不应被当作亮度遮罩调节；查实际通道与反转 |
| Luma Matte | 使用遮罩源亮度形成遮罩 | 改色、曝光、模糊或调色链可能改变遮罩结果；同时检查源 alpha 与最终边缘 |
| 共享 Matte 源 | 多个对象可被同一来源驱动，修改会传播 | 枚举实际引用者，局部修改需要独立遮罩时再复制源 |

Track Matte 与 Mask 是不同结构。现代 AE 支持显式选择遮罩来源，多个层可共用，不能强制假定必须紧邻上一层。旧版本或旧接口可能依赖层顺序；先探测当前版本和实际支持能力，绑定后读回来源、类型和反转状态。不要为兼容猜测而无条件重排用户工程。

蒙版对效果的具体作用还涉及效果的 Compositing Options、效果顺序和源边界。若要只限制某个效果，优先确认其合成选项或采用明确预合成结构，不默认一个图层蒙版能独立约束任意效果。

## 效果堆栈与混合模式

需要从参考外观选择和搭建液态、扭曲、置换、光扫、拖尾或纹理时，读取 效果制作 (`effects-construction.md`) 的相关段落；本节负责效果之间的合成关系。

效果一般按堆栈由上到下处理，后续效果读取前序结果。Blur 后接 Glow 与反过来通常不同，但“哪种更柔/更好”取决于亮度、阈值、半径、alpha 与工作色彩空间，须对照实际帧，不写成固定审美定律。

- Blur：核对源边界、Repeat Edge Pixels 等实际选项、预合成裁切和蒙版。增大半径不能修复错误边界。
- Glow：先查输入亮度、阈值、半径、强度和合成模式。亮部截断或过曝时先修输入/色彩链，不连续叠加辉光。
- CC Force Motion Blur：确认运动由何处生成、子帧采样及开销；与普通图层模糊分开检查，避免双重拖影。
- Blend Mode：控制该层结果与下方结果的结合。Add 类操作易抬高亮部，Multiply 常用于压暗，Overlay 根据输入改变对比；效果受色彩空间、位深和 alpha 影响，不等同于某个固定亮度百分比。
- Adjustment Layer：适合统一范围处理；放入组件内部或总合成会作用于不同输入。需要保留品牌文字颜色时明确处理范围，而不是全片套一个 LUT。

对照实验固定素材和参数，只交换两个效果的顺序，再查看边缘、亮部和 alpha；另做一次相同效果位于普通层与调整层的范围对照。预览需回到最终分辨率核对颗粒、细线和光晕尺寸。

## 第三方插件与原生替代

知道插件名称不等于本机已安装或当前连接能力可操作。先查询可用效果，再读取实际属性树、版本和当前渲染器兼容性；参数名、枚举和层引用按本机结果。仅在任务确需时使用，不因知识表列出插件就要求安装全部插件。

| 插件场景 | 需要追踪的驱动 | 最小验证与替代边界 |
|---|---|---|
| Particular 粒子 | 发射器类型、位置/层/灯光输入、粒子出生与寿命、速度/力、随机种子、相机 | 在短区间只改发射器位置或强度，检查粒子历史与空间跟随。原生重复图形可替代部分装饰粒子，不等价于完整粒子物理 |
| Saber 能量描边 | Core 类型、Mask/Text 源、路径动画、起止偏移、辉光与背景合成 | 先验证指定源能驱动线条，再动路径或起止参数。Shape + Trim Paths + Glow 可近似部分线条，但不保证相同材质 |
| Optical Flares 光晕 | 位置来源、是否跟随灯光、亮度、遮挡、镜头与工作色彩空间 | 改一个实际驱动源，检查屏幕投影及遮挡。原生光晕/图形叠加的替代需说明与原插件差异 |

以上是按插件类别选择检查点，不是特定版本 API 保证。需要调用时查供应商对应版本文档与本机属性；无法验证就标为待验证，不能声称已实现。打包报告实际依赖，缺插件的副本应保留可编辑结构并说明视觉差异。
