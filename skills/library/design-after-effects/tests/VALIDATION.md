## 触发自查与流程推演

案例见 scenarios.json (`scenarios.json`)。前三项是应触发的画布动画化、英文 AEP 局部编辑和纯原生参考重建；后三项是不应触发的纯视频生成、静态海报和单纯格式转换。仅依据两个入口的名称与描述做人工自查，预期分流一致；未运行模型触发评测。

产品卡片案例的桌面推演：独立产品图与标题 → 保留源角色、版本及本地文件 → 检查 AE 与现有工程 → 验证代表片段 → 保存工程并生成预览 → 取得真实画布关联后交接 → 从输出版本定位原工程，仅调整标题对应时间 → 检查非目标内容并交付新版本。每一阶段的输出能作为下一阶段输入，缺失文件、回传能力或对象映射时均有明确处理分支。

异常案例还覆盖 AE 不可用、上传不可用与要求原生画布节点转换。两种语言的目标、阶段顺序、询问条件、编辑性边界与交付规则已人工对照；共享中文知识文件不是新增的英文翻译版本。

## 0.7.0 启动恢复与权限诊断

- 依据实际失败会话修正：两个对话相隔约半分钟启动同一 AE，第二次遇到占用即退出；第一次无面板确认。现场检查显示切换语言后的活动设置关闭了脚本文件与网络访问，而旧语言配置中该开关开启。
- 兼容启动在加载面板前读取活动 AE 的权限和渲染状态。macOS 通过脚本返回值报告权限关闭，不依赖已被该权限禁止的响应文件；新诊断模式只查询运行中的应用，不启动或重载。序列化不依赖预先存在的 JSON 全局。
- 显式权限修复仅在对应用户授权后开启所需开关，保存并回读；默认不修改权限，渲染期间不改变设置或加载。Windows 可用此显式模式加载并取得确认；未授权且无法取得同步诊断时仍需可用界面能力核实活动设置。
- 启动锁新增所有者、有效期、唯一执行路径和有界等待；过期且进程已结束才回收，活动锁和未知旧锁不删除。等待结束或回收后交回连接验证，不自动重复加载。它不是制作写入的锁。
- 45 项隔离脚本测试通过，包含原有流程及新增权限关闭、无 JSON 全局、授权开启、读取未生效、语言偏好差异、并发复查、死进程过期锁、活动进程、未知锁和符号链接保护。
- 新增三个待人工验证场景。此次未执行实际权限修改、面板重载、AE 制作或客户端重启；Windows 系统调用和 AE 脚本环境使用模拟。隔离测试不等于真实端到端通过。
