# 付费点设计指南

## 三大设计原则

### 1. 情感峰值原则
付费点必须设在观众情绪最高涨的时刻，而非平淡叙事中。

### 2. 悬念未解原则
付费墙放在"答案即将揭晓但还差一步"的位置，利用好奇心缺口驱动付费。

### 3. 沉没成本原则
观众已投入大量时间精力追到此处，利用"不看完就亏了"的心理。

## 黄金付费位置

| 付费墙编号 | 位置（按总集数比例） | 功能 |
|-----------|---------------------|------|
| 第一道墙 | 8–12 集 | 首次付费转化（最重要！） |
| 第二道墙 | 18–25 集 | 留存巩固 |
| 第三道墙 | 35–45 集 | 深度锁定 |
| 终极墙 | 倒数 3–5 集 | 完结收割 |

### 密度控制公式

| 总集数 | 建议付费集数 | 密度 |
|--------|-------------|------|
| 50 集 | 8–10 集 | 16–20% |
| 80 集 | 12–16 集 | 15–20% |
| 100 集 | 15–20 集 | 15–20% |

## 5 大付费点模式

### 模式一：身份即将揭露

**场景**：主角的隐藏身份/真实关系即将被所有人知道

**示例**：
```
△ 宴会上，大屏幕突然亮起。
**反派**（得意）：
"各位，让我来揭露这个骗子的真面目——"

△ 屏幕上开始播放一段视频。
△ 特写 — 女主脸色骤变。

【本集结束 · 解锁下一集】
```

**设计要点**：
- 视频/文件/DNA 报告等"证据"即将公开
- 所有在场人物的反应尚未展开
- 观众最想知道的是"真相是什么"和"大家会怎么反应"

---

### 模式二：生死一线

**场景**：主角或重要角色命悬一线

**示例**：
```
△ 手术室外，红灯亮起。
**医生**（推门出来，摘下口罩）：
"家属，患者的情况……"

△ 医生顿了顿，表情凝重。

**女主**（抓住医生的手）：
"他怎么样了？求求你告诉我！"

**医生**：
"你需要做好……心理准备。"

△ 女主腿一软，瘫倒在地。

【本集结束 · 解锁下一集】
```

---

### 模式三：情感爆发中断

**场景**：积压的情绪即将爆发，在最高点戛然而止

**示例**：
```
**男主**（红了眼眶，握紧拳头）：
"这五年，你知道我为什么一直忍着不说吗？"

**女主**（后退一步）：
"什么……你在说什么？"

**男主**（一步步逼近）：
"因为你根本不知道，那个孩子——"

△ 男主突然停住，目光越过女主，看向门口。
△ 特写 — 一个小男孩站在门口，眼中含泪。

**小男孩**：
"爸爸……？"

【本集结束 · 解锁下一集】
```

---

### 模式四：反派得逞

**场景**：反派的阴谋成功，局势急转直下

**示例**：
```
**女主**（看着手机屏幕，手在颤抖）：
"这不可能……公司所有股权……都转到了她名下？"

**闺蜜**（打来电话，声音焦急）：
"你赶紧看微博热搜！他们把你的照片发出来了！"

△ 女主打开微博。热搜第一：#XX集团千金竟是假冒的#

△ 手机从手中滑落。

【本集结束 · 解锁下一集】
```

---

### 模式五：真相即将浮出水面

**场景**：关键线索/证据被发现，真相只差一步

**示例**：
```
△ 女主翻开日记本的最后一页，一张泛黄的照片掉了出来。

△ 特写 — 照片上两个年轻人，一个是自己的母亲，另一个……

**女主**（瞳孔骤缩）：
"这个人……怎么会是他？"

△ 门突然被推开。
**管家**（站在门口，脸色苍白）：
"小姐，这间房……您不应该进来的。"

【本集结束 · 解锁下一集】
```

## 付费点设计禁忌

1. **❌ 无悬念硬切**：不能在平淡叙事中突然结束
2. **❌ 假悬念**：下一集开头就用 30 秒轻松化解的不算悬念
3. **❌ 过度密集**：连续 3 集以上都是付费点会导致用户流失
4. **❌ 关键信息前置**：不要在付费墙前就把答案说了
5. **❌ 情绪断裂**：付费墙不能打断喜剧/轻松氛围的段落

## 免费集 vs 付费集的节奏配合

| 集型 | 节奏 | 功能 |
|------|------|------|
| 免费集 | 中速，制造期待 | 铺垫情感、建立牵挂 |
| 付费集 | 快速升温 → 高潮 → 戛然而止 | 引爆情绪、驱动付费 |
| 付费后首集 | 快速回报 → 新悬念 | 验证付费值得 + 锁定下次 |
