# 节奏曲线系统

## 单集微观结构

每集时长约 1.5–3 分钟，内部节奏遵循三段式：

| 段落 | 时长占比 | 功能 | 节奏 |
|------|----------|------|------|
| 开头 | 前 30 秒 | 钩子 + 回顾 | ⚡ 快 |
| 中段 | 1–1.5 分钟 | 冲突升级 | 📈 递进 |
| 结尾 | 后 30 秒 | 爽点/钩子 | 💥 爆发 |

### 单集节奏禁忌
- ❌ 开头铺设背景超过 15 秒
- ❌ 中段连续对话无动作超过 45 秒
- ❌ 结尾没有明确的情绪锚点或悬念

### 第一阶段：起势期（前 15% 集数）

| 项目 | 说明 |
|------|------|
| 集数范围 | 第 1–8 集（80 集剧本） |
| 节奏特征 | 中速启动，快速建立人物和矛盾 |
| 情绪强度 | 1→2.5 |
| 核心任务 | 建立主角人设、核心矛盾、主要关系、第一个小高潮 |
| 禁忌 | ❌ 前 3 集无冲突纯铺垫 / ❌ 一次性介绍超过 5 个角色 |

**节奏节点**：
- 第 1 集：强力开场（参考开场模板）
- 第 3 集：第一个小反转
- 第 5–8 集：第一道付费墙前的情绪积蓄

---

### 第二阶段：攀升期（15%–45% 集数）

| 项目 | 说明 |
|------|------|
| 集数范围 | 第 9–36 集 |
| 节奏特征 | 波浪式递进，每 5–8 集一个小高潮 |
| 情绪强度 | 2.5→3.5 |
| 核心任务 | 展开支线、角色成长、敌我升级、感情线推进 |
| 禁忌 | ❌ 连续 5 集无爽点 / ❌ 支线抢占主线篇幅 |

**节奏节点**：
- 每 5–8 集制造一个"阶段性胜利"或"阶段性危机"
- 感情线在这一阶段完成"相识→暧昧→误会→确认"
- 中期高潮（约第 25–30 集）：一次重大反转或身份揭露

---

### 第三阶段：风暴期（45%–80% 集数）

| 项目 | 说明 |
|------|------|
| 集数范围 | 第 37–64 集 |
| 节奏特征 | 密集冲突，高潮频率加倍 |
| 情绪强度 | 3.5→4.5 |
| 核心任务 | 终极反派登场、最大危机爆发、联盟瓦解/重建 |
| 禁忌 | ❌ 引入全新主线 / ❌ 感情线原地踏步 |

**节奏节点**：
- 大 Boss 真面目揭晓
- 主角"至暗时刻"（最低谷）
- 背叛/误解的极致冲突
- 每 3–5 集一个高潮

---

### 第四阶段：决战期（最后 20% 集数）

| 项目 | 说明 |
|------|------|
| 集数范围 | 第 65–80 集 |
| 节奏特征 | 全面加速，不留喘息 |
| 情绪强度 | 4→5（峰值） |
| 核心任务 | 终极对决、所有伏笔回收、情感升华 |
| 禁忌 | ❌ 新增角色 / ❌ 开新支线 / ❌ 拖沓的告白场景 |

**节奏节点**：
- 终极反转（隐藏 Boss 揭露）
- 最终决战
- 情感高潮（表白/和解/牺牲）
- 大结局 + 彩蛋（可选）

## 节奏调控工具

### 加速工具（提升紧张感）

| 工具 | 效果 | 适用场景 |
|------|------|----------|
| 短场次 | 快速切换制造紧迫感 | 追逐、对峙 |
| 交叉剪辑 | 多线并进增加信息密度 | 危机倒计时 |
| 倒计时 | 明确的时间压力 | 救援、破案 |
| 省略时间跳跃 | 跳过过渡直达冲突 | 节奏拖沓时 |
| 连续打脸 | 一集内多次反转 | 爽剧高潮 |

### 减速工具（情感沉淀）

| 工具 | 效果 | 适用场景 |
|------|------|----------|
| 对话场景 | 深入角色内心 | 关系转折点 |
| 闪回 | 补充前史、制造共情 | 角色动机揭示 |
| 日常切片 | 轻松互动缓解紧张 | 高潮后的缓冲 |
| 独白 | 角色心理展示 | 重大决定前 |
| 空镜 | 留白制造氛围 | 情绪转换 |

| 类型 | 起势期特点 | 风暴期特点 | 结局节奏 |

| 霸总 | 快速心动 | 误会虐恋 | 甜蜜收官 |

| 家庭伦理 | 矛盾触发 | 情感撕裂 | 和解/正义 |

## 每 5 集节奏自检

每写完 5 集，检查以下指标：

- [ ] 这 5 集有至少 1 个明确的爽点/高潮吗？
- [ ] 情绪强度是否比前 5 集有所递进？
- [ ] 是否有冗余段落可以删减？
- [ ] 主线是否有实质推进？
- [ ] 钩子是否足够强力？
