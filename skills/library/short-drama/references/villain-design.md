## Tier 1：小反派（炮灰型）

**活跃区间**：前 15% 集数
**功能**：让主角初露锋芒，建立"打脸"模式，给观众第一波爽感

### 特征
- 眼界狭隘，嚣张跋扈
- 实力/地位远低于主角（主角可轻松碾压）
- 背后通常有 Tier 2 撑腰

### 典型角色
| 类型 | 角色举例 |
|------|----------|
| 霸总剧 | 公司小经理、前男友、势利亲戚 |
| 战神剧 | 街头混混、保安队长、嘴贱同事 |
| 重生剧 | 前世欺负过主角的小人 |
| 宫斗剧 | 低阶嫔妃、太监、碎嘴宫女 |

### 处理方式
- **快速解决**：1–3 集内被打脸/制裁
- **不拖泥带水**：炮灰不值得多花笔墨
- **功能性退场**：被解决后为 Tier 2 登场铺路

### 示例设计
```
角色名：王强（小舅子）
身份：女主弟弟，啃老族
性格：势利眼、欺软怕硬
核心行为：看不起姐夫（主角），当众嘲讽
退场方式：在第 5 集被主角亮身份当场打脸，跪地求饶
关联 Tier 2：背后受母亲（岳母）指使
```

## Tier 2：中反派（主要对手）

**活跃区间**：15%–45% 集数
**功能**：主角的主要磨刀石，需要多次较量才能战胜

### 特征
- 有一定实力和资源
- 有自己的动机（不是纯粹的"坏"）
- 至少与主角正面交锋 3 次

### 三回合击败模式（必须遵循）

| 回合 | 结果 | 功能 |
|------|------|------|
| 第一回合 | 主角吃亏 | 建立威胁感 |
| 第二回合 | 势均力敌 | 展示主角成长 |
| 第三回合 | 主角胜出 | 制造爽感 |

### 典型角色
| 类型 | 角色举例 |
|------|----------|
| 霸总剧 | 商业对手、白月光前任、公司副总 |
| 战神剧 | 地方豪强、军区对手、黑帮头目 |
| 重生剧 | 前世的帮凶、关键节点的阻碍者 |
| 宫斗剧 | 宠妃、太后身边的人 |

### 深度设计要求
- **动机合理**：不能只是"为了坏而坏"
- **有可取之处**：让观众觉得"如果他不是反派，其实挺厉害的"
- **退场有仪式感**：被打败时要有"名场面"

### 示例设计
```
角色名：赵天明
身份：竞争公司 CEO
动机：父亲被主角家族挤出市场，立志复仇
性格：表面温文尔雅，内心阴险狡诈
三回合设计：
  R1（第 12 集）：暗中收购主角的供应商，让主角项目停摆 → 主角被动
  R2（第 22 集）：主角联合盟友反击，两人在商业峰会上正面对决 → 平手
  R3（第 30 集）：主角揭露他的黑历史，董事会倒戈 → 赵天明出局
退场名场面：在空荡荡的办公室里，看着父亲的照片说"爸，对不起"
关联 Tier 3：背后还有更大的黑手
```

## Tier 3：大反派（终极对手）

**活跃区间**：45% 集数以后（但可以提前出场铺垫）
**功能**：整个故事的终极 Boss，代表主角必须克服的最大障碍

### 特征
- 实力/权力/资源远超前面所有反派
- 与主角有深层关联（血缘、师徒、恩人等更佳）
- 有完整的世界观和行为逻辑
- 具备"最终 Boss"的仪式感

### 典型角色
| 类型 | 角色举例 |
|------|----------|
| 霸总剧 | 家族掌权人、背后财团大佬 |
| 战神剧 | 叛国将领、黑暗势力首领 |
| 重生剧 | 前世害死主角的幕后黑手 |
| 宫斗剧 | 太后、摄政王 |

### 设计要点
- **层层揭露**：大反派的真面目不要一次性暴露
- **有魅力**：观众应该又恨又"服"
- **对主角的威胁是全方位的**：不仅是实力，还有情感、道德层面

## Tier 4：隐藏 Boss（终极反转）

**活跃区间**：最后 20% 集数揭露
**功能**：制造最大反转，颠覆观众认知，提升剧作深度

### 特征
- 之前一直以友好/中立身份出场
- 至少有 3 处以上的伏笔暗示
- 揭露时所有前期"不合理"的细节都说得通了
- 动机必须有深度（不能是简单的贪婪/嫉妒）

### 伏笔设计模板

| 伏笔层级 | 位置 | 设计方式 |
|----------|------|----------|
| 第一层 | 前 20% | 一个不经意的细节（观众看不出来） |
| 第二层 | 30–50% | 一次反常行为（细心观众会注意到） |
| 第三层 | 60–80% | 一个矛盾点（观众开始怀疑） |
| 揭露 | 80%+ | 全盘揭示（前面的一切都串联起来） |

### 伏笔示例
```
伏笔一（第 8 集）：
师父在主角受伤时，翻了翻手机，欲言又止。（观众觉得是担心）

伏笔二（第 28 集）：
师父正好"出差"没来，而那天主角遭遇了最大的危机。（观众觉得巧合）

伏笔三（第 50 集）：
师父的旧照片里，他和大反派站在一起。（观众开始怀疑）

揭露（第 65 集）：
原来师父才是真正的幕后操控者，他培养主角只是为了让主角替他完成复仇计划。
前面所有的"巧合"都是他精心安排的。
```

## 反派递进规则

1. **不能跳级**：不能让 Tier 1 直接升级为 Tier 3
2. **击败低阶 → 暴露高阶**：每击败一个反派，要暴露"幕后还有人"
3. **实力递增**：每一阶反派给主角的压力必须比上一阶更大
4. **关系递深**：反派与主角的关系越来越深、越来越复杂

## 让反派"可恨"的技巧

| 手法 | 说明 | 效果 |
|------|------|------|
| 欺负弱者 | 让反派欺负老人、孩子、弱者 | 激发义愤 |
| 背叛 | 反派曾经是盟友/朋友 | 增加痛感 |
| 双标 | 对自己宽容对别人严苛 | 增加厌恶 |
| 嘴贱 | 羞辱性的台词 | 制造打脸期待 |
| 阻断爱情 | 故意拆散 CP | 观众最不能忍 |

## 反派对白风格指南

| Tier | 说话方式 | 示例 |
|------|----------|------|
| T1 | 直白嚣张、粗鲁 | "你算什么东西？" |
| T2 | 阴阳怪气、暗藏威胁 | "你很优秀，但可惜……站错了队。" |
| T3 | 从容自信、居高临下 | "在我面前，你的挣扎毫无意义。" |
| T4 | 温和慈祥（反差最大） | "别担心，一切都会过去的。" |
