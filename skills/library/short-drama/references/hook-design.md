# 钩子设计指南

## 5 大钩子类型

### 类型一：悬疑钩子

**定义**：在结尾制造未解之谜，激发好奇心。

#### 子模式

| 子模式 | 示例 | 使用频率 |
|--------|------|----------|
| 神秘来客 | 门铃响了，门外站着一个不该出现的人 | 每 8–10 集 |
| 信息残缺 | "真相是……"（被打断/画面切走） | 每 5–8 集 |
| 异常发现 | 翻到了一张不该存在的照片/文件 | 每 6–8 集 |
| 身份线索 | 看到对方身上与自己相同的胎记/信物 | 关键节点 |

#### 示例脚本
```
△ 女主整理遗物，从旧皮箱底部翻出一个信封。
△ 信封上写着："如果你找到这封信，说明我已经不在了。"

△ 她拆开信，读了第一行——

△ 手指开始颤抖。
△ 特写 — 信纸上的字迹。
△ 画面渐黑。

🎣 信里到底写了什么？

【下集预告】
"你知道吗？你的整个人生……都是一场骗局。"
```

### 类型二：反转钩子

**定义**：在结尾抛出颠覆本集认知的信息。

#### 子模式

| 子模式 | 示例 | 使用频率 |
|--------|------|----------|
| 阵营反转 | 帮助主角的人在暗处露出诡异笑容 | 每 10–15 集 |
| 事实反转 | 本集建立的"真相"被最后一秒推翻 | 每 8–10 集 |
| 身份反转 | 亲人/朋友的真实身份不是所呈现的 | 关键节点 |
| 计划反转 | 以为成功了，实际中了圈套 | 每 6–8 集 |

#### 示例脚本
```
△ 主角在书房里，对着手机微笑。
**主角**（打电话）：
"嗯，一切都按计划进行。他完全信任我了。"

△ 他挂了电话，拿起桌上的照片框——
△ 照片里，他和本集中被他"拯救"的女主站在一起。
△ 但照片的另一半被撕掉了。

△ 他的目光冰冷。

🎣 他到底是谁？他的真正目的是什么？
```

### 类型三：情感钩子

**定义**：在结尾制造情感的高峰或突变。

#### 子模式

| 子模式 | 示例 | 使用频率 |
|--------|------|----------|
| 突然告白 | "其实我……"（被打断/自我中断） | 关键节点 |
| 心碎瞬间 | 看到不该看到的画面（误会型） | 每 5–8 集 |
| 牺牲预兆 | "如果明天我不在了，记得……" | 高潮前 |
| 回忆杀 | 突然闪回一段揭示真情的记忆 | 每 8–10 集 |

#### 示例脚本
```
**女主**（在雨中，看着男主和另一个女人打着伞走过）：
△ 她的手慢慢松开了紧握的手机。

△ 手机屏幕亮着，上面是她刚打好但没发出去的消息：
"我喜欢你。从很久很久以前就开始了。"

△ 她按下了删除键。
△ 泪水和雨水混在一起。

🎣 她的心意，他永远都不会知道了吗？
```

### 类型四：信息钩子

**定义**：在结尾释放一个关键信息，改变局势走向。

#### 子模式

| 子模式 | 示例 | 使用频率 |
|--------|------|----------|
| 第三方介入 | "XX 来了"/"XX 回来了" | 每 8–10 集 |
| 秘密暴露 | 关键秘密被非预期的人知道了 | 每 5–8 集 |
| 新威胁 | 解决完一个问题，更大的问题浮现 | 每 6–8 集 |
| 时间炸弹 | "你只有 72 小时" | 高潮前 |

#### 示例脚本
```
△ 庆功宴上，所有人举杯庆祝。

**助理**（匆匆跑来，脸色苍白）：
"总裁……不好了。"

**主角**（放下酒杯）：
"什么事？"

**助理**：
"陈家……他们请了许律师。"

△ 全场笑声骤停。所有人的表情都变了。

**主角**（瞳孔微缩）：
"许……许正阳？"

△ 助理点头。

🎣 许正阳是谁？为什么所有人听到这个名字都如此恐惧？
```

### 类型五：危机钩子

**定义**：在结尾将主角或重要角色推入危险境地。

#### 子模式

| 子模式 | 示例 | 使用频率 |
|--------|------|----------|
| 生命危机 | 车祸/坠楼/中毒/被绑架 | 每 10–15 集 |
| 关系危机 | 被迫做出二选一的抉择 | 每 5–8 集 |
| 信任危机 | 最信任的人背叛的证据出现 | 每 8–10 集 |
| 局势危机 | 全盘计划被打乱/敌人反扑 | 每 6–8 集 |

#### 示例脚本
```
△ 女主独自走在停车场。
△ 她按下车钥匙，车灯闪了两下。

△ 她拉开车门——
△ 副驾驶座上，放着一束白色百合花。

△ 花中间夹着一张纸条：
"你以为换了城市就能躲开我？"

△ 女主猛然回头。
△ 停车场的灯一盏接一盏地灭了。

🎣 跟踪她的人到底是谁？
```

## 钩子叠加规则

### 可叠加组合（效果加倍）
- 悬疑 + 反转："神秘人出现"+"他竟然是……"
- 情感 + 危机："刚要告白"+"突然出事"
- 信息 + 悬疑："得到关键线索"+"线索指向意想不到的人"

### 不可叠加组合（互相抵消）
- 悬疑 + 信息：同时制造谜团又给出太多信息 → 混乱
- 两个同类型钩子：一集结尾两个悬念 → 分散注意力

## 钩子与付费墙的关系

| 付费墙模式 | 搭配钩子类型 | 效果 |
|-----------|-------------|------|
| 身份揭露 | 悬疑钩子 | "想知道他是谁？付费看" |
| 生死一线 | 危机钩子 | "他能活下来吗？付费看" |
| 情感爆发 | 情感钩子 | "她会原谅他吗？付费看" |
| 反派得逞 | 反转钩子 | "主角怎么翻盘？付费看" |
| 真相浮出 | 信息钩子 | "真相是什么？付费看" |

## 钩子质量自检

- [ ] 钩子是否在本集情绪最高点？
- [ ] 观众是否会产生"必须知道接下来"的冲动？
- [ ] 下一集是否能在 30 秒内回应钩子？（不能让观众等太久）
- [ ] 钩子的答案是否值得等待？（不能虎头蛇尾）
- [ ] 同一类型的钩子是否连续使用超过 3 次？
