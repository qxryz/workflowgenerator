# 短剧类型指南

## 13 大主流类型

### 1. 都市甜宠
- **核心受众**：18–30 岁女性
- **一句话定义**：高颜值男女从误会到心动的城市爱情
- **典型爽点**：心动暴击、吃醋名场面、公开撒糖
- **常见设定**：合租/职场/假结婚/合同恋人
- **必备元素**：反差萌、双向暗恋、肢体接触升级

### 2. 霸总/豪门
- **核心受众**：25–40 岁女性
- **一句话定义**：冷酷总裁因女主失控，从占有到深爱
- **典型爽点**：霸气护妻、身份碾压、阶层逆袭
- **常见设定**：商业联姻/替嫁/秘密恋情/豪门私生女
- **必备元素**：黑卡刷不停、保镖开路、董事会暴怒

### 3. 甜蜜恋爱
- **核心受众**：16–25 岁女性
- **一句话定义**：青春校园或初入社会的纯爱故事
- **典型爽点**：初吻、告白、暗恋被发现
- **常见设定**：校园/青梅竹马/异地恋/网恋奔现
- **必备元素**：便利贴情书、共用耳机、雨天送伞

### 4. 重生/穿越
- **核心受众**：20–35 岁，男女通吃
- **一句话定义**：带着前世记忆或穿越时空，改写命运
- **典型爽点**：提前布局、打脸渣人、命运逆转
- **常见设定**：重生回高考/穿越古代/游戏穿越/末世重生
- **必备元素**：金手指、蝴蝶效应、前世今生对比

### 5. 战神归来
- **核心受众**：25–40 岁男性
- **一句话定义**：隐藏绝世身份的强者回归，碾压一切
- **典型爽点**：亮身份打脸、以一敌百、下跪道歉
- **常见设定**：退役特种兵/隐世高手/家族弃子归来
- **必备元素**：令牌/勋章亮出、跪地求饶、战力飙升

### 6. 宫斗/宅斗
- **核心受众**：22–38 岁女性
- **一句话定义**：后宫或大宅门内的权谋较量
- **典型爽点**：以牙还牙、揭穿阴谋、绝地翻盘
- **常见设定**：古代后宫/民国大院/豪门内斗
- **必备元素**：毒计、联盟、隐忍蛰伏、一击致命

### 7. 逆袭/翻身
- **核心受众**：20–35 岁，偏男性
- **一句话定义**：底层小人物一步步逆天改命
- **典型爽点**：打脸嘲讽者、阶层跨越、身份反转
- **常见设定**：赘婿/快递员逆袭/草根创业/直播翻红
- **必备元素**：前期受辱、中期崛起、后期碾压

### 8. 家庭伦理
- **核心受众**：30–50 岁，偏女性
- **一句话定义**：家庭矛盾中的人性博弈
- **典型爽点**：渣男/渣女被制裁、真相大白、善有善报
- **常见设定**：婆媳关系/出轨/遗产争夺/重组家庭
- **必备元素**：道德审判、情感共鸣、正义裁决

### 9. 萌宝/亲子
- **核心受众**：25–40 岁女性
- **一句话定义**：萌娃牵线、破镜重圆或意外相认
- **典型爽点**：萌宝金句、亲子相认、一家团圆
- **常见设定**：未婚生子/试管宝宝/私生子相认/离婚后遇见
- **必备元素**：萌宝助攻、DNA 鉴定、父爱觉醒

### 10. 悬疑/推理
- **核心受众**：22–35 岁，男女均衡
- **一句话定义**：层层反转的案件或阴谋
- **典型爽点**：真凶反转、线索串联、真相揭露
- **常见设定**：密室/连环案/复仇追凶/职场阴谋
- **必备元素**：红鲱鱼、倒计时、多重反转

### 11. 轻科幻
- **核心受众**：18–30 岁，偏男性
- **一句话定义**：近未来背景下的科技 + 情感冲突
- **典型爽点**：能力觉醒、科技碾压、末日求生
- **常见设定**：AI 觉醒/时间循环/平行世界/基因改造
- **必备元素**：硬核设定（1–2 个）、人性拷问、科技双刃剑

### 12. 末世重生
- **核心受众**：20–35 岁，偏男性
- **一句话定义**：末日浩劫中的重生求存
- **典型爽点**：囤货打脸、以弱胜强、建立据点
- **常见设定**：丧尸/极端气候/资源枯竭/异能觉醒
- **必备元素**：生存技能、团队组建、人性考验

### 13. 喜剧/搞笑
- **核心受众**：全年龄段
- **一句话定义**：以笑料推进剧情的轻松短剧
- **典型爽点**：反差幽默、误会连锁、神反转
- **常见设定**：穿越搞笑/职场整蛊/情侣日常/家庭喜剧
- **必备元素**：包袱密度、角色反差、节奏精准

## 类型叠加规则

- 最多叠加 **3 个类型**
- 必须有 1 个**主类型**，其余为辅
- 避免冲突组合（如 "甜宠 + 悬疑推理" 需要极强功力）

### 经典叠加组合

| 主类型 | 推荐搭配 | 效果 |
|--------|----------|------|
| 霸总 | + 萌宝 | 冷酷总裁遇萌娃，反差萌 |
| 重生 | + 逆袭 | 带记忆重来 + 一路碾压 |
| 战神 | + 甜宠 | 硬汉 + 反差甜 |
| 宫斗 | + 重生 | 重生复仇 + 权谋升级 |
| 悬疑 | + 重生 | 重生追凶 + 反转密集 |
| 家庭伦理 | + 逆袭 | 被欺负的人翻身做主 |

## 出海改编指南

### 中式→西式类型映射

| 中式类型 | 西式改编 | 典型平台 |
|----------|----------|----------|
| 霸总 | Billionaire Romance | ReelShort |
| 战神归来 | Ex-Military / Secret Agent | ReelShort |
| 宫斗 | Royal Court / High Society | DramaBox |
| 重生 | Second Chance / Time Loop | 通用 |
| 赘婿 | Underdog Husband | ReelShort |
| 萌宝 | Secret Baby / Single Dad | DramaBox |
| 家庭伦理 | Family Drama | FlexTV |

### 海外验证梯队

| 梯队 | 类型 | 成功率 |
|------|------|--------|
| S 级 | Billionaire + Secret Baby | 最高 |
| A 级 | Werewolf / Vampire Romance | 高 |
| B 级 | Military + Second Chance | 中高 |

### 文化元素本地化

| 中式元素 | 西式替代 |
|----------|----------|
| 家族聚会 | Charity Gala / Cocktail Party |
| 磕头认错 | Public Apology / On Knees |
| 彩礼 | Trust Fund / Prenup |
| 拜把子 | Brotherhood Oath |
| 门当户对 | Social Status / "Old Money vs New Money" |

### 中式叙事陷阱（出海需避免）

1. **过度隐忍**：西方观众更倾向主角快速反击
2. **家长权威**：西方观众不接受无条件服从长辈
3. **道德绑架**：善良不能沦为软弱的借口
4. **大团圆执念**：开放式结局在海外接受度更高

### 英文对白技巧

- 用短句、口语化表达
- 避免直译中文成语
- 潜台词 > 直白表达
- 加入文化梗（pop culture references）
