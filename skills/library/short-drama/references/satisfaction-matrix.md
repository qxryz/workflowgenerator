# 爽感矩阵

## 5 大爽感类型

### 类型一：身份碾压

**定义**：通过暴露隐藏的高阶身份，实现对嘲讽者/欺压者的降维打击。

**情绪公式**：被嘲讽/轻视 → 身份揭露 → 全场震惊 → 下跪求饶

#### 子模式

| 子模式 | 触发场景 | 情绪核心 |
|--------|----------|----------|
| 亮牌打脸 | 被质疑身份 | 碾压 + 震惊 |
| 电话一响 | 被刁难时一个电话搞定 | 反差 + 畅快 |
| 后台撑腰 | 被欺负时大佬出场 | 安全感 + 爽 |
| 实力展示 | 被看不起时展现真实能力 | 认可 + 翻盘 |

#### 示例脚本
```
**经理**（傲慢）：
"小子，这个项目你接不了。回去告诉你老板，派个能做主的来。"

△ 主角微笑，从口袋里掏出一张名片放在桌上。

**经理**（拿起名片，脸色骤变）：
"陈……陈总？您就是北辰集团的……"

**主角**（起身）：
"现在，我能做主了吗？"
```

**强度分级**：⭐⭐ 亮名片 → ⭐⭐⭐ 一通电话 → ⭐⭐⭐⭐ 大佬跪求 → ⭐⭐⭐⭐⭐ 全城震动

---

### 类型二：打脸复仇

**定义**：主角以实力或策略反击施害者，完成"以彼之道还施彼身"。

**情绪公式**：被羞辱/迫害 → 隐忍/蓄力 → 完美反击 → 施害者崩溃

#### 子模式

| 子模式 | 触发场景 | 情绪核心 |
|--------|----------|----------|
| 以牙还牙 | 用对方的手段反击 | 因果报应 |
| 当众揭穿 | 在公开场合揭露真面目 | 正义 + 痛快 |
| 釜底抽薪 | 摧毁对方的根基 | 碾压 + 绝望 |
| 逆风翻盘 | 在对方自信满满时反杀 | 反转 + 震撼 |

#### 示例脚本
```
**前女友**（得意，挽着新男友）：
"没想到你还能出现在这种场合？我还以为你在送外卖呢。"

△ 拍卖师举起一幅画。
**拍卖师**："起拍价 500 万。"
**前女友新男友**（豪气）："600 万！"

**主角**（举牌）：
"2000 万。"

△ 全场倒吸一口气。

**前女友**（脸色铁青）：
"你哪来的钱？"

**主角**（淡淡一笑）：
"这个嘛……你不需要知道。"
```

**强度分级**：⭐⭐ 口头反击 → ⭐⭐⭐ 实力碾压 → ⭐⭐⭐⭐ 对方身败名裂 → ⭐⭐⭐⭐⭐ 连锁翻盘

---

### 类型三：逆袭翻盘

**定义**：主角从绝对劣势中逆转局面，完成从底层到顶层的跨越。

**情绪公式**：处于绝境 → 灵光乍现/贵人相助 → 逆风翻盘 → 嘲讽者目瞪口呆

#### 子模式

| 子模式 | 触发场景 | 情绪核心 |
|--------|----------|----------|
| 绝地翻盘 | 比赛/谈判/审判最后时刻 | 激动 + 热血 |
| 一鸣惊人 | 默默无闻的人爆发 | 震撼 + 认可 |
| 借力打力 | 利用敌人的力量反击 | 智慧 + 畅快 |
| 凤凰涅槃 | 经历极致磨难后重生 | 感动 + 振奋 |

#### 示例脚本
```
**投资人**（准备离场）：
"小姑娘，你这个方案连入门级别都达不到。"

**女主**（深呼吸，打开笔记本电脑）：
"给我 3 分钟。"

△ 她展示了一组数据。全场安静了。

**投资人**（坐回去，表情认真了）：
"这个用户增长模型……是你自己做的？"

**女主**：
"每一行代码，每一个数据，都是我在出租屋里用二手电脑跑出来的。"

**投资人**（站起来，伸出手）：
"5000 万。我投。"
```

**强度分级**：⭐⭐ 小胜一场 → ⭐⭐⭐ 阶段逆袭 → ⭐⭐⭐⭐ 格局逆转 → ⭐⭐⭐⭐⭐ 人生翻盘

---

### 类型四：情感爆发

**定义**：积蓄已久的情感在某一刻集中释放，引发强烈的情绪共鸣。

**情绪公式**：长期压抑/误解 → 触发事件 → 情感倾泻 → 真相/和解/决裂

#### 子模式

| 子模式 | 触发场景 | 情绪核心 |
|--------|----------|----------|
| 深情告白 | 无法再隐藏的感情 | 心动 + 感动 |
| 怒吼质问 | 忍无可忍的爆发 | 愤怒 + 共情 |
| 决裂宣言 | 不再忍耐的转身离开 | 痛苦 + 解放 |
| 牺牲守护 | 为重要的人付出一切 | 心痛 + 崇高 |

#### 示例脚本
```
**女主**（终于崩溃，眼泪涌出）：
"你知道这三年我是怎么过来的吗？每天微笑着上班，回家对着空房子哭！
你们说我坚强，说我独立，说我不需要人心疼——
可是谁问过我一句，'你累不累'？"

△ 全场沉默。

**男主**（红了眼眶，上前一步）：
"对不起……我一直以为你不需要我。"

**女主**（后退）：
"现在说这些……太晚了。"
```

**强度分级**：⭐⭐ 眼泪 → ⭐⭐⭐ 质问 → ⭐⭐⭐⭐ 崩溃 → ⭐⭐⭐⭐⭐ 牺牲

---

### 类型五：悬疑揭秘

**定义**：被层层隐藏的真相终于大白，所有线索串联成完整拼图。

**情绪公式**：线索积累 → 关键证据出现 → 真相揭露 → "原来如此！"

#### 子模式

| 子模式 | 触发场景 | 情绪核心 |
|--------|----------|----------|
| 身份揭露 | 隐藏身份被发现 | 震惊 + 恍然 |
| 阴谋大白 | 反派计划被完整暴露 | 愤怒 + 畅快 |
| 反转反转 | 你以为是 A 其实是 B | 震撼 + 过瘾 |
| 伏笔回收 | 前期铺垫的线索串联 | 满足 + 佩服 |

#### 示例脚本
```
**警探**（将照片一张张贴在白板上）：
"第一起案件，受害人左手无名指没有戒指——
第二起，受害人的日记最后一页被撕掉——
第三起，受害人手机里最后一通电话，打给同一个号码。"

△ 他画了一条线，连接三张照片。

**助手**（瞳孔放大）：
"等等……这三个人都认识同一个人？"

**警探**（转过身）：
"不只是认识。这个人，就坐在我们对面。"

△ 镜头缓缓转向审讯室的玻璃窗。
△ 窗后，一个一直微笑的"证人"，笑容凝固了。
```

**强度分级**：⭐⭐ 小线索 → ⭐⭐⭐ 身份反转 → ⭐⭐⭐⭐ 全盘揭露 → ⭐⭐⭐⭐⭐ 多重反转

## 爽感质量自检

- [ ] 是否有足够的"铺垫"让爽感有厚度？（无铺垫的爽 = 空洞）
- [ ] 反派是否足够可恨？（越恨反派，打脸越爽）
- [ ] 主角是否有自己的能力/努力？（纯靠外挂的爽感递减快）
- [ ] 爽完之后是否留有余味？（爽感 + 情感 = 高级爽感）
- [ ] 同一类型的爽感是否连续使用超过 3 次？（会审美疲劳）
