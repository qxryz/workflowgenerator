# 邮票照片动效 Skill

本 Skill 面向用户上传图片后的连续创作流程：先把照片风格化为韩式稚拙扁平插画，再把原图与插画以邮票框的形式做双风格合成，最后生成固定镜头的动态视频。适合需要“内外两种画风分层存在”、并且要求同一建筑、地平线、轨道或路径在邮票框内外保持水平对齐的画面。

## 第一步：将原图风格化为插画

以用户上传的原图为输入，先生成一张韩式稚拙扁平插画。

### 目标
- 保留场景里的物体和大致布局。
- 保留原图的主体关系、空间位置和画面结构。
- 将照片转成可爱、童趣、扁平化的插画风格。

### 画面规则
- 使用粗糙、抖动、断续的黑色手绘轮廓。
- 去掉照片里的光影、透视深度和细节纹理。
- 所有区域都改成纯色平涂。
- 物体简化成圆润的几何形状。
- 保持画面简洁、可读、稚拙、轻松、童趣。
- 最终效果要像原图的插画化版本，而不是照片描摹。

### 输出
得到可作为后续合成参考的插画图。

## 第二步：制作邮票边框双风格合成图

以用户原图作为底图，在画面中间加入邮票边框。

### 目标
- 邮票框外部保留原图的原始照片风格。
- 邮票框内部使用第一步得到的插画风格。
- 让内外同一建筑、地平线、道路、铁轨或其他主结构保持水平对齐。

### 画面规则
- 邮票框要居中，边缘清晰，具有真实齿孔邮票感。
- 邮票内部和外部不要混成一层，要能清楚看出风格分界。
- 如果同一主体同时出现在内外两侧，必须保持位置衔接和水平对齐。
- 外部区域忠实保留原始照片感，内部区域忠实保留插画感。
- 不要让边框漂移、缩放失真或变成普通贴纸。

### 输出
得到一张邮票框内外风格分明、结构稳定的合成图。

## 第三步：将合成图转成动态视频

以第二步的合成图为输入，生成图生视频。

### 目标
- 固定镜头拍摄。
- 让场景内容自然动起来。
- 保持邮票框不动。
- 保持邮票框内的画风不变。
- 保持邮票框外的画风不变。
- 根据图片内容决定运动方式：例如火车行驶、小动物活动、树叶飘动、水面波动、路人或车辆轻微移动等。

### 动效规则
- 动作必须来自画面内容本身，而不是随意加动作。
- 当动作穿过邮票框边界时，内外两种画风要同时存在。
- 不允许邮票框变形、漂移、融化或与画面融合。
- 不允许内外画风被统一成一种风格。
- 画面应保持“固定框架 + 自然运动”的清晰结构。

### 输出
得到一条邮票双风格的短视频，画面可动但结构稳定。
