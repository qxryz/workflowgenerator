# 未来科幻质感影视生成器

用于制作单条超写实真人未来科幻短片，统筹创意梳理、可复用的人物／场景／道具资产、资产结合式分镜、分段视频生成与按顺序装配。本 Skill 的所有画面输出，包括人物、物种、道具、场景、四视图、十二宫格分镜、镜头参考和最终视频，除非用户明确指定其他处理，统一采用好莱坞写实科幻大片视觉质感。用户确认的故事、人物、场景和参考资料具有最高优先级；用户未要求修改的内容必须保持不变。

## 第一步：锁定创意简报

1. 收集故事主题、主角、核心事件、世界观逻辑、基调、结尾、语言、总时长、段落数、画幅和物理介质。
2. 用户已提供风格时，将其提炼为可执行的光线、色彩、空间、材质、氛围和尺度规则；未提供时，以卡片给出：硬核深空探索、史诗太空歌剧、废土遗迹科幻、异星有机生态。
3. 用户不选择风格时，使用克制的“超写实科幻电影”默认方向，不擅自套用四个主题之一。
4. 锁定已确认风格、非赛博朋克基线、16:9 横屏、总时长、段落数、叙事语言与物理介质。缺少时长默认 60–90 秒、4–6 个段落，每段 10–15 秒。
5. 确认 100–200 字故事梗概和结尾是否需要反转。开头 3 秒必须从冲突、异常或悬念切入，梗概要交代主角、事件、世界观逻辑、基调和段落数。

## 第二步：识别参考资料与人物

1. 将资料识别为人物、场景、道具、分镜、reference_video 或 reference_audio，只提取可观察事实：人物脸部、发型、服装、比例；空间结构、材质、陈设、光源、天气；或动作、机位、节奏和声音。
2. 人物参考图直接绑定到人物 element，保留核心身份，不得擅自重设计。
3. 根据已确认剧本建立完整角色清单，覆盖所有出镜人物，以及通过画外关系或事件推动剧情的人物，包括人类、仿生人、机器人、外星人、外星生物、动物型生命和其他物种。不得遗漏任何会在短片中出现的角色或物种。
4. 为清单中的每一项记录名称／代号、物种或身体类型、叙事身份、人物关系、权力／情感状态、冲突／共同目标、出现的场景／段落和跨段落外观要求。用户确认完整清单后，才能创建角色资产。
5. 用户提供的人物或物种参考图直接绑定到对应 element，保留核心身份与设计，不得擅自重设计。
6. 为清单中每一个已确认角色和物种分别生成独立的纯白背景角色资产，包括非人类物种和外星生命体；不得为了方便把不同角色或物种合并到同一张图。每个新角色必须是独立资产：水平正面、9:16、完整主体与稳定轮廓；不得加入场景、额外角色、剧情动作或装饰环境。用户提供的参考图可保留原背景，除非明确要求纯白底版本。
7. 所有角色与物种基础资产确认后生成一张 16:9 四视图合排图，固定从左至右为：胸部以上近景、正面全身、全身侧面、背面全身。四个视角必须保持脸部、服装、身体比例和身份一致。
8. 道具和其他单体主体都生成纯白背景、完整轮廓、真实材质、比例稳定的独立资产。

## 第三步：建立场景锚点

1. 人物／四视图确认后再确认场景设定。
2. 每个 element scene 先生成一张空场景 16:9 单图。无场景参考图时使用 TextToImage，有场景参考图时使用 ImageToImage。这张单图用于确认空间结构、材质、天气／生态、色彩、光源方向和风格。
3. 场景单图只能使用 Midjourney V7；正文必须是一段连续的英文正向描述，字段标题可用中文，不写负面提示词或独立禁止段。
4. 用户确认场景单图后，以该图生成一张 16:9、4K、2×2 场景四视图。固定视角为：正面中心线、左前方 45 度、右前方 45 度、最深处／后侧向外；纯室外景观的第四格改为远端向前景回望。
5. 四格必须是同一地点、时间、天气／生态状态、光源方向、比例、材质、色彩和风格的连续空间说明。场景图中禁止人物、剪影、人物倒影／影子、人物活动、剧情事件和带人物的屏幕。
6. 将确认后的四视图绑定为最终场景资产，确认前不得进入资产结合式分镜。

## 第四步：编写分镜与可选草稿

1. 先写 100–200 字核心梗概，再输出严格时间轴。60 秒以内默认 4–5 段；90 秒项目使用 6–10 段。每段是一个 shot 和一个视频段落，最长 15 秒。总时长、段落数、shot 数和视频段落数必须严格相等。
2. 每段只能对应一个生成任务。段内 3–4 秒节拍仅用于组织动作和情绪，不能拆成额外 shot。
3. 以中景、近景和特写为主；只有交代深空尺度、巨构建筑、废墟孤立感或异星生态未知感时才使用远景或大全景。
4. 每段明确引用已绑定资产，并写明环境、有来源的光线、物理介质、可见动作、情绪反应、关键事件、特效和下一段衔接。严格保持已确认的事件顺序。
5. 当短片包含六个剧情段落时，每段生成一张十二宫格推荐分镜图，优先采用 3×4 或 4×3 布局，并为十二个画格清晰编号。十二个画格用于展示该段内部的视觉节拍、连续性线索、人物动作、镜头推进和与下一段的衔接。所有画格统一采用本短片的好莱坞写实科幻大片质感：真人电影摄影般的写实画面、可信的电影美术、真实物理材质、有来源的光线、受控色彩和长片级构图。不得默认使用黑白铅笔、粗糙草图、卡通、动漫、游戏 CG 或未完成概念艺术风格，不出现对白字幕。十二宫格只提升连续性审阅，不改变“一段剧情对应一个 shot 和一个视频段落”的关系。段落数不同的项目，按照当前简案或工作流明确要求的网格数量执行。
6. 高成本视频生成前先提交分镜确认。用户修改时只回到受影响的资产或段落，其他已确认模块保持不变。

## 第五步：编译提示词并生成视频

1. 最终视频生成前，让用户选择“先生成 shot 1 预览”或“一次性生成全部视频段落”。选择预览时只生成 shot 1，并等待确认。
2. 默认使用 MiniMax-H3 的视频生成路径；每段严格遵守分镜时长、16:9 和已锁定分辨率。用户明确指定其他模型时，先检查其能力，兼容后遵循用户选择。按角色绑定传入人物、确认后的场景四视图和必要道具，每段最多 9 张 reference_image。
3. 只有当连续性确实依赖上一段的动作、构图或运镜时，才追加上一段 final_shot 作为 reference_video；它不能替代人物或场景资产。
4. 提示词固定按“主体／资产引用 → 场景与空间 → 可见动作与情绪 → 摄影机与构图 → 有来源的光线与物理介质 → 已锁定风格 → 约束”顺序编写，并使用 `<<<image_N>>>` 作为图片引用占位符。
5. 除场景单图外，所有提示词都包含：禁止字幕、禁止水印、禁止文字、禁止卡通、禁止动漫、禁止游戏 CG、禁止塑料化 3D 渲染。所有视频提示词都包含无背景音乐、无字幕，但不得默认禁止对白；有对白时写明角色和逐字台词，并保留表演、口型与环境声空间。
6. 保持单一已确认风格，不用霓虹、高饱和紫／粉／洋红／蓝光污染、全息界面、赛博义体或雨夜街道作为未来感捷径。异星生物发光必须局部、柔和、有明确生物来源。
7. 生成失败时只针对报错原因修正并重试失败段落，保留已确认的人物、场景、时长、画幅和事件顺序；随后必要时切换其他兼容模型，不反复死磕同一模型，也不改变风格或重做成功段落。

## 第六步：装配与交付

1. 按确认后的时间轴装配 final_shot，保留段尾与下一段开头在动作、视线、光线方向、色彩或环境介质上的衔接。
2. 优先使用直接切换、动作匹配、光线延续或短暂环境声桥，避免没有叙事动机的特效转场。
3. 调色和声音氛围服从锁定风格：深空偏机械、克制、低噪；太空歌剧庄严肃穆；废土粗粝多尘；异星生态湿润且有机。独立音频可服务节奏与情绪，但不能压住对白和环境声。
4. 后期不得额外加入霓虹光污染、全息 UI、赛博义体或雨夜街景，除非用户明确提出。
5. 交付最终成片和用户明确要求的中间资产。只有所有必需输出可用并已进入项目画布时，才能宣称完成。

## 风格规则

- 硬核深空探索：严谨航空结构、可维护接口、舱内实用点光源、磨损钛合金、反光宇航服、仪表屏幕和符合失重物理的微尘。
- 史诗太空歌剧：极简／粗野主义巨构、巨大负空间、庄严自然光、风化石材、厚重哑光金属、防沙布料和干燥扬沙。
- 废土遗迹科幻：被侵蚀的科技遗迹、刺眼日光、沙尘颗粒、锈蚀钢铁、风化装甲、磨损皮革和干裂表面。
- 异星有机生态：内部规律一致的有机建筑、植物／真菌、湿润表面、半透明叶脉、水滴、角质鳞片、真实折射和局部生物发光。
- 默认或自定义方向：遵守用户确认的可见规则，使用真实材质、有来源光线、深黑位、受控饱和度和清晰叙事空间；不得把赛博朋克信号当作未来科幻的默认定义。

## 统一画面质感

本 Skill 的全部画面统一采用好莱坞写实科幻大片质感：真人电影摄影、可信的空间尺度与物理材质、电影级美术置景、有来源的光线、受控饱和度、自然景深、真实镜头语言和长片级构图。除非用户明确要求其他媒介，不得将任何资产或分镜图默认处理为黑白铅笔草图、卡通、动漫、游戏 CG、塑料化 3D 或未完成概念图。

## 输出约定

使用 Markdown 标题和固定模块顺序，不使用表格。面向用户的描述及所有生成提示词正文均使用中文，只有 Midjourney V7 场景单图提示词正文使用英文。模型名、工具名、资产标识和 `<<<image_N>>>` 保持字面形式。不得用创作者或已有影片名称作为执行指令。所有决策分阶段确认，不能在中间确认点后自动跑完整流程。
