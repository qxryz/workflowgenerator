# 旁白音色预设 v2.0

本表只用于旁白。人物对白必须保持视频原声，不能从本表生成对白。

## 选择原则

STEP 0 必须执行：先根据题材、情绪、目标平台（抖音 / 红果 / ReelShort 等）推荐 2–3 个音色，再让用户确认或试听。推荐不是默认跳过确认；用户不选择时才使用推荐项。

下列 voice_id 为预设命名约定。调用前必须向当前 MiniMax 音色目录校验；目录中不存在时展示“试听 / 自定义”并要求用户选择可用 voice_id，不得静默替换。

| 性别 | 用户看到的标签 | voice_id | 适合题材 / 平台 |
|---|---|---|---|
| 男 | 经典抖音剧情解说 | selected catalog narrator voice ID | 都市悬疑、逆袭、古风；抖音 / 红果 |
| 男 | 抖音新闻叙事男声 | selected catalog narrator voice ID | 权谋、案件、惊悚；抖音 / 红果 |
| 男 | 青年口语解说 | selected catalog narrator voice ID | 校园、轻喜剧、都市情感；抖音 |
| 男 | 温润情感男声 | selected catalog narrator voice ID | 虐恋、治愈、古风情感；红果 |
| 女 | 经典抖音剧情女声 | selected catalog narrator voice ID | 都市情感、悬疑、逆袭；抖音 / 红果 |

## 推荐逻辑（必须执行）

1. 先判定短剧类型：都市悬疑 / 情感婚恋 / 古风权谋 / 校园成长 / 逆袭 / 惊悚等。
2. 再判定叙事视角和情绪：第一人称或第三人称、冷静 / 紧张 / 温柔 / 爽感。
3. 结合平台推荐：抖音偏清晰、前置钩子和口语感；红果偏连续叙事、情感承接和耐听度。
4. 输出“推荐首选 + 备选男声 + 备选女声”，说明理由，让用户确认。

## 锁定规则

- 一集只使用一个旁白 voice_id 和一个 `voice_profile_id`（或同一参考音频哈希）；整集锁定后不得中途切换。
- 旁白优先整集合成一条母轨，再切片到镜头；不支持母轨时，全部文本必须在同一 TTS batch / session 内生成。
- 项目锁必须同时记录 `speed`、`pitch`、`emotion`、`pause_policy`、`volume`、`sample_rate`、`codec` 和响度目标；这些值不得按镜头调整。抖音短剧默认 `speed=1.15`，采用清晰快速、钩子前置、句间紧凑、转折落点明确的解说节奏。
- 语速以项目锁为准，禁止用单镜加速解决时间冲突；快节奏来自统一语速、短句、压缩非必要停顿和明确重音，不是逐镜随机加速；冲突应改写、拆句、移窗、拆镜或延长镜头。
- 任意一镜音色、音高、语速或响度漂移时，整批旁白重做，不只替换单镜文件。
- 换旁白只重做旁白，不改变视频原声对白。
