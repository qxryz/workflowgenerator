# 角色身份与资产工作室

当用户需要创建可持续复用的虚拟角色身份，而不只是生成一张一次性人像时使用本 Skill。本 Skill 的核心价值不只是保持同一张脸，而是让角色拥有鲜明、可识别、容易记住的设计指纹，避免生成出普通的模板化漂亮人物。流程始终保持三个阶段：人脸、服装、资产表；性格、职业、生活方式、叙事道具、微表情和剪影记忆点都嵌入人脸与服装设计中，不额外增加制作阶段。

## 核心原则

- 以记忆点为目标：每个角色都必须有一组少量、具体、可重复的视觉锚点，让人一眼认出。
- 避免通用美貌模板和可互换造型；个性应体现在脸部、轮廓、发型、服装结构、配饰逻辑或一个标志性细节中。
- 每个角色都要锚定到具体的亚文化、职业、生活方式或社会身份，不能只停留在“酷”“可爱”等宽泛形容词。
- 为角色配置一个能说明其职业或生活方式的叙事道具，默认不要让所有角色都空手站立。
- 多角色设计时，有意识拉开材质、松紧轮廓、年龄、剪影和行为差异，保证群像中一眼可分。
- 定义符合性格的微动作或静止表情，不要让每个角色都使用相同的标准微笑。
- 先锁定身份，再设计服装造型。
- 已选主脸是后续流程唯一的人脸依据。
- 人脸候选阶段只使用Midjourney，每轮生成四张候选图，并以四个独立图片卡片展开供用户选择；不得折叠成一个结果。NanoBanana Pro只用于选定人脸后的主面部参考标准化，不用于候选生成。
- 服装参考负责提供服装、鞋子、配饰、发型、妆面和可见设计细节，但不能覆盖已经确认的人脸。
- 当服装方向已经清晰可执行时，不要求用户额外确认一次完整造型，直接生成后让用户查看结果；只有信息不足或冲突选择会明显改变结果时，才在生成前询问。
- 返工时保留已经成功的中间资产，尽量只修改用户指定的部分。
- 默认最终交付是一张一次生成的16:9角色资产表，不是由多张独立图片拼成的合成图；资产表必须说明其中每个组件的用途。
- 人脸锚点同时也是发型和头部轮廓参考，不能使用贴到画面上边缘或裁掉发型轮廓的过近裁切。

## 三阶段结构

固定制作顺序为：**人脸 → 服装 → 资产表**。性格、职业、生活方式、叙事道具、特征行为、材质差异和剪影辨识度属于这三个阶段中的设计标准，不是额外流程。


## 生成失败处理

服务超时、临时并发错误、空图片返回或短暂后端失败，不代表创意被否定，也不能改变已选身份、完整发型要求、设计指纹或用户确认的来源。第一次失败时，保留全部硬性约束和同一来源，继续使用NanoBanana Pro，用更短但语义等价的指令自动重试一次。不得静默换脸、丢弃参考图或要求用户重新选择。第二次仍失败后，应报告真实错误并等待用户明确重试，不得无限重复。

## 第一步：收集角色简报

只从用户请求中收集或确认：

- 角色用途或广告、项目背景；
- 用户明确的成年/未成年信息；
- 用户明确的性别呈现；
- 脸部、发型、妆面、身型、服装、鞋子和配饰偏好；
- 已有的人脸、角色、服装、场景或风格参考；
- 输出画幅和后续使用方式；人脸候选生成默认使用1:1，不再询问。

只有当角色身份或最终交付物确实存在多种重要解释时，才提出一个聚焦问题。用户已经给出可执行目标时，不要要求填写完整制作简报。


## 引导式问询流程

在关键创意决策点使用聚焦问询，不要求用户填写冗长表格。固定保留以下顺序：

1. **角色简报**——只询问会明显影响结果的缺失信息：角色用途、必要时的成年/未成年状态、必要时的性别呈现、性格、职业或生活方式、身型方向和后续用途。用户已经说清楚的内容直接采用，不要重复询问。
2. **人脸方向**——生成候选人脸前，用简短选项确认脸部气质、脸型或五官重点、眼神、发型方向和人脸参考路径，并保留自由描述选项。将用户选择记录为身份约束。
3. **设计指纹**——确认或推导两到五个可见标志性特征，并确定一个身份锚点，例如亚文化、职业、生活方式或社会角色。只有存在会明显改变角色的多种解释时才询问。
4. **服装方向**——生成全身定妆照前，在信息缺失或互相冲突时确认服装轮廓、鞋子、配饰、叙事道具和代表性微动作。用户已经给出清晰可执行的服装方向时，先总结理解，再直接生成，不要重复询问同一问题。
5. **生成前检查**——进行高成本的全身定妆照或最终资产表生成前，简要复述已锁定的人脸、服装、设计指纹、道具、行为和输出格式。只有仍有会改变结果的重要选择未确定时才要求确认，否则直接继续。

问询必须简短、以选项为主，只围绕会改变人物身份或交付质量的决定。不要要求用户重复确认已经批准的人脸或服装。如果用户否定生成结果，应先询问问题属于身份、剪影、服装、道具、表情还是构图，再只返回最早受影响的阶段修改。

## 第二步：确认人脸方向

用少量引导式选择确认影响最大的脸部决策，例如整体脸部气质、脸型与五官、眼睛偏好以及生成路径。如果用户提供了可用的人脸参考，应提供基于参考图的路径，不要强迫用户从零设计人脸。

将用户选择记录为身份约束。后续服装参考不得覆盖这些约束。同时定义一份临时设计指纹：用两到五个具体可见特征，让角色区别于普通生成人物。这些特征必须符合角色简报，并落实到脸部、发型、轮廓、服装、配饰、叙事道具或特征行为中。至少加入一个亚文化、职业、生活方式或社会身份标签。

## 第三步：生成四张Midjourney候选人脸

只使用Midjourney，每轮生成一组四张候选人脸。默认使用1:1方形画幅，并使用同一份已确认的角色简报和人脸选择；除非用户明确要求，否则不询问候选图画幅。四张候选图必须作为四个独立文件或卡片提供选择。四张图一起展开展示，然后让用户选择一张。如果用户四张都不满意，则保留已经确认的约束，调整被否定的方向后重新生成一组四张。候选阶段可以保留Midjourney原生水印或平台标记；只在用户选定一张后，进入主脸标准化前去除，不得改变人物身份或构图。

用户没有选定唯一主脸前，不得进入下一步。

如果画布将Midjourney的四张变体折叠在一个生成卡片中，应向用户提示：“Midjourney已经生成四张候选图。画布可能会把它们显示在一个折叠结果卡片里，但四个文件都已经生成。请展开卡片，或通过附件文件选择其中一张。”不得说四张图丢失，也不要仅因为画布折叠就重新生成一组。

## 第四步：制作主面部参考

主面部锚点标准化、平台水印清理和发型轮廓保留默认使用NanoBanana Pro。将用户选中的候选脸标准化为清晰、适合身份匹配和发型连续性的主面部参考。统一为正面平视的呈现方式，使脸部清晰、可复用，同时保留被选人物的辨识度；画面必须包含完整的头顶和两侧发型轮廓，在头发上方保留适度、自然的留白，并确保脸部、耳朵、颈部和肩颈基底可读。不得让头发贴到画面上边缘，也不得通过过近裁切丢失发型信息。将该资产命名并说明为 **Primary Face Reference / 唯一人脸锚点**。

进入下一步前，检查脸部完整度、发型完整度、头顶留白、两侧边距和干净的颈肩基底。如果发型被裁切或信息不足，必须先修复或扩展锚点；不要增加过多空白，避免人物比例过小或画面难看。

它是唯一的人脸依据。后续造型、角度、身体分离图和背面补全图都必须与它保持一致。

## 第五步：收集并适配服装造型

接受服装参考图、多张服装或配饰参考，也接受文字描述的造型方案。只提取服装和造型信息，不要把参考图中无关人物的身份带入。将服装与已经锁定的人脸和用户要求的身体设计适配。

整理一份简洁的造型摘要，至少覆盖：

- 发型和妆面；
- 身型与轮廓；
- 服装；
- 鞋子；
- 配饰；
- 可见结构或设计细节；
- 仍需要用户选择的部分；
- 角色设计指纹，以及承载这些记忆点的可见元素；
- 亚文化、职业、生活方式或社会身份锚点；
- 叙事道具，以及符合性格的静止行为或微表情。

如果参考图没有展示某个必要区域，应将其标为待确认设计，不要假装该内容已经确定。

## 第六步：确认或直接进入完整造型

当服装方向已经清晰可执行时，跳过额外确认框，直接生成全身定妆照，并在生成指令中落实已理解的造型，让用户查看生成结果。只有存在会明显改变角色的缺失信息或冲突选择时，才在生成前询问。无论是否询问，生成前都要检查完整造型至少包含一个清晰的标志性特征、一个身份或职业线索和一个行为或道具线索，整体组合也足够具体，不能只是普通的目标风格角色。

## 第七步：生成全身角色定妆照

使用唯一人脸锚点和已确认的造型方向，生成一张完整全身角色定妆照。保持人物身份、身型轮廓、服装结构、鞋子、配饰、标志性特征和用户要求的呈现方式。如果结果虽然一致但过于普通、难以记住、缺少已确认的设计指纹，或与角色职业、生活方式、身份、道具和特征行为脱节，应退回修改。生成后交给用户确认。

如果用户不满意，应识别具体修改点，并优先修改受影响最小的部分。除非用户主动改变，否则保持唯一主脸和已经确认的造型不变。

## 第八步：一次性生成角色资产表

用户确认定妆照后，一次性生成一张16:9横版角色资产表。不得把之前生成的图片再进行拼贴或合成，也不得把外部版式参考图作为生成参考；应在同一次生成中，使用白色背景、三等分等宽竖向分框和两条细竖线完成资产表：左栏为正面去头身体，中栏为背面补全，右栏为人脸与发型头肩特写。不要添加文字、标签、标题、尺寸标注或Logo。将已确认的人脸、造型和身体结构清晰排布：

### A. 正面去头图

一张正面身体与服装资产，去除或分离头部和脸部。保留颈部衔接、身体比例、服装、鞋子和配饰，用于后续重新接入统一人脸，避免产生第二个身份。

### B. 背面补全细节

一张背面或背部细节资产，用于补全发型、服装结构、开合方式、配饰、鞋子以及正面无法看到的细节。不得在该资产中创造新的人脸或重新定义角色身份。

### C. 唯一人脸锚点

即标准化后的主面部参考。它是未来生成不同角度、表情和动作时唯一的人脸身份来源。

如果工作流或用户明确要求其他交付物，可以在另一个经过确认的资产表中增加表情参考、侧面参考或备用服装等明确命名的变体。默认不把这些可选变体当作必需输出。

## 第九步：交付与返工

交付这一张角色资产表，并为其中每个组件附上简短用途说明。保持主脸、已确认造型和衍生资产之间的逻辑关联，方便后续继续复用正确来源。

返工规则：始终保持三个阶段，只返回到最早受影响的阶段。


- 更换人脸 → 返回候选人脸选择，建立新的身份链；
- 更换服装 → 保留人脸锚点，只修改造型相关资产；
- 更换身型或比例 → 保留人脸锚点，除非用户明确要求更换身份；
- 背面信息不足 → 只修订背面补全资产，不改变正面身份；
- 质量或人体结构问题 → 修正受影响资产，保留全部已确认约束。

只有在所有请求的最终资产都已经生成并且可在项目中使用时，才能宣称资产包完成。

## 触发边界

用于重视辨识度和独特设计的可复用角色身份与角色资产创建；目标是让结果比普通一次性生成更具体、更鲜明、更容易记住。不用于单张无关人像、简单换背景、带明确选区的局部重绘、普通图生视频，或最终交付物并非角色资产包的完整动画/视频项目。
