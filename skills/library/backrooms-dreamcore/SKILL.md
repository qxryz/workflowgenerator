# Backrooms Dreamcore

当用户想做“我的后室 / 梦核测试 / 把角色或场景后室化 / 生成专属异空间”时使用本 Skill。核心产物是一套个人化后室创作结果：**参考图 + 4 个沉浸式答案 + Backrooms Level 0 语法**，最终可输出空间档案卡、AI 配图需求、可选 BGM 方向，并按用户要求继续生成图片或视频。

目标不是心理诊断，也不是普通恐怖图，而是生成一个真实、廉价、空、重复、泛旧、带后室滤镜和克制荒诞感的个人化空间切片。

## 适用边界

触发：
- 用户上传人物、角色、宠物、物体图，想生成“这个主体的后室 / 固有空间 / 梦核空间”。
- 用户上传房间、街道、店铺、校园、办公区等场景图，想把它后室化或梦核化。
- 用户说“测一下我的后室 / 我的异空间 / 固有空间 / dreamcore test”。
- 用户要求输出结果卡、AI 配图需求、BGM 方向，或直接生成后室图片 / 视频。

不触发：
- 纯后室 lore 问答，例如“Level 0 是什么”。
- 普通恐怖怪物图、血腥惊吓图。
- 不带测试、参考图或个性化输入的通用后室图片。

## 步骤 0：确认图片输入

本 Skill 默认需要用户提供 **1 张人物 / 角色 / 宠物 / 物体 / 场景图片**。

如果用户没有上传图片，先用自然语言要求上传，不进入测试：

> 请先上传一张图：可以是人物、角色、宠物、房间、街道、店铺或任何场景。我会根据这张图和 4 个问题，生成你的专属后室空间。

用户上传后判断图片类型：
- **角色图**：有人、动物、虚拟角色、宠物或明确主体肖像。目标是“主体进入或对应的后室空间”。
- **场景图**：房间、街道、商店、校园、办公区、公共空间。目标是“原场景被 Level 0 化”。
- **混合图**：同时有人和场景时，如果用户没说明重点，只问一个聚焦问题：“优先保角色还是保场景”；如果用户已说明则直接执行。

图片理解规则：
- 已有可靠素材说明时直接复用，否则分析参考图本身。
- 分析必须聚焦本任务：角色图提取身份轮廓、姿态、服装轮廓和可迁移情绪；场景图提取空间结构、关键物件、材质、门窗 / 走廊 / 光源和可 Level 0 化元素。
- 不需要读取与任务无关的颜色细节；颜色由参考图本身承载。

## 步骤 1：4 个沉浸式问题

只问 4 个问题，并在同一次交互中成组展示，避免逐题多轮打断。每题都提供 A/B/C/D 选项。

内部维护 5 个维度：
- `boundary`：负数=开放，正数=封闭
- `time`：负数=凝固，正数=流动
- `presence`：负数=独行，正数=痕迹
- `light`：负数=自然光，正数=人造光
- `order`：负数=规则，正数=混沌

如果用户说“跳过问题 / 直接生成 / 你来决定”，直接采用快速模式，不再询问。

### Q1：入口

题面：你上传的那张图开始变得不太对劲，背景里的某个角落出现了一条本来不存在的走廊。灯亮着，但里面没有声音。你会——
- A. 走进去，看它通向哪里：`boundary -2, time +1`
- B. 先站在门口观察很久：`boundary +2, order -1`
- C. 把身边的东西留在入口，做个记号：`presence +2, order -1`
- D. 关掉附近的灯，再进去：`light +2, order +1`

### Q2：重复

题面：你走了一段路，发现墙面、地毯、天花板都开始重复。不是完全一样，但相似到让人怀疑自己回到了原点。你的反应是——
- A. 加快脚步，试图打破循环：`time +2, boundary -1`
- B. 停下来找规律：`order -2, boundary +1`
- C. 接受它，继续慢慢走：`time -2, presence -1`
- D. 在墙上留下一个只有自己看得懂的标记：`presence +2, order +1`

### Q3：光

题面：前方有两种光。一种像旧荧光灯，平、闷、带着嗡鸣。另一种像远处门缝里漏出的光，像出口，也像陷阱。你更靠近——
- A. 荧光灯下，至少它是真的：`light +3, order -1`
- B. 门缝的光，也许那边有变化：`light -1, boundary -2`
- C. 两边都不靠近，待在阴影里：`presence -2, boundary +1`
- D. 先找到光的开关：`order -2, light +1`

### Q4：留下什么

题面：你意识到，这个后室正在根据你上传的那张图生成。它不会完全复制原图，只会保留一个最重要的东西。你希望它保留——
- A. 主体本身：人、角色、宠物或物体：`presence -1, boundary +1`
- B. 场景结构：房间、走廊、门窗、空间关系：`order -2, boundary +1`
- C. 情绪：那张图给人的感觉：`time -2, light -1`
- D. 一个细节：某件物品、姿态、痕迹或角落：`presence +2, order +1`

## 步骤 2：合成后室化方案

完成 4 题后，累加维度分数，并结合图片类型生成后室化方案。

### 角色图方案

保留：
- 主体身份、轮廓、姿态、服装或关键身体语言。
- 默认模式：主体可以出现在后室空间中，像被真实拍到；不要变成动漫海报或商业角色海报。
- 如果用户要求“后室怪物 / Entity / 追逐 / 恐怖化”，允许把主体异化成后室实体，但要保留原图轮廓、姿态、服装气质或可识别来源。
- 如果用户不想主体出镜，可生成“这个主体对应的固有后室空间”。

生成方向：
- 主体或异化实体位于 Level 0 风格空间中，像监控、旧数码相机或意外抓拍。
- 空间根据 5 个维度微调：封闭 / 开放、凝固 / 流动、独行 / 痕迹、自然 / 人造、规则 / 混沌。
- 即使怪物化，空间仍是画面主体，避免过度怪物大片感。

### 场景图方案

保留：
- 原场景的空间结构、关键物件或主要情绪。
- 把原图元素 Level 0 化：墙纸、低绒地毯、格栅吊顶、荧光灯、重复隔墙、空旷迷宫。

生成方向：
- 原场景像被 Backrooms Level 0 吞入。
- 真实摄影感优先，不能变成概念插画。
- 原图中最有识别度的 1-2 个元素可保留为违和物。

## 步骤 3：Backrooms Level 0 视觉语法

所有出图都必须先成立 Level 0 感，再嫁接用户图片元素。

核心语法：
- 复古暗纹墙纸、低绒商业地毯、矿棉板格栅吊顶。
- 嵌入式矩形荧光灯盘，单一荧光灯滤镜。
- 厚重矩形立柱或隔墙反复出现。
- 空旷无人或极少孤立主体。
- 墙面直接接地面和吊顶，缺少正常门窗、插座和家具。
- 深邃透视、远处转角或低矮门洞，暗示无限延伸。
- 真实照片、旧数码相机、监控截图感。

后室滤镜：
- 偏黄 / 偏绿荧光、低动态范围、旧相机白平衡偏差。
- 压缩感、监控 / VHS 噪点、轻微过曝、霉湿空气。
- 廉价室内装修，普通但不舒服。

克制荒诞：
- 出口逻辑消失。
- 门或通道位置不合理。
- 房间比例略微错误。
- 墙、柱、隔断重复得过长。
- 日常物件孤立出现，如折叠椅、空白书或来自上传图的小物件。

避免：
- 概念插画、奇幻建筑、魔法感、过度电影感。
- 让“图书馆 / 泳池 / 商场 / 教室”等主题压过 Level 0。
- 画面文字、标题、字幕、logo。

## 步骤 4：输出空间档案卡

先输出简短结果卡，并询问用户是否继续生成图片；如果用户已经说“直接生成 / 生成图 / 生成视频”，就不再确认，直接进入生成步骤。

结果卡建议包含：

```text
═══════════════════════════════
       你 的 后 室 切 片
═══════════════════════════════

RM-XXXX ▸ 空间名
英文代号

来源图类型：角色 / 场景
保留核心：主体 / 结构 / 情绪 / 细节

空间描述：3-5 句
后室滤镜：1 行
异常点：1-2 行

「一句短 tagline」
═══════════════════════════════
```

同时输出：
- AI 配图需求：用自然语言描述，不要把它当成固定模型 prompt。
- 可选 BGM 方向：例如低频荧光嗡鸣、空调管道声、远处脚步回声、梦核垫底音。
- 5 个维度倾向摘要。

将档案卡作为标题为“后室切片档案”的可审阅文本产物交付。

## 步骤 5：生成图片

当用户要求生成图片时，根据自包含的创作简报完成。默认沿用上传图画面形态；用户确认了其他平台或画面形态时按其要求。用户指定的模型能够满足简报时优先使用，否则选择当前可用且可见能力相当的模型，并在切换会造成明显差异时先说明。

创作简报必须包含：
- 是新建图片还是改造参考图
- 已确认的交付画面形态
- 上传参考图及其角色图 / 场景图 / 混合图角色
- 4 个问题答案与 5 维倾向
- Level 0 视觉语法、后室滤镜、克制荒诞规则
- 角色图：保持主体身份 / 轮廓，但空间优先；如果怪物化，保留来源特征
- 场景图：保留场景结构或关键物件，把其 Level 0 化
- 最终图像必须像真实照片，不是插画
- 用户原话或已消解后的自包含需求

## 步骤 6：生成视频

当用户要求视频时，根据已批准参考图和后室简报完成。用户明确选择的模型、质量目标、时长或画面形态视为已确认要求；执行前检查当前能力，任何会明显影响结果的调整都先询问用户。

后室追逐视频模板可用于“角色后室怪物化 / Entity 追逐”请求：
- 视角：第一人称 POV，手持、奔跑或监控感；不要第三人称电影预告片。
- 场景：Backrooms Level 0 廉价室内迷宫，复古墙纸、低绒地毯、格栅吊顶、荧光灯阵列、重复隔墙与立柱。
- 怪物：由上传角色图异化而来，保留原图轮廓、姿态气质或服装特征，但变成后室 Entity。
- 运动：镜头在走廊里快速后退或转身奔跑，实体从远处或转角逼近，在短片内形成一个清晰追逐动作。
- 画质：旧数码相机、VHS、监控噪点、低动态范围、荧光灯偏色、压缩感、轻微运动模糊。
- 声音：如果所选视频模型支持原生音频，把环境声、荧光灯嗡鸣、脚步回声和空间压迫感写入本次生成；不要为同一用途重复制作语音或音乐轨。
- 禁止字幕、画面文字、logo、电影海报感、过度怪兽大片感。

## 快速模式

用户说“跳过问题 / 直接生成 / 你来决定”时：
- 仍然必须有上传图片。
- 默认 4 问答案为混合态：Q1=B、Q2=C、Q3=A、Q4=根据图片类型自动选择；角色图默认 A，场景图默认 B，情绪特别强时可选 C。
- 根据图片直接生成“Level 0 化后室切片”。
- 如果用户明确要求直接出图或视频，不再输出中间确认。

## 输出

- 所有展示给用户的内容使用用户语言。
- 将空间档案卡作为可复用文本资产交付。
- 图片或视频只展示一次，并使用清晰标签；不要在最终回复中重复同一资产。
- 一次产出多个资产时，按档案卡、图片候选和视频结果分组。

## 质量要求

- Level 0 语法优先，用户图片元素轻嫁接。
- 真实、廉价、空、重复、泛旧。
- 不做医学、人格优劣或命运判断。
- 结果适合社媒分享，但画面不要像商业海报。
- 任何生成请求都不得添加字幕或画面文字。
