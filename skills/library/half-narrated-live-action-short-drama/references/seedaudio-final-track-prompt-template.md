# Seed Audio 最终音轨提示词模板

## 用途

用于短剧最终视频完成合并之后，生成一条独立的 Seed Audio 旁白音频；它只负责旁白，不再负责最终混音或对白保留。

核心原则：

- 只调用一次 Seed Audio 生成最终旁白音频；Seed Audio 输出的是独立旁白素材，不是最终混音成片。
- 不为旁白、主播或其他角色分别生成最终音轨，也不把原视频对白写进这条音频。
- 角色声音在整条音轨内保持稳定且彼此区分。
- 时间戳必须来自最终合成视频的实际时长、实际镜头边界、真实旁白转写和真实静音间隔，而不是原始分镜的计划时间。
- 最终旁白音频总时长以合并后视频的真实媒体时长为准；不要为了匹配计划时长裁剪成片，也不要把计划时长当成最终交付边界。
- 所有未标注说话的区间必须绝对静音，不要在这条音频里加入对白、环境声或音效。

## 使用前准备

在填写模板前，必须完成：

1. 合并最终视频，并读取其实际时长。
2. 读取每个源视频的实际时长，计算最终镜头边界。
3. 对照最终视频，核对每个镜头内实际出现的角色和旁白。
4. 保留用户确认的台词原文，不得自行改写。
5. 明确最终音轨总时长，包括尾部静音。

```text

1. 输出总时长必须精确为【音轨总时长】秒。
2. 所有角色只能在各自标注的时间段内说话。
3. 每一句旁白按指定时间段生成；不执行后期倍速、时间拉伸或重切对齐，不把原视频对白写入本音频。
4. 未标注台词的所有时间区间必须是绝对静音。
5. 禁用所有音效，包括提示音、礼物音、连麦音、玻璃碎裂声、脚步声和转场声。
6. 禁用背景音乐。
7. 禁用环境声、房间底噪、麦克风噪声和额外呼吸声。
8. 不要加入开头或结尾提示音。
9. 不要添加任何未提供的台词、笑声、叹息、拟声词或口头填充音。
10. 每个角色在整条音轨中的音色、年龄感、音量和说话方式保持稳定。
11. 不要朗读时间戳、角色名、括号内容或制作说明。
12. 所有旁白和台词必须逐字保持原文，不得改写、增删或补充。
13. 最终视频画面结束后的剩余时间必须保持静音。
```

## 填写规则

### 角色表

每个角色只定义一次。不要在不同时间段重复创建同一角色，也不要用“低沉男声”“温柔女声”等模糊词替代已经锁定的角色说明。

推荐写法：

```text
1. 男声旁白：中年男性，低沉、成熟、略带粗粝质感，冷静克制，带悬疑叙事感。
2. 女主播平平：青年女性，清晰、冷静、敏锐，语气笃定、锋利。
3. 年轻男性连麦观众：青年男性，紧张、困惑、害怕，带求助感。
4. 中年神秘连麦人：中年男性，前段疲惫克制，后段被揭穿后压抑愤怒并突然爆发。
```

### 时间轴表

时间轴必须覆盖从 `00:00.000` 到音轨结尾的全部范围。每个相邻区间都要明确是某个角色说话还是绝对静音，不能留下未定义空档。

推荐顺序：

```text
时间码 → 说话人 → 原文台词 → 下一段时间码
```

### 时间码来源

如果源视频使用整数生成时长，也不能直接用提示词里的时长代替真实时长。必须读取最终合并视频的媒体时长，并使用真实帧边界或真实源视频时长计算。例如：

```text
镜头01实际时长 8.000 秒
镜头02实际时长 6.583 秒
镜头03实际时长 9.417 秒
```

则后续镜头边界必须按照累计实际时长计算，而不是按照 `8 + 6 + 9` 的计划值计算。

### 静音规则

以下区间必须显式写出“绝对静音”：

- 画面中没有任何旁白内容的区间
- 旁白句与旁白句之间的间隔
- 镜头切换时没有旁白的区间
- 最终画面结束到音频结束的尾部区间

“没有台词”不等于“自由添加声音”。默认全部为绝对静音。

### 旁白和画面核对

生成前逐条核对：

- 旁白是否属于当前最终视频中的角色。
- 角色是否在对应视频区间出现。
- 旁白是否与画面动作和镜头顺序一致。
- 是否保留用户原始标点和文字。
- 是否把旁白错误分配给其他角色。
- 是否把视频提示词中的音效误写成音频内容。

视频提示词中的动作声、礼物提示音、连麦提示音和环境声，不得自动加入这条音频，除非用户明确要求保留。
