# 输出格式

## 规划与前期制作输出

对话中返回：

1. **需求理解**和**视频生成方案**，用于快速确认方向。
2. 明确说明**制作方案文本文件已创建或已更新**。
3. 简要概括文档包含哪些内容。
4. **下一步卡片**，提供 3-5 个编号选项，推荐项放在第一位。

不要只用“你接下来想做什么？”这类开放式句子结尾；必须给出卡片选项。默认优先把“生成 1-3 张主视觉图”放在第一个推荐项，作为从方案进入视觉探索的过渡。

制作方案文本文件本身包含：

1. 需求理解
2. 视频生成方案
3. 视频核心
4. 口播脚本
5. 图解系统
6. 分镜脚本
7. 主视觉方向计划
8. 素材与生产计划
9. 事实核查备注（如需要）

“下一步卡片”必须出现在对话回复里，不要嵌入制作方案文档。

## 媒体生产输出

额外返回：

- 生成素材路径，
- 合成后的最终视频路径，
- 已烧录字幕的最终视频路径和/或生成的字幕文件路径，
- 简洁生产总结，
- 可执行的优化建议，
- 用于修改或导出的下一步卡片。

## 触发示例

- “把工业革命做成简约线条小人科普动画。”
- “帮我做一个关于莎士比亚的科普视频。”
- “生成一个板书感图解科普视频。”
- “把这段教材做成 60 秒知识讲解视频。”
- “Make a line-doodle explainer about photosynthesis.”
- “Create a science explainer video in a whiteboard line-doodle style.”
