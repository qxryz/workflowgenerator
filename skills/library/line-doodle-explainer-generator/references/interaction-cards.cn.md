# 下一步卡片要求

每个步骤边界都要使用简洁、结构化的确认选项。每个阶段结束的回复顺序应为：先用一句短话确认“当前这一步是否有问题 / 是否需要修改”，再给出紧贴当前阶段的下一步选项。即使下一步很明显，也要提供选项，除非用户明确授权自动继续。

卡片内容建议：

- 推荐下一步放在第一项。
- 提供 3-5 个清晰动作。
- 每个选项必须是创作动作，不是课堂提问。
- 选项必须紧贴刚完成的步骤。例如：制作方案完成后，只提供生成主视觉、修改方案、调整语言或比例等相邻动作；不要直接跳到最终合成，除非用户明确要求。
- 如果界面支持自定义输入，可以保留“自定义方向”。

示例选项：

1. 先生成 1-3 张主视觉图。
2. 先确认一个主视觉，再生成关键帧。
3. 跳过主视觉，直接生成关键帧。
4. 先生成旁白音频。
5. 修改脚本、时长或受众。

不要默认问“你学到了什么？”“你能回答吗？”这类课堂互动问题，除非用户明确要求教学练习。
