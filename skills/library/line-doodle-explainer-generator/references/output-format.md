# Output Format

## Planning / Pre-production Output

Return in chat:

1. **Request Understanding** and **Video Generation Plan** for quick alignment.
2. A clear note that the **production-plan text file has been created or updated**.
3. A concise summary of what the document contains.
4. A **Next Step Card** with 3-5 numbered options, with the recommended option first.

Do not end with an open-ended sentence such as “What would you like to do next?” without card options.

The production-plan text file itself should include:

1. Request Understanding
2. Video Generation Plan
3. Video Core
4. Narration Script
5. Diagram System
6. Storyboard
7. Main Visual Direction Plan
8. Asset and Production Plan
9. Fact-check Notes when needed

Show the Next Step Card in the chat reply, not inside the document.

## Media Production Output

Also return:

- generated asset paths,
- the final video path when assembled,
- the subtitle-burned final video path and/or subtitle file path when subtitles are generated,
- a concise production summary,
- specific improvement suggestions when useful,
- a Next Step Card for revisions or export options.

## Trigger Examples

- "Make a line-doodle explainer about the Industrial Revolution."
- "Turn this lesson into a stick-figure infographic teaching video."
- "Create a science explainer video in a whiteboard line-doodle style."
- "把这个知识点做成简约线条小人科普动画。"
- "生成一个板书感图解科普视频。"
- "帮我做一个关于莎士比亚的科普视频。"
