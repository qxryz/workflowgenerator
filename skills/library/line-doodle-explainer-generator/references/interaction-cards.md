# Next Step Card Requirements

At every step boundary, present concise, structured confirmation choices. Each step-ending response should follow this order: (1) one short line asking whether the current step is acceptable or needs changes; (2) tightly adjacent next-step options. This applies even when the next step seems obvious, unless the user has explicitly opted into automatic continuation.

Preferred card content:

- Put the **recommended next step** first.
- Provide 3-5 clear options.
- Make each option an action, not a classroom question.
- Keep options adjacent to the completed step. For example, after the production plan, offer main visual generation or plan revision; do not jump directly to final assembly unless the user explicitly asks.
- Include “custom direction” only if the interface automatically supports it or the user may need it.

Example card options:

1. Generate 1-3 main visual direction images first.
2. Choose one main visual and generate storyboard keyframes from it.
3. Skip main visuals and generate storyboard keyframes directly from the script.
4. Generate narration audio first.
5. Revise the script, duration, or audience.

Avoid questions like “What did you learn?” or “Can you answer this quiz?” unless the user explicitly requests learning activities.
