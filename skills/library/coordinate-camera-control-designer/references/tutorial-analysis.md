# B 站教程方法提炼：坐标作为运镜提示词

来源：用户提供的 B 站教程第 2P，标题为“AI作画 - 高速运动打斗 / 教程-高速运动打斗作画测试”。

## 关键观察

教程把画面控制拆成两层：

1. 自然语言动作导演：描述蓄力、消失、现身、撞击、飞出、残影、烟尘、速度线等动作节奏。
2. 比例坐标定位：用 `[L=..., T=..., W=..., H=...]` 指定角色、目标、撞击点或背景区域在画面中的位置。

这种方法不是三维坐标控制，而是二维画面边界框控制。它把“角色从哪里到哪里”“镜头跟谁”“撞击发生在哪里”写成模型更容易执行的视觉锚点。

## 坐标格式

```text
[L=左, T=上, W=宽, H=高]
```

- `L`：目标框左边距。
- `T`：目标框上边距。
- `W`：目标框宽度。
- `H`：目标框高度。
- 数值为 0-1 的画面比例。

## 教程中可见的示例类型

- 角色初始位置：`[L=0.516, T=0.148, W=0.071, H=0.249]`
- 跑动目标位置：`[L=0.003, T=0.096, W=0.053, H=0.203]`
- 地面背景区域：`[L=0, T=0.324, W=1, H=0.667]`
- 大主体近景框：`[L=0.34, T=0.21, W=0.52, H=0.701]`
- 运动终点小框：`[L=0, T=0, W=0.075, H=0.131]`
- 撞击相关位置：`[L=0.684, T=0.316, W=0.075, H=0.351]`
- 连续冲击点：`[L=0.348, T=0.176, W=0.09, H=0.496]`、`[L=0.009, T=0.025, W=0.191, H=0.619]`

## 可复用原则

1. **先定主体**：用 `@Image 1`、`@Image 2` 或角色名明确是谁在动。
2. **再定起点**：主体从哪个画面区域开始。
3. **再定终点**：主体冲向、看向、出现到哪个区域。
4. **再定事件点**：撞击、爆炸、烟雾、落点等关键事件发生在哪里。
5. **最后定镜头**：镜头是跟随、前推、后拉、摇镜、俯视还是环绕。
6. **补节奏**：把动作拆成蓄力、爆发、现身、命中、停顿、飞出。
7. **保可读性**：高速运动不是全程糊掉，而是让观众看清起点、方向、现身位置和结果。

## 适合转成 Skill 的能力

- 用户给一段动作描述，自动改写成坐标运镜提示词。
- 用户给分镜表，补充每个镜头的主体框、目标框、撞击点和镜头运动。
- 用户要高速打斗、追逐、冲刺、撞击时，用坐标减少模型乱跑和镜头漂移。
- 用户给参考图时，可先估算主体/目标区域，再生成 `[L,T,W,H]` 控制语句。
