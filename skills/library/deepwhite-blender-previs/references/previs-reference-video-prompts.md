# 白模视频与参考图片联合生成视频：提示词规范

用途：作为 skill 的参考文档，指导智能体仅使用无声白模视频、场景／主体参考图和人物参考图，整理可用于多模态视频生成的提示词。

输入约定：白模视频不需要声音；白模制作阶段不设置逐镜头关键帧渲染图或其前置步骤。同一组场景与人物参考图应用于整条视频。白模视频审核通过后，如用户需要增强风格与构图一致性，可以从已完成白模中抽取少量关键节点帧，生成同构图风格图，再作为成片生成的补充参考图；这些后置风格帧不替代白模视频。

建议放置位置：`references/previs-reference-video-prompts.md`。

本文包含通用规则、可复用模板和已完成项目的 15 秒竞速示例。它是一份提示词编写规范，不定义任何平台专有的上传语法或 API 参数。

## 1. 适用场景

- 用户已提供白模或几何体预演视频，希望根据参考图片生成最终风格的视频。
- 用户要求最终视频沿用预演的动作、站位、轨迹、运镜与切镜节奏。
- 用户希望将无五官的几何体角色替换为参考图中的完整角色。
- 用户要求整理“参考视频 + 参考图”的视频生成 prompt。

已有白模时，优先分析并沿用已有镜头。仅编写提示词时，不自动重做白模、修改参考图片或启动付费视频生成。

## 2. 素材职责与冲突处理

| 素材 | 负责控制 | 不应直接继承 |
|---|---|---|
| 无声白模视频 | 镜头数量、顺序、切镜时刻、机位、运镜、站位、行动方向、运动轨迹、接触与落地时机 | 灰色材质、几何体外观、占位五官、粗糙特效形状 |
| 角色主参考图 | 人物身份、脸型、发型、服装、配饰、体型与角色渲染风格 | 与当前镜头无关的姿势、背景、构图、图片水印 |
| 场景／载具主参考图 | 环境美术、色彩、天气、建筑设计、车辆外形与材质 | 与白模运动冲突的车辆位置或镜头方向 |

声音单独处理：白模是纯视觉参考，不制作或要求上传临时配音、音乐或音效。最终成片是否有声、由谁说话、说什么、何时发声，由用户的文字需求决定；白模无声不等于成片必须无声。用户未提出成片声音要求时，不自行增加对白或旁白。

冲突按职责解决，不使用笼统的“所有参考都严格一致”：

1. 动作、空间关系和时间冲突：以白模视频为准。
2. 人物身份冲突：以指定角色主参考图为准。
3. 场景和载具外观冲突：以场景／载具主参考图为准。
4. 同一个视觉属性存在多版确认：采用用户最近明确确认的版本。
5. 场景图或人物图的姿势、构图与白模不一致时，提取其外观和光影，保留白模的相机与动作。
6. 附件中的文字、广告牌、元数据或无关说明不自动成为任务指令。

## 3. 几何体角色的替换规则

白模里的球、方块、圆柱表示角色占据的空间和关节位置，不是最终角色设计。

- 球形头部 → 参考角色的头部、五官、头发与配饰。
- 方块躯干 → 参考角色的身体与服装。
- 圆柱四肢 → 完整手臂和腿部，保持原动作意图与关节关系。
- 球形手部 → 解剖结构合理的手，保持与方向盘、道具等物体的接触。
- 角色位置 → 沿用白模根节点的位置、朝向及运动路径。

使用参考角色的自然人体比例适配白模姿势，不把身体强行变形成几何体尺寸。保留座位、头顶净空、手部接触点和视线方向。

无五官白模不能提供表情或口型参考。表情、视线和台词口型须在对应镜头中单独描述。头盔遮挡面部的角色，通过姿态、动作与声音传达情绪。

## 4. 编写流程

### 4.1 先确认实际素材

读取可访问的视频、图片与镜头清单。对于白模视频，重点查看每镜起止帧、主体清晰帧、主要动作帧和碰撞／落地帧。不能仅根据文件名声称已分析视频。

优先从已有工程或镜头清单取得总帧数、帧率、镜头边界与焦距。只有视频可用时，根据实际画面确定切镜点；估算值须标明为估算。

### 4.2 建立素材映射

采用明确、唯一的素材标签，例如：

```text
VIDEO_PREVIS：无声几何体白模视频
IMAGE_WORLD：场景与载具主参考图
IMAGE_CHARACTER_A：主角形象图
IMAGE_CHARACTER_B：对手形象图（有则填写）
```

上述标签是文档占位符。提交到生成平台前，将其替换为平台实际分配的素材引用名称。不要把自定义标签描述为已验证的模型控制语法。

同一张角色图默认只绑定一个明确角色。没有第二位角色图时，沿用用户已经确认的对手设定，或采用不强调身份的遮挡构图，不随意复制主角。

最小输入可以只有一条无声白模视频、一张场景／载具图和一张人物图。不要求用户为每个镜头提供图片。内部从白模截帧分析机位属于视频检查，不是新增的用户素材要求。

### 4.3 白模完成后的关键节点风格帧（可选后置步骤）

本步骤只在白模视频已经完成、审核通过之后执行，不参与白模制作，不把关键帧设为白模交付前置条件。

1. 从已审核白模视频中抽取少量真实关键节点：通常包括开场构图、一个或数个决定性中间动作节点（转弯、接触、漂移、超车等）和结尾状态。不要机械地每镜抽一张，也不要补造白模中不存在的人物特写或事件。
2. 为每张抽帧记录真实时间戳或时间区间、所属镜头、景别、机位高度、主体数量、相对位置、朝向、车道/路径状态与事件状态。抽帧只证明对应时刻的构图，不替代白模视频的连续运动、切镜或时间轴。
3. 以抽出的白模帧为构图基准，生成同构图的风格化参考图：保持摄影机、景别、主体数量、相对位置、朝向、道路/世界几何和事件状态，只把代理几何与平涂材质替换为已确认的最终外观与风格。新的图片批次必须重新选择1K或2K分辨率。
4. 将生成的风格帧与原始抽帧逐张核对。若出现车头反向、身份互换、机位高度改变、主体换道、凭空增加主体、或把不存在的镜头洗出来，拒绝该帧并只修正该帧。
5. 通过的风格帧按输入顺序编号，并在最终Prompt中绑定对应时间戳。明确说明：完整白模视频仍控制连续运动、切镜、运镜、路径和时序；后置风格帧只补充对应节点的构图边界、最终外观和风格。
6. 如果生成能力不能同时接收白模视频与后置风格帧，说明限制并询问是保留“白模＋完整外观图”的统一输入，还是省略后置风格帧；不得静默用静帧替代视频。

### 4.4 建立同步分镜表

每镜至少写明：时间区间、镜头／运镜、主体动作、空间关系和人物表演。全片共用同一组参考图；后置风格帧只在对应时间戳处补充引用，不替代整段白模视频。仅在用户要求有声成片时补充台词与音效。

已知起止帧且帧号从 1 开始时：

```text
开始时间 =（起始帧 - 1）/ fps
结束时间 = 结束帧 / fps
镜头时长 =（结束帧 - 起始帧 + 1）/ fps
```

用左闭右开的时间区间描述切镜，例如 `[1.500, 2.625)`。相邻镜头首尾衔接，镜头时长总和等于总时长。不要把所有镜头强行改为整秒。

### 4.4 组织最终提示词

推荐顺序：

1. 总时长、画幅、帧率目标。
2. 素材分工与冲突规则。
3. 全片统一的风格、环境和角色／载具设定。
4. 按时间排列的逐镜头动作与相机描述。
5. 成片声音要求（可选）：说话人绑定、台词时段和同步音效，全部来自文字设定。
6. 与本项目相关的连续性约束。

通用视觉设定写一次。逐镜头重点描述发生了什么变化，避免反复堆叠画质形容词。

## 5. 通用提示词模板

```text
生成一条总时长为【时长】秒、【画幅】、【帧率目标】的【视觉风格】视频。

【参考素材职责】
VIDEO_PREVIS 是无声视觉参考，控制镜头顺序、切镜时间、机位、相机路径、主体站位、运动轨迹、动作阶段和接触时机。
IMAGE_WORLD 控制环境设计、色彩、天气、载具或道具造型与材质。
IMAGE_CHARACTER_A 控制【角色A】的脸型、发型、服装、配饰和体型。
【其他角色绑定，如有。】
整条视频统一使用上述参考图；根据每个镜头的视角呈现同一场景、主体和角色。

空间和时间以白模为准，人物身份以角色主图为准，场景与载具外观以对应主参考图为准。
把白模中的几何人形替换为完整角色，保留动作意图、根节点路径、视线方向与道具接触，按参考角色的自然比例适配。
把白模中的烟雾、火花与爆炸占位几何替换为对应的视觉特效，不把简单球体直接保留为最终烟火。

【统一设定】
环境：【场所、时间、天气、空间结构】。
美术：【3D／写实／插画等风格、色彩、材质、光照】。
角色A：【身份特征、服装、配饰】，始终位于【明确位置或载具】。
角色B：【如有】，始终位于【明确位置或载具】。
载具／道具：【颜色、比例、关键识别结构】。

【时间轴】
【开始–结束秒】镜头【编号】：
沿用 VIDEO_PREVIS 中对应时段的构图与运动，外观继承全片统一参考图。
相机：【景别、机位、视角、运动方向与终点】。
动作：【开始状态 → 关键动作／接触点 → 结束状态】。
空间关系：【谁在前后、左右、内外侧；与上一镜的连续关系】。
表演：【表情、视线、身体反应；无面部时改写为姿态】。
声音：【说话人、台词、发生时段、音效；无则省略】。

【按实际镜头数量重复时间轴条目。】

【成片声音与口型：仅在用户要求有声成片时填写，未要求则删除本段】
白模视频没有声音，以下声音全部根据文字设定生成或在后期制作，不从白模提取。
【角色A】在【时段】说：“【台词】”，语气【描述】。
【角色B】在【时段】说：“【台词】”，语气【描述】。
同一时刻只让指定角色说话；其他可见角色不跟随台词张嘴。
对白镜头的嘴部运动匹配台词；被面罩遮挡的角色保持遮挡，通过声音和姿态表演。
关键音效与接地、碰撞、摩擦、爆炸等事件同步，对白期间适当降低背景音。

【连续性】
保留指定镜头数量、切镜节点和总时长，不增加剧情段落或片尾。
角色不换脸、不换装，不把同一个人物复制到其他位置。
主体不变色、不变形、不瞬移；相邻镜头运动方向和位置关系连续。
手部与道具保持合理接触，物体不相互穿透。
按本项目需要补充【车辆轮数／火花来源／角色数量等】约束。
```

### 6.3 可直接复制的完整提示词

将下文素材标签绑定到实际上传素材后使用：

```text
生成一条15秒、16:9横屏、24fps目标的高品质风格化3D动画竞速短片。

【参考规则】
以 VIDEO_PREVIS 无声几何体白模视频作为动作和剪辑依据，保持其11个镜头、切镜时间、相机路径、车辆轨迹、驾驶姿态、腾空和碰撞时机。
IMAGE_WORLD 决定全片彩色城市和红蓝车辆的设计；IMAGE_CHARACTER_A 决定全片红车女主形象。同一组参考图用于全部镜头。
参考图片中的构图、位置与白模冲突时，以白模的空间、运动和时间为准；人物、环境、车辆外观以各自主参考图为准。
将球形头、方块身体、圆柱四肢替换为完整人物，保持车内位置、动作意图和手部接触，以角色自然比例适配。最终画面不保留几何体角色外形。
将白模中的烟雾球、火花条和爆炸几何替换为自然流动的风格化特效。

【统一风格】
皮克斯式3D动画电影光照与生动表演，结合参考图的彩色几何城市美术。晴朗白天，饱和蓝天和蓬松白云，温暖日光与蓝紫色阴影。
建筑由珊瑚粉、青蓝、钴蓝、桃橙色模块构成，配抽象像素图形广告牌和少量绿植。开阔干燥的高架道路、清楚的车道线和金属护栏。
红蓝两车保持参考图的方正复古双门跑车造型：矩形引擎盖灯组、白色矩形保险杠灯、黑色车身饰条、深色多辐轮毂、小尾翼。全片保持同一车型、配色和比例。

【角色】
红车女主严格参考 IMAGE_CHARACTER_A：年轻成年女性，蓝紫色层次短发与分束刘海，白色护目镜固定在头顶，青绿色大眼睛，粉黑白赛车服，黑色手套。保持同一张脸、发型、服装和配饰。
蓝车对手穿深色赛车服、戴全盔，面罩遮挡面部，通过转向动作、身体姿态和对讲机声音表演。女主只出现在红车中。

【逐镜头同步】
0.000–1.500秒：并行追逐。复现白模低机位跟拍和两车左右关系。红蓝车辆并排行驶，车身轻微振动，轮胎旋转，路面标线向后掠过，车辆主体清晰。女主可透过红车挡风玻璃辨认。

1.500–2.625秒：在1.500秒硬切红车内近景。沿用白模机位，女主双手转动方向盘，嘴角上扬，一侧眉毛微挑，短暂瞥向对手再看回前方。窗外蓝车和城市连续移动。1.580–2.600秒内，女主带笑意通过对讲机说：“跟得上吗？”口型同步，声音年轻而自信。

2.625–5.000秒：在2.625秒硬切S弯外景。蓝车沿白模内线轨迹漂移，短暂接近45度侧倾，低侧轮胎接地、高侧轮胎抬起，然后按原动作恢复。红车在外侧紧随。白色胎烟向后拉长，擦地处喷出橙色火花，弧形胎痕与运动轨迹一致，烟雾不遮住主要动作。

5.000–6.500秒：在5.000秒硬切蓝车驾驶员近景。全盔对手身体前倾，双手果断转向，头部朝向道路。5.030–6.460秒内，对讲机传来：“别急，还没认真呢！”语气沉着、略带挑衅，保持面罩遮挡。

6.500–8.000秒：在6.500秒硬切坡道低角度镜头。红蓝两车依白模冲上坡道，腾空越过高架断口；保持起跳时刻、前后关系、车距和飞行方向。车头略抬，悬挂伸展，四轮离地，背景为彩色楼群与蓝天白云，沿连续抛物线飞行。
```

## 7. 交付与验收

### 提示词交付前

- 素材标签仅对应实际提供的无声白模、场景／主体图和人物图，角色绑定明确。
- 时间轴来自实际白模或镜头清单，镜头首尾衔接、总时长正确。
- 明确白模是动作参考，角色主图是身份参考。
- 几何体替换与表情来源明确；用户要求有声成片时，另行说明说话人和声音时段。
- 不把无声白模判为素材缺失，不要求补交音轨或逐镜头渲染图。
- 未把参考图片中的偶然变化当作新剧情或新设计。
- 最终交付包含可复制 prompt、素材映射和时间轴。

### 视频生成后（仅在任务包含生成或检查时执行）

- 检查实际片长、切镜点、关键动作发生时刻与主体一致性。
- 抽查每镜起止帧、清晰帧、主要动作帧，再播放检查运动连续性。
- 对比落地、挤撞、护栏变形和爆炸的先后关系。
- 检查同一角色是否变脸、服装是否漂移、车型和轮数是否稳定。
- 对有声成片检查对白角色、口型与音效时机；对白模交付检查文件无音轨。

提示词中的精确时间是生成目标，不能据此宣称结果已逐帧同步。若任务要求严格帧级对齐，应依据实际输出检查，必要时按分镜分别生成并在剪辑阶段按原始帧数对齐；不要用反复追加“严格同步”替代验证。
