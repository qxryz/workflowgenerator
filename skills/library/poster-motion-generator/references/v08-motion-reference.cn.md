# Poster Motion Generator（海报动态生成器）

## 何时使用

当用户上传至少一张海报图片，并希望把静态海报转化为一条 8–15 秒、一镜到底、铺满全画幅、保留原构图与文字可读性的动态海报视频时使用本 Skill。

不用于从零设计海报、多镜头剧情片或普通幻灯片。

## 语言一致性

- 按用户对话语言执行全部规则。
- 用户用中文交互时，Agent 回复、方向卡、`Final_Video_Spec.md`、Storyboard 和生成提示词全部使用中文。
- 用户用英文交互时，全部使用英文。
- 用户中英混合或指定语言时，保持用户的混合语言或指定语言。
- 海报原有文字默认保持原语言，不翻译、不本地化，除非用户明确要求。

## Step 1：强制前置校验

- 用户必须上传至少一张海报图片才能启动本 Skill。
- 若用户未上传海报，直接回复：`请先上传一张海报图片`。
- 不得在没有海报时继续分析、方向选择、规格写入或生成。

## Step 2：海报分析与比例映射

上传海报后，先调用媒体分析工具提取：

- 方向判断：横版（宽>高）、竖版（高>宽）、正方形（宽≈高）。
- 宽高比数值估算：直接估算宽÷高，输出小数，如 1.78、0.80、1.00。
- 数学映射：将估算值与 MiniMax H3 支持比例逐一比对，取绝对差最小者：
  - 21:9 = 2.3333
  - 16:9 = 1.7778
  - 4:3 = 1.3333
  - 1:1 = 1.0000
  - 3:4 = 0.7500
  - 9:16 = 0.5625
- 输出结论格式：`方向：[横版/竖版/正方形]，宽高比估算值：≈[X.XX]，映射到支持比例 [最终比例]`。
- 标注偏差程度：比例基本一致 / 存在比例偏差，需通过扩展背景填充适配。
- 标注海报内容是否铺满图片画幅，是否存在白边、留白或边框。

接受任意比例海报，不拒绝、不要求用户确认比例。若真实比例与输出比例有偏差，下游必须通过延伸背景色调与纹理填满画幅，核心内容不裁切、不拉伸、不加黑边。

## Step 3：方向交叉验证

分析结果返回后立即自动验证：

- 数值 > 1 应对应横版。
- 数值 < 1 应对应竖版。
- 数值 ≈ 1 应对应正方形。

若方向判断与数值矛盾，仅重分析一次，提示聚焦：`请直接对比这张图片的宽度和高度，哪个更大？宽是高的大约多少倍？给出一个宽÷高的数值估算。` 以第二次结果为准，不无限循环。第二次即使仍有矛盾也采纳，并通过背景扩展兜底。

## Step 4：海报内容分析要点

必须分析并记录：

- 海报类型：人物 / 产品 / 食品 / 建筑 / 纯文字 / 抽象图形 / 无明确主体。
- 视觉主体：位置、占比、朝向、最终姿态。
- 无人物海报的核心运动承载：主标题、产品、Logo、图形、纹理、光线或颜色层次。
- 构图与空间：主体位置、前景/中景/背景、留白区域、空间纵深。
- 风格与色调：极简、复古、赛博、手绘、潮流等，以及主色调。
- 文字版式：标题、标语、Logo、辅助信息的位置、层级与排版结构；文字必须稳定可读。
- 五层拆分：背景与基础色块、核心识别元素、主标题与 Logo、辅助信息、装饰图形与氛围效果。
- 视觉锚点：人物海报为人物，产品海报为产品，食品海报为主食品，建筑海报为建筑，纯文字海报为主标题或核心字体，抽象/无主体海报为最具辨识度的图形、纹理、色块、光线或颜色关系。
- 动效潜力：分别评估两个方向可用的显现方式、核心元素、逐元素出场顺序、入场轨迹和动作建议。
- 前后景深：标注核心视觉锚点的远景→中景→近景推进路径，辅助元素的切入景深。
- 方向二专用：检测海报外轮廓是否为规则矩形；若有缺口、异形裁切、圆角，标注位置、形状和尺寸。
- 方向二专用：根据比例和排版建议纸卷轴线与展开方向；横版优先横向展开，竖版优先纵向展开。

## Step 5：提供常用动态方向供用户选择

通过选择卡展示动态方向，并暂停等待用户选择。用户选择前不得继续。推荐方向必须优先展示方向一「视觉元素渐进激活成版」和方向二「纸卷展开成版」，其余方向作为补充推荐；若用户要求完整选项，可展示全部方向。

### 方向一：视觉元素渐进激活成版

从简洁初始画面开始，原海报元素按视觉层级和重要程度逐步从无到有显现并回到原位，围绕视觉锚点展开纵深运动，最终形成与原海报一致的完整版式。

### 方向二：纸卷展开成版

完全卷紧的实体纸质卷轴从画面上方坠落进入，落定后短暂蓄力，以果断弹开动作猛然舒展。展开过程中纸面空白无内容，纸张铺平后铺满全画幅，随后海报元素通过前后层次、运动视差、材质变化和局部动作逐层出现，最终恢复原海报完整构图。

### 方向三：裸眼 3D 破框冲出

核心人物、产品、主食品、建筑局部或主标题从原海报平面向镜头方向主动冲出，形成强纵深冲击；随后回到原版式并锁定。适合人物、产品、运动、食品、潮流、电商海报。

### 方向四：多层视差镜头唤醒

保持原海报版式，拆分前景、中景、背景与文字层，通过推近、横移、微环绕、景深变化和局部微动形成“活的海报”。适合摄影类、人物、建筑、品牌、生活方式海报。

### 方向五：粒子 / 线框 / 点线面重组

海报核心元素先被拆解为点、线、面、粒子、线框或图形碎片，再按层级聚合成原海报版式。适合科技、赛博、游戏、抽象图形、品牌 Logo、纯文字海报。

### 方向六：光影材质微雕

以体积光、扫光、反射、高光、阴影、材质光泽变化唤醒海报，强化金属、玻璃、塑料、布料、皮肤、食物、建筑表面等质感；版式运动克制。适合奢侈品、产品、食品、建筑、极简海报。

### 方向七：动态文字排版成版

主标题、Logo、标语和辅助文字沿笔画、字距、排版方向、网格系统逐字写入、滑入、压缩展开或拼合成版。适合纯文字海报、活动海报、音乐海报、展览海报、品牌口号海报。

### 方向八：场景物理氛围循环

保留原海报构图，以雨、雪、烟、雾、风、尘、火花、光斑、水波、纸张颗粒、胶片颗粒等环境物理运动增强氛围，主体仅做极轻微动态。适合电影感、文化、旅行、建筑、情绪氛围海报。

方向选择规则：

- 所有海报类型：推荐卡排序必须先给方向一「视觉元素渐进激活成版」，再给方向二「纸卷展开成版」。
- 人物海报：方向一、方向二之后，可补充裸眼 3D 破框、多层视差或物理氛围循环。
- 产品 / 食品海报：方向一、方向二之后，可补充裸眼 3D 破框、光影材质微雕或多层视差。
- 建筑海报：方向一、方向二之后，可补充多层视差、光影材质微雕或物理氛围循环。
- 纯文字海报：方向一、方向二之后，可补充动态文字排版或粒子线框重组。
- 抽象 / 无明确主体海报：方向一、方向二之后，可补充粒子线框重组、光影材质微雕或物理氛围循环。
- 所有方向都必须保持最终锁版与原海报一致，文字清晰可读，画面铺满全画幅。

## Step 6：建立全局规格

> **v1.0.0 重大变更**：工作流从「单次 H3 一镜到底」改为「关键帧 → 逐段 → 拼接」三段式，并新增「BGM 可选」段落（默认关闭，用户明确说"加 BGM"才启用）。详细规范请同步参考 SKILL.md 英文版。下方仅做最小同步：字段、流程、Changelog。

用户选择方向后，写入 `Final_Video_Spec.md`，锁定：

- aspect_ratio：Step 2 数学映射得到的最近支持比例。
- model：MiniMax H3（逐段）+ image_synthesize（关键帧）+ FFmpeg（拼接）。
- resolution：1080P 用于视频段（工具限制时从 2K 妥协）；关键帧 1K–2K。
- duration：8–15 秒，按用户选择，不默认 15 秒；每段内部一镜到底，段间用 FFmpeg concat 拼接。
- camera mode：**逐段一镜到底**（段内不切）；段间用 FFmpeg concat 拼接（默认无花式转场）。
- dynamic direction：用户选择的动态方向。
- keyframe_count：预渲染关键帧数（推荐 5–9 张）：1 张开场 + N 张元素入场 + 1 张锁版。
- bgm_required：`true`（用户明确要求加 BGM）或 `false`（默认）。BGM 由 `batch_text_to_music` 单独生成，在 Step 9.3 阶段混入。
- full-frame policy：全画幅填充，无黑边、无上下留白、无左右留白、无 letterbox/pillarbox。
- ratio adaptation：比例偏差时延伸背景色调与纹理，核心内容不裁切、不加黑边、不拉伸变形。
- lock-state policy：最后一张关键帧（KF N）必须 1:1 还原原海报（构图、色彩、文字版式）。拼接后视频的末 1–2 秒仅保留呼吸感 / 光斑闪烁 / 材质微变；文字完全静止，主体不得继续放大、缩小或位移。
- 动效术语锁定：Storyboard 和 prompt 中显式标注每段使用的动效类型术语（参见下方「动效术语速查表」），H3 对动效类型术语敏感，显式使用比泛泛描述更易命中预期效果。
- 拟声词风格锁定：根据所选方向的情绪和调性，锁定一套中文化拟声词风格（参见 Step 8「拟声词风格库」），整条视频保持一致风格。

## Step 7：Storyboard 设计规则

仅为用户选中的方向设计单镜头动态方案，不为未选方向生成 Storyboard。

### 通用规则

- 全片 8–15 秒，一镜到底，无内部剪辑、无转场。
- 视频铺满全画幅，不得出现黑边或留白。
- 将上传的海报视为最终锁版参考，而不是必须的开场帧。开场可以是空白、半成品或抽象态，只要最终锁版帧与原海报构图、色彩、文字版式一致。
- 默认只为三大主层级设计动态出场：背景与基础色块、核心识别元素、主标题与 Logo。辅助信息、装饰图形和氛围效果默认静态淡入就位；仅当海报极简（≤2 层实质内容）时才为所有层设计动态出场。
- 出场顺序严格递进：背景与主要视觉结构先建立 → 视觉锚点以纵深运动或尺度变化入场 → 主标题与 Logo 在高潮附近强化 → 辅助文字和装饰信息结尾进入原位。
- 前一元素完全就位并稳定约 0.5–1 秒后，下一个元素才开始入场。
- 任一时刻只能有一个元素处于主动入场动作中，禁止多个元素同时涌现。
- 核心主体入场时，周围辅助文字、装饰信息不得同步出现。
- 核心视觉锚点禁止逐渐浮现、透明度渐显、渐变显形、从雾气或光影中慢慢浮现等被动方式；必须主动入场，如跑入、走出、旋转上升、逐层组装、从空间纵深冲近、从纸面动态破出。
- 每个元素的入场轨迹必须与最终位置一致：左侧元素从左侧进入，下方元素从下方进入，远处元素由远及近。
- 每个元素须声明景深层级：远景 / 中景 / 近景。
- 文字就位后完全静止，保持清晰可读，不扭曲、不模糊。

### 海报类型推荐

按海报类型选择视觉锚点与入场方式：人物偏动作与空间入场，产品偏动作与材质入场，食品偏光影与材质细节，建筑偏空间生长，纯文字偏书写与版式运动，抽象海报围绕图形、纹理、色块或光线关系组织运动。

### 时间参考（10 秒）

背景铺底 1–2 秒 → 核心锚点入场 2–3 秒 → 主标题与 Logo 1–2 秒 → 辅助与装饰 1 秒 → 收束与微动态 1–2 秒。元素多时压缩辅助层，不压缩核心元素稳定间隔。

### 方向一专属 Storyboard（渐进激活成版 · 10 秒时间码版）

> 时间码模板，可按节奏压缩至 8 秒或拉长至 15 秒。元素多的海报可压缩「辅助与装饰」段，不得压缩元素稳定间隔。

| 时间码 | 视觉动作（Visual） | 动效类型术语 | SFX 拟声词 |
|---|---|---|---|
| 0:00–0:01 | 全画幅纯白/纯色简洁底铺满 | — | BGM 渐入，`<ambient drone>` |
| 0:01–0:02 | 背景与基础色块结构建立（若有装饰图形，先做最底层渐显） | `材质微变`（如适用） | `<subtle texture sound>` |
| 0:02–0:04 | 视觉锚点从远景纵深推近至中景，再到近景落定；摆出海报最终姿态 | `视差推近` / `放大回弹` | 人物：`<footsteps>` + `<fabric rustling>`；产品：`<mechanical rotation>` + `<parts clicking>` |
| 0:04–0:04.5 | 锚点稳定 0.5s | — | SFX 衰减 |
| 0:04.5–0:06 | 主标题与 Logo 入场（沿笔画方向 / 果冻弹跳 / 放大回弹） | `果冻弹跳` / `逐字书写` / `放大回弹` | `<pen scratching>` 或 `<paper sliding>` + 字符卡点音 |
| 0:06–0:06.5 | 标题稳定 0.5s | — | SFX 衰减 |
| 0:06.5–0:08 | 副标题、辅助标签、装饰元素逐个入场 | `卡片滑入` / `打字机` / `卷轴展开` | `<pen scratching>` 续 / `<swoosh>` |
| 0:08–0:09 | 收束过渡（运动减速稳定） | — | BGM 渐弱 |
| 0:09–0:10 | 锁版后微动态：呼吸感 / 光斑闪烁 / 材质微变 | `呼吸感` / `光斑闪烁` | 极低音量 `<ambient drone>` 持续 |

成型后进入锁版状态：文字完全静止，主体只保留极微幅呼吸感、微表情、发丝微动、光影流动或材质微变；不得改变主体占比和构图。

### 方向二专属 Storyboard（纸卷展开 · 10 秒时间码版）

## Step 8：音频设计

默认开启 MiniMax H3 同步音频。Storyboard 和提示词须规划音频节拍：

### 8.1 BGM 氛围（贯穿全程）

- 一条贯穿全程的氛围底音，音量克制、不喧宾夺主。
- 节奏曲线：开场轻柔铺底 → 中段随高潮加强 → 收束段渐弱至低声量持续。
- 收束后不完全静音，保留极低声量的持续氛围底音以配合锁版后微动态。

### 8.2 拟声词风格库（按方向调性锁定一套，整条保持一致）

H3 对中文化拟声词响应良好，**显式写入拟声词比仅写英文 SFX 标签更易命中预期**。按所选方向的情绪调性，锁定一套拟声词风格库：

| 方向情绪 | BGM 风格 | 拟声词风格（示例） | 适用方向 |
|---|---|---|---|
| **克制 / 优雅** | 极简电子 + 钢琴泛音 | "咻——叮！"、"嗒——" | 方向 1、方向 4、方向 6 |
| **冲击 / 夺目** | 鼓点 + 低频 bass | "轰——"、"啪嗒！"、"啵-唧-啵" | 方向 2、方向 3 |
| **科技 / 专业 / B 端** | 合成器 pad + 电流声 | "嗡——"、"嘶——"、"咔哒" | 方向 5、方向 6 |
| **文艺 / 人文 / 艺术** | 钢琴 / 木吉他 / 弦乐 | "沙沙——"、"唰——"、"滴答滴答" | 方向 7 |
| **现代 / 设计 / 几何** | 电子节拍 + 节奏碎点 | "嗖——"、"咔哒"、"叮-咚-铛" | 方向 5、方向 8 |
| **电影感 / 氛围 / 情绪** | 弦乐 + 颗粒 ambient | "呼——"、"咝——"、环境拟声 | 方向 4、方向 8 |

### 8.4 各方向专属 SFX 序列

| 方向 | SFX 序列（按时间码） |
|---|---|
| 方向 1 渐进激活 | ambient drone 起 → 元素逐个入场 SFX（按入场时序）→ 收束段 ambient 渐弱 |
| 方向 2 纸卷展开 | paper roll drop → impact → paper unfurling → paper flutter → paper settling → 元素 SFX 续 → ambient |
| 方向 3 破框冲出 | whoosh 冲出 → impact 弱化 → 元素 SFX → ambient |
| 方向 4 视差 | ambient drone 全程 → 极轻 fabric rustling（环绕时）→ ambient |

### 8.5 音效纪律

- 音效须严格跟随元素逐个递进的时序
- 不得出现与当前未入场元素对应的音效
- 不得多元素音效同时响起
- 每个音效仅在该元素入场动作启动时触发、就位后自然衰减
- 锁版后微动态 SFX 音量须远低于入场音效

## Step 9：生成流水线（关键帧 → 逐段 → 拼接）

> **v1.0.0 重大变更**：旧的「单次 H3 一次生成、一镜到底」流水线被替换为三段式流水线。详细规范见 SKILL.md 英文版 Step 9.1 / 9.2 / 9.3；本节做最小同步。

### 9.1 预渲染关键帧（image_synthesize）

- 工具：`image_synthesize`，单次最多并行 10 张。
- 关键帧 prompt 格式见 SKILL.md 英文版 Step 10.5。
- 关键帧总数 5–9 张；最后一张（KF N）为锁版帧，必须 1:1 还原原海报，调用时把原海报作为 `input_file_paths` 传入。
- 输出路径：`output/<case_id>/keyframes/kf_NN.png`。

### 9.2 逐段渲染视频（gen_videos / batch_image_to_video）

- 工具：`batch_image_to_video`，每段一次调用，**永不为整条视频单次生成**。
- `input_image_path` = 上一张关键帧；`reference_type` = `first_frame`。
- `prompt` = 该段的逐段 prompt（≤ 1500 字符），从 SKILL.md Step 10 故事板脚本式 prompt 模板拆出。
- `duration` = 该段时长（典型 1–3s；工具只支持 6/10s 时按 6s 跑，最后用 FFmpeg trim）。
- `resolution` = 1080P（工具限制时 768P）。
- 输出路径：`output/<case_id>/segments/seg_NN.mp4`。
- 验证：每段最后一帧必须落在"下一张关键帧"附近；不达标则加 prompt 强约束后重跑。

### 9.3 拼接 + 可选 BGM 混入（FFmpeg）

- 9.3.1 视频拼接（必做）：用 FFmpeg concat 把所有段拼成 `output/<case_id>/assembled.mp4`。
- 9.3.2 可选 BGM 混入（仅 `bgm_required: true`）：用 `batch_text_to_music` 出 BGM，再 FFmpeg amix 混入，音量约 -20dB。
- 9.3.3 最终交付：`output/<case_id>/final.mp4`（含 BGM，如有）+ `assembled.mp4`（仅 SFX）。
- v0.8.1 的锁版强约束（"主体 MUST 回到原位" / "1:1 复原"）仍然适用，但**改为约束最后一段的最后一帧**（即最后一张关键帧 = 原海报 1:1 还原）。

## Step 10：提示词写法（分镜脚本式）

提示词总字符数不超过 7000 字符（含 `<<<image_1>>>` 标签），语言跟随用户对话语言。**采用分镜脚本式结构**（参考 ComfyUI 圈 H3 主流玩法）：开篇「整体氛围段」+ 主体「N 个镜头段落」+ 收尾「锁版约束段」+ 末尾「音频段落」。H3 对显式时间码 + 动效类型术语 + 拟声词响应良好，**远比泛泛描述更易命中预期效果**。

### 10.1 结构总览

```
[整体氛围段] ← 一段简短的全局声明（不超过 300 字符）
   ↓
[镜头段 1：0:00–0:01] 画面动作 + 动效术语 + 拟声词
[镜头段 2：0:01–0:02] ...
...
[镜头段 N]
   ↓
[锁版约束段] ← 收束 + 锁版 + 微动态
   ↓
[音频段落] ← BGM + 拟声词总表 + 音效纪律
```

### 10.2 整体氛围段（开头必写，≤300 字符）

按顺序写明：

1. **基准声明**：以 `<<<image_1>>>` 作为最终锁版参考；开场不要求是完整海报，可为空白、半成品或抽象态；最终画面还原海报构图、色彩、文字；画面内容填满全部画幅，无黑边、无留白、无 letterbox/pillarbox。
2. **比例适配**（若存在偏差）：以海报核心内容为主体居中，向多出区域延伸背景色调与纹理填满全画幅，不裁切核心内容、不加黑边、不拉伸变形。
3. **所选方向声明**：dynamic direction = [方向名]；情绪 = [克制/冲击/科技/文艺/现代/电影感]；比例 = [最终比例]；时长 = [N 秒]。
4. **核心硬约束**：`single continuous shot, no cuts, no transitions`。
5. **文字保护**：保持海报文字清晰可读，不产生变形或模糊；就位后完全静止。
6. **拟声词风格锁定**：[克制/冲击/科技/文艺/现代/电影感]，使用对应拟声词风格库（参见 Step 8.2）。

### 10.3 镜头段落写法（主体 N 段，按时间码排）

**每个镜头段落必须包含 4 项**：

```
[镜头段 X · 时间码 0:XX–0:XX]
画面动作：[具体视觉动作描述，含动效类型术语（见 Step 6 速查表）]
SFX：[对应拟声词 + 英文标签]
景深：[远景 / 中景 / 近景 / 前景 / 背景]
```

#### 写法纪律

- 时间码须与 Storyboard 表格一致，按真实时长（8/10/15 秒）写。
- 动效类型术语须使用 Step 6 速查表中的标准术语（中文或英文），不得自造。
- 每个镜头段内只描述**一个主元素**的动作，**禁止在同一镜头段内合并多个元素同时运动**。
- 拟声词与画面对齐——人物入场用脚步/衣料；产品用机械；文字用笔/纸；方向专属拟声词（纸卷/光束/切片/线稿/氛围）按 Step 8.4 调用。
- 前一元素须完全就位并稳定 ≥0.5s，下一元素才开始入场（**通过时间码天然实现**，相邻镜头段间隔 ≥0.5s）。
- 镜头段按时间码升序排列，不得乱序。

### 10.4 锁版约束段（末尾）

- 1–2 秒收束过渡（运动减速稳定）。
- 主体 / 角色 / 主视觉必须精准回到原海报位置——不得有水平漂移、缩放变化、Z 轴位移；最终画面必须 1:1 保留原海报构图、色彩、文字版式。
- 锁版后仅保留极微幅 `呼吸感` / `光斑闪烁` / `材质微变`；主体占比和构图不得改变。
- 文字完全静止且与原位对齐。
- 画面内容始终填满全画幅，无黑边、无留白、无 letterbox/pillarbox。

### 10.5 音频段落（最末）

```

[SFX 序列]
- [时间码 + 拟声词 + 元素名 + 英文标签]
- ...
[锁版后微动态 SFX]
极低声量持续 ambient / 材质微变声，音量远低于入场音效。
[音效纪律]
- 严格跟随元素逐个递进的时序
- 不得提前响起未入场元素音效
- 不得多元素音效同时响起
- 每个音效仅在该元素入场动作启动时触发、就位后自然衰减
```
