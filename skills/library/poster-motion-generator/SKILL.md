# Poster Motion Generator（海报动态生成器）

## 何时使用

当用户上传至少一张海报图片，并希望生成 8–15 秒、一镜到底、铺满全画幅、最终保留原构图和文字可读性的动态海报视频时使用本 Skill。不用于从零设计海报、多镜头剧情片或普通幻灯片。

## 语言一致性

- 从用户最新一条包含实际任务的输入中判断运行语言，不根据本 Skill 文件语言、文件名、元数据或参考资料语言判断。
- Agent 回复、方向卡、`Final_Video_Spec.md`、Storyboard、生成提示词、错误提示和交付总结全部跟随该用户输入语言。
- 用户用中文输入时，即使加载的是 `SKILL.md`，也必须用中文回复和撰写运行内容；用户用英文输入时，即使存在中文元数据或 `SKILL.cn.md`，也必须用英文回复和撰写运行内容。混合语言输入时使用占主导的语言；若不明确，则使用直接指令短语的语言。
- 海报原有文字默认保持原语言，不翻译、不本地化，除非用户明确要求。

## Step 1：强制前置校验

- 用户必须先上传至少一张海报图片。
- 若未上传海报，只用检测到的用户输入语言回复：中文 `请先上传一张海报图片`；英文 `Please upload a poster image first`；其他语言使用同义表达。
- 没有海报时不得继续分析、方向选择、规格写入、Storyboard 或生成。

## Step 2：海报分析与比例映射

展示方向前必须分析：

- 方向判断：横版、竖版或正方形。
- 宽÷高数值估算：直接输出小数，如 1.78、0.80、1.00。
- 数学映射：与 MiniMax H3 支持比例逐一比对并取绝对差最小者：21:9=2.3333、16:9=1.7778、4:3=1.3333、1:1=1.0000、3:4=0.7500、9:16=0.5625。
- 输出结论：`方向：[横版/竖版/正方形]，宽高比估算值：≈[X.XX]，映射到支持比例 [最终比例]`。
- 标注比例偏差和是否需要背景扩展。
- 标注海报是否铺满画幅、有无白边或留白。

接受任意比例海报，不拒绝、不要求用户确认比例。若有偏差，通过延伸背景色调与纹理填满输出画幅，核心内容不裁切、不拉伸、不加黑边。

### 方向交叉验证

立即检查：数值 >1 应为横版，<1 应为竖版，≈1 应为正方形。若方向判断和数值矛盾，仅重分析一次：`请直接对比这张图片的宽度和高度，哪个更大？宽是高的大约多少倍？给出一个宽÷高的数值估算。` 采用第二次结果，不无限循环。

## Step 3：内容分析

记录：

- 海报类型：人物 / 产品 / 食品 / 建筑 / 纯文字 / 抽象图形 / 无明确主体。
- 视觉主体的位置、占比、朝向、最终姿态。
- 无人物海报的核心运动承载：主标题、产品、Logo、图形、纹理、光线或颜色关系。
- 构图与景深：主体位置、前景/中景/背景、留白、纵深路径。
- 风格与主色调。
- 文字版式：标题、Logo、标语、辅助信息的位置和层级；文字必须保持可读。
- 五层拆分：背景/基础形、核心识别元素、主标题/Logo、辅助信息、装饰/氛围层。
- 视觉锚点和可动元素。
- 纸卷方向专用：海报轮廓、纸卷轴线和展开方向；横版优先横向展开，竖版优先纵向展开。

## Step 4：提供动态方向

用选择卡展示动态方向并暂停。推荐卡必须先列方向 1，再列方向 2；其余方向作为补充。用户要求完整选项时展示全部 8 个。

1. **视觉元素渐进激活成版**：从简洁或抽象开场开始，背景、锚点、标题、辅助信息逐层进入，最终锁成原海报。
2. **纸卷展开成版**：实体纸卷坠落弹开，空白纸面铺满画幅，随后海报元素逐层破出 / 激活 / 回到最终版式。
3. **裸眼 3D 破框冲出**：核心人物、产品、食品、建筑局部或主标题向镜头冲出再回版。
4. **多层视差镜头唤醒**：前景、中景、文字、背景以不同深度运动，形成活的海报。
5. **粒子 / 线框 / 点线面重组**：元素拆解为粒子、线框、点线面后重组成原版式。
6. **光影材质微雕**：用扫光、反射、高光、阴影和材质微变唤醒海报。
7. **动态文字排版成版**：标题、Logo、标语和辅助文字以书写、滑入、打字、弹跳或网格运动成版。
8. **场景物理氛围循环**：雨、雪、烟、风、尘、火花、光斑、胶片颗粒或纸张颗粒做轻微氛围运动。

## Step 5：全局规格锁定

用户选择方向后，写入 `Final_Video_Spec.md`：

- aspect_ratio：Step 2 映射比例；model：MiniMax H3；resolution：2K；duration：8–15 秒。
- camera mode：single continuous shot，一镜到底，无内部剪辑。
- dynamic direction：用户选择的方向。
- 上传海报是最终锁版参考，不是必须的开场帧。
- 全画幅策略：无黑边、无留白、无 letterbox/pillarbox。
- 比例适配：需要时延展背景，不裁切、不拉伸核心内容。
- 锁版策略：还原后 1–2 秒收束，再保留极轻微微动态；文字完全静止，主体不得继续缩放或漂移。
- 锁定本方向使用的动效术语和 SFX 语气。

## Step 6：Storyboard 规则

只为用户选中的方向设计一条连续镜头。

通用规则：

- 全片 8–15 秒，一镜到底，无剪辑、无转场。
- 开场可以是空白、半成品、抽象底或材料设定，不需要一开始显示完整海报。
- 最终锁版帧必须还原上传海报的构图、色彩、层级和文字版式。
- 默认只让主要层级动态出场：背景/基础、核心识别元素、主标题/Logo。辅助信息和装饰通常淡入或滑入即可。
- 顺序严格递进：背景结构 → 视觉锚点 → 主标题/Logo → 辅助信息/装饰 → 收束 → 微动态。
- 任一时刻只能有一个元素或层组主动入场。
- 核心锚点必须主动入场，不使用被动渐显或慢慢浮现。
- 每个轨迹必须符合最终位置和景深层级。
- 文字必须清晰可读，就位后完全静止。

提示词中显式使用动效术语：`果冻弹跳/Jelly Pop`、`放大回弹/Scale & Bounce`、`逐字书写/Kinetic Typography`、`打字机/Typewriter`、`卷轴展开/Scroll Unroll`、`卡片滑入/Card Slide-in`、`纸面破出/Paper Breakout`、`光束扫掠/Light Sweep`、`笔触勾勒/Brush Stroke`、`切片飞入/Slice Reassembly`、`视差推近/Parallax Push-in`、`环绕展示/Orbital Display`、`粒子重组/Particle Reconstruction`、`呼吸感/Breathing Pulse`、`光斑闪烁/Lens Flare Blink`、`材质微变/Material Shift`。

## Step 7：方向时间码模板

采用“时间码 + 画面动作 + 动效术语 + SFX”的分镜脚本格式。可压缩到 8 秒或延展到 15 秒。

### 方向 1 模板

- 0:00–0:01：简洁 / 抽象底铺满画幅，氛围音开始。
- 0:01–0:02：背景与基础结构建立。
- 0:02–0:04：视觉锚点从纵深主动入场，并落到最终海报姿态。
- 0:04–0:04.5：锚点稳定。
- 0:04.5–0:06：主标题与 Logo 用果冻弹跳、逐字书写或放大回弹成版。
- 0:06–0:06.5：标题稳定。
- 0:06.5–0:08：辅助文字和装饰用卡片滑入、打字机或卷轴展开逐个入场。
- 0:08–0:09：收束过渡。
- 0:09–0:10：锁版后呼吸感、光斑闪烁或材质微变。

### 方向 2 模板

- 0:00–0:02：纸卷坠落、蓄力、弹开；使用纸张坠落、冲击、展开、抖动音效。
- 0:02–0:02.5：空白纸面铺满画幅。
- 0:02.5–0:05：背景和核心元素逐个出现；核心元素使用纸面破出 + 材质微变。
- 0:05–0:07：主标题和 Logo 用果冻弹跳 / 逐字书写落位。
- 0:07–0:08：辅助文字和装饰用卡片滑入 / 卷轴展开就位。
- 0:08–0:09：完整海报收束。
- 0:09–0:10：锁版微动态。

方向 3–8 沿用同样时间码格式，根据方向名称选择相应动效术语。详细旧版模板保存在 `references/v08-motion-reference.md` 和 `references/v08-motion-reference.cn.md`。

## Step 8：音频设计

默认开启 MiniMax H3 同步音频。全程使用克制氛围底音，中段高潮略增强，锁版后降为低音量持续。音效严格对齐元素出现时序：人物 `<footsteps>` / `<fabric rustling>`，产品 `<mechanical rotation>` / `<parts clicking>`，文字 `<pen scratching>` / `<paper sliding>`，图形或纹理 `<subtle texture sound>`，纸卷 `<paper roll drop>` / `<impact>` / `<paper unfurling>` / `<paper flutter>` / `<paper settling>`。未入场元素不得提前发声音效。

## Step 9：MiniMax H3 生成

- 使用 MiniMax H3 全能参考模式。
- 上传海报作为主图像参考，并作为最终锁版参考使用。
- 若有额外参考图、视频或音频，可传入对应多模态参考槽。
- 单次生成整条视频，不拆分多次生成。
- 使用 2K、映射比例、8–15 秒、同步音频。

## Step 10：提示词写法

提示词顺序：

1. 基准声明：`<<<image_1>>>` 是最终锁版参考；开场可为空白 / 半成品 / 抽象；最终还原构图、色彩、层级和文字；全画幅无黑边。
2. 比例适配。
3. 方向与时间码分镜。
4. 每个元素的动作、轨迹、景深层级、动效术语和 SFX。
5. 文字保护与锁版约束。
6. 音频段落与音效纪律。

必须包含：`single continuous shot, no cuts, no transitions`。

## Step 11：交付

交付生成的单镜头视频，保留 MiniMax H3 原生音频和完整时长。询问用户是否继续调整、换方向或导出。
