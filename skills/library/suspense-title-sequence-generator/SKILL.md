# 悬疑美学电影片头

当用户想生成一支短电影预告片头 / 电影片头 / Title Sequence 时使用本 Skill。用户只提供少量变量，Skill 先把每个 Shot 的关键帧视觉锚定，再进行视频生成，避免人物参考图直接进视频导致构图和身份崩坏。

默认输出是一支 15 秒 16:9 横版视频，视觉语言为复古日系动画片头、硬边剪影、漫画拼贴、非对称分屏、强烈几何色块、清晰英文署名、少量日文片假名装饰，以及 60% 悬疑 / 40% 爵士的都市犯罪气质。

## 核心原则

用户只需要提供：

1. 电影类型
2. 电影名字
3. 一句话剧情
4. 演员表
5. 可选参考图片

其他全部使用默认值。除非用户明确要求，不要重新设计主模板结构。

重要：一句话剧情只作为内部理解辅助，不要把一句话剧情原文粘贴或复述到最终视频 Prompt 里。它只用于推断合适的视觉意象、人物关系、道具线索、证据墙对象、对峙双方和背景地点。

本 Skill 的执行顺序必须是：

```text
确认影片资料与参考图理解 → 生成6个关键帧生图Prompt → 生成6张关键帧锚图 → 基于关键帧锚图编译视频Prompt → 生成最终视频
```

不要在确认影片资料后直接生成视频。

## STEP 1：收集最小变量

只收集缺失的必填变量：

- `film_type`：电影类型，例如轻悬疑犯罪、黑色爱情、复古间谍、心理悬疑、女性复仇犯罪。
- `title`：电影名字。默认建议英文片名，因为片头默认只出现英文标题和英文署名。
- `logline`：一句话剧情。不会写入最终视频 Prompt，只用于内部推断画面意象。
- `cast`：演员表，用于唯一的 `STARRING ...` 署名。
- `references`：可选参考图片。可以是主角、配角、道具、场景、风格参考、影视截图、片头截图、服装参考或构图参考。

如果用户已经提供完整信息，不要重复询问。如果缺少信息，用一个简短问题一次性询问。

### 演职员署名解析规则

- 用户提供的职位和姓名优先级最高，必须严格使用，不得被默认值覆盖。
- 用户提供导演时，`DIRECTED BY` 必须使用用户提供的导演姓名。
- 用户提供主演时，只用于 `STARRING {cast_names}`。
- 不要把用户提供的导演改写为 `CREATED BY`，也不要用默认导演替换用户导演。
- 未提供的职位不得自动生成姓名，不得自动使用旧模板里的 `EDITED BY JUNE PARK`、`CREATED BY MIRA HOLT`、`DIRECTED BY NOAH VOSS`、`PRODUCTION DESIGN BY VERA LIN`。
- 如果源模板中某个 Shot 原本需要署名，但用户没有提供该职位，则该 Shot 在关键帧阶段完全不要提及 credit、署名区、空白标签、人名、职位或英文占位区；只保留构图、人物、道具、色块、线框和版式设计。
- 如果视频阶段也未提供该职位，则该 Shot 不显示该职位署名，也不要描述空白标签或署名区动效；只描述画面元素、版式运动和转场。
- 只有当用户明确允许“自动补齐主创署名”时，才可以为未提供职位生成虚构英文姓名。允许自动补齐前，必须先问用户。
- 若用户提供了导演和主演但没有提供剪辑、主创、美术指导，则默认只出现片名、`STARRING ...` 和 `DIRECTED BY ...`。

推荐提问：

```text
请补充以下缺失信息，我会用默认模板生成6个关键帧生图Prompt，再生成关键帧图和最终视频：
1. 电影类型：
2. 电影名字：
3. 一句话剧情，只用于内部理解，不会复制进最终视频 Prompt：
4. 演员表，建议提供 1–3 位英文演员名：
5. 可选参考图片，可上传主角、配角、道具、场景或视觉风格图：
```

## STEP 2：识别参考图片

如果用户标注了每张图的用途，严格按用户说明执行。用户说明优先于自动识别。

如果用户没有标注图片用途，则将每张上传图识别为以下一种或多种角色：

- `protagonist`：主角 / 核心人物参考
- `supporting_character`：配角 / 群像人物参考
- `prop`：线索道具 / 象征物 / 片头插入画格
- `scene`：环境 / 场景 / 世界参考
- `style`：视觉语言 / 色块 / 字体 / 拼贴 / 版式参考
- `shot_reference`：影视截图 / 镜头 / 构图 / 节奏参考

参考图使用规则：

- 人物图首先是人脸身份和角色线索参考。保留可识别的人脸身份、发型、五官结构、显著配饰和基础服装身份，然后进行电影化重构。不要直接复制原图姿势、自拍角度、生活照构图、原始光线、原始背景、身体朝向或坐/站动作，除非用户明确要求。
- 人物图只有在遵守电影化重构规则后，才提供剪影、服装轮廓、发型轮廓、首饰/配饰身份和角色设计线索。
- 配角图可用于电影化重构后的群像剪影、对峙人物、档案照片或分屏画格。
- 道具图可转化为线索插入、拼贴画格、证据墙元素、特写、转场遮罩或设计过的拼贴面板。
- 场景图提供环境结构、都市氛围、窗户形状、屋顶、天桥、港口灯光、走廊或室内空间线索。
- 风格图提供硬边剪影、低饱和或高饱和撞色色块、分屏语法、线框、字体版式、动态图形拼贴节奏和片头包装感。
- 影视截图只用于抽象视觉语言、构图、氛围和节奏，不要精确复刻受版权保护的画面、真实演员或已有 IP。

只有当图片角色模糊且会明显影响结果时，才简短询问。例如：某张人物图应该作为主角还是配角。否则直接继续。

## STEP 3：确认影片资料与参考图理解

在生成关键帧生图 Prompt 前，必须先简短确认影片资料和参考图角色，而不是直接进入视频生成。

推荐确认文案：

```text
我将按以下影片资料继续：
- 电影类型：{film_type}
- 电影名字：{title}
- 演员表：{cast_names}
- 一句话剧情：已收到，只用于内部分析，不会复制进最终视频 Prompt
- 参考图理解：
  - 图1：{role}，用于{usage}
  - 图2：{role}，用于{usage}
- 参考图重构：人物图只用于人脸身份和可识别角色线索，姿势、镜头角度、光线、构图和背景都会电影化重构。
- 默认规格：15秒，16:9横版，复古日系动画片头，硬边剪影，漫画拼贴，只出现英文署名，不新增中文。

确认后我会先生成6个关键帧生图Prompt，再生成关键帧图，最后生成视频Prompt和最终视频。
```

如果用户明确说“直接继续、不用确认资料”，可以跳过本确认。

## STEP 4：生成6个关键帧生图 Prompt

确认影片资料后，先为 Shot 01–Shot 06 生成中文生图 Prompt。默认每个 Prompt 生成一张 16:9 横版关键帧锚图，用于后续图生视频。

生图 Prompt 必须：

- 使用中文编写，除片名和英文署名外不写中文屏幕文字。
- 每个 Shot 单独一个 Prompt，不要把6个 Shot 合成一张图。
- 明确写出 16:9 横版、电影片头关键帧、用于后续图生视频。
- 锁定画面构图、人物位置、道具数量、文字位置、分屏/边框/色块结构。
- 人物参考图只用于身份线索，画面必须电影化重构。
- 片名和英文署名必须清晰可读，不错拼，不乱码。
- 不要把一句话剧情原文写进画面或 Prompt 的屏幕文字部分。

### 统一关键帧生图风格锁

所有关键帧必须采用高饱和波普拼贴电影片头风格：高饱和红、黄、蓝三原色作为主要色彩，黑色和白色作为压重与辅助。整体色彩必须高对比、高饱和、纯色块，不使用低饱和灰调，不使用柔和渐变，不使用复杂纹理。

背景采用大面积纯色几何色块拼接，不同颜色之间以干净利落的直线分割。大面积红色常作为主背景，黄色和蓝色作为强对比辅助色块，黑色用于人物剪影、黑胶唱片和重文字，白色用于细线、边界、高光和排版辅助线。

画面融合波普艺术、瑞士平面设计、构造主义几何构成、20世纪60年代黑胶唱片封面、复古悬疑电影片头和日本杂志式排版。整体要像高饱和复古片头设计稿、黑胶唱片封面、电影片头包装关键帧，而不是写实电影剧照。

人物处理方式：默认仍以纯黑或深色硬边剪影为主，但当用户上传主角人脸参考图时，必须提升用户体验，让主角的脸在 Shot 01 和 Shot 06 中有限露出。露出的脸不能是纯真人照片、生活照脸或写实肤色复制，而要转译为与整体画风一致的高饱和波普插画脸 / 图形化漫画脸：保留可识别的脸型、五官比例、发型、眉眼特征和显著配饰，用硬边色块、少量面部阴影、有限肤色色块或单色调面部色块表现。Shot 02、Shot 03、Shot 04、Shot 05 仍保持全身剪影、背影、侧脸剪影或档案化图形，不露出清晰主角正脸。人物参考图不能直接复制原图姿势、背景、光线或拍摄角度。

道具处理方式：道具可以采用写实静物抠图拼贴，边缘清晰，带轻微统一投影和商业静物高光，例如玻璃、珍珠、口红、黑胶、玫瑰、录像带、手表、文件夹等可以保留一定体积感。道具必须像被剪贴到纯色几何背景上的拼贴素材，不要放入真实空间。

排版方式：文字是画面结构的一部分，不是简单标题。大量使用现代无衬线字体、细体英文、大字号标题、小字号辅助文字、竖排文字、横排文字、边缘排版和色块交界处排版。可加入少量英文、日文片假名或抽象字体作为图形化视觉元素，但主标题和署名必须清晰可读，不得乱码，不得出现中文。

画面加入极细白色辅助线、裁切线、十字定位线、网格线、排版参考线和细线框，模拟平面设计稿和电影片头版式系统。线条必须极细、克制、专业，不抢占主体视觉。

禁止：低饱和灰调、柔和渐变、复杂纹理、写实背景、照片堆叠、生活照拼贴、电影剧照感、三维空间场景、过度阴影、脏旧恐怖风、血腥、鬼怪、欢乐MV、中文屏幕文字。

生成后先向用户展示6个生图 Prompt。若用户要求修改某个 Shot，只改对应 Shot 的 Prompt。用户确认或要求继续后再生成关键帧图。

### Shot 01 生图 Prompt 规则：片名 / 黑胶开场

- 画面采用高饱和波普拼贴电影片头风格。背景以大面积高饱和红色为主，搭配高饱和黄色、蓝色、黑色和白色。色彩必须是纯色块、高对比、高饱和，不要低饱和灰调，不要柔和渐变，不要复杂纹理。
- 构图采用复古黑胶唱片封面和瑞士平面设计式几何分区：左侧可使用竖向色块分区，右侧可使用倾斜黄色平行四边形色块，中下偏左放置圆形黑胶唱片，黑胶唱片作为画面视觉重心。
- 几何色块之间用干净利落的直线分割，整体平面感强。
- 黑胶唱片必须明显出现，可带有同心圆纹理和中心彩色标签，但仍保持图形化。黑胶圆形是后续圆形遮罩转场的视觉核心，不要被文字或色块完全遮住。
- 如果用户上传主角人脸参考图，Shot 01 必须让主角脸部有限露出：可放在右侧黄色平行四边形色块、黑胶边缘或片名旁，表现为半身图形化肖像、三分之二侧脸或正侧结合的波普插画脸。保留可识别脸型、眉眼比例、发型和显著配饰，但不能是纯真人脸、生活照脸或照片贴脸；脸部必须被转译为硬边色块、漫画线条、有限单色调肤色色块和高饱和片头设计语言。若没有人脸参考图，则人物可保持纯黑硬边剪影。
- 道具数量控制在5个以内。道具可以包括黑胶唱片、口红、高脚酒杯、珍珠项链、带刺玫瑰，或根据剧情替换为一个关键线索物。除人物外，道具采用写实静物抠图拼贴方式：边缘清晰，有轻微统一投影，玻璃、珍珠、口红、玫瑰可保留商业静物质感。
- 主片名 `{title}` 只出现一次，必须清晰可读，使用现代无衬线字体，可以大字号横排或与几何结构结合排版。不要出现 `MUSIC BY`，不要出现任何主创署名，不要出现中文。
- 可加入少量英文、日文片假名或抽象字体作为图形化排版元素，分布在画面边缘、色块之间、竖向边栏、底部或右下角色块内。辅助文字不强调可读性，但必须有设计感，不能像乱码，不能影响主片名识别。
- 画面像动态图形片头刚启动的一瞬间：分屏线快速划出，色块逐块贴入，黑胶即将旋转，片名即将被遮罩揭示。

### Shot 02 生图 Prompt 规则：主演登场 / 斜线主角团分屏

- 画面必须分成对应主演人数的均等斜线分屏区域；三位主演时使用三个均等斜线分屏面板。
- 分割线锐利、干净、图形化，分屏底色可使用高饱和红、黄、蓝，黑色线条和白色细线作为分隔。
- 每个分屏里出现一位主角的全身背影剪影或全身图形剪影，从头到脚完整出现，人物轮廓清晰可读。
- 人物必须是纯黑或深色硬边剪影，不出现写实脸、肤色、五官细节或生活照质感。
- 角色只通过不同发型轮廓、服装外轮廓、肩颈线条和站姿区分。动作和姿态要对称、镜像或有编舞式节奏。
- 所有分屏背景必须看上去属于同一个整体空间，而不是割裂场景。背景不是写实公寓，而是由红黄蓝黑白纯色几何色块构成的连续室内空间暗示。
- 背景必须保持连贯性：跨越斜线分屏的主要色块、窗格线、墙面结构、地面透视、远处城市灯光或室内轮廓要能在不同分屏之间接续，像同一个空间被斜线切开，而不是三张独立背景图。
- 背景物体和色彩风格必须连贯：如果出现窗框、墙线、栏杆、落地窗、城市灯点、抽象家具轮廓或建筑剪影，它们的尺度、方向、线条粗细、透视关系和色彩体系要统一；不要每个分屏使用不同物体语言、不同光源、不同饱和度或不同风格。
- 每个分屏可以有不同主色倾向，但三屏必须共享同一套高饱和红黄蓝黑白色彩系统，色块边缘和辅助线要跨屏对齐或呼应，形成完整统一的主角团登场版式。
- 本镜头禁止出现任何道具：不要高跟鞋、戒指、镜子、信件、酒杯、城市碎片、贴纸、线索物、录像带或漂浮抠图。允许作为背景结构的窗框、墙线、地面线、城市灯点或抽象建筑轮廓，但它们必须属于连续背景的一部分。
- 出现唯一署名：`STARRING {cast_names}`。文字使用现代无衬线字体，可沿底部、边缘或斜线分屏边界排列，必须清晰可读。

### Shot 03 生图 Prompt 规则：屋顶追踪 / 平行四边形奔跑拼贴

- 画面是整齐的漫画拼贴结构，每一格都有完整清晰的白色边界，边框干净、规则、有印刷纸张和片头版式设计感。
- 画面中央放置一个大的平行四边形拼贴边框，里面是长外套女人剪影在月下奔跑。
- 主角必须是纯黑或深色硬边剪影，不要写实人物，不要肤色，不要五官；可带轻微漫画拖影，裙摆和发丝被风掀动。
- 背景不要做写实屋顶，而用纯色几何色块暗示夜晚屋顶和城市天际线：高饱和红色主背景，深蓝色夜空块，黄色或白色月光块，黑色建筑剪影。
- 左右两边分别在角落放置四个道具画格，总道具数量不超过四个。道具根据剧情选择，如旧VHS录像带、闪烁时间码画面、日记本、儿童发夹、阳台栏杆、望远镜圆形视角、手表等。

### Shot 04 生图 Prompt 规则：档案线索 / 证据墙

- 画面主体是一面平面化证据墙：大面积高饱和红色作为主背景，黑色档案块、黄色信息卡、蓝色照片框和白色细线构成证据墙版式。

### Shot 05 生图 Prompt 规则：对峙 / 冲突色块构图

- 根据一句话剧情分析对峙双方：主角团之间、主角与反派，或主角团与反派阵营。
- 画面必须是对称构图，双方分别占据左右两侧或画面两端，形成明显张力。
- 人物必须是纯黑或深色硬边剪影、背影、侧脸剪影或图形化肖像，不出现写实脸、肤色、五官细节或生活照质感。

- 若用户提供导演职位，则出现唯一署名：`DIRECTED BY {director_name}`，署名可从画面左右或中心分界处出现，清晰可读；若用户未提供导演，则不要出现 `DIRECTED BY`、任何虚构导演姓名、credit、署名区、空白标签或英文占位区，只描述对峙构图、冲突色块、人物剪影和道具面板。

### Shot 06 生图 Prompt 规则：群像高潮 / 片名遮罩

- 背景地点根据参考图片和一句话剧情分析，或虚构符合故事设定的城市天台、港口、天桥、夜间公寓外立面、车站、证据档案室、豪宅露台或爵士酒吧屋顶，但必须图形化处理。
- 背景中的城市天际线、港口吊机、老电视雪花屏切片和几何色块都用平面剪影、纯色块和拼贴画格表现，不要普通写实场景。
- 构图以人像为核心。主演剪影或主角团图形人像占据画面中心，是绝对视觉重点。
- 如果用户上传主角人脸参考图，Shot 06 必须以主角脸部为核心视觉之一：中心人物可以是风格化半身肖像、主角团图形化头像或错层人像拼贴，主角脸要清晰可辨但保持波普插画化、硬边色块化、漫画封面化；保留参考图的人脸身份、发型、五官比例和显著配饰，不要生成纯真人脸、生活照质感、写实皮肤纹理或照片贴脸。没有人脸参考图时，人物保持纯黑或深色硬边剪影、背影群像或错层视差人像。

- 片名 `{title}` 在人物背后形成巨大的遮罩字母或标题遮罩。标题不是普通小字，而是巨大的背景结构，城市灯光、几何色块、人物边缘光和拼贴画格从标题遮罩中透出。标题必须清晰可读。

## STEP 5：生成关键帧锚图

用户确认6个生图 Prompt 后，生成6张关键帧锚图。默认使用适合复杂构图、文字和版式的图像模型；如果用户指定模型、质量、分辨率或比例，以用户指定为准。

默认关键帧图规格：

- 数量：6张，每个 Shot 1张。
- 画幅：16:9 横版。
- 用途：作为后续视频生成参考图，不是最终海报。
- 文件命名：`shot01-片名黑胶开场`、`shot02-主演分屏`、`shot03-屋顶追踪`、`shot04-证据墙`、`shot05-对峙`、`shot06-群像高潮`。

生成后让用户确认关键帧。若某张图失败，优先重写该 Shot 的图片 Prompt 并只重生对应关键帧，不要直接重跑视频。

## STEP 6：基于关键帧编译最终视频 Prompt

关键帧确认后，再编译最终视频 Prompt。最终视频 Prompt 不是工具说明文档，必须回到用户源视频 Prompt 的段落结构、语气、密度和片头包装描述。关键帧只在开头作为“视觉锚点”说明一次，后续 Shot 段落不要反复写“从@图片X出发”，也不要写成字段式执行说明。

视频 Prompt 编译原则：

- 开头必须直接写：`生成一支15秒16:9横版{film_type}电影片头。电影名字是《{title}》。`
- 接着用一段自然语言说明：全片以六张关键帧作为视觉锚点，分别对应 Shot 01–Shot 06；每个 Shot 必须继承对应关键帧的构图、人物位置、道具数量、分屏结构、色块布局、英文署名、片名版式和主要画面关系。
- 关键帧引用要“隐身”：只在开头说明整体锚点关系，不要在每个 Shot 里重复 `@图片1`、`@图片2` 或“从图片出发”。
- 后续必须恢复源 Prompt 的高密度片头语气：整体风格段、氛围段、片头动效段、英文署名规则段、Shot 01–06 段、转场段、BGM 段。
- Shot 段落标题使用源 Prompt 格式：`Shot 01，片名/黑胶开场：`，不要改成 `【镜头1】` 或表格字段。
- 每个 Shot 要像成片描述，而不是技术指令。关键帧决定构图，Prompt 负责把画面动起来。
- 不复制一句话剧情原文，只使用其分析结果。
- 所有英文署名和职位只出现一次，英文必须清晰可读，不新增中文，不乱码，不错拼。
- 视频 Prompt 中只能出现用户提供过的职位署名；未提供职位不要自动补齐，不要使用默认虚构姓名。未提供职位对应的 Shot 只描述画面、人物、道具、色块、线框和版式运动，不写具体职位英文，不写空白标签或署名区。
- 每个 Shot 段落必须包含明确的转场句，不能只在结尾用一句概括性 `Transition grammar` 代替。Shot 01 写黑胶圆形遮罩扩张；Shot 02 写斜线分屏塌缩或镜面竖切黑色遮罩；Shot 03 写奔跑人物长影横扫；Shot 04 写红线拉直成锋利切割线擦屏；Shot 05 写巨大标题字母遮罩、冲突色块重组或道具画格硬切进入群像高潮；Shot 06 写最后0.5秒完全定格。
- 最终视频 Prompt 结尾必须保留完整转场总段落，不能弱化成一句“所有转场来自图形系统本身”。

## STEP 8：定向修复

如果结果失败，不改变用户变量，优先定位失败发生在哪张关键帧或哪个视频 Shot。

### 关键帧构图失败

只修改对应 Shot 的图片 Prompt 并重生该关键帧。

### 英文署名乱码或错拼

强化：

```text
每个镜头只出现一个职位署名。姓名必须严格照抄。文字入场后短暂停住。不要添加额外英文、中文、符号或乱码。
```

### 太写实或太像剧情动画

强化：

```text
这不是写实剧情动画，必须是动态图形片头包装：分屏、硬边色块、剪影、遮罩、画格和清晰英文署名动效。
```

### 太欢乐或爵士占比过高

强化：

```text
保持60%悬疑、40%爵士。音乐和动效要冷感、紧张、低频、都市暗涌、危险优雅。避免欢乐 swing、舞台演奏感或音乐 MV 气质。
```

### 太恐怖或太沉重

强化：

```text
降低恐怖感，保留神秘、危险、优雅、酷感和都市犯罪气质。不要血腥、惊吓、鬼怪、怪物或沉重恐怖感。
```
