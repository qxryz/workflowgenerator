# Chinese Prompt Pack

Use these Chinese prompts verbatim during execution. Do not translate them before sending them to image or video prompt-writing steps.

## Image Plate Prompt

```text
提取图片中产品的品牌名称、logo、标语，并结合用户输入的品牌名称和标语文本，只保留品牌名称、logo、标语，重新设计一个横版的品牌名称图，背景使用原图的主题色+尽可能保留原图的设计背景；如果读取到原图中有标语，或用户明确输入了标语，则排版时必须将标语放在品牌名称下面，字号小于品牌名称、层级清晰；如果原图和用户输入中都没有标语，则生图时不要写任何标语，也不要留标语占位；所有文字资料只能来源于原图或用户明确输入的文本
```

## Motion Prompt Rewrite Instruction

```text
参考图片是图片1。请在源 prompt 基础上做“最小必要替换”，生成 prompt1。目标是保留源 prompt 的运动结构，而不是重新描述参考图。

修改要求：
1. 只提取品牌名称，以及参考图中明确可见或用户明确输入的 slogan；禁止加入任何其他文字。
2. 只替换以下内容：品牌名称；源 prompt 中“M”对应品牌名称第一个字 / 字母；源 prompt 中“H”对应品牌名称最后一个字 / 字母；是否保留 slogan；主题色；“参考图中的 logo 装饰 / 背景”。这里的品牌名称和 slogan 必须以生成后的图片1中清晰可见的文字为准，而不是以上传原图为准；如果上传原图显示 G，但图片1生成结果显示 Google，则 prompt1 必须使用 Google。生成 prompt1 前必须从图片1显式提取 brand_name_from_image_1、slogan_from_image_1、first_character_exact、last_character_exact、prefix_before_last_character，并校验 prompt1 的品牌字标、大小写、标点、空格、首字母锚点、尾字母锚点和滑出前缀与这些字段完全一致；若不一致，必须先修正文本锚点，再继续后续生成。
3. 严格保留源 prompt 的段落顺序、时间段编号、圆点铺满屏幕、圆环、“M”到“H”、最后一个字母底部从右向左滑出到参考图位置、最终落定这些核心动效逻辑；不得改写成新的品牌故事。若品牌名称是中文，则源 prompt 中的 “M” 必须替换为品牌名称第一个汉字，“H” 必须替换为品牌名称最后一个汉字；最终 prompt 中不得保留任何独立出现的 M、H 占位字母。如果品牌名称不需要英文副标题，则不得自动补出英文品牌名。
4. 禁止展开描述参考图中的具体物体、人物、包装、产品、边框、纹样、品类、规格、功效、价格或品牌知识；统一写成“参考图中的 logo 装饰”“参考图中的背景元素”“参考图中的主题色”。
5. 第一秒必须保持“白色圆形 / 白色圆点”，禁止自适应改成水滴、叶片、山峰、星星、人物、食物或任何具象形状；但不要在最终 prompt 中继续扩写更多负面枚举。
6. 最后一个字 / 字母（源 prompt 中“H”）必须采用参考图中最终品牌字标的字体、字形、颜色、大小和位置，不得用主题色重新上色。
7. 5-6秒增加动态变形：第一个字 / 字母由圆点和细线结构解体、爆散、被旋转轨道吸回、弹性过冲、重组成最后一个字 / 字母。保持一句话表达，不要扩写成新段落。
8. 8-9秒必须先让最后一个字 / 字母缩小并落到最终位置，且最后一个字 / 字母始终保持不动，作为遮挡锚点存在。完成后，前面的字 / 字母不是从画面下方或字形正下方垂直飞出，而是从最后一个字 / 字母遮挡住的底部后缘区域向左滑出；这里的“底部”指被最后一个字 / 字母盖住的后方下缘，不是垂直方向的下方。所有前序字 / 字母必须沿水平方向从右向左依次滑出，像横幅一样连续展开，并滑动到参考图片中对应文字的最终位置，组合成完整品牌名称；禁止垂直下落、向下飞出、弧线弹出或从画面外独立出现。
9. 尾帧规则只写一次：最终0.5-1秒必须直接匹配图片1的静态画面，不得有圆环、轨道线、临时圆点或过渡图形残留。
10. 如果没有 slogan，则删除所有 slogan 内容；如果有用户明确输入的 slogan，可以写入【必须准确显示的文字】。
11. prompt1 的总长度不得超过源 prompt 的 120%；禁止重复规则，禁止追加“严格文字规则”总结段。
12. 保留源 prompt 的 8 秒时间戳设计，不要改成 15 秒结构；但必须在最终 prompt 中保留【严格的平面视觉规则】【视觉语言】【声音设计】【负面 Prompt】四个模块。
13. 只输出最终 prompt1，不要解释，不要说明，不要分析过程。
```

## Source Motion Prompt

```text
为品牌“MiniMax H”创作一支8秒高端平面动态图形品牌影片。【必须准确显示的文字】品牌名称：“MiniMax H”
品牌 Slogan：“xxxxxxx”
除以上两组文字外，画面中不得出现任何其他可读文字。

智能从一个微小节点出发，通过连接、共享与共同生长，形成属于每个人的开放智能网络。
以两种基础元素建立一套原创品牌视觉系统：
  - 一个极小的二维实心圆点
  - 字母“M”所代表的连接桥梁
所有圆点、线条、轨道、字形和转场必须由这套基础元素连续演化。每次变化都具有清晰的视觉因果关系，形成统一的品牌视觉 DNA。

【严格的平面视觉规则】
所有节点必须表现为完全平面的二维实心圆点，而不是立体小球。圆点采用纯色矢量填充，边缘清晰，没有明暗面、渐变体积、反光、高光、玻璃质感、金属质感、阴影或透视厚度。
所有元素位于同一个正面二维平面。采用正交、正视、固定视角，不使用空间纵深、景深、立体摄影机运动或三维旋转。
信号传播只能通过圆点的颜色、大小、透明度和二维波纹变化表达。即使出现光感，也只能是扁平的二维透明光环，不能让圆点变成立体发光球体。

【时间与画面设计】
0-1秒：首帧是一个全黑背景图，画面中心是一个视频播放按钮，配合一声鼠标点击的按钮声音，视频播放按钮变成一个略大一些的白色圆形圆点，然后又变成一个更大尺寸的圆形圆点；这里必须始终是抽象白色圆点 / 圆形，不得变成水滴或任何具象物体，大尺寸圆形的颜色采用参考图中的主题色；变化动态+先缩小后放大的动态感，一个快速的心跳效果；
1-2秒：中心点消失，整个屏幕铺满均匀分布的小圆形，小圆形从中心点以波纹形状逐渐散开，逐步填满整个画面；小圆形有两种颜色：白色+参考图片的主题色；
2-4秒：屏幕中的小圆形沿着直线向屏幕中心汇合，做加速直线运动，形成一个“M”形状的图形，该图形由约7-10个大圆形排列而成，强调小圆形汇聚变成大一些的圆形的过程；每个小圆形快速射出多条密集的细线，将小圆形连接起来成“M”形状，形成一个抽象的文字“M”，短暂定格停留维持“M”的画面，同时：小圆形的颜色变成参考图片中的主题色；
4-5秒：第一个字 / 字母由圆点和细线结构解体、爆散、被旋转轨道吸回、弹性过冲，动态变形重组成最后一个字 / 字母“H”；“H”采用参考图最终字标中对应字 / 字母的字体、字形、颜色、大小和位置。
5-6秒：镜头拉远，“H”先单独出现并逐渐缩小，移动到参考图中最终品牌名称里最后一个字 / 字母的准确位置和大小，完成落位后短暂停格；一个黑色粗圆环和一个参考图中主题色粗圆环围绕文字“H”旋转，最外层有细黑线圆环，几个黑白圆点在轨道上移动，保持平面效果；参考图中的背景元素逐渐出现。
6-7秒：形状“H”始终出现在画面中，保持连贯并作为遮挡锚点不动；只有在“H”已经完成落位后，其他文字“MiniMax ”才从“H”遮挡住的底部后缘区域沿水平方向从右向左依次滑动出去，像横幅一样连续展开，并滑动到参考图片中对应文字的最终位置，组合成最终的品牌名称“MiniMax H”。这里的“底部”不是画面下方或字形正下方，禁止垂直下落、向下飞出、弧线弹出或从画面外独立出现。其他几个字母的构成由粗圆环的形状，强调圆环形状变成文字效果，圆环变成文字后圆环消失；
7-8秒：画面中是完整的“MiniMax H”品牌名称（文字和形状使用参考图中的文字和形状）；如果有 slogan，则显示在品牌名称下方；周围装饰使用参考图中的 logo 装饰；背景使用参考图中的背景；最终0.5-1秒直接匹配图片1的静态画面，不得有圆环、轨道线、临时圆点或过渡图形残留；

【视觉语言】
Premium flat 2D brand motion identity, intelligent minimalism, Swiss editorial grid, original modular geometry, kinetic typography, micro-to-macro scale transformation, distributed intelligence, collective nodes, elegant negative space, crisp vector graphics, solid color vector discs, precise shape morphing, magnetic alignment, clean masking transitions, restrained motion, sophisticated easing, calm, inclusive, human-centered and highly intelligent.
使用参考图主题色、暖白色与深墨黑色作为主色。所有颜色以纯色平面填充为主，避免默认彩虹渐变。画面干净、锐利、克制，可以加入极轻微的纸张颗粒，但不能影响矢量图形的清晰度。固定正面图形视角，中心安全构图。

【声音设计】
声音从一个清晰的电子脉冲开始，逐渐加入多个不同音高的点击声。随着节点同步，声音组合成一个温暖、稳定、和谐的共同和弦。结尾以一次轻柔而明确的收束音完成品牌揭示。无旁白。

【负面 Prompt】
No spheres, no 3D balls, no orbs, no volumetric particles, no shading, no specular highlights, no reflections, no glass material, no metallic material, no gradients on the circular nodes, no extrusion, no perspective thickness, no depth of field, no 2.5D layers, no 3D rotation and no complex camera movement.
所有节点必须是完全平面的二维实心圆点，禁止生成带高光、阴影、体积和反射的立体小球。禁止随机粒子云、粒子爆炸和无规则漂浮。
禁止复制 Google、Gemini、OpenAI、Apple 或其他现有品牌的 Logo、配色、四角星、结形标志和产品界面。不要机器人、大脑、芯片、电路板、地球、握手、人物剪影、社交网络图标、廉价彩虹渐变、赛博朋克霓虹、金属3D字、玻璃球、模板化Logo旋转、混乱运镜、无关镜头、错误文字、水印或平台Logo。
不得改变、遗漏或错误拼写必须准确显示的品牌名称和品牌 Slogan。
```
