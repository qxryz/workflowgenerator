# Clarification for Architectural Prompt Generation

Read only when a new unresolved choice materially affects the H3 prompt. The all-purpose reference mode, RGB input, 3–4 time-state images, and existing A/B workflow are already established.

1. Inspect the actual inputs and current manifest.
2. Identify the specific gap and what output it would change.
3. If the existing references satisfy the request, proceed without another question.
4. Otherwise explain which dimensions are supported and which are missing. Ask at most 1–3 focused questions about those gaps; do not reopen already confirmed choices.
5. Reuse the answer for the agreed scope, then write the six-field prompt.

For a partially sufficient image, preserve its valid dimensions and repair only the missing requirement. If a required source video or style image is absent, return to that production stage. Additional generated references follow the package's existing authorization and version/QA rules. Do not offer to discard references or change generation modes.

Do not output a submission-ready prompt while a material required answer is pending. Continue independent preparation when possible. Necessary clarification is not a new recurring approval point.
