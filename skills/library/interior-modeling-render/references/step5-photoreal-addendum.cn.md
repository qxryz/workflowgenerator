# STEP 5 补充｜参考图驱动的照片级实景处理与验收

路线与模型确认后，将已批准的漫游处理为具有真实建筑摄影质感的完整室内视频。本阶段改变表面表现与用户批准的照明、天气或窗外环境，不重新设计户型、家具或运动路线。提示词用于提高稳定性，不能保证生成模型每次必然成功；以实景参考、检查和有界重做形成质量门槛。

### 5.1 分开指定结构、运动与外观依据

1. 已确认的 Blender 场景及实际渲染负责墙体、门窗、物体数量、尺度关系、家具身份与位置；已确认漫游负责机位、运动、时序、遮挡和画幅。参考之间如有结构冲突，先沿用已确认的结构优先级；没有明确优先级时只询问这项冲突。
2. 对当前用户提供的效果参考逐张判断其作用。选择实景表现用于材质与受光标准，简化模型仅用于结构或差异对照；不依据文件名、软件水印或“照片级”标语判断质量。
3. 为每张参与生成的参考单独注明贡献，按实际输入顺序绑定。让图片承载自身视觉信息，不凭文字重造其颜色关系。不要把对照图的边框、文字、界面或水印带入结果。
4. 所有用户指定参考均须纳入分析，生成前再核验当前可接受的参考数量及格式。若不能同时使用，不静默删图；提出代表图选择或分组整理方案并按需取得确认。
5. 参考库必须真的存在且可读取，才可声称调用。跨项目复用时保留获准使用的参考文件或可用主体库关联，不能只保存易失效链接或当前会话编号。缺少参考时明确按文字标准执行；若用户要求贴近某张具体图片，则先取得该图。

本附录的参考制作、抽帧与验收均受主文件“画布最小交付规则”约束。内部使用不等于需要展示；优先复用已确认参考，必要创意确认仅展示一张当前参考，其余过程图、检查片段与失败重试版不默认上画布。

### 5.2 每次进入 STEP 5 的必经步骤

1. 检查输入漫游、模型依据、时长、画幅及已确认的声音方案；不重复询问已经锁定的值。
2. 确定唯一且内部一致的光照条件：用户本次要求优先，其次为已批准场景条件。不得把多张参考中的直射日光、阴天柔光和室内灯光叠成矛盾的照明。
3. 先从批准场景或漫游的代表视角制作一张实景外观参考，保持原构图和家具。若已有匹配本次条件且通过验收的参考，则直接复用。静图参考不是影片首帧，除非用户明确指定。
4. 检查该图的结构、光源逻辑、材质区分、接触阴影和用户指定改动。只增加纹理或整体亮度却仍有明显模型感，不算通过。新外观涉及实质创意选择时，先请用户确认，再开展视频重绘。
5. 同时使用批准漫游约束运动、通过检查的实景参考约束外观。不要因源视频布局正确而同时保留其简化材质、均匀照明和线稿渲染风格。
6. 完成后检查整个视频，不用单帧通过代替全片通过。保留批准音轨；用户未要求时不增加音乐、对白、脚步或字幕。

### 5.3 实景处理核心 Prompt

使用下列完整核心，根据当前场景填写方括号内容并删除未适用的材料项。每张输入都需在最终提示词中单独对应实际编号；不得把未填写占位符提交生成。

> 将[已批准的源漫游]转换为真实相机在同一室内空间拍摄的连续视频。[源漫游]提供原有机位、视高、焦段、路线、速度、时序、画幅和遮挡关系；[已批准的模型依据]提供建筑结构、家具身份、形状、数量和位置；[逐张列明的实景参考]只提供与本空间兼容的材质、光照和摄影表现。保持原来的墙体折线、门窗开口、功能区、层高关系、家具布置及一镜到底连续性。效果升级不是空间改造，不增加、删除、复制或移动主要物体。
>
> 让原有材质呈现真实尺度的细节和受光差异，而不是给简化模型叠加噪点：木材保留原有纹理走向、板缝、细小导管与克制的表面反光，纹理尺度符合家具尺寸；原有涂料表面有细微起伏与自然反射变化，仍保留其设计中的平整程度，不统一改成粗糙微水泥；石材、瓷砖与陶瓷表现适当的细纹、釉面、接缝及边缘厚度，是否手作起伏以原材质为准；布艺与软包具有柔软褶皱、受压变形、缝线和可见时才出现的纤维，不能成为僵硬网格或塑料表面；金属依其拉丝或光滑表面呈现可信高光；玻璃同时保留透射、反射、厚度感和外景遮挡。不要让所有表面拥有相同光泽，也不新增大面积污渍、破损或装饰来伪造生活感。
>
> 采用[已确认的时间、天气与照明状态]。主光从本场景真实开口或现有灯具进入，窗边到房间深处有可信照度衰减、反弹光和暗部层次；家具腿、台面器物、踢脚、墙角及接缝的阴影交代真实接触关系，不悬浮、不形成粗黑描边。对于用户要求的直射日光，给出能对应原窗框的光斑、投影方向与合理半影；对于柔和漫射日光，使用大面积柔光、连续渐变与微弱但清楚的接触阴影，不强加硬太阳光斑。保留现有灯具开关状态，不擅自增加顶灯、侧窗或发光面。高光保留纹理，暗部有细节，明亮窗外仍能读出场景；避免均匀照平、过曝、死黑、泛光光晕和过度局部对比。
>
> 窗外[保持原外景／替换为用户明确指定的外景]。景物位于真实窗洞与阳台之外，保留窗框、玻璃、护墙和已有物体的遮挡；具备符合观察高度的尺度、距离层次与运动视差，不贴在玻璃上，不以替换外景为由扩大开口或消除阳台。室外光照与室内太阳方向、天气和时刻一致。
>
> 保留原镜头的建筑透视、空间深度和构图，不用新的广角畸变、倾斜垂直线、强景深模糊或变焦掩盖空间差异。清晰度来自真实表面与光照，不来自锐化描边、过量颗粒或过度磨皮。整体干净、自然，有真实尺度和承重感，而不是玩具、蜡质模型、线稿上色或实时预览。
>
> 全程保持纹理贴附于物体，太阳与照明在空间中的位置稳定，光斑及接触阴影不随相机滑移。反射和高光应随视点自然变化，不冻结成贴图，也不无故跳变。墙体、门窗、家具数量和轮廓不变形、不闪烁、不重复、不消失；不穿墙穿门，不瞬移、切镜或添加镜头。沿用[已批准的声音方案]；不添加用户未要求的文字、人物、动物、字幕、标志或声音内容。

### 5.4 光照分支与本项目要求的边界

- **直射日光分支**：借鉴有窗框及植物投影的参考，但根据本项目窗位、天气和太阳高度重建投影。正午要求不能自动变成长距离黄昏光影；只有原场景存在植物及遮挡时才出现相应枝叶投影。
- **漫射日光分支**：借鉴柔和侧光、墙面渐变与家具底部接触关系。没有硬光斑不代表失败；缺少层次、材质区分和光源逻辑才是失败。
- **已有灯具混合分支**：保持批准的灯具状态，由灯具附近的局部影响与窗外环境光共同塑形。不得为了参考效果统一新增灯具或固定灯光色温。
- 正午阳光与落叶街景是当前公寓的明确要求，不写成所有未来户型的永久默认主题。以同样的材质和摄影质量标准适配未来用户的时间、天气、空间类型。

### 5.5 交付门槛、回退与有界重做

逐项标记“通过／失败／无法确认”，并说明具体画面或时间段：

| 项目 | 通过依据 | 处理 |
|---|---|---|
| 结构与家具 | 主要墙体、窗洞、家具身份数量、布置与批准来源一致 | 明显漂移即失败，不以好看抵消 |
| 运镜与边界 | 保留批准路径和时序，无切镜、穿墙、越过关闭门窗 | 不通过则修复该视频，不重做批准模型 |
| 光照逻辑 | 光照能对应真实开口及用户条件，具备合适的衰减与层次 | 强日光场景缺失日照证据，或柔光被擅改为硬光，均失败 |
| 材质 | 本场景主要材质之间有可辨认的微纹理、光泽与受光差异 | 仅换贴图、统一塑料反光、蜡质软装不通过 |
| 接触与曝光 | 物体接地、缝隙可信，高光暗部保有必要细节 | 悬浮、粗黑接缝、过曝掩盖外景等需修正 |
| 时间一致性 | 起始、中段、结尾及高风险转向处均无明显漂移、闪烁或消失 | 静态图片不能替代此项验收 |
| 用户明确改动 | 窗外环境、光照、材质或其他约定在画面里真实可见 | 不以提示词写过或模型自述作为成功证据 |

画面遮挡或分辨率不足时标记无法确认，不能宣称隐藏几何或精确相机参数已验证。静图可支持视觉判断，无法证明真实相机焦距、精确太阳高度、物理渲染参数或施工尺寸。

失败时只修复失败维度，保留通过的结构、运动与外观参考；初次生成后只进行一次有实质调整的重做，不得无限抽卡或仅替换同义词。指定模型仍失败时如实说明差距，核验锁定输入与参数后切换其他兼容模型；若没有兼容能力，再提出调整目标、补充参考或采用更可控的 Blender 渲染方法。

若交付要求是几何、机位和时间的严格逐帧一致，优先采用实际 Blender 摄像机动画与渲染，或说明生成式视频编辑不能提供该保证。只有视觉验收通过才能称为实景成片；没有通过的结果明确标为预览或待修正，不承诺“每次必达”。
