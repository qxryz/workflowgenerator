# Climax Reset Patterns — high-tension micro-expression structure

Use this reference for emotionally intense close-up performances where the user wants strong tension without relying on large body action. Do not encode any weapon, tactical, injury, or real-world violence instruction. This file only captures transferable acting and video-prompt structure.

## Core pattern

A high-impact close-up can be built as:

1. **Compressed baseline** — face is still, jaw slightly held, breath contained.
2. **First crack** — one tiny involuntary signal: gaze tremor, delayed blink, brow twitch, lip-corner twitch.
3. **Internal conflict** — gaze drifts away, mouth starts to speak but stops, throat swallows the line.
4. **Physical leakage** — eyes moisten, lower eyelids tense, breath becomes short, chin or lower lip trembles.
5. **Climax reset** — eyes close sharply or briefly, breath is taken, eyelids tremble; reopening reveals a changed emotional state.
6. **Aftershock suppression** — lips press, jaw steadies, eyes remain wet, emotion is held rather than discharged.

## 2-second density structure for 10–12s close-ups

- 0–2s: establish still baseline and controlled breath.
- 2–4s: first visible crack, very small and involuntary.
- 4–6s: gaze shift and swallowed speech / interrupted intention.
- 6–8s: moisture, breath instability, chin/lip/jaw leakage.
- 8–10s: closure/reset beat — blink/close eyes + breath + reopen.
- 10–12s: aftershock, emotion held in the face rather than acted out.

For 6–7s clips, compress the same logic into 5–6 beats:

- baseline → crack → conflict → leakage → reset → aftershock.

## Useful acting cues

- 眼神一颤 / gaze tremor
- 焦点飘移后被强行拉回 / focus drifts then is forced back
- 眉心浅蹙后展开 / shallow brow pinch then release
- 唇角短促抽动 / brief lip-corner twitch
- 嘴唇微张欲言又止 / lips part as if to speak, then stop
- 喉咙轻滚 / throat swallow
- 下眼睑绷紧 / lower eyelids tense
- 眼眶发湿但不立刻流泪 / eyes moisten without immediate tears
- 猛然闭眼不到半秒 / eyes close sharply for less than half a second
- 眼皮轻颤 / eyelids tremble
- 睁眼后情绪状态改变 / reopening reveals changed emotional state
- 唇线压住 / lips press to suppress emotion

## Prompt discipline

- Use timed beats, not broad emotional labels.
- Keep macro action minimal; put density in eyes, breath, throat, lips, jaw, and blink timing.
- A climax is not always a scream or collapse; it can be a brief eye closure and breath reset.
- The aftershock should carry the emotion forward. Do not reset to neutral too quickly.
- Never include harmful operational details from any source clip. Translate only performance rhythm and emotional structure.
