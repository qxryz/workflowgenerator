# STEP 1 原始生图提示词模板

> 使用规则：这是 STEP 1 的主提示词模板。执行时只允许最小替换，不要重构、摘要、改写整体结构。把“参考图中的角色”理解为用户上传的 IP 角色。可在“角色统一要求”后插入必要的角色身份观察，但不要改变布局、宫格编号、比例、宫格功能和负面要求。执行前必须先判断用户上传参考图的背景色，并把模板中的【参考图背景单色】替换为具体颜色词，例如“纯白色”“浅蓝色”“米白色”“浅灰色”；最终生图提示词里不要保留“根据用户上传参考图来决定”这类判断依据。

请生成一张 9:16 竖版海报，整体为纯黑背景上的不规则六宫格拼贴构图。画面不是标准六宫格，不是平均分割，不是整齐矩阵，而是潮流杂志式、非对称、错落排布的图像拼贴。黑色背景作为宫格之间的留白和分隔线。

所有宫格必须是整齐圆角矩形，每个宫格四个角的圆角半径完全一致，统一约为 32px。圆角干净利落，不要不同圆角，不要直角。

建议画面比例：
- 宫格1：左上，宽约45%，高约30%。
- 宫格2：右上，宽约46%，高约25%，宫格2是一个长宽都比宫格1更小的矩形，对齐右上角。
- 宫格3：中间横向桥接块，宽约98%，高约15%，位于画面中上部。
- 宫格4：左下上方小块，宽约29%，高约20%。
- 宫格5：左下下方块，宽约38%，高约28%；宫格5是一个比宫格4更大的矩形，两个矩形左边界对齐，右边界不对齐。
- 宫格6：右下主视觉大块，宽约53%，高约50%，是全图面积最大的宫格。

间隔要求：
宫格之间必须保留明显黑色间隔，整体边缘保留极窄黑边。不要让任何宫格互相贴死，也不要让间隔消失。黑底必须清楚可见。

角色统一要求：
六个宫格内容必须属于参考图中的同一个角色。使用参考图中的角色作为唯一 IP 身份来源，保留参考图角色的核心识别特征、身体覆盖状态、身体结构、身体表面材质、发型或头部造型、参考图已有服装或配饰、标志性道具和整体气质。将参考图中的角色统一转译为超写实潮玩盲盒、Q版角色，不要混入其他角色。身体覆盖状态必须严格遵循参考图：如果参考图中的角色没有穿着服装，六个宫格必须保持参考图中的自然未穿服装状态，不得添加衣服、外套、上衣、裤子、裙子、袖口、鞋子、帽子或其他人类服装；保留动物原本的身体轮廓、皮肤或毛发材质、四肢结构、爪子、耳朵、尾巴和其他物种特征，不要将动物拟人化为穿衣人物。参考图中已有的耳机、道具或配件可以保留，但不要将它们扩展成服装系统。如果参考图中的角色有服装，则严格保留参考图已有服装，不新增其他服装或改变服装结构。

宫格1内容：
参考图中的角色正在拨动电吉他琴弦、音乐道具或其标志性道具的局部特写。画面只拍手部、前肢或爪部、参考图中已有的身体局部、道具和细节，强调正在弹奏或操作的动作。构图为近距离局部摄影，手和道具占满画面，保留参考图角色的身体表面、已有服装或配饰材质和颜色特征；如果参考图没有服装，不得添加袖口或衣物

宫格2内容：
【参考图背景单色】背景下，一个正方形、带 Y2K 周边质感的 MP4 播放器产品图悬浮在空中，没有接触地面，没有阴影。MP4 外形极简，正方形机身，无按键，无多余装饰，只有屏幕区域。屏幕中显示参考图中的角色头像或角色画面。整体像 Y2K 千禧风电子周边产品，3D 产品渲染质感，干净、居中、高清。

宫格3内容：
参考图中角色双眼或核心面部识别区域的超近景微距特写。只拍眼睛、眼妆、睫毛、额前发丝、眼周皮肤或该角色最具识别度的面部局部，不拍完整脸。横向狭长构图

宫格4内容：
参考图中的角色正在唱歌或表演的全身 / 近全身小画面。角色手持麦克风或与角色气质匹配的表演道具，呈现音乐表演姿态。保留参考图中的身体结构、头部造型、已有服装或配饰、标志性道具和整体材质；如果参考图没有服装，不得为角色添加服装。背景为【参考图背景单色】纯色背景，主体清楚但画面面积较小。

宫格5内容：
参考图中的角色正在弹奏键盘、合成器，或操作其标志性道具的局部特写。画面主要拍双手、前肢或爪部、参考图中已有的身体局部、黑白琴键、乐器局部、设备局部或道具局部，突出音乐表演或操作动作。局部裁切，近距离摄影感。

宫格6内容：
参考图中角色头部以下的特写画面，不露出头部，不露出完整脸。画面只展示颈部以下、肩部、上半身、身体表面、已有服装或配饰、手部、前肢或爪部、麦克风、麦克风架或标志性道具等元素。重点突出参考图角色的身体表面材质、已有服装或配饰材质、身体姿态和音乐表演氛围；如果参考图没有服装，不得添加任何服装。该宫格是右下最大的主视觉块，但必须避免出现头部和脸部。宫格6的上边界必须裁在颈部以下或身体区域，只允许出现身体、手部、前肢或爪部、道具和局部材质，不要出现下巴、嘴、眼睛、耳机、头顶或任何头脸轮廓。

整体画面要求：
不规则拼贴、黑底分割、圆角六宫格、单边对齐、错落排布、强设计感、潮流杂志排版、音乐主题、高清细节、统一光影、统一参考角色。

负面要求：
不要标准九宫格，不要平均六等分，不要规整矩阵，不要对称排版，不要把宫格1和宫格2做成同高，不要把宫格4和宫格5做成同宽，不要让相邻宫格自动等高等宽，不要白底整体画面，不要直角宫格，不要不同圆角，不要扁平插画，不要真人摄影，不要混入不同角色。宫格2不要按键，不要长方形播放器，不要复杂按钮。宫格6不要露出头部，不要露出脸，不要完整人物头像。
