# STEP 2 原始视频提示词模板

> 使用规则：这是 STEP 2 的主视频提示词模板。执行时只允许最小替换，不要重构、摘要、改写整体结构。“参考图”指 STEP 1 已生成的六宫格静态海报。视频开场固定使用宫格4，即左下上方小块。

使用第一步生成的图片作为参考图，生成一条 9:16 竖版六宫格动态视频。

0-2秒：
画面中是参考图中宫格4（即左下角上方宫格）的角色和背景占据屏幕全部，角色在优雅地唱歌或表演，伴随轻微的手部动作和自然扭动。固定机位，动作轻柔，避免快速运镜、大幅甩镜、夸张变形或身份漂移。

2-3秒：
宫格4缩小到参考图中左下角上方宫格的位置，其他几个宫格分别从左右两边、从画外飞入，动作干脆利落。所有宫格最终拼成参考图中的不规则六宫格布局。黑色背景作为宫格之间的留白和分隔线，圆角矩形边界保持稳定，不新增宫格，不删除宫格，不要让宫格互相贴死，不要让黑色间隔消失。

3-6秒：
请基于参考图生成一组六宫格动态视频分镜，整体风格统一为：3D 潮玩盲盒、Q版角色、音乐主题、Y2K 千禧风、复古胶片质感、柔和自然光、轻微胶片颗粒、细腻软胶材质、高清稳定、电影感、镜头平稳、动作自然。

整体要求：
- 所有镜头都保持参考图中的同一个角色设定、身体覆盖状态、身体结构、身体表面材质、发型或头部造型、参考图已有服装或配饰和整体气质一致；如果参考图角色没有穿着服装，视频全过程不得添加衣服、袖口、鞋帽或其他人类服装。
- 画面以固定机位为主，避免大幅运镜、避免频繁切换、避免夸张变形。
- 动作要轻柔、自然、跟随音乐节奏，突出材质细节和潮玩质感。
- 不要加入多余角色，不要改变角色身份，不要露出不该出现的部位。
- 如果是局部特写，就严格保持局部构图，不要自动补成全身。
