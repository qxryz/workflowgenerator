# 提示词保真规则

本 Skill 的核心不是自由重写提示词，而是基于原始提示词模板做最小必要替换。

## STEP 1

STEP 1 生图时必须读取并使用：

`references/static-six-grid-prompt-template.cn.md`

该文件是第一步生图的主模板。禁止摘要、重构、翻译、扩写为另一套结构，或把模板改写成新的提示词。只允许做以下最小替换：

1. 把“参考图中的角色”理解为用户上传的 IP 角色；
2. 在“角色统一要求”后补入上传 IP 的必要身份观察，例如轮廓、物种与身体结构、身体覆盖状态、身体表面材质、头部造型、参考图已有服装或配件、标志性道具和气质；
3. 执行前先判断用户上传参考图的背景色，将 `【参考图背景单色】` 替换为具体颜色词，例如“纯白色”“浅蓝色”“米白色”“浅灰色”；最终发给生图模型的提示词必须写成确定结果，例如“纯白色背景下……”，不要保留“根据用户上传参考图来决定”“从用户上传图片背景中提取”等判断依据；
4. 当模板中的音乐道具与上传 IP 的标志性道具冲突时，可替换为该 IP 的标志性道具，但宫格功能不能改变；
5. 当其他颜色词与用户明确要求或源图核心识别特征冲突时，可做必要替换；
6. 输出语言保持中文。

必须尽量原样保留：9:16、纯黑背景、不规则六宫格、宫格编号、宫格比例、圆角要求、黑色间隔、六个宫格的功能、整体画面要求和负面要求。

## STEP 2

STEP 2 视频生成时必须读取并使用：

`references/motion-six-grid-prompt-template.cn.md`

该文件是第二步视频提示词的主模板。禁止自由重写。只允许把“参考图”绑定为 STEP 1 生成的六宫格静态海报，并补充必要的角色身份一致性信息。

必须尽量原样保留：0-2 秒宫格4全屏开场、2-3 秒宫格4缩小归位并让其他宫格飞入、3-6 秒稳定六宫格动态、六个宫格分别动态、统一负面要求。

## 禁止事项

- 不要把模板重排成新的段落结构；
- 不要把原始中文模板翻译成英文再回译；
- 不要把布局规则压缩成摘要；
- 不要改宫格编号；
- 不要把宫格4开场改成宫格5；
- 不要删除负面要求；
- 不要因为通用化而改变原始提示词的排版控制力。


## 背景色占位符规则

执行 STEP 1 前先判断用户上传参考图的背景色，将 `【参考图背景单色】` 替换为具体颜色词，例如“纯白色”“浅蓝色”“米白色”“浅灰色”。最终发给生图模型的提示词必须写成确定结果，例如“纯白色背景下……”，不要保留“根据用户上传参考图来决定”“从用户上传图片背景中提取”等判断依据。

## 身体覆盖状态规则

执行 STEP 1 和 STEP 2 前必须判断参考图角色是否穿着服装。无衣服也是角色设计的一部分：如果参考图角色没有穿着服装，最终图像和视频提示词必须明确保持自然未穿服装状态，不得添加衣服、外套、上衣、裤子、裙子、袖口、鞋子、帽子或其他人类服装；保留动物或非人角色原本的身体轮廓、皮肤或毛发材质、四肢结构、爪子、耳朵、尾巴等物种特征。参考图中已有的耳机、道具或配件可以保留，但不要扩展成服装系统。如果参考图角色有服装，则严格保留已有服装，不新增其他服装或改变服装结构。
