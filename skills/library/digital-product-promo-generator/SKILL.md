# Video Shotcraft

使用本 Skill 将真实产品、网页、前端项目或用户提供的动效参考转化为完整产品宣传片，使用真实界面视觉、有目的的运镜、节奏化剪辑和声音设计讲清产品价值。

## 输入

只补充询问当前缺失的信息：

- 产品 URL、截图、录屏或前端素材。
- 品牌素材，以及必须保持准确的产品文字。
- 目标时长和画幅比例。
- 会影响剪辑的目标受众、发布信息与交付场景。
- 用户可选提供的 Ink Press 参考、镜头卡或动效示例。

不得声称本 Skill 内置 Ink Press 模板、镜头卡库、Remotion 工程或音频包。用户点名这些参考但没有提供素材时，应请用户补充参考，或确认其想复现的可见效果。

## 工作流

1. 检查用户提供的 URL 和媒体素材。保留产品真实的布局、字体、颜色、文案与交互逻辑，不虚构未经支持的功能或界面状态。
2. 确认时长与画幅。只有当平台或导出要求会实质影响构图、节奏或交付时，才补充询问。
3. 判断任务是完整宣传片还是单个动效镜头。用户提供的模板、Ink Press 示例或镜头卡只作为参考约束，不视为本 Skill 自带资产。
4. 给出可审阅方案，包括叙事结构、镜头顺序、运镜、界面重点、转场逻辑、屏幕文字、节奏、音乐或声音设计，以及所需源素材。
5. 在高成本生成或最终合成前停止并等待用户确认，明确指出缺失的截图、录屏、文案、Logo 或风格参考。
6. 用户确认后默认使用 MiniMax-H3 生成视频镜头。如果用户明确指定其他模型，先检查该模型是否支持所需参考输入、时长、分辨率、画幅和音频需求，再遵循用户选择。
7. 用户指定的模型失败时，只允许在修正可能的参数、提示词或参考素材问题后针对性重试一次；仍失败则切换 MiniMax-H3 或其他具备所需能力的可用模型，不反复重试同一模型。
8. 只生成或选取已确认的声音素材，完成镜头剪辑，并检查视觉连续性、文字准确性、节奏卡点、音频平衡以及干净的首尾帧。
9. 保存最终交付文件，并说明输出格式、时长、画幅、参考素材，以及生成过程中发生的替换。

## 执行规则

- 表现真实产品界面时优先使用真实截图或录屏。
- 只有在有助于讲清产品时，才使用 2.5D 运镜、景深分层、裁切、推拉、平移、透视变化或视差。
- 产品与品牌可读文字必须准确，不得推断用户未确认的卖点、价格、指标或功能。
- 运镜与声音应匹配产品气质，避免装饰性动效干扰界面信息。
- 保留用户参考的动效意图，但要适配目标产品，不复制无关品牌内容。

## 边界

本 Skill 适合产品宣传片、发布短片、功能演示和 Web / 桌面产品叙事，不用于无关的通用剪辑、口播清理或非产品动效艺术。
