# 潮流3D social app 卡片

使用本 Skill 将用户上传的照片转化为社交媒体界面构图：一个类似 social app 帖子的卡片框架中，放入由照片主体转化而来的酷感 3D 人物形象。Skill 先生成静态卡片；如果用户希望继续做动态，再引导生成手指滑动、点击点赞、爱心粒子、人物微反应，或用户在菜单中选定的其他互动内容等互动短视频。

它的重点是一套可复用视觉格式：用户照片 → 低模手办身份 → 极简社交框卡片 → 可选互动动画视频。

## STEP 1：素材接收与必问问题

确认用户已经提供至少一张适合转化的人像、自拍、角色照片、穿搭照片或其他可作为人物形象依据的图片。

如果没有可用照片，先请用户上传一张照片再继续。

生成前必须询问用户想要的输出尺寸 / 画面比例。默认推荐 **3:4**，因为它能给界面卡片、3D 人物和后续手指互动留下足够空间。

推荐问法：

- “你想要什么尺寸？我推荐 3:4，更适合做 社交框风界面和 3D 人物卡片。也可以选 1:1、3:4、4:5、9:16 或 16:9。”

不要主动询问字幕。本 Skill 以视觉为主，除非用户明确要求，否则字幕关闭。

## STEP 2：分析用户上传照片

生成卡片前，先将上传图片作为人物来源进行观察。只提取可复用的人物证据：

- 主体数量，以及哪一个人应成为主 3D 人物；
- 发型轮廓、表情、眼镜、帽子、首饰或其他身份感配饰；
- 服装廓形和主要穿搭结构；
- 用户希望保留时，记录姿势或态度；
- 判断来源是人像、全身、宠物、物品拟人，还是多人照片。

让图片本身传递颜色信息。不要在文字里自行发明颜色，除非用户已经明确写出。

如果画面里有多个人，而用户没有指定目标人物，先问用户要转化哪一位。

## STEP 3：生成静态卡片

在生成前，先锁定参考视频优先级：

- 脸部要同时兼顾可爱和酷感：大头、圆脸、偏长的狭长眼、外眼角上扬、神态冷静自持；
- 装扮要像手工感很强的潮酷手办：头部体量或发型轮廓明确、配饰更厚重、领口叠穿更强、外套轮廓更硬；
- 构图尽量贴近参考视频逻辑：正面、居中、胸部以上特写为主，外面包一层竖向社交框，里面的媒体区保持方形；
- 媒体区背景保持极简干净，不要装饰过度，这样人物才会像高级 3D 手办展示；
- 卡片默认呈现“已经点赞”的状态，让社交外壳在互动前就有生命感。


除非用户明确要求多个版本，否则先生成一张最终静态图。

静态卡片必须包含：

1. **类似 social app 的界面外壳**
   - 帖子卡片布局，包括顶部头像 / 用户名 / 位置占位、媒体窗口、点赞 / 评论 / 分享图标、文案区域，以及必要时的轮播指示点；
   - 界面应像社交 App 的视觉模拟，不要伪造真实账号、商标或真实个人主页；
   - 避免真实私人用户名、真实品牌背书或未经授权的名人 / 账号冒充。

2. **酷感 3D 人物形象**
   - 将上传主体转化为卡通超酷的 3D 手办 / 潮玩 / 收藏人偶风角色；
   - 保留照片中主体的主要身份特征和穿搭线索；
   - 强调实体建模感、大眼睛表情、好玩的头身比例和时尚配饰细节；
   - 姿态要具备可动感：轻微歪头、放松手臂、表情鲜明。

3. **参考视频酷感规则**
   - 不要只做普通可爱头像，要让人物更像潮流 3D 角色：脸型轮廓更有设计感，眼睛更有表现力，眉眼更自信，头部体量更像玩具模型，整体态度更酷；
   - 当源照片没有配饰时，可以加入合理的潮流配饰，例如耳机、眼镜、帽子、贴纸、徽章、服装补丁或小型可穿戴装置，除非用户要求完全朴素；
   - 媒体窗口背景要保持极简、干净，像影棚手办产品照；酷感主要来自 3D 手办人物的脸型、配饰、材质和态度，而不是复杂背景；整体要更像收藏手办展示而不是装饰海报；
   - 社交框 框默认应处于“已经点赞”的状态，点赞图标已被触发，并在人物周围保留少量爱心 / 互动反馈暗示。

4. **卡片构图**
   - 人物是媒体窗口里的视觉主角；
   - 人物周围预留空间，方便后续做手指互动和漂浮爱心粒子；
   - UI 在用户选择的比例下保持清晰、平衡；
   - 如果用户没有指定尺寸，默认采用 3:4 竖向画幅，社交帖子像参考视频一样占据画面主体。

推荐静态图提示词结构：

```text
Transform the uploaded photo subject into a trendy 3D collectible chibi character inside an social-app-like social post card. Preserve the subject identity, main facial/accessory cues, and outfit silhouette from the uploaded photo. Build a clean social media interface frame with profile row, media window, reaction icons, caption area, and carousel-like details. The character is the hero inside the media window, posed like a premium designer toy with expressive oversized eyes, solid 3D modeling, fashion details, and enough surrounding space for future tap / swipe interaction. Chosen aspect ratio: <confirmed ratio; default 3:4 when unspecified>.
```

根据照片证据和用户确认的尺寸改写提示词。提示词以正向描述为主，不要在没有具体失败的情况下堆叠负面清理词。

## 低模手办默认规则

当用户提供低模 3D 模型、手办参考，或反馈生成结果“不够像”时，默认套用以下规则：

- 脸型比例：远离真人椭圆头像比例。使用二头身 Q 版 / 低模手办比例，大头、短圆脸、大额头、五官位置偏下、脸颊饱满、下巴短而圆钝。
- 眼睛：避免真人写实眼。使用大号玩具眼，形状偏扁半椭圆或柔和扇形，上眼睑略压，外眼角上扬，硬边眼线明显，瞳孔更大，有玩具眼高光，可加入点状下睫毛。神态应偏酷、慵懒、厌世或冷静自持，而不是普通可爱。
- 装饰：配饰必须像实体手办零件，有厚度、接触阴影和建模边缘。耳机、帽子、耳环、贴纸、创可贴、徽章或可穿戴科技件都应像真实 3D 部件，而不是平面印花。不要默认加眼镜，除非用户明确要求或源图里本来就有眼镜。
- 服装建模：减少真实布料褶皱，改用低模 / 软胶手办式服装体块：加厚卷边、厚领口、圆角袖口、分层领口、硬挺外套拼片，并在接缝处保留 AO 遮蔽阴影。
- 材质：优先 soft-vinyl / matte-plastic / semi-gloss 收藏手办材质，圆角低模边缘，大面积柔和高光和自然接触阴影。避免变成普通 2D 头像滤镜。
- 背景：背景保持极简，但不要默认灰白。使用干净的非灰白纯色或柔和渐变影棚背景，并在人物底部保留轻微接触投影。背景只服务于手办展示感，不要复杂装饰，并且画面重点要落在胸部以上的人物细节。
- 社交框：除非用户特别要求，否则 社交框风卡片默认保持已经点赞状态。

- 卡片边距：社交框左右保留明显呼吸空间，与画布边缘保持干净距离；边框留白要干净，让 UI 看起来更高级、更有设计感。
- 眼妆平衡：眼睛可以比源照片更角色化，增加更明显的眼线、眼影层次、玩具眼高光和点状下睫毛，同时保留源照片人物的平静眼神、眉眼印象和可识别五官气质，让角色仍然像原主体。


## 视频互动方向菜单

静态卡片通过后，先给用户一组可选的视频互动方向，再进入视频生成。整个过程中保持镜头固定，保留外层卡片边框，不要让边框消失。背景可以保持极简，但在需要时可以叠加简单的表情符号、漂浮形状、反应图标或图形爆炸元素，用来加强所选互动。

推荐选项：

1. **戳脸反应** —— 手指或手戳一下角色的脸，角色做眨眼、歪头、噘嘴、脸红或惊讶反应。
2. **框内跳舞** —— 角色在框内跳舞或轻跳，卡片本身保持固定，外框始终可见。
3. **拉手 / 伸手** —— 用户的手伸进画面，角色也伸手回应，形成一种“冲破画面”的感觉，但外层边框仍然保留。
4. **滑动 / 点击反馈** —— 手指滑动或点击，角色或 UI 做出俏皮反馈。
5. **自定义互动** —— 用户自行描述任何其他想要的互动内容。

向用户提问时要简洁，直接列出选项；如果用户选择自定义，只追问一句简短描述即可。

## STEP 4：复核与可选视频分支

静态卡片生成后，告诉用户可以继续做互动视频。

只有当用户表现出兴趣，或一开始就要求视频时，才继续询问：

- “要不要把这张卡片继续做成参考视频那样的互动短片？比如手指滑动卡片、点击点赞、爱心飘出、3D人物做可爱反应。”

如果用户不需要视频，就停在静态卡片交付。

如果用户确认要视频，而时长或平台比例还没确定，再确认一次。推荐单个互动 5–8 秒；如果要滑动 + 点赞 + 人物反应，推荐 10–15 秒。

## STEP 5：生成互动视频

使用已通过的静态卡片作为主要视觉锚点。保持人物身份和界面布局一致。

视频应遵循参考视频中的互动模式：

1. **开场停留**
   - 正面固定机位展示社交帖子卡片；
   - 角色有非常轻微的 idle 动作，例如头部微晃、眨眼、呼吸般的微动。

2. **手指手势**
   - 一个真实感前景手指出现；
   - 手指在媒体区域横向滑动，或点击点赞图标；
   - UI 对手势产生反馈。

3. **界面反馈**
   - 滑动：媒体窗口内部横向切换，带弹性缓动；
   - 点赞：爱心图标轻微弹跳放大；
   - 需要时在人物周围加入向上漂浮并淡出的爱心 / 反应粒子。

4. **人物反应**
   - 3D 人物眨眼、歪头、挥手、微笑，或做一个可爱的反应；
   - 动作要小而清楚，避免破坏卡片布局稳定性。

5. **结尾停留**
   - 卡片回到干净的 hero 构图，适合循环播放或发布。

推荐视频提示词结构：

```text
Animate the accepted social-frame 3D character card into a short interactive social UI video. Keep the same character identity, same card layout, and same front-facing composition. A realistic finger enters in the foreground, interacts with the card by <swipe or tap>, and the interface responds with elastic motion. The 3D chibi character performs subtle idle animation, blink, head bob, and a cute reaction. Add floating heart particles after the like tap when requested. Keep the motion beat-synced, playful, and loop-friendly.
```

## STEP 6：失败处理

如果静态图没有保留用户主体：

- 强化照片中的身份线索：脸部印象、发型轮廓、配饰、穿搭结构和姿态；
- 始终把源图作为人物参考；
- 不要用无关风格词去掩盖身份丢失。

如果界面变得杂乱：

- 简化为顶部资料行、媒体窗口、反应图标、文案线和轮播点；
- 减少装饰性文字，避免细小不可读标签。

如果视频里的手指遮挡人物或污染人物形象：

- 指定手指停留在前景边缘和交互区域，不遮挡人物脸部；
- 每条视频只做一个清晰互动，不要塞入过多手势。

如果用户要多人：

- 先问用户想做一张合影卡，还是每个人单独一张卡；
- 如果拆成单人卡，每个主体生成一张，并用不同文件名交付。

## STEP 7：交付

如果只做静态图，交付生成的卡片，并提示可以继续做互动视频。

如果做视频，交付最终视频。如果同一轮同时生成了静态图和视频，把它们在画布上归为一组，标签可用“潮流3D卡片”。
