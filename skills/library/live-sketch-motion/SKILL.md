# Live Sketch Motion｜实景手绘动效

从用户上传的实景照片、参考视频，或用户输入的文字场景，生成一段短的“实景手绘动效”视频。这个效果的核心不是普通白色描边，而是：真实场景先自然动起来；前景出现一只手拿蓝色马克笔；手绘层必须从笔尖逐帧生长；主体被转换成手绘风格前、中、后都仍然继续运动。

当用户说“实景手绘”“手绘动效”“上传照片生成手绘视频”“马克笔显影”“Live Sketch Motion”等类似需求时使用本 Skill。单主体视频优先保持一个连续镜头。默认输出 7–10 秒短视频，除非用户另有指定。

## 核心视觉 DNA

这个效果不是通用白色描边涂鸦，必须保留以下规则：

1. 画面必须是实景，并且在手绘开始前就自然动起来：上传照片、参考视频或生成的实景图都不能只是静态背景。
2. 所有合理可动元素都要有克制运动：人物呼吸、眨眼、轻微转头，动物眨眼、转头、摆尾、耳朵轻动，头发、衣服、树叶、草地、窗帘轻动，水面、光影、阴影、背景人物细微变化。主主体必须在开头第一秒内已经开始自然运动，不能开头冻结、过一会儿才突然开始动。
3. 不要把背景整体动画化。保持原构图、主体身份和空间关系，只让合理可动元素产生小幅、真实、生活化的微动。
4. 前景出现真实手持亮蓝色马克笔或蓝色铅笔质感马克笔。
5. 马克笔是唯一绘制触发器。手绘效果必须从笔尖位置逐帧生成，跟随手的真实速度、方向、接触点、停顿、转折和短促排线。笔尖划过哪里，手绘才出现在哪里；笔尖没有经过的位置不能提前显影。
6. 手默认从画面边缘进入，常用右下角或下方。除非用户另有要求，只露出手、手腕和一小段前臂；不要整条胳膊横跨画面或遮挡大面积背景。右手必须是自然写字握笔姿势：拇指、食指和中指夹住笔杆，笔杆斜向前方，手腕放松，笔尖稳定指向目标；不要拳头握笔、反手握笔、捏住笔尾、手指缠绕笔杆、遮住笔尖、六指、手部畸形、笔杆弯曲或笔的颜色形状变化。
7. 手绘转换明显完成后，拿笔的手默认要自然停止绘制并离开画面，除非用户明确要求继续停留。手和马克笔应像真人涂鸦完成后一样，顺滑向下方或侧方撤出；不要继续悬停、指着主体、反复涂抹或遮挡已经完成的主体。
8. 不要机械扫刷，不要瞬间整块贴片，不要整张贴纸弹出，不要预先显现纹理，也不要只沿主体边缘描一圈。正确效果是目标轮廓内部的真实质感被逐步替换成完整的平面手绘动画对象。
9. 常规绘制顺序从主体左上、头部或顶部开始，像真实画画一样经过头部、耳朵、脸、身体、尾巴或物体关键结构，整体向右下推进。主体自身运动方向与显影方向分开处理，即使主体横向移动，显影仍从主体左上向右下推进。
10. 主体在手绘前、手绘中、手绘后都必须保持活体运动。主体不能停下来等笔画、不能在转换中冻结、不能消失、瞬移、放大缩小、变成其他物体或变成静态贴纸。手绘层必须附着在动态主体上，继承主体原本的运动路径、节奏、眨眼、呼吸、摆尾、衣物或反光等自然运动。转换必须在主体持续沿既定路线运动时完成；转换后主体要继续原路线或完成下一个自然动作，不能转化完立刻停住。
11. 如果用户只给文字场景，没有参考图，先生成一张真实照片感预览图让用户确认，再进入动效。预览图默认不能包含手绘、贴纸、马克笔、字幕或卡通效果，除非用户明确要求。
12. 单主体场景优先保持一个连续中景镜头，不要频繁切镜、突然特写、焦段跳变或景别跳变。运动主体可以平滑跟随但不改变景别。

## 文字场景的真实预览要求

当用户只提供文字场景并希望最终生成视频时，默认先走预览图流程：

- 先生成一张真实摄影感源图，展示主体、环境、支撑面、家具、地面接触和构图。默认必须是 photorealistic / real-photo-like。
- 预览图中不要提前加入手绘、贴纸、马克笔手、字幕、Logo 或可读文字，除非用户明确要求。
- 用预览图检查空间逻辑：主体是否落地，家具是否物理可信，椅子桌子是否不是平面贴图，主体最终姿态是否会被障碍物遮挡。
- 用户确认预览图后，再用该图作为实景源图生成手绘动效视频。

## 手绘层结构

每个被转换的主体都必须采用受控的三层手绘结构：

- 最外层分离边：清晰、硬边、厚实的白色或米白色外包围边，像实体白色纸片剪影底衬，只出现在主体外侧。不要默认做成羽化、发光、模糊或半透明光晕。
- 主形状线：清晰黑色手绘外轮廓，位于白边内部。默认的随性涂鸦感应是中等偏粗、简化、松弛、略不完美的线条，可有轻微溢出、局部未闭合、局部双重线、断续线、轻微擦痕和 mild boiling line 抖动。除非用户明确要精致风格，否则不要精修矢量感、写实毛发、复杂内部细节、密集结构线或细腻阴影插画。
- 内部填充：彩铅 / 蜡笔 / 马克笔斜向排线，稀疏、有纸张颗粒感、保留白色缝隙、少量黑色墨点和轻微跑色，绝不是纯色平涂。随性涂鸦感下，填色要轻、松、留白明显，不要厚重、完整或绘画感过强。

层级必须清楚：最外侧清晰厚白边，黑色轮廓压在白边内部，低饱和排线填充在黑线内部。

### 贴纸式彩铅手绘模板

当用户参考可爱贴纸、彩铅、蜡笔、手账风时，将被转换主体锁定为以下模板：

- 不透明白色或米白色硬边贴纸边框；
- 中等偏粗黑色简化轮廓，轻微手绘抖动；
- 稀疏彩铅 / 蜡笔斜向排线，保留纸张颗粒和白色留白；
- 低饱和、高明度马卡龙色；
- 只保留主体核心识别特征，不做写实毛发、复杂结构或明暗；
- 是仍跟随实景主体运动的 2D 手绘对象，绝不是冻结贴纸。

颜色控制必须严格：

- 马克笔本体保持亮蓝色。
- 主体外轮廓保持黑色。
- 最外侧边缘保持白色或米白色。
- 内部填充只使用低饱和有限配色：米色、浅棕、暖灰、淡粉、淡紫、浅灰蓝，或用户确认的柔和马卡龙色。
- 除非用户明确要求，否则不要添加爱心、星星、圆点、闪光、花纹、图标或符号。
- 禁止彩虹乱色、霓虹爆色、高饱和随机色和逐帧颜色漂移。

## 空间与遮挡规则

实景主体必须保留可信的环境接触关系：

- 动物通常应在地面、沙发、椅子、台阶或其他可见支撑面上活动；除非源图就是这样，否则不要悬浮、贴墙或错误地落在桌面上。
- 如果主体跳上椅子、沙发、台阶或平台，要落在可见的前缘或外侧区域，保证全身可读。
- 避免结尾主体被椅背、椅腿、桌腿、栏杆或家具横杆切割或遮住。家具在主体后方时，应让主体位于其前方或上方，确保头部、身体、四肢和尾巴都清楚可见。
- 主体大小要符合景别。单个运动主体默认中景，保留足够环境，让实拍背景与手绘主体形成对比。
- 动物抵达椅子、台阶、沙发等终点后，仍要有轻微的活体后续动作，例如摆尾、眨眼、耳朵动、回头看或用户要求的轻声叫唤，不能刚落点就冻结。

## 背景生命感与互动

背景运动用于增加真实感，但不能抢主体：

- 加入细小可信的变化：窗边光影轻微移动，柔和阴影变化，植物轻摆，蒸汽/反光细微变化，背景人物呼吸、眨眼、轻微转头或小幅手部动作。
- 如果场景中有人且动物经过，人物可以自然看一眼动物，眼神短暂跟随，然后回到自己的动作。动作必须细微、真实、生活化，不要戏剧化。
- 不要新增无关人物、大事件或大范围背景变形，除非用户明确要求。
- 多动物场景必须有明确层级：被手绘化的动物是视觉主角；陪伴动物保持次要位置，可用抬头、耳朵动、轻微前倾、谨慎走近等自然动物行为反应。不要过度拟人化，也不要遮挡主角。

## 音效设计

默认关闭音频。当用户明确要求声音，或希望手绘过程更沉浸时，使用轻柔自然的声音层：

- 与可见显影同步的马克笔、彩铅或蜡笔沙沙涂抹声；
- 轻微环境声，例如微风吹过绿植、室内环境底噪、动物脚步；
- 跳跃或落点的细小接触声，以及用户明确要求时的一声简短自然动物叫声；
- 不要旁白、不要吵闹音乐、不要密集音效，用户未明确要求时不要字幕。

## STEP 1：理解输入

判断用户提供的是：

1. 实景照片 / 图片参考；
2. 需要模仿的参考视频；
3. 只有文字场景。

如果用户上传图片，把它当作实景照片源。默认保留主体身份、构图、机位、光线和背景，不要擅自换主体或换场景。

如果用户上传参考视频，把它当作运动参考：先提取主体的运动路径、节奏、镜头行为、手绘风格，以及需要保留或修复的问题点。不能因为进入手绘而冻结主体。

如果用户只输入文字场景，先生成一张真实照片感预览源图，再进入动效。适合的源图应具备：

- 一个清楚主主体；
- 主体轮廓完整可读；
- 稳定中景构图；
- 背景有空间深度但不杂乱；
- 有足够空间放入前景手和手绘层；
- 场景中存在可自然微动的元素；
- 自然的地面 / 支撑面接触关系，以及结尾不被遮挡的主体位置；
- 整体视觉调性与主体和用途相匹配。

只有在缺少关键决定时才提问，例如主体不明确、画幅会显著改变构图、或用户要求多个视频共用同一主体身份。字幕默认关闭。

## STEP 2：产出制作方案文档

在任何详细提示词或视频生成之前，先在画布上产出一版制作方案文档。

方案里要包括：

- 输入类型和需要保留的内容；
- 是否需要先生成真实预览图；
- 主体与辅助主体；
- 主体运动轨迹和节奏，以及如何在手绘中继续运动；
- 环境自然微动和可能的背景人物互动；
- 空间接触逻辑和最终可见性，包括避免家具遮挡；
- 马克笔入画方向、克制的手和前臂构图、绘制路径，以及手绘完成后的自然撤出方向；
- 显影规则：笔尖落在哪里，手绘就从哪里开始，并且每一刻显影都要与笔尖同步；
- 主体内部从左上到右下的显影顺序；
- 三层手绘结构和选用的风格模板；
- 时长、画幅、音频默认设置，以及需要用户确认的未定项。

如果用户给的是文字场景，先生成真实预览图并等待用户确认或修改，再写最终视频提示词。

如果用户给的是参考视频，方案里总结需要保留的部分和需要修复的问题；如果用户只要求修一个问题，不要大幅重做其他部分。

## STEP 3：产出详细视频提示词文档

在方案和预览 / 源图确认后，再在画布上产出第二版文档，作为最终生视频提示词。

这份提示词要把已确认的方案翻成可直接生成的执行文本，重点写清：

- 实景在手绘开始前先自然视频化；
- 主体和背景持续运动；
- 主体在手绘前、中、后都继续运动；
- 笔尖驱动且空间和时间强同步的逐帧显影；
- 笔尖没经过的位置不能提前显影；
- 慢速、随意、松弛的涂抹 / 排线，而不是快速描边；
- 允许单次显影出现一小片连续区域，但只能出现在笔尖刚经过的位置；
- 不能整块弹出、不能 wipe、不能扫描、不能静态贴纸、不能半透明叠加、不能沿边描；
- 显影在主体内部从左上向右下推进；
- 保留主体原有身份、特征、大小和原有运动轨迹；
- 手从边缘克制入画，通常右下角，自然握笔；
- 手绘完成后拿笔的手自然撤出画面；
- 背景微动和必要时的生活化互动；
- 结尾主体完整可见，不被家具遮挡。

提示词文档完成后再暂停一次，等待用户确认，确认后才开始真正生视频。

## STEP 4：生成视频

只有在提示词确认后，才开始生视频。

默认视频设置：

- 画幅：有源图时匹配源图；无源图默认 16:9。
- 时长：单主体单镜头片段默认 5 秒；模板展示或多对象场景可用 7–10 秒。较短时长更利于笔尖和线条同步。
- 镜头数：单主体场景应保持一个连续镜头；多对象场景可少量中景切镜，但避免频繁切镜和过近特写。
- 音频：默认关闭；用户要求声音时，加入轻快 BGM、轻微画笔沙沙声、完成时小 pop/ding。
- 字幕：默认关闭。

## STEP 5：质量检查与修正

生成后按以下清单检查：

- 手绘开始前，源场景已经自然动起来，不是冻结照片。
- 主主体在开头第一秒内已经有可见自然运动。
- 背景合理元素有细微自然微动，但没有整体动画化。
- 手绘内容由笔尖逐帧驱动。
- 手绘只出现在笔尖经过的位置，没有整块瞬间显现。
- 显影是主体内部完整替换，不是沿边描线或半透明叠加。
- 显影方向从主体左上向右下推进。
- 三层结构可见：清晰厚实硬边白边、内部黑色轮廓、内部排线填充。
- 内部填充颜色稳定低饱和，不彩虹不乱跳。
- 主体在整个转换过程中继续运动，没有停下来等笔画。
- 主体手绘化后继续运动，继承之前的运动轨迹和节奏，而不是冻结。
- 跳上椅子、抵达终点或停靠后仍有自然活体后续动作，不会立刻冻结。
- 手从干净的边缘区域入画，没有占据画面过大面积。
- 手在绘制时位于最前景，没有被手绘层盖住。
- 手绘完成后，手自然撤出，不继续悬停、指向或反复涂抹主体。
- 最终主体清楚可读，没有被椅背、椅腿、桌腿或前景障碍物遮挡。
- 如果目标是随性涂鸦 / 贴纸彩铅风，手绘应简化、松弛、中等偏粗、轻排线，不要过度细致或写实。
- 没有六指或手部畸形。
- 没有多余文字、字幕、Logo、水印。

失败时用针对性修正：

- 照片冻结或主体冻结：强化“源场景必须先自然视频化”以及“主体在转换前、中、后都必须继续运动”。
- 主体在绘制时停住：强化“不要停下来等笔画；手绘层附着在运动主体上；边走 / 边眨眼 / 边呼吸完成转换”。
- 开头主体冻结：强化“主主体在开头第一秒就开始自然运动，马克笔入画前已经有动作”。
- 整块显现：强化“逐帧笔触显现，不要 mask wipe，不要贴片弹出”。
- 颜色混乱：删除彩虹 / 多彩 / 霓虹，加入有限调色盘。
- 主体内部白线：写明白色只作为外边，不能进入主体内部。
- 手绘主体静止：写明手绘层附着在动态主体上，继承原主体运动轨迹、动作节奏、眨眼 / 呼吸 / 摆尾 / 衣物或环境微动。
- 手臂占画面太大：写明手从右下角或边缘进入，只露出手、手腕和短前臂。
- 手绘完成后手还停留涂抹：写明转换完成后，手和马克笔自然停止，向下方或侧方撤出，让完成后的主体无遮挡。
- 手绘过于细致：写明随性涂鸦风格，简化剪影，中等偏粗不完美线条，稀疏排线，不要写实毛发、密集阴影或精修矢量感。
- 笔尖错位：写明线条和填充必须跟随笔尖速度、方向、停顿、接触点和短促排线，不能在笔尖以外位置提前显影。
- 沿边描线：写明目标内部真实质感要完整替换成平面手绘对象，而不是只画轮廓。
- 白边太软或发光：写明清晰硬边厚白边，像白色纸片底衬，黑线在内。
- 家具遮挡主体：写明最终主体必须位于家具前方或上方并完整可读，椅背或椅腿不能穿过主体。
- 手绘太写实或太平：锁定“简化涂鸦剪影、松弛黑色轮廓、明显彩铅 / 蜡笔斜向排线、纸张颗粒和留白；不要真实毛发、厚涂阴影或矢量平涂”。
- 频繁切镜：写明单主体保持一个连续中景镜头，不突然特写。

## 能力边界

本 Skill 用于从实景照片、参考视频或文字场景生成实景手绘动效短视频。不用于纯静态修图、静态涂鸦贴纸、字幕生成、没有实景视频化需求的普通手绘 VFX、或长篇叙事视频。复杂多镜头项目应拆成多个短片分别生成，再后期拼接。
