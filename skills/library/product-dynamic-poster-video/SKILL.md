# 万物产品海报与视频

当用户提供一张清晰产品图，并希望先制作商业海报，再生成四种受控光位变化和一条时长 10–15 秒产品广告时使用本 Skill。产品原图是身份事实来源：除非用户明确要求重设计，否则必须保留包装、标签、Logo、可读文字、比例、材质、颜色身份、封口结构和口味线索。

这是严格的线性流程。每一阶段完成后，才能把其输出交给下一阶段。随 Skill 分发的权威提示词和光位预设必须逐字节保留；使用时不得概括、翻译、重排或“优化”。

## 阶段 1：素材接收与源文件检查

1. 要求一张产品轮廓、标签、Logo 和可见文字尽可能清晰的产品原图。
2. 只确认会实质影响交付的选择：海报画幅、画面风格、投放渠道、活动文案、受众和明确的配色方向。海报画幅必须由用户在 `9:16`、`3:4`、`4:5`、`16:9` 四种选项中决定，不得静默代选。广告时长必须在 10–15 秒之间；若用户没有指定时长，必须在生成视频前弹出询问框让用户确认，不得静默默认；若用户指定了该范围内的时长，就严格采用并按时长调整时间结构；若超出范围，则说明支持范围并请用户重新选择。若用户没有写明画面风格，先分析上传的参考内容，提出恰好三个有参考依据且彼此有明显差异的风格方向，并用简短说明呈现，等待用户选择后再进行创作。用户选定后，所有阶段都必须延续该风格。其他未指定项使用社交媒体广告、从产品推导文案、从产品推断受众、从产品可见颜色推导环境颜色。
3. 在创作前检查随 Skill 分发的权威资源。完整性检查失败时必须停止并报告受影响资源，不能用近似内容或重构后的提示词继续。
4. 以原图作为产品身份和风格方向提案依据的最高优先级证据。不要臆造看不清的标签文字、隐藏包装细节、法律声明、条形码、二维码或与口味矛盾的配料。

## 阶段 2：海报规格

1. 根据产品原图和用户选定的风格方向进行内部分析，并按照随 Skill 分发的海报源指令生成且仅生成一个结构化海报规格。
2. 规格必须保留被拍摄的准确产品，并落实用户选定的画幅与风格，同时描述紧凑的商业饮品构图：产品主导的层级、动态但安全的摆位、立体白色活动字体、从产品推导的环境调色板，以及符合饮品类别的物理效果。
3. 将活动字体与包装字体分开处理。不得遮挡 Logo、产品名、可读标签文字、封口或其他身份关键细节。
4. 使用随 Skill 分发的 Schema 和结构校验器验证结果。失败时只修复语法或结构，不修改源指令或创意意图。保留已知源文件矛盾：正文提到 12 个示例字段，但明确的机器校验结构包含 13 个命名字段。

## 阶段 3：主海报

1. 使用产品原图和已通过校验的海报规格制作一张主海报。
2. 使用图像条件编辑或合成，把广告环境构建在原产品周围，不要独立生成一个新的产品渲染图。
3. 验收同一商业 SKU 是否仍然清晰可辨，包装轮廓和标签是否完整，默认是否只有一个主产品，以及活动文字是否避开关键包装信息。

## 阶段 4：四张光位参考图

1. 以主海报作为唯一底图，分别生成四个独立输出。
2. 按以下顺序一次使用一个预设：轮廓/勾边光、侧主光、顶置主光、低角度/底部主光。
3. 每张图只改变光照和阴影行为，同时保留几何、画幅、主体数量、包装身份、文字、材质和构图。不得混用预设、平均四种预设，或把它们做成幻灯片。
4. 验证恰好存在四张独立图片，且全部来自同一张主海报。若其中一张失败，只重试该光位，保留已经成功的结果。

## 阶段 5：视频提示词

1. 将四张光位参考图作为一个互补参考集合，一起交给随 Skill 分发的视频源指令。
2. 只生成一段简洁、可直接用于制作的英文提示词，构建时长等于用户确认值、且在 10.0–15.0 秒之间的统一商业广告。使用最清晰的参考图作为产品身份锚点，将重复出现的产品细节作为连续性约束，把光位差异转化为受控的光照推进，而不是让图片互相变形。
3. 必须将五段时间结构按用户确认的时长进行缩放：氛围钩子、产品揭示、能量递进、视觉高潮、英雄定格；五段相加必须恰好等于确认时长，最后约 1.5–2.0 秒要清晰稳定地保持产品锁定画面。
4. 写明镜头连续性、焦点行为、材质物理、具有因果关系的运动、光照连续性，并明确禁止包装变形、标签错误、产品重复、幻灯片式表现、不稳定镜头和曝光闪烁。

## 阶段 6：最终视频

1. 根据四张光位参考图、已校验的视频提示词和用户确认的 10–15 秒时长生成视频。
2. 让产品始终是主角：产品只做温和、可追踪的运动；镜头和光照负责主要注意力引导；液体、冰块、水果、气泡和字体作为具有层次、延迟反应且可读的次级运动。
3. 验证时长、产品连续性、高潮段包装可读性、稳定的最终画面，以及不存在简单淡入淡出或随机图片变形。

## 失败与交付规则

- 不得跳过失败的校验闸门，也不得用临时资源替代缺失的权威资源。
- 后续阶段失败时保留所有已完成产物，并明确报告停止在哪个阶段。
- 同类资源尽量批量完成：先形成四张光位参考图，再制作一条视频；不要按“一个光位接一个视频”交替处理。
- 在可用时交付主海报、四张按光位命名的参考图、最终 15 秒视频，以及阶段 2 和阶段 5 的原始文本输出。
- 所有产物保存在当前项目工作区；后续阶段使用工具返回的资产路径。

随 Skill 分发的资源位于 `references/authoritative/`：不可变的源提示词、四套光位预设、源文件清单、海报 Schema 和校验脚本。Skill 只描述创作意图与闸门，具体动作由运行时映射到当前 MiniMax Design 能力。
