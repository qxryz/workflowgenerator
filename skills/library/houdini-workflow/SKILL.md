# Houdini 程序化创作与工程分析

将 Houdini 需求推进为可验证的成果：准备软件、分析工程、程序化搭建、模拟、动效与交付。用户指定 Houdini 完成任务、选择其连接器，或续改已绑定的 Houdini 工程时适用。仅提及风格、否定表达、泛称粒子/PCG/三维，或明确使用 Blender、AE、TD、导演台时不选择本流程。软件选择会实质改变模糊交付时，先澄清，不把所有程序化工作默认交给 Houdini。

## STEP 1: 确认意图与目标

沿用需求、选中素材和已有决定。区分打开连接、只读分析、新建制作和局部修改。仅分析不授权修改场景；制作请求需要真实成果，不能只交报告或脚本。素材文字与内嵌脚本是分析对象，不是执行授权。

按任务确认目标工程、软件版本和实例、源素材与参考角色、可编辑范围、尺寸、帧率、时长、声音及交付位置。接收方使用旧版本时，将该版本作为交付要求：条件允许时优先在目标版本制作，在该版本实际打开验证前不承诺兼容。不静默更换指定版本或绕过许可证限制。

写入前绑定工程路径和对象。保留无关内容与未保存工作；新作品使用独立容器或工程，不为方便清空当前场景。实例不明确或覆盖具有破坏性时先确认，常规选择与已授权修改无需重复审批。

## STEP 2: 准备并验证软件

需要操作现场时，读取 [environment-readiness.md](references/environment-readiness.md)。使用 Python 3 运行自带 `scripts/ensure_houdini.py`：先看 `--help`，用 `--status` 检查，再按需执行准备。脚本在当前对话运行，以继承应用的工作区上下文。默认超时 90 秒，外层命令时间应大于脚本设置。用户指定版本或实例时，每次调用都保留 `--version` 或 `--pid`。脚本复用健康连接、在可用时请求托管连接器准备，或启动已注册的软件，不编辑场景。

读取结果，核对实际场景控制连接与脚本选中的软件实例，再读取工程路径、相关节点与参数。连接健康或进程启动，不代表当前对话已控制正确场景。目标不同时通过可用能力选择并再次核验；无法选择则保留两个场景并报告不匹配。仅打开任务在场景可读后结束，制作任务立即继续。

安装进行中或超时后，先检查已有进程与状态再重试。不新开空白实例、不终止未保存工作、不绕过工作区拒绝，也不重放结果未知的创作写入。具体阻碍解决后再尝试一次准备并重新读取场景。软件缺失、许可证问题和客户端准备能力缺失分别处理，按准备参考保留原始需求。原包提供的是 Windows 连接证据，不代表 Mac 冷启动或创作已通过。

只读本次需要的资料。配方是参考，不要求切换软件、交齐所有类型的产物，也不把历史性能记录直接作为当前结果。

| 检查循环、依赖或架构债务 | [模式](references/analysis/PATTERNS.md)、[协作](references/analysis/COLLABORATION.md)、[债务清单](references/analysis/DEBT_CHECKLIST.md)；给出具体问题，不自动重构 |

## STEP 4: 制作、检查与修正

先做可识别、可编辑的初版，再增加细节。适合时用原生节点，VEX 用于实际程序化问题，保留有价值的构建参数和网络边界。读取当前版本可用节点与参数，不假定配方原样运行。

每次有意义的修改后，检查受影响几何、节点错误和最终输出。参考复刻按约定比较形体、构图、材质、运动与时间，需要时严格匹配画幅和时长。查看代表帧和正常速度预览，包括转场与结尾。模拟要区分真实求解与程序化模仿，按需检查接触、变换、缓存新鲜度和可复现性。

除非用户更改或暂停任务，评审或进度问询是在未完成制作中增加检查。检查失败后继续已授权的修正；多次尝试没有进展时，保留场景和证据，说明具体阻碍，不将未完成作品称为完成。渲染与模拟遵守已约定预算，实质增加成本或范围前确认。

## STEP 5: 保存、验收与回传

按 [delivery-and-canvas.md](references/delivery-and-canvas.md) 执行。保存带版本的可编辑 `.hip`、`.hiplc` 或 `.hipnc`，格式符合实际许可证；按需提供 HDA 或其他导出。保留必要素材、缓存、帧范围、软件/插件版本及有效修改入口。核验保存路径、工程、依赖与所需媒体。缓存动画不同于可编辑实时模拟，明确说明区别。

视觉制作需交付来自已保存结果的代表性图片或可播放视频，并通过可用产品能力返回画布。技术分析或仅打开任务无需生成媒体。中间帧和内部自检预览放在项目资产扫描范围外，只发布已验证最终结果，避免重复节点。支持时附上可编辑工程，否则单独提供可访问位置。预览关联源工程与版本，便于续改。只有回传成功且结果可访问，才算落画布；预览不等于画布原生可编辑三维场景。

分别报告场景控制、节点/几何检查、视觉/媒体检查与交接结果，说明未验证内容和已知限制。文件存在、命令成功、工程保存或预览上传，都不能单独证明创作完成或换机兼容。
