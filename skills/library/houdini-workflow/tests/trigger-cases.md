# 触发与工作流验收用例

这些是预期行为与静态走查，不代表已运行 Agent 触发实验。

| 输入 | 预期 |
|---|---|
| 用 Houdini 做一栋能调层数的程序化小楼，保留工程。 | 本 Skill，实际搭建、保存工程、验证预览与画布交接 |
| Analyze this Houdini HIP and explain its VEX; do not change it. | 本 Skill，只读分析，不启动制作或保存原工程 |
| @Houdini 帮我把当前场景的碎片碰撞修好。 | 本 Skill，先绑定实际场景与控制实例，再检查求解和缓存 |
| 用 Blender 做一个程序化城市。 | Blender，不因 PCG 或程序化词汇触发 Houdini |
| Make an AE title animation with a Houdini-like look. | AE，Houdini 是风格参考，不改变软件 |
| 在导演台里搭一个三维场景，做一下运镜。 | 导演台，不触发 Houdini |
| 帮我做一段粒子动画。 | 软件不明确，不默认选 Houdini；按已有上下文或必要问询确定 |
| 用 Houdini 20.5 制作，交给同事继续编辑。 | 保留指定版本，不能静默用 21.0；交付兼容性需目标版本实际验证 |

走查：新建可调小楼需要确认目标工程 → helper 准备及实际读场景 → 按模板先制作轮廓 → 修改层数验证控件影响最终输出 → 保存工程与依赖 → 检查预览 → 回传画布并关联工程。未安装软件应给官方安装引导并保留需求；未保存场景不自动关闭；画布能力不足时明确待交接。所有步骤均待实机验证。
