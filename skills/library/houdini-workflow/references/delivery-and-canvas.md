# 产物与画布交接

## 根据任务交付

| 任务 | 交付与检查 |
|---|---|
| 打开/连接 | 确认指定实例和场景可读，不额外创建作品 |
| 工程分析 | 真实节点、拓扑和代码支持的结论；按需交报告，不要求渲染 |
| 程序化建模 | 可编辑工程和必要依赖；按需导出模型或 HDA，视觉作品提供代表性预览 |
| 动画/模拟 | 可编辑工程、所需缓存和媒体；区分实时求解、缓存回放与程序化动画，检查时间、运动与接触 |
| 图片/视频 | 真实可解析文件、正确尺寸与内容，视频检查时长、帧率、帧数与所需音轨，实际查看或播放 |

工程格式遵守实际许可证。保存新版本，检查真实路径、场景状态、主要节点和依赖；可安全重开时检查可读性，未验证重开要说明。跨版本交付列出目标 Houdini 版本、渲染器、插件和 HDA 定义，在接收方版本验证前不能承诺兼容。不能只改后缀或把工程复制成功称为版本转换。

保留可携带的相对依赖，验证 `$HIP`、外部 HDA、贴图、字体、缓存/rest 帧和预滚范围。控制器必须实际影响最终输出；修改参数后核验缓存是否仍适用，必要时重新生成。只有用户要求可复用 HDA 时才做资产封装及重命名、迁移测试，不能把每次建模扩为组件产品开发。

## 过程文件隔离

渲染帧、低清自检图、缓存与待验收合成放到独立任务临时目录，确认不在项目资产扫描范围内。不要依赖目录名称推断不会入库。需要随工程交付的模拟缓存归入依赖包，不自动逐帧展示。先验证再复制最终媒体到目标位置；用户明确要过程预览时只展示相关少量结果。

## 返回画布

视觉制作完成后，从已保存结果导出代表性图片或可播放视频，使用当前产品实际提供的导入、上传或挂载能力回传。检查结果确实可见/可播放；自动收录已生成节点时复用它，不重复创建。保留原始参考和旧版本，关联源工程、输出版本、主要修改入口与预览。

支持工程附件时附上可编辑工程；只支持媒体时展示预览，并单独提供工程文件的可访问位置，明确工程是否入库。只能提供本地文件时说明画布交接未完成，不能说已经放上画布。预览、可下载工程、可原生编辑的三维画布对象分别是不同能力。

续改时从选中预览找回对应工程和对象，再读取实际状态，修改本次范围并输出新版本。不要重新生成一份未知版本只为完成资产登记。完整完成需要工程、必要依赖、媒体验收与实际交接分别有证据。
