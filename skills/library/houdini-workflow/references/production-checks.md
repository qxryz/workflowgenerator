# 制作中的关键检查

以下从用户提供的 2026-09-10 资料包提炼；原作者的历史修复与数值不作为当前工程验收。这里保留方法，移除个人路径、缺失的项目文件引用和客户端实现说明。

## 相机、角色与接触

- 区分局部、父级和世界空间。相机已经继承父级时不要再次叠加世界变换；用父级平移/旋转和时间变化验证跟随。
- 区分 HScript、VEX、Python 表达式的参数顺序与时间单位，读取当前函数签名，检查区间边界和端点。根节点平移不证明四肢持续运动，查看最后一段、过渡段和循环相位。
- 骨架命名、蒙皮属性存在不代表最终渲染皮肤被驱动。实际改变一个目标控制，检查最终皮肤而非隐藏代理；验证后恢复。缓存或代理不能冒充原生可编辑绑定。
- 蒙皮暗折应区分权重、绑定方法、几何和灯光。不要用“没有未加权点”证明所有关节变形正确。仅修改当前模式真正启用的质量参数，避免无效控件。
- 发生矩阵重载错误时核对当前 HOM 类型，可显式转换为兼容的元素序列；先检查影响范围，不把旧错误日志全部当成当前失败。
- 水面脚步等事件用实际接触帧固定出生位置，再从固定中心扩散。脚踝代理不等于真实脚底，改变步频后重新检查接触与穿透。
- 镜像、可见性和转场必须覆盖全时间范围；阶段切换后旧建筑或角色不应意外残留。单目参考隐藏几何和三维运动仅能推断，标记近似。

## 刚体、几何与缓存

- 质心/pivot 初始化可能改变点位置而非真实物体运动。比较相同物质点在完整 packed 变换下的结果，不只比较 `P` 或包围盒。
- 检查 packed scale、orient、pivot 与实际几何。显示和碰撞必须一致；需重打包时保留恢复来源，避免重复变换。
- 预设质量不代表求解初始化后的实际质量，必要时读取求解后的数据。区分无撞击对照中的自行沉降与撞击效果；总接触数量不能证明指定物体命中。
- 随机旋转值不等于偏心力矩。沿真实受力点、法向和力臂解释旋转，并验证表面采样不会产生假穿透。
- 区分真实 Bullet/Pyro 求解与用动画模仿动力学，遵循用户对模拟方式的约束，不静默替换。
- 修改种子、尺寸、质量或时间后检查缓存来源与参数是否一致。控件存在不代表缓存自动失效；需要重算时明确执行范围并核验最终输出。
- 交付移动目录后测试相对引用、外部资源、rest 与预滚帧。封装 HDA 时检查固定根节点名与绝对节点路径；尚未验证任意改名/复用时说明限制。

## 验收不能互相替代

脚本语法通过、节点计算无错、数值审计通过、文件存在和画面还原是不同检查。重点验证最终输出和完整时间段，不能只取有利帧。检查发现缺项后继续授权范围内的修正；无法完成时报告具体阻碍和可恢复位置，而不是用计划清单冒充制作完成。
