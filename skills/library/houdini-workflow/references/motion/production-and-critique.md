## 1. 制作阶段与过关条件

### 阶段 A：方向

交付：一句话创意、美术圣经、色彩脚本、音乐与 4–6 段乐句图。

过关条件：

- 任何成员能用同一句话描述感受与产品承诺
- 视觉形容词已翻译成配色、材质、光、镜头和运动限制
- 缩略色彩脚本能看出开场、展开、高潮、落版

### 阶段 B：英雄帧

交付：5–9 张关键 style frame，覆盖开场、主体建立、功能、高潮、落版。

过关条件：

- 缩到手机预览仍能读出主语
- 各帧属于同一视觉世界，但不是同一构图重复
- 产品关键轮廓、材质与品牌色准确

### 阶段 C：Animatic

交付：灰模/低模、临时灯光、最终或等价音乐、完整时间线。

过关条件：

- 静音仍能看懂叙事
- 镜头长度有长短对比
- 高速运动后有阅读窗口
- 高潮和落版有明确时间预算

### 阶段 D：主运动

交付：相机、主体、主要装配/变形曲线。

过关条件：

- 每镜一个主要视觉动词
- 命中点与乐句/拍点有理由
- 相机与主体没有无动机漂移
- 进入/退出方向支持镜头连续性

### 阶段 E：材质、灯光与 FX

交付：最终材质家族、灯光、次级运动、模拟、渲染测试。

过关条件：

- 主体在最终显示条件可读
- FX 不遮挡产品、文字和命中动作
- 金属/玻璃有可控反射环境
- 抽查帧无噪点、闪烁、破面和模拟穿插

### 阶段 F：合成与声音

交付：调色、光效、景深/运动模糊、字体、音效与最终输出。

过关条件：

- 合成强化层级，不改变已通过的美术方向
- 声音有主次，不为每个小动画堆音效
- 品牌落版满足安全区和停留时长

## 2. 软件映射

先给出跨软件的视觉要求，再提供实现建议。软件选择服从镜头，不让工具决定创意。

### Cinema 4D

- 用 Takes/Layer 管理 style frame 与镜头版本
- 用 Fields 统一克隆、材质、灯光与形变节奏
- 用 Stage/Camera Morph 前先验证焦段与轴线，不依赖随机相机
- Redshift/Octane 中用反射卡设计高光形状

### Blender

- 用 Collections/View Layers 管理段落和渲染层
- 用 Geometry Nodes 处理模块化、聚合、流动和图解系统
- 在 Graph Editor 中显式设计准备、命中、沉降，不只用默认 Bezier
- 用 Cryptomatte、AOV 与 Light Groups 保留合成控制

### Houdini

- 用 SOPs 建立可控形状逻辑，再引入 DOPs/粒子/流体
- 把模拟驱动力绑定到音乐乐句或空间场，而不是纯随机噪声
- 缓存低分辨率预览用于 animatic；方向通过后再提高采样/体素
- 为转场输出稳定的 id、age、velocity、mask 等属性

### Unreal Engine

- 用 Sequencer 先锁剪辑与镜头，再做 Niagara 和材质动画
- 用 Lumen/Path Tracer 前先验证主光、轮廓和曝光区间
- 控制自动曝光，避免不同镜头明度漂移
- 用 Movie Render Queue 固定抗锯齿、运动模糊和色彩管理

### After Effects / Nuke

- 合成用于统一色彩、层级与镜头连接，不用于挽救错误构图
- 用分层景深、光效和颗粒统一不同 3D 渲染
- 用音频标记区分乐句点、动作命中和纹理拍
- 最后检查文字安全区、压缩、banding、闪烁和色彩空间

## 3. 渲染与合成优先级

按观看价值投入算力：

1. 主体轮廓和材质响应
2. 关键反射、阴影和轮廓光
3. 运动模糊、景深与体积的稳定性
4. 背景细节和次级 FX

优先提高英雄帧和慢镜头质量。高速运动、深景深或被遮挡区域不要与落版、微距和产品近景同等采样。

### 常见技术问题

| 问题 | 视觉表现 | 优先修复 |
|---|---|---|
| 运动模糊过大 | 产品轮廓和 Logo 消失 | 降快门角/速度，增加停靠帧 |
| 景深过浅 | 只有无意义小区域清楚 | 把焦点绑定叙事主体，降低虚化 |
| 体积噪点 | 暗部闪烁，显得低质 | 提升体积采样，减少无价值体积 |
| 反射跳动 | 产品表面高光不连贯 | 稳定反射卡/环境，避免随机 HDRI 旋转 |
| 模拟频率过高 | 噪声感强、抢节奏 | 降小尺度扰动，保留一个大形变化 |
| 调色压黑 | 暗色片只剩纯黑 | 恢复暗部层级与轮廓分离 |

## 4. 100 分评审量表

### 美术 40 分

| 项目 | 分值 | 满分标准 |
|---|---:|---|
| 色彩系统 | 10 | 底色/主体/强调色分工清楚，章节有色彩弧线 |
| 构图与视觉层级 | 8 | 每帧主语明确，缩略图可读，负空间有效 |
| 材质与灯光 | 8 | 材质可区分且服务情绪，反射与轮廓受控 |
| 镜头与空间 | 8 | 焦段、机位、深度和尺度构成统一镜头语法 |
| 独特性与品牌归因 | 6 | 视觉母题可记忆，不能轻易换成其他品牌 |

美术低于 32/40，不进入高成本精修。

### 节奏 35 分

| 项目 | 分值 | 满分标准 |
|---|---:|---|
| 乐句与情绪弧线 | 10 | 开场、展开、高潮、落版清楚，有张弛 |
| 镜头长度变化 | 8 | 快慢交替，英雄帧和阅读窗口充足 |
| 音画关系 | 7 | 结构点与乐句一致，微动效承接细分拍 |
| 转场与连续性 | 6 | 形状、轴线、遮挡、光或因果有依据 |
| 停顿与落版 | 4 | 高潮前有负空间，结尾稳定且可读 |

节奏低于 27/35，回到 animatic。

### 制作 25 分

| 项目 | 分值 | 满分标准 |
|---|---:|---|
| 动作曲线与物理 | 5 | 命中清楚，材质/重量与曲线一致 |
| 相机执行 | 5 | 运动有动机，无漂移、穿插和突兀速度 |
| FX 控制 | 4 | 模拟与粒子服务主语，不遮挡信息 |
| 字体/UI | 3 | 可读、对齐、时长与空间正确 |
| 渲染/合成 | 5 | 无闪烁/噪点/色带，层级与色彩稳定 |
| 声音 | 3 | 主次清楚、物理可信、落点准确 |

总分至少 80/100，并同时通过两个子项门槛。

## 5. WIP 评审格式

先给结论，不先列细节：

`当前版本的主要问题是 [美术/节奏/叙事]，它导致 [具体观看结果]。优先修改 [1–3 件事]，其他精修暂缓。`

再按以下表格输出：

| 优先级 | 时间码 | 问题 | 原因 | 修改动作 | 验收信号 |
|---|---|---|---|---|---|
| P0 | 00:00–00:03 | 示例：钩子看不清主体 | 相机、主体与粒子同时高速运动 | 固定相机，主体保留一次命中，粒子延后 4 帧 | 首次观看能在 1 秒内说出主体轮廓 |

最后给：

- 当前分数：美术 /40、节奏 /35、制作 /25
- 只做一轮修改时的三项任务
- 修改后需要重新验证的风险

禁止使用“再高级一点、节奏更好、颜色更舒服”等不可验收表述。

## 6. 交付前检查

### 美术

- [ ] 关掉颜色后，主语与空间仍可读
- [ ] 每个章节只有一个主强调色
- [ ] 产品关键轮廓、材质和品牌色准确
- [ ] 相邻镜头在色、形、轴或光上至少有一项连续
- [ ] Logo 和文字背后有稳定负空间

### 节奏

- [ ] 开场 1–3 秒有明确钩子
- [ ] 中段有一次变奏或尺度重置
- [ ] 没有连续 4 个以上等长镜头
- [ ] 高速镜头后有阅读窗口
- [ ] 高潮前有停顿或密度对比
- [ ] 落版稳定 1.5–3 秒

### 动效与相机

- [ ] 每镜只有一个主要视觉动词
- [ ] 主、次、纹理运动没有同时达到峰值
- [ ] 动作包含命中和沉降，而非默认匀速
- [ ] 相机运动有信息收益
- [ ] 遮挡转场、景深和运动模糊没有隐藏关键信息

### 技术

- [ ] 无破面、穿插、粒子跳变、阴影/反射闪烁
- [ ] 暗部与高光在目标屏幕可见
- [ ] 色彩空间、帧率、分辨率、编码与音频规格正确
- [ ] 手机尺寸与静音播放均已检查
