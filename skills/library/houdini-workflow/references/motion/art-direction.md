## 1. 美术系统而非风格词

把“高级、未来、治愈、科技”等形容词翻译成一组互相支持的视觉决定。要求每个项目至少锁定以下变量：

| 变量 | 要回答的问题 | 可执行表达示例 |
|---|---|---|
| 形状 | 画面由什么轮廓统治？ | 圆角模块、锐利切片、有机薄膜、机械骨架 |
| 比例 | 主体与空间是什么关系？ | 巨物压迫、微观探索、标准产品英雄比例 |
| 密度 | 一帧允许多少信息？ | 单主体留白；3–5 层深度；满屏机械细节 |
| 颜色 | 颜色如何分工？ | 冷灰环境、银色主体、橙色能量 |
| 材质 | 哪种表面承担情绪？ | 雾面聚合物、拉丝金属、清澈玻璃、液体薄膜 |
| 光 | 观众从哪里读形？ | 大面积柔光读体块；窄轮廓光读边缘 |
| 镜头 | 观众以什么身体感受观看？ | 低机位巨物、微距贴行、正交图解、手持亲历 |
| 运动 | 世界遵守什么物理？ | 精确轴向、柔性回弹、磁吸聚合、连续流体 |

先让这些变量达成一致，再增加视觉奇观。

## 2. 配色与色彩脚本

### 2.1 建立角色分工

从 70/20/10 起步，不把它当成死比例：

- 约 70%：环境与负空间，控制整体明度和情绪
- 约 20%：主体与主材质，保证品牌/产品识别
- 约 10%：能量、交互、危险、卖点或高潮强调

控制强调色的出场权。强调色在所有镜头都满屏出现，就不再是强调。

### 2.2 先定明度，再定色相

在灰度缩略图中检查：

- 主体与背景是否至少有一条清晰明度边界
- 文字背后是否有稳定负空间
- 暗片是否仍能读出轮廓，亮片是否仍有高光层次
- 高潮是否在明度、饱和度或对比度上出现可感知峰值

低调科技片避免“全黑”：用 3–5 个暗部层级区分背景、主体、凹槽、反射和轮廓。高调软质片避免“全白”：用冷暖、粗糙度和柔和投影建立空间。

### 2.3 设计章节色彩弧线

常用弧线：

- 暗冷开场 → 单色能量出现 → 高对比高潮 → 品牌色落版
- 中性产品 → 强调色解释功能 → 回到中性英雄帧
- 冷自然 → 暖生命 → 金属/矿物 → 纯白品牌落版
- 白色世界 → 单个饱和物体引路 → 多彩展开 → 收束到品牌色

章节换色要有叙事原因：进入内部、切换功能、情绪转折、时间变化或材质转变。

### 2.4 避免颜色噪声

- 每个段落只允许一个主强调色
- 相邻近似色统一到同一色相走廊
- 让材质的粗糙度与明度差承担层次，不依赖增加色相
- 用光色和环境反射解释颜色，不给每个对象独立随机色

## 3. 构图与视觉层级

### 3.1 每帧只设一个视觉主语

先写一句“观众这一帧先看哪里”。如果有两个答案，降低其中一个的面积、对比度、锐度、运动幅度或饱和度。

用以下顺序建立层级：

1. 主体轮廓与面积
2. 明暗和色彩对比
3. 运动与焦点
4. 细节、文字和 FX

### 3.2 使用三层深度

最小空间结构：前景遮挡/纹理、中景主体、后景环境/光。需要宏大时增加远景或体积层；需要图解时主动压扁深度。

前景的价值不是装饰，而是：

- 给相机速度提供视差
- 隐藏转场接缝
- 建立尺度
- 把视线导向主体

### 3.3 在中心构图与偏心构图之间轮换

- 中心/对称：仪式感、精密、落版、英雄展示
- 偏心/对角：运动、探索、危险、过程
- 顶视/正交：模块、系统、流程、UI
- 超近景：材质、触感、机械精度、抽象钩子
- 大远景：世界观、尺度、结果

避免每个镜头都把产品放在正中间同样大小。用“微距—中景—全景—英雄近景”制造尺度句法。

### 3.4 给文字留真正的负空间

在分镜阶段锁文字安全区，不在渲染后寻找空位。文字背景应在 1–2 秒内保持稳定明度与低纹理，不让高光和粒子持续穿过字形。

## 4. 镜头与空间

### 4.1 用焦段定义性格

- 18–28mm 等效：夸张空间、速度、巨物、穿越；谨防产品变形
- 35–50mm：自然、叙事、环境中的产品
- 60–100mm：高级产品、压缩空间、干净轮廓
- 100mm 以上微距：材质、细节、抽象开场
- 正交/近正交：图解、模块化、UI 与装配

数值是起点，最终以轮廓、透视和运动感验收。

### 4.2 让相机有动机

相机只因以下原因运动：

- 揭示新信息
- 追随主体或能量
- 建立尺度与空间
- 连接前后镜头的轴线
- 在音乐乐句上制造加速或呼吸

删除没有信息收益的漂移。高级感通常来自稳定、意图明确和速度受控，而不是一直缓慢推镜。

### 4.3 控制空间连续性

建立进入/退出向量：左→右、前→后、旋转顺/逆时针、由暗入亮。相邻镜头至少继承一个向量，除非要故意制造断裂。

优先用真实可解释的连接：穿过孔洞、沿表面滑行、被物体遮挡、跟随能量线、由微观结构拉远成完整产品。

## 5. 材质与灯光

### 5.1 材质从功能和情绪出发

材质家族最多 3 个：

- 主体材质：产品识别与触感
- 对比材质：突出主体轮廓或功能
- 能量/隐喻材质：承担变化与高潮

每种材质至少检查 base color、roughness、specular/IOR、normal/微表面、透射/体积。不要只换颜色而保持完全相同的高光响应。

### 5.2 让材质变化有句法

可用的变化不是随机 shader noise，而是：

- 粗糙→光滑：从原料到成品
- 不透明→透明：揭示内部
- 冷金属→暖能量：激活
- 颗粒→连续表面：聚合
- 固体→液体/织物：柔性与流动

### 5.3 灯光先塑形，再渲染气氛

基础灯光职责：

- 大面积 key：读主体体块
- 轮廓/rim：从背景分离
- 反射卡：设计产品表面的高光形状
- 环境/体积：统一空间与情绪
- 动态灯：只在功能、转场或高潮时使用

金属与玻璃先设计“它反射什么”。没有可控反射环境，再高的采样也只会得到灰物体。

### 5.4 使用光作为节奏层

让灯扫、曝光脉冲、体积光开合承担音乐的次级拍，不必每次切镜头。保持主体轮廓稳定，避免用全屏闪白代替转场设计。

## 6. 字体、UI 与图形信息

- 字体只承担命名、功能、数据或品牌，不与 3D 奇观争夺主语
- 重要短句至少稳定 1.2–1.8 秒；品牌落版通常 1.5–3 秒
- 文字入场和镜头运动共享同一方向或速度逻辑
- UI 线条、数字、网格只在能解释产品系统时出现
- 把屏幕空间 UI 与真实 3D 结构区分；需要空间感时给 UI 遮挡、透视和景深逻辑

## 7. 四类常用美术系统

### 7.1 明亮柔性科技

适合视觉、健康、软件、创意工具。

- 高调白/淡蓝/淡紫环境
- 透明、半透明、薄膜、织物、软体
- 柔光、长渐变、低硬度阴影
- 慢速连续 morph 配少量清晰产品镜头
- 用一个暖色小物体或局部粉/橙建立视觉锚点

风险：发灰、主体融入背景、过度梦幻而失去卖点。

### 7.2 暗色精密科技

适合硬件、汽车、工业、传感器。

- 黑/深蓝/石墨为底，单一青、绿或橙为能量色
- 窄轮廓光、硬边高光、受控反射
- 微距、拆解、轴向运动、图解式装配
- 用明暗层级而非多色区分零件

风险：全黑、细节只在高亮显示器可见、每个镜头同样冷酷。

### 7.3 玩具化/模块化彩色世界

适合消费电子、软件功能、游戏化体验。

- 白/浅灰或单色空间，2–3 个高纯度品牌色
- 圆角模块、按钮、球体、轨道、磁吸与积木结构
- 顶视、正交、快速 match cut、弹性动作
- 用固定引导物贯穿章节

风险：颜色过多、所有物体同时弹跳、可爱但没有产品层级。

### 7.4 电影化自然隐喻

适合品牌片、户外、影像、材质与性能叙事。

- 真实或超现实自然环境，色温按章节转变
- 水、冰、云、矿物、火、植物作为功能隐喻
- 长镜头、宏观/微观尺度切换、慢动作与爆发对比
- 产品在世界中经受测试，而非悬空自转

风险：自然奇观与产品无因果关系，漂亮但不可归因。

## 8. 美术失败模式

| 症状 | 根因 | 修改动作 |
|---|---|---|
| 每帧都很满 | 没有视觉主语 | 砍掉一半 FX；降低背景对比与饱和度 |
| 颜色很多但不鲜明 | 没有颜色分工 | 回到底色/主体/强调色，章节只留一个强调色 |
| 产品像灰模 | 没设计反射环境 | 添加反射卡与轮廓光，区分 roughness |
| 高级感不足 | 相机和对象都在漂 | 固定一个运动层，改用更长焦、更明确的命中点 |
| 科技感俗套 | 蓝色 HUD 与粒子无功能 | 删除装饰 UI，用结构、扫描或数据因果解释 |
| 场景像拼贴 | 焦段、光向、色温不一致 | 建立镜头/灯光圣经并统一章节变量 |
| 片子没有高潮 | 所有镜头同亮同饱和 | 在色彩脚本中保留一次明度、饱和度或尺度峰值 |
