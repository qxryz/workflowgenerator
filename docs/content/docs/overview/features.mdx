# 功能介绍

WorkflowGenerator 把工作流编排、AI 创作、终端 Agent、提示词、Skills 和本地资产放在同一个桌面工具箱中。

## 工作流画布

- 创建、重命名、导入、导出和管理多个画布项目。
- 组合文本、图片、视频、音频、生成、终端和插件节点，并通过连线声明输入与输出。
- 支持框选、多选、复制粘贴、撤销重做、小地图、背景样式、深浅主题和常用快捷键。
- 生成结果使用可切换的版本槽保存；重新生成不会覆盖仍可用的旧结果。
- 完整工作流可按节点执行、失败重试、分支探索，也可保存为可继续编辑的方案。

## Zodiac

- 根据目标和当前画布生成可确认的工作流提案。
- 在真正改动画布或执行生成前展示结构化操作，确认后再应用。
- 可读取当前节点、上游素材、已启用 Skills 和模型配置，并持续记录会话。
- 成功方法可整理为 Skill 草稿，交给用户检查后保存。

## 创作工作台

- 图片、视频和音频工作台提供生成记录、结果预览、创作参数与本地资产入口。
- Seedance 2.5 工作台支持普通生成、指定首尾、视频延长与精准编辑。
- 3D 导演台支持角色、姿势、群众、几何体、机位、全景背景和镜头截图；截图可保存到“我的资产”或送回画布。
- 工作台和画布共用模型渠道及模型专属参数，生成媒体在桌面端落盘后再进入记录和资产库。

## 模型渠道

- 支持添加多个模型渠道，并分别配置 Base URL、API Key、模型和原生调用方式。
- 已适配 OpenAI 兼容接口、Gemini、xAI Grok、Agnes、火山方舟、MiniMax API、MiniMax Token Plan、DashScope 等渠道能力。
- 图片、视频、文本和音频会按所选模型展示相应参数，不把不支持的选项混在一起。
- API Key 只保存在当前设备的应用数据中，不会随导出配置带出。

## Skills、提示词与作者私藏

- Skills 支持官方来源、本机导入、启用顺序和使用范围管理。
- 提示词支持搜索、标签、来源筛选、详情、复制和保存到本地。
- “作者私藏”可下载作者分享的 Skills、提示词和资产；下载后的内容只进入对应的“作者私藏”分类或“我的资产”。
- 下载内容会校验 SHA-256，发布目录可更新作者备注、版本和文件内容。

## 我的资产

- 保存文本、图片、视频、音频和其他工作流素材。
- 支持搜索、类型筛选、标签、来源、备注、预览、下载和删除。
- 可从工作台、画布、提示词库、导演台和作者私藏直接收入资产。
- 桌面版媒体文件保存在应用媒体目录，结构化索引保存在应用 SQLite 中。

## 终端与插件

- 画布终端节点可调用本机已安装的 Agent，并向会话提供当前工作区及启用的 Skills。
- 节点插件支持安装、启用、更新和卸载；内置 Markdown、SVG、HTML、3D 全景、便利贴和导演台节点等插件。
- 第三方插件代码会在应用页面中运行，只应安装可信来源的插件。

## 本地数据与同步

- 桌面版的画布、Zodiac 会话、配置和资产索引保存在本机应用数据目录，媒体保存在独立媒体目录。
- 网页兼容模式使用当前浏览器的 IndexedDB/localForage，不与桌面数据自动互通。
- WebDAV 是可选的跨设备同步方式，不替代本机主存储，也不是账号云同步。
- 配置页可查看当前设备实际使用的数据目录，并导入或导出不含 API Key 的配置。

## 当前限制

- macOS 公开包目前没有 Apple Developer ID 公证，首次打开需要按 README 的 Gatekeeper 方法放行。
- 网页兼容模式不包含桌面原生终端、SQLite 和媒体目录能力。
- 画布以桌面端为主，移动端触控体验尚未系统完善。
- AI 服务的额度、素材限制、审核和结果地址有效期由用户选择的模型服务决定。
