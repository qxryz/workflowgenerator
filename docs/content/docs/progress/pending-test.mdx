# 待测试

- 仓库来源与文档：应用内官方 Skills、提示词和插件应只从 `qxryz/workflowgenerator` 的对应分发分支读取；Skills 清单变更、插件发布与定时提示词同步应分别更新 `skills-dist`、`plugins-dist` 和 `wg-prompt-sources`，不再向 `main` 写入同步提交。文档、Docker、Render、安全策略和 GitHub 入口不得跳转到旧上游站点或已失效仓库。README 中保留的上游项目链接只用于致谢。
- 软件更新：进入“设置 → 软件更新”后应显示当前版本并自动检查；检查地址必须是 `qxryz/workflowgenerator` 的最新 GitHub Release，不再读取上游仓库。没有 Release 或网络不可用时只显示友好提示，并可前往 Tags；发现更高版本时显示“下载并安装”。下载过程应显示进度，安装前等待画布、Zodiac、导演台和本机存储刷盘，随后替换应用并自动重启；保存或签名校验失败时不得安装。网页版只提供检查与前往 Tags，不尝试调用桌面安装。首个 Release 已核对 DMG、macOS updater 压缩包、签名、`latest.json`、校验和与构建证明；发布下一版本时还需从 0.1.0 完成一次真实下载、安装和自动重启，并确认 Gatekeeper 放行后可运行。
- 安全边界：链接导入不得接收 API Key，配置文件导入不得恢复 API Key、WebDAV 密码或自定义调用脚本；Markdown 与 SVG 插件中的脚本、事件属性和危险链接不得执行。作者私藏目录与远程官方插件目录缺少签名、签名无效或插件哈希不一致时应使用内置内容并停止安装；正式版不显示第三方或本机插件入口。WebDAV 非本机地址必须使用 HTTPS，异常路径、超大响应、压缩包目录穿越和异常压缩比均应被拒绝。终端会话启动前必须显示系统确认，取消后不创建进程；远程媒体不得访问本机、局域网或云元数据地址。
- DSH Launcher：桌面版顶部“别点我”菜单的分割线下方应显示带 DeepSeek 图标的“DSH”，右侧版本号应与本机独立 DSH 内实际安装的 DSH 包一致，更新本机 DSH 后再次打开菜单应同步变化，无法读取时不显示空版本占位。点击后应在 Workflow Generator 主窗口进入 `/dsh` Launcher 页面，不应立即启动 DSH；页面应展示当前版本和“准备就绪 / 正在运行”状态，底部按钮按状态显示“启动 DSH / 回到 DSH”。点击按钮后打开或聚焦原有独立 DSH 窗口，不重复创建实例。关闭 Workflow Generator 后 DSH 应继续运行，DSH 的配置、工作区、会话和插件不得进入 Workflow Generator 数据。网页版菜单不显示 DSH；未安装或读取失败时只显示友好提示，不出现终端、命令或本机绝对路径。独立 DSH 应加载官方界面，并能不经过 Workflow Generator 从 Dock 单独启动。
- DSH 插件市场监控：Launcher 应读取 DSH Web Profile 中 dsh-market 的真实安装状态与版本；当前机器应显示“已安装 v1.5.1”。未安装时才显示“安装”按钮，打开页面、自动轮询或点击“重新检查”均不得触发安装。点击安装应先弹出第三方插件权限提醒，只有点击“继续安装”后才执行官方 Web Profile 安装；取消确认不得改写 DSH。安装成功后页面应切换为“已安装”，若 DSH 正在运行则提示重新打开后使用；安装失败只显示友好错误，不向用户展示命令、本机绝对路径或安装日志。该入口只安装 dsh-market，不默认安装市场内的任何其他插件。
- 作者私藏与作者入口：顶部应以略小字号、薄荷色显示“别点我”，并在明暗主题下保持清晰；点击后展开菜单。分割线上方的“说了别点”进入本地原生作者库并立即关闭菜单，分割线下方保留后续工作台区域，不能直接点击主入口跳转。目录为空时显示“作者还没有发布内容”。连接测试发布目录后，每项均显示“作者备注”，未填写时显示“作者暂未留下备注”；填写 `authorNote` 后应支持搜索，并在保存到 Skills、提示词或我的资产后继续显示原备注。Skill 保存后只出现在 `Skills → 作者私藏`，提示词只出现在 `提示词 → 作者私藏`，图片、视频、音频与文本进入“我的资产”并保留作者来源。重复保存应显示已保存，内容哈希或版本变化后应显示更新；伪造哈希、非 HTTPS 地址、超长作者备注、超大文件、类型不匹配和路径异常均须停止保存。完全退出再打开后，各类已保存内容、作者备注及媒体仍应存在。
- 3D 导演台侧栏背景：场景与属性两侧栏应使用与应用外层一致的纸面背景，浅色主题显示米白纸面、深色主题显示深色纸面，不再维持原导演台的独立深灰色块；搜索框、输入控件、文字和左右分隔线仍应清晰可辨，滚动与紧凑窗口面板不受影响。
- 3D 导演台底部工具栏：浅色主题下悬浮工具栏应显示米白纸面、深色图标与蓝色选中态，深色主题下同步切换为深色纸面；添加角色、群众设置、几何模型、模型库与画幅比例等弹出面板应沿用同一主题，按钮、输入和滚动仍可正常使用。
- 3D 导演台菜单层级：点击顶栏“工程”，导入、导出、保存与恢复菜单应完整浮在 3D 场景及左右面板上方，所有菜单项均可点击；在常规宽度与低于 920px 的紧凑窗口中均不应被顶部边界裁切或被导演台内容遮挡。
- 首页 Zodiac 标题：浅色与深色主题下均应恢复为原版常规半粗字形，不再显示 Zapfino 花体；字号应比原版更紧凑，位置和首页其他内容保持不变。
- 媒体工作板结构对齐：音频与 SD2.5 左侧均应显示“生成记录”、记录数量、“多选”和“新创作”，真实记录采用与图片、视频一致的预览卡，可全选并批量删除；SD2.5 的创作草稿仍保留但与真实记录分开。音频中部结果预览框应与 SD2.5 同尺寸、同边框和空状态结构；语音生成、声音克隆、语音转录应使用与 SD2.5 三种任务一致的顶部模式栏。右侧“模型与参数”应使用与图片、视频一致的模型选择器、标题层级、间距和主题色，并保留随当前模型与任务切换的原生接口路线卡、请求路径及官方文档入口。
- 工作台提示词与资产导入：音频“语音生成”应显示“提示词库 / 我的资产”，提示词或文本资产选中后立即进入朗读内容；声音克隆与语音转录只显示可用的音频资产，选中后应展示文件名、大小并可移除，格式、大小及 MiniMax 样本时长限制继续生效。SD2.5 三种任务都应显示“提示词库 / 我的资产”；图片开场与指定首尾时资产弹窗只显示文本和图片，自由创作、延长与编辑可显示文本、图片、视频和音频。文本进入当前描述，图片进入对应参考位，音频显示在参考素材中并随成功或失败记录在重启后恢复；视频只有 https 公网地址或 `asset://` 方舟素材 ID 可用，本机视频应明确拦截。切换到图片开场或指定首尾后，不兼容的视频和音频不得残留；图片、视频工作台原有资产类型及入口不受影响。
- 页面标题统一：图片、视频、音频、SD2.5 工作台与 3D 导演台的顶部标题应采用和其他页面一致的单行结构，不再显示标题前的装饰图标或标题下的解释性小标题；导演台顶栏应与应用纸面背景连续，并随浅色、深色主题切换，工作台切换、记录、参数、视角与工程操作仍应保持原位置和功能。
- 顶部全局导航与页面侧栏复用：工作流、工作台、导演台、Skills、提示词、资产、会话和文档入口应位于应用顶部，宽屏显示图标与名称，中等宽度仅显示带提示的图标，当前入口有明确选中态且“导演台”紧跟“工作台”。一级页面不再长期占用独立全局左栏；提示词、Skills、文档和各类工作台已有的筛选、目录、历史或属性面板应直接使用释放出的左侧空间。切换入口不应产生横向滚动，首页与沉浸式工作流画布保持原有顶栏策略。
- Seedance 2.5 三入口：进入任一图片、视频或音频工作台，顶部应新增并列的“SD2.5”入口；打开后页面标题为“专属工作板”。同一个已配置的 Seedance 2.5 模型还应在视频工作台显示原生任务面板，并在工作流画布视频生成节点中显示同样的生成、延长、编辑设置。
- Seedance 2.5 专属任务：生成视频应支持 4–30 秒与镜头序列；视频工作台和画布还可选择智能时长。延长视频至少连接 1 个 MP4/MOV 原片，可选 4–30 秒或智能时长，并提供自然续写/指定结尾；编辑视频至少连接 1 个原片，主原片需为 4–30 秒，画幅与时长跟随原片。参考视频使用 https 公网 URL 或 `asset://` 方舟素材 ID，本机视频不应被转成官方未声明支持的 Base64。三处只显示 480p/720p，可选 MP4 通用输出或 MOV 专业后期输出，不出现 60/90 秒、1080p 或 4K。任务完成后，视频与创作记录都应先写入本机再显示成功，重启应用后仍可预览、下载和存入资产；打开任一成功生成记录后，点击“用于延长”或“用于编辑”应直接切换到对应模式，并把该记录设为“原片”。
- Seedance 2.5 扩展参数：专属工作板、视频工作台与工作流参数面板都应显示自由创作、从图片开始、指定开始与结束三种方式；开场画面只能使用 1 张图，开始与结束画面按顺序使用 2 张图并固定为素材自适应，不能混入参考视频或音频。视频工作台只在自由创作中显示参考视频链接、参考视频说明以及图片/音频选择；切换到从图片开始或指定开始与结束后，素材标题、说明、空状态、添加按钮和文件选择器都只能提及并接受图片。专属工作板的延长与编辑任务应依次显示原片、内容描述和可选参考图，视频地址、原片时长及必填/可选状态须有明确标签，不再出现“普通参考图片”或无标签的数字输入。随机种子接受 -1 到 4294967295；开启“保存尾帧”后成功记录应保留 PNG 尾帧，点击“尾帧续作”会新建首帧任务。联网检索和固定机位只在纯文字生成时可用，添加任一参考素材后自动关闭。开发者模型卡应列出 `content[].role`、`seed`、`return_last_frame`、`tools[].type`、`camera_fixed`、`callback_url`、`execution_expires_after`、`safety_identifier` 和固定为 default 的 `service_tier`，并明确 2.5 不支持 draft、frames 与 flex。
- 导演台入口与角色：顶部导航的“导演台”应紧跟“工作台”；外层保持现有应用顶栏和页面标题，内部编辑器保持炭黑专业界面。个人本机版应使用原开源项目的 UE 骨骼人体，并可添加男性、女性、宽厚、健壮、纤细、少年、儿童和二头身 8 种体型、群众、6 种几何体和机位；8 种体型应由真实骨骼缩放形成清晰差异，切换导演/机位视角、体型与画幅均应生效。模型资源无法加载时才回退到程序化人体。
- 导演台全部姿势：依次切换 20 套姿势，站立、行走、跑步、坐姿、蹲姿、单膝跪、双膝跪及各类手势都应符合动作含义；支撑脚或膝盖应贴地，头、短颈、肩胸、躯干与四肢不得断离，手脚不得反向弯折，深蹲、跪姿等大角度动作不得因关节范围不足而被截断。再拖动身体、头部、手腕和脚掌调节项，确认 8 种体型在允许范围内都保持连续。
- 导演台内容删除：角色、群众、几何体、导入模型和机位的场景列表行均应常驻垃圾桶；选中单个对象后，右侧属性面板也应提供对应删除入口，并可使用 Delete / Backspace 快捷键。点击可见删除入口后须显示二次确认，取消后内容保持不变；删除群众时应明确提示将删除整组角色，删除机位时应同时移除其镜头设置。
- 导演台紧凑布局：把桌面窗口缩窄到内部视口低于 920px 后，3D 视口上方应显示“场景 / 属性”入口；选择角色后仍能打开“属性 → 姿势”，工程菜单和关闭按钮在常见窄窗口中不应消失或被裁切。
- 导演台工程：顶栏“工程”应可导入、导出 JSON，并可保存和恢复最近工程；完全退出再打开后主工程仍应保留。导入 2:1 全景图并重启后背景不得失效。
- 导演台资源导入：导入有效或无效的 FBX、OBJ、JPG、PNG、WEBP 时应显示成功或失败提示；修改导入模型的颜色后画面应立即变化，其他使用同一源模型的实例材质不得被连带污染。
- 导演台持久化与镜头：修改场景并截图时不应立即提示保存失败；完全退出再打开桌面应用后，当前导演项目、截图缩略图和最近工程都应继续保留。一级导演台的单张与批量入口应显示“保存到我的资产”，完成后截图出现在“我的资产”，可预览、下载且带有“导演台 / 镜头”标签。点击任一截图卡片的小眼睛后，大图预览应覆盖完整导演台而非只占右侧属性栏；图片和右上角缩放、下载、关闭操作完整可见，Esc 可关闭，常规与紧凑窗口均不得被侧栏裁切。工程与资产应复用同一份本机媒体，连续保存不产生重复文件，移除镜头时不误删仍被资产或其他工程引用的截图；工程记录不应包含大段 Base64，也不应只留在 WebView localStorage。画布内导演台仍显示“送回工作流”并生成、连接图片节点；关闭窗口前应完成最后一次工程刷盘，写入失败不得提示成功。
- 导演台节点：在画布“节点插件”的官方插件中安装并启用“导演台节点”后，创建菜单应出现导演台；上游图片连入后可作为场景背景，打开全尺寸导演台仍使用同一项目，发送镜头截图会生成并连接图片节点。关闭节点内导演台后应回到明确的“打开导演台”入口；禁用插件后原节点数据应保留，重新启用后恢复。
- Zodiac 与导演台：只有导演台插件已启用时，Zodiac 才能提出 `director-desk:project` 节点的新增、更新、连接、删除和选择操作；导演台是交互式分镜项目，不得被当作生成步骤执行，未安装或已禁用时不得静默降级成文本节点。
- 默认音色：在偏好设置切换 OpenAI、Qwen Audio、Qwen3 Voice Clone 与 MiniMax 音频模型，默认音色下拉应随模型展示对应厂商的可用预设；选择“自定义音色 ID”后应出现输入框，保存的 Voice ID 应在新建音频任务和工作流音频节点中继续使用。
- 页面背景：工作流、工作台、Skills、提示词、资产、会话和文档等纸面背景不再出现女性人物、天平或手持仪器，仅保留浅灰星盘、星座、几何线稿与左侧留白，文字和卡片对比度不受影响。
- 标签页视觉一致性：依次打开工作台、Skills、提示词、资产和文档，标题栏高度、点划分隔线、页面纸面背景、蓝色主操作、输入框与卡片边框应与工作流和会话一致；图片/视频/音频仍保持三栏专业布局，文档仍保持目录/正文/脚本布局，功能不因换肤改变。
- 模型接口参数文档：模型 API 分组只应出现已适配的推荐模型，不显示旧 MiniMax M2 系列或重复的 Token Plan/API 模型页；“参考文档”分组应独立保留架构与新增渠道示例、绑定模型的原生 UI 解释、Zodiac 工作流技术说明三章，且不计入推荐模型数量。逐个打开 OpenAI、Gemini、MiniMax、Grok、Agnes 与火山方舟模型，应看到对应原生 API 字段、允许值、输入素材限制和界面控件建议；MiniMax 单个模型页同时说明 Token Plan 与 API 计费两种接入，方舟图片显示 `/images/generations`，xAI / Agnes 地址不应重复 `/v1`。
- Skill 使用范围：Registry Skill 更新后应保留“Zodiac 专属 / 终端可用”选择；对话框临时附加的 Skill 只影响发送它的当前轮，下一轮未附加时不再进入上下文；编辑已启用的终端 Skill 后，新终端会话应使用最新正文。
- 模型渠道体验：首次打开时仍使用单连接渠道结构，不自动写入任何第三方 API Key；新增渠道时可选择 OpenAI、Gemini、MiniMax Token Plan、MiniMax API 计费、xAI Grok、Agnes 和火山方舟，并自动填写各自接口地址。切换厂商后应展示相应推荐模型且可一键添加；侧栏不再显示「日志」和「公告」。
- MiniMax 独立厂商与适配器：分别新增 MiniMax Token Plan 与 MiniMax API 计费渠道，每个编辑页都只应显示一组 Base URL 和一组 Key；两个厂商使用各自固定的内部适配器，渠道表单不显示只有一个选项的适配器下拉。Token Plan 只接受 `sk-cp` Key，API 计费只接受 `sk-api` Key；把另一类 Key 填入时输入框应立即报错，保存、选择模型和运行请求均被阻止。模型列表响应只表示接口返回目录，不得作为 Key 或计费线路验证。缺少当前厂商的 Key 时不得读取另一厂商的 Key，也不得自动切换。两家厂商均完整展示已接入模型，不按套餐等级或本地能力表过滤；具体权限由 MiniMax 接口返回。
- MiniMax Token Plan：不得显示只有一个选项的内部适配器下拉、套餐权益检测、手动权益开关或独立权益卡片。“选择模型”和接口返回模型须完整显示，不得按本地能力表或套餐等级二次过滤；生成请求直接使用当前 Token Plan 线路，具体权限与额度错误由 MiniMax 接口返回，任何失败都不得自动改用 API 计费 Key。
- MiniMax 推荐与完整列表：渠道编辑页推荐区只展示 M3、Image 01、H3、Hailuo 2.3 / Fast、Speech 2.8 HD / Turbo 等已适配代表模型；M2 系列等其他目录模型只出现在“选择模型”或接口拉取结果中。推荐区收敛不等于过滤，完整列表仍须保留所有目录和接口返回模型。
- 模型来源分栏：渠道模型选择弹窗必须分别显示“推荐模型”“模型目录”“接口返回”“已添加”及各自数量；打开弹窗时接口返回应为空，点击拉取后只刷新接口返回分栏并自动切换过去。推荐模型或目录与接口同名时可以分别出现，但来源不得合并或伪装成接口返回。
- MiniMax 原生接口：M3 使用 `POST /anthropic/v1/messages`；Image 01 使用 `POST /v1/image_generation`；H3 使用 `POST /v2/video_generation` 并通过 `GET /v2/query/video_generation/{task_id}` 查询；Hailuo 使用 `POST /v1/video_generation` 创建、`GET /v1/query/video_generation?task_id=...` 查询、`GET /v1/files/retrieve?file_id=...` 取回文件；Speech 2.8 使用 `POST /v1/t2a_v2`；声音复刻依次使用 `POST /v1/files/upload` 和 `POST /v1/voice_clone`。
- MiniMax 界面路线：M3 在两家厂商中都复用现有会话界面，并使用 Anthropic Messages 原生请求，不显示成 MiniMax 专属工作台；Image 01、H3、Hailuo 与 Speech 2.8 使用路线二的 MiniMax 原生工作台。Image 01 应显示官方画幅、1–9 张、提示词优化、水印与角色参考；H3 在两家厂商目录中都显示，并提供首帧、尾帧、首尾帧、多模态参考互斥模式、768P / 2K、4–15 秒、官方画幅和水印；Hailuo 2.3 支持文生视频和单首帧图生视频，2.3 Fast 必须提供单张首帧，两者都不显示尾帧模式，并正确联动 768P / 1080P 与 6 / 10 秒；Speech 2.8 与快速声音复刻在两家厂商目录中都显示，调用权限由上游返回。音乐生成与 MiniMax 转录不显示。
- MiniMax AIGC 标识：Image 01、H3、Hailuo 与 Speech 2.8 的参数文档都应列出 `aigc_watermark`，并分别对应工作台中的图片水印、视频水印和 AIGC 音频标识开关；快速声音复刻的同名参数在复刻页开放开关前应明确标为“待接入”。
- 模型专属工作台：Grok 图片显示 1K/2K、官方画幅和生成张数；Grok 视频显示 1-15 秒、支持画幅及 480p/720p，1.5 图生视频可选择 1080p；Agnes 只显示当前接入支持的参考素材与参数；Seedream 显示 1K/2K/4K、提示词优化和水印；Seedance 显示分辨率、比例、智能时长、声音和水印。切换模型后界面应立即更新，不保留不支持的控件。
- 模型专属画布节点：生成配置节点切换图片或视频模型后，参数摘要和弹层应与工作台一致；节点刷新后应保留模型、画幅、清晰度、时长、声音、水印及提示词优化设置，实际生成请求应使用这些节点覆盖值。
- 桌面启动屏与导航：暗色和浅色主题下，完整首屏应以 Zodiac 居中，React Bits ASCII 光标轨迹覆盖背景但不遮挡顶部设置、开始编排、新建及最近工作流；开启系统“减少动态效果”后不加载该动效。进入工作台后只显示一套左侧创作导航，工作流搜索、真实节点缩略图、导入和新建应可用，窄窗口不产生横向滚动。
- 桌面原生存储：从旧版本升级后，已有画布、配置、提示词缓存和媒体应自动出现在应用内；新增或修改画布、Zodiac 会话和媒体后，完全退出再打开应用应继续保留。删除过的数据不应被旧 WebView 数据重新带回。
- 桌面交互性能：连续拖动节点、缩放和平移画布、在长文本中输入、持续接收终端输出或 Zodiac 流式回复时，其他节点和历史消息不应跟随整页重绘；终端移出视野后会话应继续运行。
- 终端工作流数据传递：终端只应读取与自身直接相连节点的当前输出；上游文本重新生成后，重新打开终端应在 `$WG_INPUT_DIR/input.txt` 和 `$WG_INPUT_TEXT` 中得到最新正文。终端输出类型选择图片、视频或音频后，无论命令行工具返回文件名、相对路径，还是将文件保存到 `$WG_OUTPUT_DIR`，文件写入稳定后都应自动创建对应画布节点并与终端连线；重新打开现有终端时应恢复尚未导入的输出，已导入媒体不应重复创建。
- Zodiac：配置 OpenAI 兼容、火山方舟或 Gemini 文本模型后，右侧 Zodiac 应可流式显示回复；上传图片后应随当前轮请求传给模型；要求新增、连线或更新节点时，回复应生成一项可批准或拒绝的画布提案。批准后只应用该提案的操作，拒绝后画布不应变化；未配置文本模型时应只引导到模型设置，不再要求安装任何本地 Agent 或外部插件。
- Zodiac 工作流执行：普通要求应默认按步骤确认，只有明确要求“全自动”“直接跑完”或“无需确认”时才自动执行；提案应用失败后可重新尝试且不重复创建节点，运行中不能切换到新会话；完成后只显示一行摘要，可展开查看每一步。
- Zodiac 分层决策：当且仅当一个缺失选择会改变结果时，应显示单选、多选、短输入、画布资产选择或摘要确认中的一种原生卡片；当前选择完成后卡片收成一行，再进入下一步。资产卡只允许引用当前画布的真实产物，内部 `zodiac-ui` / `zodic-ops` 数据在流式回复、重启恢复和历史会话中都不应出现。
- 画布结果槽：图片、视频、音频和文本生成步骤均应连接一个同类型结果槽；重新生成应在同一槽追加版本，多候选可选择或单独删除，失败版本可删除且不隐藏上一次成功结果。逐步模式确认当前版本后才运行下游，自动模式必须等媒体和画布记录落盘后再继续。
- 画布分支与输入：A 同时连接 B、C 时应保持真实分支而非串成 A→B→C；下游的 `@` 候选只显示直接上游及其当前结果，工作流启动后切换历史版本不应改变本次运行已冻结的输入。
- 画布桌面媒体：生成或导入的图片、视频、音频在完全退出并重开桌面应用后仍可预览、下载和保存到我的资产，不应出现 `Load failed`；保存资产只有在原生存储写入并读回成功后提示完成，失败时不留下假记录。
- 画布渐进界面：生成节点默认只显示生成类型、输入与提示词、折叠的模型参数及“生成这一步”；打开输入时应直接看到可用上游素材，选入后再描述目标。结果槽只常驻当前情境的一个主操作，同时直接显示下载和存入资产，删除及后续方式留在更多菜单；窄节点和音频结果槽不应裁掉主要操作。

- 画布文本设置：文本节点和生成配置节点切换到文本模式后应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时默认 OpenAI Responses 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留；文本模型自定义调用脚本应能读取 `reasoningEffort`，OpenAI 模板应按自动或指定档位正确组装请求。
- 生图工作台参考图：将一张或多张图片拖入参考图区域后应直接上传并显示缩略图；拖入非图片文件应忽略，拖动过程中区域应显示高亮提示，放下文件不应导致浏览器打开或替换当前页面。
- 视频创作台参考资产：将图片、MP4/MOV 视频或 MP3/WAV 音频拖入任一参考资产区域后，应按文件类型自动上传到对应列表；当前拖入区域应显示高亮提示，原有数量、大小、时长和格式限制应继续生效。
- 画布组装提示词：输入或连接超长提示词后，浮层正文高度不应继续撑大，内容应可在正文区域内滚动查看和编辑，标题及关闭按钮保持可见。
- 画布节点提示词：图片等节点下方的提示词超过输入区域高度后，鼠标悬停在输入区域内滚动应查看提示词内容，不应缩放画布。
- 画布节点提示词回显：单图或多图生成完成后，切换选择生成结果的根节点及任一子节点，下方输入区域都应继续显示生成时的提示词；切换到其他节点再选回来后也不应清空。
- 画布生成配置：连接文本节点后连续点击生成（包含失败重试），组装提示词不应重复追加上游文本；在生图、文本、视频、音频之间切换时，实际请求应始终使用当前面板展示的对应类型模型。
- 画布左侧元素列表：点击元素整行应平滑定位并选中对应节点；有内容的图片元素应显示预览按钮，点击后打开大图弹窗且不触发画布定位。
- 配置与用户偏好：导出 JSON 后应包含渠道、默认模型、生成偏好、提示词来源和 WebDAV 配置，但不得包含 API Key 或 WebDAV 密码；在修改当前配置后重新导入该文件，应恢复非敏感设置，错误 JSON 文件应提示格式不正确。
- 偏好设置作用域：默认模型应作为下一次工作台创作和新建节点的初始值，但不得覆盖已有节点；画布生图张数只初始化新节点；Qwen、MiniMax 和通用音频模型应显示各自支持的音色、格式与语速范围，音频工作台首次打开时应读取当前默认方案。
- 提示词作用域：Zodiac 默认角色只应进入 Zodiac 文本请求；图片提示前缀只应进入图片生成与编辑请求；两者都不得进入视频、音频或既有工作流节点。旧版系统提示词升级后只迁移为图片提示前缀。
- 配置保存反馈：修改任一偏好后应立即持久化，底部显示“修改已自动保存在本机”，点击右上角关闭或底部关闭都不应回滚修改。
- 本机数据目录：桌面应用进入“配置与用户偏好 → 偏好设置”后，应显示应用数据根目录、配置与业务数据、图片、视频音频文件和临时写入五项实际路径；路径应与当前系统一致并用 `~` 隐去用户名，网页预览只提示由浏览器站点存储管理。
- 模型渠道协议：渠道编辑可选择「火山方舟」并自动填入方舟接口地址；任意名称的生图模型应按方舟 JSON 格式提交参考图，任意名称的视频模型应按方舟任务格式提交和查询，不再依赖模型名包含 `doubao`、`seedream` 或 `seedance`；1080p 不应再因模型名包含 `fast` 被禁用，参考视频应允许最大 200MB、总像素 409600-8295044，并继续校验官方宽高、比例和时长限制。
- 图片编辑弹窗：遮罩、切图和裁剪连续滚轮缩放时，图片与遮罩应保持同步且不再闪烁、短暂消失或跳动；遮罩画笔圆心应始终固定在鼠标位置，仅直径随缩放变化，缩放后仍可准确涂抹、拖动切分线和调整裁剪框。
- 提示词中心布局：页面标题及提示词总数应居中；连续输入搜索文字时应在停止输入约 300ms 后再查询；桌面端分类与标签应在左侧独立滚动，右侧搜索框下直接展示提示词卡片；标签数量较多时不能继续向下挤压提示词，窄屏下应恢复上下排列且内容不溢出；不再显示「我的提示词」Tab，收藏提示词应直接加入我的资产。
- 提示词详情弹窗：封面和参考图应固定显示在上方，复制及加入资产操作栏固定在底部，只有中间的标签、描述及提示词内容区域可以滚动；弹窗宽高应受视口限制且不超出屏幕。
- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 画布提示词库：不应再显示「我的提示词」分组；不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示向下箭头且新消息不强制打断阅读，点击箭头后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧以主题浅底气泡显示，AI 回复应在左侧保留 Agent 图标并使用开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。

# 音频工作台

- 首次安装或清空配置后，设置「渠道」应固定显示“免费”和“语音模型”两个预设，二者均不包含 API Key；“语音模型”默认地址应为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，界面标明华北 2（北京）。编辑预设后点击重置，应恢复默认模型、地址并清空 Key；首个自定义渠道应命名为“渠道 1”。
- 音频工作台应与图片、视频工作台保持同一三栏宽度、结果区域、创作输入区、记录卡和参数栏样式；语音生成、声音克隆、语音转录使用与 SD2.5 一致的创作区顶部模式栏，窄窗口下不应遮挡输入或主按钮。
- 使用北京地域的百炼 API Key，分别验证 `qwen-audio-3.0-tts-flash`、`qwen3-tts-vc-2026-01-22` 与 `qwen3-asr-flash` 的真实账户权限和计费开通状态。
- 声音克隆使用 10–20 秒清晰单人样本，确认返回的 voice ID 能直接带入同一 Qwen3 TTS 模型生成语音。
